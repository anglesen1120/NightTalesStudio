## Independent QA contrast and semantics decisions (D1, D2, D8)

- **D2 — dark error/warn chips:** reduced only the dark `error-soft` playhead tint from 15% to 9%. The error text/background pair moves from `#ff786c` / `#4a3c37` = **4.09:1** to the same approved `#ff786c` playhead over its 9%-tinted sheet = **4.52:1**; the unchanged light 9% pair is **5.08:1**. Nine percent is the nearest whole-percentage tint below the 9.35% threshold, preserving the deck's playhead-on-sheet recipe and hue rather than introducing a new colour.
- **D8 — control outlines:** `--nts-color-outline` remains the deck hairline for decorative structure. The retry button in `ErrorState` and the close/cancel/ordinary action buttons in `ConfirmDialog` use the new `--nts-color-control-outline`, because their transparent outlined shape is the sole persistent visual affordance. The token is derived only from the deck line and ink hues (dark `#727e78`, a 20% ink blend; light `#7f8a85`, a 35% ink blend). Its ratios are **3.68:1 dark / 3.16:1 light** against the page background in `ErrorState`, and **3.15:1 dark / 3.57:1 light** against the dialog surface. The destructive confirm keeps the playhead border (**5.17:1 dark / 5.80:1 light** against the dialog surface). The dialog shell keeps the decorative deck outline; it does not identify or delimit an interactive control, so WCAG 1.4.11's 3:1 control-affordance requirement does not apply there.
- **D1 — page-header actions:** kept the translated accessible name and added `role="group"`. The slot is a coherent set of page-level actions, so the group role gives its existing label valid semantics and a useful navigation announcement instead of discarding localized context.
