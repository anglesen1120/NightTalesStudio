# 01.1.1-T1 — Install tools + version manifest

| Story | Size | Area | Depends on | Blocks | Gate |
|---|---|---|---|---|---|
| 01.1.1 | XS (0.25 d) | Ops | — | 01.1.1-T2, 01.1.2-T1…T4, 01.3.1 (`start_run.sh` embeds the manifest) | 01-ready |

## Goal
`git`, `uv`, `ffmpeg` (with `libmp3lame` + `aac`) and `gitleaks` are on PATH. `worker-node/bin/env-versions.sh` prints one valid JSON object describing the machine and tool versions, so every `run.json` records them instead of repeating them in each sheet row (F20).

## Inputs
- ✅ E2: Homebrew 7.0.6, git 2.49.0 and ffmpeg 9.0.2 (`libmp3lame`, `aac`) are installed; `uv` and `gitleaks` are missing.
- ✅ E1: macOS 27.0, 16 GB.
- F18: no system `python` is required. uv installs per-project interpreters (✅ M7 3.11, ✅ V3/V4 3.12).
- D1 (`$NTS_HOME`, default `$HOME/.nts`), D9 (script conventions).
- Consumer contract: `trial/tools/start_run.sh` (01.3.1) stores the stdout as `run.json` key `env`. The key list below was agreed with MeasurementPlan.

## Steps
0. **Implementation machine + trusted execution location (DEC-2, D13, F26, SEC-01) — decide on the target machine, before any secret exists.**
   > **Implementation note (owner, 2026-09-24):** plan 01 will be implemented on **another machine**, not the planning Mac. E1/E2 and every machine-specific value in these plans (`/Volumes/Project`, USB/unencrypted, free disk, installed Homebrew/git/ffmpeg versions, free ports) describe the planning Mac only. On the target machine: re-capture E1/E2 (`sw_vers`, `sysctl -n hw.memsize`, `fdesetup status`, `diskutil info <volume of the repo>`, tool versions, `lsof -nP -iTCP -sTCP:LISTEN`) into `worker-node/README.md` § Machine, then pick the D13 mode below. If the target is not Apple Silicon macOS, stop and re-plan (VieNeu ONNX-CPU and faster-whisper CPU paths, Keychain and `diskutil` all assume macOS).
   - **Mode `internal` (preferred):** the repo lives on the internal, FileVault-encrypted disk with ownership enforced → D13 is satisfied with no extra step. Verify `fdesetup status` → `FileVault is On` and `diskutil info "$(df -P . | awk 'NR==2{print $1}')"` shows it is internal ⚠️ labels.
   The steps below apply only if the repo sits on an external volume (as on the planning Mac: E1, USB, Owners disabled, not encrypted).
   - **Preferred (owner, admin, one time):** back up the volume first. Then encrypt it (Finder → right-click the volume → Encrypt ⚠️ label on macOS 27) and enable ownership: `sudo diskutil enableOwnership /Volumes/Project` ⚠️ (the only `sudo` in plan 01; the owner runs it, not a script). Verify: `diskutil info /Volumes/Project | grep -E 'Owners:|Encrypted:|FileVault:'` → `Owners: Enabled` and `Encrypted: Yes` (or `FileVault: Yes`) ⚠️ exact labels. Then prove modes are now enforced: `f=/Volumes/Project/.nts-mode-test; : > "$f"; chmod 600 "$f"; stat -f %Lp "$f"; rm "$f"` → `600` (⚠️ supporting evidence only: the `diskutil` line is the proof, because a volume that ignores ownership may still report the mode it was given).
   - **Fallback (owner declines):** record `D13 mode: export` in `worker-node/README.md`. `bootstrap.sh --export` (01.1.2-T3) then copies the committed tree to `$NTS_HOME/exec/<sha>/`, and every secret-reading script is started only from there. `lib.sh` `secret` refuses otherwise (01.1.2-T2 `_nts_trusted_location`). **Order in this mode** (the repo has no commits yet, E2, and `git archive HEAD` needs one): 01.1.2-T1 layout → 01.1.2-T4 hooks → first commit → `bootstrap.sh --export` → only then `secrets.sh init-local` / 01.2.4-T2. Every later change to a secret-reading script needs a commit + re-export before it runs.
   - Record the mode (`internal`, `volume` or `export`) and the evidence lines (`fdesetup status`, `diskutil info` of the repo volume) in `worker-node/README.md` § "Trusted execution location".
1. Install the missing tools (user-level, no sudo):
   ```sh
   brew install uv gitleaks
   ```
2. Check the gitleaks licence (⚠️ U1, expected MIT):
   ```sh
   brew info --json=v2 gitleaks | uv run --no-project --python 3.12 python -c 'import json,sys; print(json.load(sys.stdin)["formulae"][0]["license"])'
   ```
   The expected output is `MIT`. Also open `https://github.com/gitleaks/gitleaks/blob/master/LICENSE` and confirm the text. Record the result (tool, licence, URL, date) in `worker-node/README.md` § "Tool licences".
   If step 1 has not run yet, `uv` is not available; in that case read the `License:` line of `brew info gitleaks` instead.
3. Verify the tools and encoders:
   ```sh
   for t in git uv ffmpeg gitleaks; do command -v "$t" || echo "MISSING $t"; done
   ffmpeg -hide_banner -encoders | grep -E 'libmp3lame|aac '
   ```
   The encoder grep MUST print 2 lines: one containing `libmp3lame` and one containing `aac ` (native AAC). The trailing space in the pattern keeps it from matching `aac_at` alone.
4. Specify and write `worker-node/bin/env-versions.sh`. The rules:
   - `#!/usr/bin/env bash`, `set -euo pipefail`, `--help`.
   - Sources `lib.sh` only for `nts_home`. If `lib.sh` is absent (this task runs before 01.1.2-T2), it falls back to `NTS_HOME="${NTS_HOME:-$HOME/.nts}"`. Once T2 has landed, the fallback is removed.
   - Builds the JSON with `uv run --no-project --python 3.12 python -c '…'` (stdlib `json`, D9), because jq is not assumed. Shell values are passed to Python as **environment variables**, never interpolated into the code string. This avoids quoting and injection problems.
   - One object on stdout, UTF-8, newline-terminated. Diagnostics go to stderr only.
   - Missing optional values become `"n/a:<reason>"`. Exit 2 only if `git`, `uv` or `ffmpeg` is missing (D9 environment error). Otherwise exit 0.
   - It never prints paths, `$USER`, the hostname, the serial number, or any Keychain value.

   | Key | Type | Command (inside the script) | `n/a` reason |
   |---|---|---|---|
   | `schema_version` | int | constant `1` | — |
   | `captured_at` | str | `date -u +%Y-%m-%dT%H:%M:%SZ` | — |
   | `macos_version` | str | `sw_vers -productVersion` | — |
   | `macos_build` | str | `sw_vers -buildVersion` | — |
   | `hw_model` | str | `sysctl -n hw.model` | — |
   | `cpu_brand` | str | `sysctl -n machdep.cpu.brand_string` | — |
   | `memory_bytes` | int | `sysctl -n hw.memsize` | — |
   | `git` | str | `git --version` → 3rd field | — (required) |
   | `uv` | str | `uv --version` → 2nd field | — (required) |
   | `ffmpeg` | str | `ffmpeg -version` line 1 → 3rd field | — (required) |
   | `gitleaks` | str | `gitleaks version` → strip leading `v` | `n/a:not-installed` |
   | `ffmpeg_encoders` | list[str] | `ffmpeg -hide_banner -encoders`, 2nd column ∈ {`libmp3lame`,`aac`}, sorted | `[]` |
   | `uv_pythons` | list[str] | `uv python list --only-installed` → version tokens `3\.[0-9]+\.[0-9]+`, unique, sorted (⚠️ U5 output format) | `[]` |
   | `mpt_commit` | str | `git -C "$NTS_HOME/src/mpt" rev-parse HEAD` | `n/a:not-cloned` |
   | `vieneu_commit` | str | `git -C "$NTS_HOME/src/vieneu" rev-parse HEAD` | `n/a:not-cloned` |
   | `nts_home_on_internal_disk` | bool | `diskutil info <device of $NTS_HOME>` shows internal + FileVault (⚠️ label text) | `false` |

   The pinned SHAs themselves are not in the manifest; `start_run.sh` reads `pins.env`. Comparing `mpt_commit` with `MPT_COMMIT` is the collector's job (01.3.1).
5. Run it and validate it (no jq):
   ```sh
   worker-node/bin/env-versions.sh | uv run --no-project --python 3.12 python -m json.tool
   ```
   Note: this call also makes uv install Python 3.12 on first use (download ≈ tens of MB). That is expected, and the same interpreter is used by all D9 helpers.
6. Add a section "Tools" to `worker-node/README.md`: the install command, the licence line, and how to run the manifest. The skeleton comes from 01.1.2-T1; if it does not exist yet, create the section and 01.1.2-T1 keeps it.

## Failure handling
| Failure | Action |
|---|---|
| `brew install` fails (network, formula) | Retry once. Check `brew doctor`. Do not install from other taps without TL approval |
| `diskutil enableOwnership` or encryption fails or is refused | Use the D13 export fallback; never create secrets while neither mode holds |
| gitleaks licence is not MIT / not OSI-approved | Stop 01.1.2-T4. Record it and escalate to the TL (the alternative is a different scanner, which would be a new decision) |
| ffmpeg lacks `libmp3lame` or `aac` | `brew reinstall ffmpeg`. If it is still missing, stop: the proxy's MP3 path (plan 04) depends on it |
| `uv python list` output format differs (U5) | Adjust the regex in the script. The field stays a list of versions |
| `diskutil` labels differ (macOS 27) | Take the exact labels from `diskutil info /` on this Mac and update the script. Report `false` rather than guessing |
| Rollback | `brew uninstall uv gitleaks`, delete the script |

## Notes
- ⚠️ U1 gitleaks licence; ⚠️ U5 uv output format; ⚠️ `diskutil` label text on macOS 27.
- `hw_model` example values are not verified; the script records whatever `sysctl` returns.
- The manifest deliberately repeats nothing that is in `pins.env`, so it cannot drift from it.
- JSON validation uses `uv run --no-project --python 3.12 python -m json.tool` (D9 helper interpreter). `python3 -m json.tool` is equivalent where `/usr/bin/python3` exists, but F18 means it is not assumed.
