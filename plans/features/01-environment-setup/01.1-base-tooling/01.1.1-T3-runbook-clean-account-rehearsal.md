# 01.1.1-T3 — Runbook + timed clean-account rehearsal

| Story | Size | Area | Depends on | Blocks | Gate |
|---|---|---|---|---|---|
| 01.1.1 | S (0.5 d) | Ops | all 01.1.x, 01.2.x and 01.3.x tasks (runbook sections exist); 05.5.2-T1 (trial done, so the runbook reflects what actually worked) (05 CR-13) | — | **01-closed** (NFR-01-2) |

## Goal
`worker-node/README.md` is a complete runbook. A rehearsal that follows it verbatim in a **new standard macOS user account** reaches `smoke.sh` green in **≤ 120 min of hands-on wall time, excluding model downloads** (NFR-01-2). The timings are recorded.

  | Section | From |
  |---|---|
  | Layout, Tools, Tool licences, Pins, Secrets, Bootstrap, Secret scanning | 01.1.1-T1/T2, 01.1.2-T1…T4 |
  | VieNeu install/start/smoke, weight fetch (`worker-node/bin/fetch-vieneu-weights.sh`) | 01.2.1 |
  | MPT config render, strip, start API (no WebUI, D14), smoke, wiring render | 01.2.2 |

  | Proxy | 04 |
- D1–D12, gate text README §7, ✅ E2 (Homebrew exists machine-wide).

## Steps
1. **Finalise the runbook** `worker-node/README.md` in this order (each step = a copy-pasteable command block + its expected output):
   0. Prerequisites: macOS version, Homebrew present, internal disk free ≥ 20 GB [INFERENCE: clones + venvs + weights], OpenAI keys available to the owner (01.2.4).
   1. Tools: `brew install uv gitleaks` (admin account), `env-versions.sh`.
   2. Get the repo (clone or copy; see step 3 below) and `git config core.hooksPath .githooks`.
   3. `$NTS_HOME`: `source worker-node/bin/lib.sh && nts_home` (creates, 700, TM exclusion).
   4. Secrets: `worker-node/bin/secrets.sh init-local`, `secrets.sh set nts.openai.story`, `secrets.sh set nts.openai.image`, `secrets.sh check` → exit 0. In the rehearsal these are the **rehearsal keys** (step 2), never the owner's trial keys.
   5. `worker-node/bin/bootstrap.sh all`.
   6. Weights: `worker-node/bin/fetch-vieneu-weights.sh`, `worker-node/bin/fetch-whisper-model.sh` (+ `--verify`). **Timed separately, excluded.**
   7. Start services, one terminal each (D9): VieNeu, proxy, usage tap, MPT API (commands from 01.2.x/04/01.3.1).
   8. `worker-node/bin/smoke.sh` → green; `worker-node/bin/check-binds.sh` → exit 0.
   9. Optional in the rehearsal: the wiring render (01.2.2-T6), not timed against NFR-01-2.
   10. Sections Troubleshooting, OpenAI key leak / rotation, Undo (plan.md §11 table).
2. **Prepare the rehearsal account** (owner, admin account):
   - System Settings → Users & Groups → Add User → **Standard**, name `ntsrehearsal` (⚠️ label text on macOS 27).
   - The tools are machine-wide already (Homebrew under the admin account, E2). The rehearsal therefore times everything **except** `brew install`. If the owner wants `brew install` timed too, run 01.1.1-T1 step 1 in the admin account first and add its measured time to the sheet (column `admin_prereq_min`).
   - **Rehearsal OpenAI keys (SEC-11) [DECISION, default].** The owner creates two separate keys with the 01.2.4-T2 flow, named `nts-trial-story-rehearsal-<YYYYMM>` and `nts-trial-image-rehearsal-<YYYYMM>` (same projects, same Restricted scope, same hard limits). They are typed at the `secrets.sh set` prompt **in the rehearsal account by the owner**, never sent by chat, screen-share, clipboard sync or file. They are revoked at teardown (step 8). The owner's trial keys never enter the rehearsal account.
3. **Getting the repo into the account (D13, SEC-01).** The rehearsal never runs code from `/Volumes/Project`, and the rehearsal account is created only **after** D13 holds (01.1.1-T1 step 0), so it cannot plant scripts in the owner's working tree. Preferred: clone from the remote, if the repo has one by then. Otherwise the owner writes a bundle from committed history only: `git -C /Volumes/Project/NightTalesStudio bundle create /Users/Shared/nts-rehearsal.bundle --all`, and the rehearsal user runs `git clone /Users/Shared/nts-rehearsal.bundle "$HOME/nts-repo"`, then the owner deletes the bundle after the clone. A clone carries only committed files, so the rehearsal proves that tracked files alone suffice. `$NTS_HOME` stays the D1 default `$HOME/.nts` of the rehearsal user (internal disk). In D13 mode `export`, the rehearsal also runs `bootstrap.sh --export` in its own clone.
4. **Run the rehearsal** (log in as `ntsrehearsal`, Terminal only, runbook open in a browser/editor as the only guide):
   - Start a stopwatch at runbook step 1 (after login). For each runbook step record start/end (`date -u +%H:%M:%S`).
   - Only **model weight downloads** (runbook step 6) are marked `excluded: true`, per NFR-01-2 "excluding model downloads". [DECISION] `uv python install` / `uv sync` package downloads count as included time, because they are part of the install; they are timed in their own step row (`excluded: false`).
   - Any deviation from the runbook (a missing step, a wrong command, an unclear output) is written down immediately, with the step number. The rehearser may fix it only by editing the runbook afterwards, not by improvising silently (improvisation is logged as `deviation`).
5. **Timing sheet** `trial/baselines/rehearsal-mac-<YYYYMMDD>.json` (tracked; D1 baseline pattern):
   ```json
   {
     "schema_version": 1,
     "date": "2026-10-XX",
     "account": "standard, fresh",
     "repo_commit": "<git rev-parse HEAD of the clone>",
     "env": { "...": "output of worker-node/bin/env-versions.sh" },
     "steps": [
       {"n": 1, "name": "tools check", "start": "HH:MM:SS", "end": "HH:MM:SS", "minutes": 0.0, "excluded": false, "deviation": ""},
       {"n": 6, "name": "weights", "start": "…", "end": "…", "minutes": 0.0, "excluded": true, "deviation": ""}
     ],
     "total_minutes": 0.0,
     "excluded_minutes": 0.0,
     "counted_minutes": 0.0,
     "admin_prereq_min": "n/a:not-timed",
     "result": "pass|fail",
     "deviations": 0,
     "nts_home_gb": 0.0
   }
   ```
   `counted_minutes = total_minutes − excluded_minutes`. It contains no secrets (keys are typed at prompts only) and no user paths.
6. **Pass criteria** (all must hold):
   - `counted_minutes ≤ 120`.
   - Runbook step 8 is green: `smoke.sh` exit 0 (health, 401s, binds D4) and `check-binds.sh` exit 0.
   - `secrets.sh check` exit 0; `git config --get core.hooksPath` = `.githooks`; `env-versions.sh` `mpt_commit`/`vieneu_commit` equal `pins.env`.
   - `deviations == 0` **or** every deviation was fixed in the runbook and a second rehearsal of the affected steps passed (the full clock is not re-run for a pure text fix; for a missing step, re-run from that step with a new account).
   - Fail → fix the runbook, delete the account (step 8), repeat. Each attempt gets its own JSON file (suffix `-2`, `-3`).
7. **Commit** the runbook fixes and the timing JSON (through the gitleaks hook).
8. **Tear down the rehearsal account**:
   - Stop its services.
   - `worker-node/bin/secrets.sh` items in that user's login keychain go with the account.
   - System Settings → Users & Groups → delete `ntsrehearsal` → "Delete the home folder" (⚠️ label).
   - Owner: revoke `nts-trial-story-rehearsal-<YYYYMM>` and `nts-trial-image-rehearsal-<YYYYMM>` in the dashboard (01.2.4-T3 §D step 1) **before** deleting the account; delete `/Users/Shared/nts-rehearsal.bundle` if it still exists. Confirm with the dashboard key list that only the owner's trial keys remain active.

## Outputs
- Tracked: `worker-node/README.md` (complete runbook), `trial/baselines/rehearsal-mac-<YYYYMMDD>.json` (one per attempt).
- Gate 01-closed item "clean-account rehearsal ≤ 2 h excluding model downloads" is marked done in the gate checklist with a link to the JSON.

## Acceptance checks
- [ ] `grep -c '^## ' worker-node/README.md` ≥ 12 and it includes `Secret scanning`, `Bootstrap`, `OpenAI key leak / rotation`, `Undo`
- [ ] The runbook contains no secret-like values: `gitleaks dir worker-node --redact --no-banner; echo $?` → `0` (⚠️ U2 syntax)
- [ ] Timing JSON is valid: `uv run --no-project --python 3.12 python -m json.tool trial/baselines/rehearsal-mac-<YYYYMMDD>.json >/dev/null; echo $?` → `0`
- [ ] Keychain reads are non-interactive (README F25): after logging out and back in as `ntsrehearsal`, run `worker-node/bin/start-vieneu.sh --check` from a fresh Terminal. It must complete with no "allow access" dialog; if a dialog appears, count it as a deviation and fix the `-T /usr/bin/security` ACL in 01.1.2-T2
- [ ] `uv run --no-project --python 3.12 python -c 'import json,sys; d=json.load(open(sys.argv[1])); print(d["result"], d["counted_minutes"] <= 120)' trial/baselines/rehearsal-mac-<YYYYMMDD>.json` → `pass True`
- [ ] In the rehearsal account: `worker-node/bin/smoke.sh; echo $?` → `0` was observed and noted in the JSON step 8
- [ ] `dscl . -list /Users | grep -c '^ntsrehearsal$'` → `0` after teardown

## Failure handling
| Failure | Action |
|---|---|
| Over 120 min | Find the slowest counted steps in the JSON; script them (for example fold manual checks into `smoke.sh`) or remove steps. Re-run. If still over, escalate to the TL with the numbers (NFR-01-2 may need a change in 01) |
| Standard account cannot use a tool (U9) | Record it; move the step to "admin prerequisites" in the runbook; re-run |
| Keychain prompt blocks a script in the new account | Record the exact prompt text; add it to the runbook (expected on first use) |
| A download that should be excluded is mixed into a counted step | Split the step in the runbook so downloads are their own step; re-time |
| Services from the owner account are still running (ports busy, D4 exit 2) | Stop them in the owner account before the rehearsal; note it in the runbook prerequisites |
| Rollback | Delete the rehearsal account (step 8); the runbook changes stay (they are improvements) |
