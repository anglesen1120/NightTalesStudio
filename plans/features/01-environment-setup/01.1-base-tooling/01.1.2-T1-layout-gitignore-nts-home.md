5. **`$NTS_HOME`** (internal disk; D1 default `$HOME/.nts`):
   ```sh
   NTS_HOME="${NTS_HOME:-$HOME/.nts}"
   case "$NTS_HOME" in /Volumes/*|"$PWD"/*) echo "NTS_HOME must be on the internal disk, outside the repo" >&2; exit 2;; esac
   mkdir -p "$NTS_HOME"/{src,hf,logs,runs}
   chmod 700 "$NTS_HOME"
   tmutil addexclusion "$NTS_HOME"
   ```
   - `src/mpt`, `src/vieneu` are created by `bootstrap.sh` (01.1.2-T3) and `src/proxy-venv` by plan 04; they are not pre-created (an empty dir would confuse bootstrap's "absent → clone" test).
   - `current_run` is created by `start_run.sh` (01.3.1).
   - `tmutil addexclusion` without `-p` is a sticky, user-level exclusion (⚠️ U7: confirm no sudo prompt).
   - The same guard and `mkdir`/`chmod` logic become `nts_home` in `lib.sh` (01.1.2-T2). This step is the manual first run.
6. Record in `worker-node/README.md` § Layout **why** the runtime is on the internal disk: E1 (USB volume unencrypted, ownership disabled, so `chmod 600` is meaningless there) + M8 (MPT writes secrets into `config.toml` in its root and replaces symlinks).

## Failure handling
| Failure | Action |
|---|---|
| `tmutil addexclusion` asks for admin / fails (U7) | Do not use `-p` or sudo (D9). Record the failure; set the exclusion manually in System Settings → General → Time Machine → Options → Exclude (⚠️ label); verify with `tmutil isexcluded` |
| `$HOME` itself is on an external volume (unusual) | Stop. Set `NTS_HOME` to a path on the internal disk and record it in the runbook |
| A negation does not work (`LICENSES.csv` ignored) | Check the rule order with `git check-ignore -v`; `worker-node/music/*` must be a child pattern, never `worker-node/music/` |
| Rollback | Delete the appended `# --- 01.1.2-T1` block from `.gitignore` (no commit exists yet, so `git checkout` cannot restore it); `tmutil removeexclusion "$HOME/.nts" && rm -rf -- "$HOME/.nts"`; delete the placeholder files |
