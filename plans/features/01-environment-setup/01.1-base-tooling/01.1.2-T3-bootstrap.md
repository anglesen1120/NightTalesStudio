# 01.1.2-T3 — `worker-node/bin/bootstrap.sh`

| Story | Size | Area | Depends on | Blocks | Gate |
|---|---|---|---|---|---|
| 01.1.2 | S (0.5 d) | Ops | 01.1.1-T2 (`pins.env`), 01.1.2-T2 (`lib.sh`) | 01.2.1-T1, 01.2.2-T1 (they call it; they do not re-implement clone/sync), 01.1.1-T3, 04.1.5-T1 (fills the `proxy` target, 04 CR-16) | 01-ready |

## Goal
One idempotent command puts MPT and VieNeu at exactly the pinned commits in `$NTS_HOME/src/{mpt,vieneu}` with their uv environments synced from the upstream locks. For MPT it re-applies the bundled-music strip after every checkout. The script refuses to report success unless `git rev-parse HEAD` equals the pin.

## Inputs
- `worker-node/pins.env` (D2): `MPT_REPO`, `MPT_COMMIT`, `MPT_PYTHON`, `VIENEU_REPO`, `VIENEU_COMMIT`, `VIENEU_PYTHON`, `PROXY_PYTHON` (proxy target, 04 CR-4).
- `lib.sh`: `nts_home`, `load_pins`, `log`, `die`.
- ✅ M7: MPT `uv python install 3.11 && uv sync --frozen`.
- ✅ V3: VieNeu Mac install is plain `uv sync` (ONNX, CPU, no extras).
- ⚠️ U3: whether VieNeu tracks `uv.lock` at the pin (recorded by 01.1.1-T2).
- ✅ M6: MPT bundled music is in `resource/songs`. `worker-node/bin/strip-bundled-music.sh` is owned by 01.2.2-T3. Bootstrap expects it to be idempotent with exit 0 ok · 1 audio remains · 2 environment error, and to take the MPT clone path from `nts_home` (contract broadcast to MptPlan).
- ✅ M8: MPT creates `config.toml` in its root; the renderer (01.2.2-T2) owns it. Bootstrap never touches it.
- D9 exit codes, no sudo.

## Steps
1. **CLI**: `worker-node/bin/bootstrap.sh [--help] [mpt|vieneu|proxy|all]`, default `all`; `all` = `mpt`, `vieneu`, `proxy` (04 CR-4). It sources `lib.sh`, runs `set -euo pipefail`, calls `nts_home` and `load_pins`, and checks that `git` and `uv` are present (else exit 2). Output goes to stderr via `log`; a summary line per project goes to stdout: `<project> <sha> python=<x.y> sync=<frozen|unlocked> strip=<ok|skipped|n/a>`.
2. **Per project** `p ∈ {mpt, vieneu}`, with `dir="$NTS_HOME/src/$p"`, `repo`/`pin`/`py` from the pins:
   1. **Clone if absent**: if `$dir/.git` does not exist:
      - If `$dir` exists and is non-empty → `die 2 "$dir exists but is not a git clone"`. Never delete it.
      - Else run `git clone --no-checkout --filter=blob:none "$repo" "$dir"`. The partial clone saves disk and time; ⚠️ confirm GitHub serves the filter, else drop `--filter`.
   2. **Remote sanity**: `git -C "$dir" remote get-url origin` must equal `$repo`, else `die 2` (protects against a stale clone from another fork).
   3. **Fetch the pin only if it is missing**: `git -C "$dir" cat-file -e "$pin^{commit}" 2>/dev/null` or `git -C "$dir" fetch --quiet origin` (then `git -C "$dir" fetch --quiet origin "$pin"` if still missing; GitHub allows fetching reachable SHAs). Still missing → `die 2 "pin $pin not found in $repo"`.
   4. **Tracked-tree cleanliness before checkout**: `git -C "$dir" status --porcelain --untracked-files=no`. For MPT the only allowed changes are **deletions under `resource/songs/`** (left by the previous strip). They are undone explicitly with `git -C "$dir" restore --worktree -- resource/songs` (git ≥ 2.23 ✅ E2 2.49), so the checkout starts from a clean tracked tree and sub-step 8 strips again. Any other modification → `die 1 "local changes in $dir: <paths>"`. No `--force`, no `reset --hard`, no `clean`: untracked files (`config.toml`, `.venv/`, `models/`, `storage/`) must survive (⚠️ U8: MPT's own `.gitignore` ignores them).
   5. **Checkout**: `git -C "$dir" checkout --quiet --detach "$pin"`. Because the tracked tree is clean, this never conflicts, and it keeps untracked and ignored files.
   6. **Verify the pin**: `[ "$(git -C "$dir" rev-parse HEAD)" = "$pin" ] || die 1 "HEAD != pin"`.
   7. **Python + sync** (in `$dir`):
      ```sh
      uv python install "$py"
      uv sync --frozen --python "$py"      # MPT always; VieNeu when uv.lock is tracked at the pin
      ```
      Sync mode:

      | Project | Condition | Command | `sync=` |
      |---|---|---|---|
      | MPT | `uv.lock` tracked (✅ M7 implies it) | `uv sync --frozen --python "$MPT_PYTHON"` | `frozen` |
      | VieNeu | `git -C "$dir" ls-files --error-unmatch uv.lock` succeeds | `uv sync --frozen --python "$VIENEU_PYTHON"` (no extras, no groups: V3 torch-free ONNX path) | `frozen` |
      | VieNeu | no tracked `uv.lock` (U3) | `uv sync --python "$VIENEU_PYTHON"` (plain, V3) + `log` WARN + print `shasum -a 256 uv.lock` so 01.3.3 can record it | `unlocked` |

      ⚠️ Check that `--frozen` works with VieNeu's lock (its `pyproject` declares a required darwin-arm64 uv environment). If `--frozen` fails with a resolution error while a lock is tracked, stop (exit 1) and report it. Never fall back silently to an unfrozen sync.
      Then check the interpreter: `uv run --python "$py" python -c 'import sys; print("%d.%d" % sys.version_info[:2])'` must equal `$py`, else exit 1.
   8. **MPT only: re-apply the music strip.** If `worker-node/bin/strip-bundled-music.sh` exists and is executable, run it. Exit ≠ 0 → bootstrap exits with the same code (`strip=` failed). If the script does not exist yet (01.2.2-T3 not landed), `log` a WARN and print `strip=skipped`: bootstrap still exits 0, but 01.2.2-T3's acceptance and `smoke.sh` require `strip=ok`. VieNeu: `strip=n/a`.
2a. **`proxy` target (04 CR-4)** — no clone (the source is `worker-node/proxy/` in this repo): `UV_PROJECT_ENVIRONMENT="$NTS_HOME/src/proxy-venv" uv sync --frozen --project worker-node/proxy --python "$PROXY_PYTHON"`, so no `.venv` is created inside the repo (D1). The case body and its `all` membership are implemented by 04.1.5-T1, which also adds `PROXY_PYTHON` to `pins.env`; this task only reserves the target name (04 CR-4).
3. **Idempotency**: a second run with the same pins does no clone, no fetch (pin present), no checkout change, and a no-op `uv sync`, re-strips (no-op), and exits 0. Changing a pin in `pins.env` and re-running moves the clone to the new SHA and re-syncs.
3a. **`--export` (D13 fallback, SEC-01).** `bootstrap.sh --export` runs only in D13 mode `export` (01.1.1-T1). It refuses (exit 1) unless the repo tree is clean for the executed paths: `git -C "$REPO" status --porcelain -- worker-node trial/tools .githooks` → empty. Then:
   ```sh
   sha="$(git -C "$REPO" rev-parse HEAD)"; dst="$NTS_HOME/exec/$sha"
   [ -d "$dst" ] || { mkdir -p "$dst.tmp" && git -C "$REPO" archive "$sha" worker-node trial/tools .githooks | tar -x -C "$dst.tmp" && mv "$dst.tmp" "$dst"; }
   chmod -R go-rwx "$dst"; printf '%s\n' "$sha" > "$dst/.nts-exec-sha"
   ```
   The export contains committed code only: `git archive` never includes uncommitted or planted files. Old exports stay (one per commit, small) until `rm -rf "$NTS_HOME/exec/<old sha>"`. The runbook then starts every secret-reading script as `"$NTS_HOME/exec/$(git rev-parse HEAD)/worker-node/bin/<script>"`; `lib.sh`'s `_nts_trusted_location` (01.1.2-T2) accepts only this location in mode `export`.
4. **Explicitly not done** (other owners): weight downloads (01.2.1-T1 `worker-node/bin/fetch-vieneu-weights.sh`, 01.2.3-T1 `worker-node/bin/fetch-whisper-model.sh`), `config.toml` rendering (01.2.2-T2), starting services (01.2.x), the proxy code and lock (`worker-node/proxy/`, 04.1.5-T1; its venv is the `proxy` target above, 04 CR-4).
5. **Runbook** section `## Bootstrap` in `worker-node/README.md`: the command, the summary line format, what each exit code means, and "never edit files in `$NTS_HOME/src/*` by hand; upstream changes = new pin".
6. `shellcheck worker-node/bin/bootstrap.sh` at implementation time (D9).

**Exit codes (D9)**

| Code | Meaning |
|---|---|
| 0 | Both (or the selected) projects at pin, synced, strip ok or skipped with a warning |
| 1 | Check failed: HEAD ≠ pin, local tracked changes, Python version mismatch, `--frozen` failure, strip left audio |
| 2 | Usage/environment: bad argument, missing git/uv, invalid pins (`load_pins`), non-clone directory in the way, wrong remote, network/fetch failure, pin not found |

## Failure handling
| Failure | Action |
|---|---|
| Network/GitHub down | Exit 2; rerun later (idempotent). No partial state beyond an incomplete clone: if `git clone` failed, remove `$NTS_HOME/src/<p>` only if it contains nothing but `.git` (the script logs the exact path; the operator deletes it) |
| `--filter=blob:none` unsupported | Remove the flag (full clone; MPT ships audio and fonts, so the clone is larger) |
| `uv sync --frozen` fails for VieNeu with a lock present | Stop; record the uv error in the runbook; escalate to the TL. Options: pin a VieNeu SHA whose lock matches, or accept plain `uv sync` with a hashed lock (a reproducibility ⚠️ in CARRY-OVER) |
| Python mismatch after sync | Check `.python-version` at the pin versus `pins.env` (01.1.1-T2) |
| Strip script exits 1 | Audio re-appeared: run `strip-bundled-music.sh` manually and see the 01.2.2-T3 failure handling. Do not start MPT |
| Rollback | `rm -rf -- "$HOME/.nts/src/mpt" "$HOME/.nts/src/vieneu"` (rebuilt from pins); a pin rollback is `git revert` of the `pins.env` commit, then re-run |

## Notes
- ⚠️ U3 (VieNeu lock), ⚠️ whether `--frozen` works with VieNeu's required-environments lock, ⚠️ U8 (MPT `.gitignore` covers `config.toml`, `models/`, `storage/`), ⚠️ partial-clone filter (with `blob:none`, blobs for `resource/songs` are already local after the first checkout, so `git restore` in sub-step 4 needs no network [INFERENCE]).
- On each re-run the bundled audio is back on disk inside `$NTS_HOME/src/mpt` for a few seconds (between sub-steps 4 and 8). This is acceptable: nothing starts MPT in between, and the files never leave the clone.
- Stripping tracked files leaves the MPT clone "dirty" by design. `git status` in `$NTS_HOME/src/mpt` will list the deletions. Plan 05.3.1 reuses the strip as a build check (CR-7).
- Weight-fetch scripts named by their owners: `worker-node/bin/fetch-vieneu-weights.sh` (01.2.1), `worker-node/bin/fetch-whisper-model.sh` (01.2.3).
