# 01.2.1-T1 — Install VieNeu at pin, pin and checksum the weights, licence check

| Story | Size | Area | Depends on | Blocks | Gate |
|---|---|---|---|---|---|
| 01.2.1 | XS (0.25 d) | Worker | 01.1.1-T2 (`pins.env` incl. model/codec revisions), 01.1.2-T2 (`lib.sh`, `secrets.sh`), 01.1.2-T3 (`bootstrap.sh`) | 01.2.1-T2, 01.1.1-T3 (rehearsal runs `fetch-vieneu-weights.sh`), 01.3.3-T1 | 01-ready |

## Goal

VieNeu runs from `$NTS_HOME/src/vieneu` at `VIENEU_COMMIT`, its two weight repos sit in `HF_HOME=$NTS_HOME/hf` at exactly `VIENEU_MODEL_REVISION` / `VIENEU_CODEC_REVISION`, every weight file has a recorded sha256, and a clean machine can re-fetch the same bytes with one command. Licences and the v3turbo (not v4) path are confirmed at the pin.

## Inputs

- ✅ V3: Mac install = plain `uv sync` (torch-free ONNX, no extras); start `uv run python -m apps.openai_speech`; `.python-version` 3.12.
- ✅ V5: weights `pnnbao-ump/VieNeu-TTS-v3-Turbo` subfolder `onnx_update` (fp32) + codec `OpenMOSS-Team/MOSS-Audio-Tokenizer-Nano`; `hf_hub_download(repo, fn, repo_type="model", subfolder=…)` **without `revision`** and without `cache_dir` → honours `HF_HOME`, always resolves `main`. Server loads `mode="v3turbo"`.
- ✅ V7: code Apache-2.0, weights/voices apache-2.0 (HF card), v4 proprietary.
- ✅ V1: `HOST` default `0.0.0.0`, `VIENEU_API_KEY` unset = open.
- `worker-node/pins.env` (D2, written by 01.1.1-T2): `VIENEU_REPO`, `VIENEU_COMMIT`, `VIENEU_MODEL_REPO=pnnbao-ump/VieNeu-TTS-v3-Turbo`, `VIENEU_MODEL_REVISION`, `VIENEU_CODEC_REPO=OpenMOSS-Team/MOSS-Audio-Tokenizer-Nano`, `VIENEU_CODEC_REVISION`, `VIENEU_PYTHON=3.12`. Revisions are 40-char SHAs resolved by 01.1.1-T2 from the HF `revision/main` API before any download.
- `worker-node/bin/lib.sh` (01.1.2-T2): `nts_home`, `load_pins`, `log`.
- `worker-node/bin/bootstrap.sh vieneu` (01.1.2-T3): clone to `$NTS_HOME/src/vieneu`, `git checkout --detach "$VIENEU_COMMIT"`, verify HEAD, `uv python install "$VIENEU_PYTHON"`, `uv sync --frozen` (no extras); if `uv.lock` is not tracked at the pin → plain `uv sync` + WARN + sha256 of the generated lock. Does **not** download weights.
- No secrets are needed in this task (see step 4).

## Steps

1. **Install at pin** (no re-implementation of clone/sync):
   ```bash
   worker-node/bin/bootstrap.sh vieneu
   ```
   Expected: exit 0, log line with HEAD = `VIENEU_COMMIT`; `$NTS_HOME/src/vieneu/.venv` exists. If bootstrap logged the "no `uv.lock`" WARN, copy the printed lock sha256 into the T1 notes for 01.3.3.

2. **Confirm upstream facts at the pin** (read-only, in `$NTS_HOME/src/vieneu`):
   ```bash
   cd "$NTS_HOME/src/vieneu"
   head -n 3 LICENSE                                                   # expect "Apache License" / "Version 2.0, January 2004"
   grep -n 'mode="v3turbo"' apps/openai_speech.py                      # expect 1 hit (V5)
   grep -n 'hf_hub_download' src/vieneu/_v3_turbo_engine/onnx_runtime_lite.py   # expect no revision= argument (V5)
   grep -n '"0.0.0.0"\|VIENEU_API_KEY\|VIENEU_WATERMARK\|VIENEU_PRECISION\|VIENEU_MAX_STREAMS\|VIENEU_BACKEND' apps/openai_speech.py   # V1 names unchanged
   grep -n 'onnx_update\|MOSS-Audio-Tokenizer-Nano\|VieNeu-TTS-v3-Turbo' src/vieneu/v3turbo.py      # V5 repos/subfolder
   cat .python-version                                                 # expect 3.12
   uv run --no-project --python 3.12 python -c 'import json;d=json.load(open("src/vieneu/assets/voices_v3_turbo.json"));print(d.get("meta",d).get("count") if isinstance(d,dict) else len(d))'   # expect 25 ⚠️ key path
   test ! -d .venv/lib/python3.12/site-packages/torch && echo "no torch"   # expect "no torch" (plain sync, V3)
   ```
   Any mismatch → stop, record it in the Notes of this file (plan.md §2) and message the plan owner; do not continue with a different model/mode.

3. **Resolve the cache location:** `export HF_HOME="$NTS_HOME/hf"; mkdir -p "$HF_HOME"`. `$NTS_HOME` is on the FileVault disk (D1, E1). Confirm `hf/` is excluded from Time Machine by the `$NTS_HOME` exclusion (01.1.2-T1): `tmutil isexcluded "$NTS_HOME"` → `[Excluded]`.

4. **First online start (download)** [DECISION]. VieNeu itself cannot take a revision (V5), and `start-vieneu.sh` (T2) always runs offline, so the first download is a one-off foreground run bound to loopback, **without** a key (no requests are made; the process is stopped as soon as `/health` answers; only reachable from this Mac):
   ```bash
   cd "$NTS_HOME/src/vieneu"
   lsof -nP -iTCP:8000 -sTCP:LISTEN                                   # expect no output; any line → stop, port busy (D4)
   mkdir -p "$NTS_HOME/logs"
   env -u VIENEU_API_KEY HOST=127.0.0.1 PORT=8000 HF_HOME="$NTS_HOME/hf" HF_HUB_DISABLE_TELEMETRY=1 \
       VIENEU_BACKEND=onnx VIENEU_DEVICE=cpu VIENEU_PRECISION=fp32 VIENEU_MAX_STREAMS=1 VIENEU_WATERMARK=1 \
       uv run python -m apps.openai_speech 2>&1 | tee "$NTS_HOME/logs/vieneu-firstrun-$(date +%Y%m%d-%H%M%S).log"
   ```
   In a second terminal: `until curl -fsS -o /dev/null http://127.0.0.1:8000/health; do sleep 2; done; echo ready` → then Ctrl-C the server. Record the download+load wall time in Notes (excluded from NFR-01-2 rehearsal time). Keep the log: T4 reads its watermark lines.

5. **Verify the downloaded revisions equal the pins:**
   ```bash
   worker-node/bin/fetch-vieneu-weights.sh --record
   ```
   The script (specified below) first checks `refs/main` of both repos against `pins.env`. If `main` moved between 01.1.1-T2 and step 4 → exit 1 "revision drift"; then re-run the 01.1.1-T2 procedure (re-resolve both revisions; never hand-edit `pins.env`), `rm -rf` the two `models--*` dirs, and repeat step 4.

6. **Offline proof:** re-run step 4's command with `HF_HUB_OFFLINE=1` added; `/health` must return 200 with no network access to the Hub (the log shows no download progress). Stop it.

7. **Licence of the weights at the pin** (network read of public cards; no key):
   ```bash
   . worker-node/pins.env
   curl -fsSL "https://huggingface.co/$VIENEU_MODEL_REPO/raw/$VIENEU_MODEL_REVISION/README.md" | grep -m1 -i '^license:'   # expect "license: apache-2.0" (V7)
   curl -fsSL "https://huggingface.co/$VIENEU_CODEC_REPO/raw/$VIENEU_CODEC_REVISION/README.md" | grep -m1 -i '^license:'   # ⚠️ codec licence not verified yet
   ```
   Record both values in Notes and in the `weights.sha256` header comment. Codec licence not permissive for commercial hosted use (e.g. contains `nc`, `non-commercial`, `research`) → stop and escalate to the TL (DECISIONS §10.9 needs a permissive stack).

### `worker-node/bin/fetch-vieneu-weights.sh` (specification)

Bash, D9 conventions (`set -euo pipefail`, `--help`, exit 0/1/2, sources `lib.sh`, `load_pins`, `HF_HOME="$(nts_home)/hf"`). Uses the VieNeu venv's `huggingface_hub` via `uv run --directory "$(nts_home)/src/vieneu" python -` (not a stdlib helper, because it needs `huggingface_hub`; the VieNeu venv already contains it ⚠️ confirm with `uv run python -c 'import huggingface_hub, sys; print(huggingface_hub.__version__)'`). Cache dir of a repo `<org>/<name>` = `$HF_HOME/hub/models--<org>--<name>`.

| Mode | Network | Does | Exit 1 when |
|---|---|---|---|
| `--record` | no | (a) `refs/main` of model and codec == `VIENEU_MODEL_REVISION` / `VIENEU_CODEC_REVISION`; (b) `ls "$HF_HOME/hub"` contains exactly these two `models--*` dirs (anything else → list it, exit 1); (c) for every file under `snapshots/<rev>/` (follow symlinks, `find -L … -type f`, sorted): `shasum -a 256`; (d) writes `worker-node/vieneu/weights.sha256` atomically: header comments (`# generated <ISO UTC> by fetch-vieneu-weights.sh --record`, `# vieneu_commit=<sha>`, `# licence model=<…> codec=<…>`), then lines `<sha256>  <repo>@<revision>/<path-in-repo>` | revision drift, extra repo, empty snapshot |
| `--fetch` (default) | yes | for each line of `weights.sha256`: `hf_hub_download(repo_id=<repo>, filename=<basename>, subfolder=<dir or None>, revision=<revision>)`; then writes `<rev>` to `refs/main` of each repo (so VieNeu's revision-less lookup resolves offline ⚠️ see Notes); then runs `--verify` | download error (exit 1), `weights.sha256` missing (exit 2) |
| `--verify` | no | `refs/main` == pins; every listed file exists under `snapshots/<rev>/` and its sha256 matches; prints `OK <n> files` | any mismatch/missing file |

Output never contains tokens (the repos are public; no `HF_TOKEN` is used — if `HF_TOKEN` is set in the environment the script unsets it for the child).

## Failure handling

| Failure | Action |
|---|---|
| `bootstrap.sh vieneu` exits 2 (HEAD ≠ pin, uv missing) | fix per 01.1.2-T3; do not run `uv sync` by hand |
| `uv sync --frozen` fails on darwin-arm64 | stop; record the error; try the next upstream commit only via a new 01.1.1-T2 pin |
| Download slow/fails (HF outage, rate limit) | retry step 4 later; partial downloads are resumed by `huggingface_hub`; never use a mirror without recording it |
| Revision drift (step 5 exit 1) | re-run 01.1.1-T2 procedure, delete both `models--*` dirs, repeat step 4 |
| Extra repo in `$HF_HOME/hub` | record repo + purpose (read the code path at the pin); ask the TL whether it gets a D2 pin; `pins.env` gains a key only via 01.1.1-T2 |
| Offline start fails (step 6) with "cannot find the requested files in the local cache" | check `refs/main` content and `snapshots/<rev>/` completeness with `--verify`; if VieNeu requests a file not downloaded online → a code path differs between online and offline; stop and report |
| Server grep shows `mode="v4"` or proprietary weights | stop: v4 is proprietary (V7), escalate |
| Codec licence non-permissive/unknown | stop before T2; escalate to TL (DECISIONS §10.9) |
| Rollback | `rm -rf "$NTS_HOME/src/vieneu" "$NTS_HOME/hf/hub/models--pnnbao-ump--VieNeu-TTS-v3-Turbo" "$NTS_HOME/hf/hub/models--OpenMOSS-Team--MOSS-Audio-Tokenizer-Nano"`; `git restore worker-node/vieneu/weights.sha256` |

## Notes

- ⚠️ `huggingface_hub` offline resolution: with `HF_HUB_OFFLINE=1` a revision-less `hf_hub_download` reads `refs/main` from the cache and serves `snapshots/<sha>/<file>` — confirm with the `huggingface_hub` version in the VieNeu lock. When downloading with `revision=<commit sha>`, `huggingface_hub` may not write `refs/main` ⚠️; that is why `--fetch` writes it explicitly.
