# 01.2.1-T2 — `start-vieneu.sh` and `env.example`

| Story | Size | Area | Depends on | Blocks | Gate |

## Goal

One command, `worker-node/bin/start-vieneu.sh`, starts VieNeu in the foreground on `127.0.0.1:8000` with the Keychain key, fp32/ONNX/1 stream, watermark on, weights offline at the pinned revisions, logs to `$NTS_HOME/logs/`, and prints a `READY` line only when `/health` returns 200 (FR-01-1).

## Inputs

- ✅ V1: env names and defaults — `HOST` (`0.0.0.0`), `PORT` (8000), `VIENEU_API_KEY` (unset = open), `VIENEU_WATERMARK` (on unless `0`), `VIENEU_BACKEND`, `VIENEU_DEVICE`, `VIENEU_PRECISION` (fp32; int8 needs x86 VNNI), `VIENEU_MAX_STREAMS` (1 on CPU fp32), `VIENEU_QUEUE_TIMEOUT` (10 s).
- ✅ V2: `/health` never needs auth and answers only after model load (≈ 19 s CPU).
- ✅ V3: `uv run python -m apps.openai_speech` from the repo root.
- ✅ V5: `hf_hub_download` honours `HF_HOME`.
- D1 paths, D3 Keychain `nts.vieneu.api_key`, D4 port 8000 on `127.0.0.1`, D9 conventions, D11 fp32 + 1 stream.
- T1: clone at `$NTS_HOME/src/vieneu`, weights in `$NTS_HOME/hf` with `refs/main` = pins, `worker-node/bin/fetch-vieneu-weights.sh --verify`.
- `lib.sh`: `nts_home`, `load_pins`, `secret <service>`, `require_port_free <port>` (exits 2), `log <msg>` (stderr, ISO UTC).

## Steps

1. **Write `worker-node/vieneu/env.example`** (tracked; no secrets; the start script reads it — single source for Mac values and the template for plan 11):
   ```dotenv
   # VieNeu openai_speech runtime env (non-secret). Read by worker-node/bin/start-vieneu.sh.
   # VIENEU_API_KEY is NOT set here: it comes from Keychain service nts.vieneu.api_key (D3).
   HOST=127.0.0.1
   PORT=8000
   VIENEU_BACKEND=onnx
   VIENEU_DEVICE=cpu
   VIENEU_PRECISION=fp32
   VIENEU_MAX_STREAMS=1
   VIENEU_WATERMARK=1
   HF_HOME=${NTS_HOME}/hf
   HF_HUB_OFFLINE=1
   HF_HUB_DISABLE_TELEMETRY=1
   ```
   Format rules: one `KEY=VALUE` per line, `#` comments, no quotes, no spaces around `=`, the only substitution is the literal `${NTS_HOME}`.

2. **Write `worker-node/bin/start-vieneu.sh`** (Bash, D9: `#!/usr/bin/env bash`, `set -euo pipefail`, `--help`, shellcheck clean, never `set -x`):

   | # | Step | Failure → exit |
   |---|---|---|
   | a | `source "$(dirname "$0")/lib.sh"`; `NTS_HOME="$(nts_home)"`; `load_pins` | 2 |
   | b | Parse `worker-node/vieneu/env.example` line by line: skip blank/`#`; each line must match `^[A-Z][A-Z0-9_]*=[^'"\` ]*$`; key must be in the allow-list {`HOST`, `PORT`, `VIENEU_BACKEND`, `VIENEU_DEVICE`, `VIENEU_PRECISION`, `VIENEU_MAX_STREAMS`, `VIENEU_WATERMARK`, `HF_HOME`, `HF_HUB_OFFLINE`, `HF_HUB_DISABLE_TELEMETRY`}; replace literal `${NTS_HOME}`; no `eval`/`source` of the file. `VIENEU_API_KEY` in the file → `log "secret in env.example"`, exit 2 | 2 |
   | c | **Guards** (D4/D11/F09): `HOST == 127.0.0.1`, `PORT == 8000`, `VIENEU_BACKEND == onnx`, `VIENEU_PRECISION == fp32`, `VIENEU_MAX_STREAMS == 1`, `VIENEU_WATERMARK == 1`, `HF_HUB_OFFLINE == 1`, `HF_HOME == $NTS_HOME/hf`. Values inherited from the caller's environment are ignored (the child gets `env -i` + explicit list, step g) | 2 |
   | d | Clone at pin: `git -C "$NTS_HOME/src/vieneu" rev-parse HEAD` == `VIENEU_COMMIT`; else `log "run bootstrap.sh vieneu"` | 2 |
   | e | Weights at pin: `refs/main` of `models--pnnbao-ump--VieNeu-TTS-v3-Turbo` == `VIENEU_MODEL_REVISION` and of `models--OpenMOSS-Team--MOSS-Audio-Tokenizer-Nano` == `VIENEU_CODEC_REVISION`; empty revision or missing dir → `log "run fetch-vieneu-weights.sh"`. `--verify-weights` flag additionally runs `worker-node/bin/fetch-vieneu-weights.sh --verify` (sha256 of all files; used by T3/rehearsal, not every start) | 2 |
   | f | `require_port_free 8000`; `KEY="$(secret nts.vieneu.api_key)"`; empty or `${#KEY} -lt 32` → `log "run secrets.sh init-local"` (never print the value) | 2 |
   | g | `LOG="$NTS_HOME/logs/vieneu-$(date +%Y%m%d-%H%M%S).log"`; `mkdir -p`; `log "log: $LOG"`. Start in `$NTS_HOME/src/vieneu`: `env -i PATH="$PATH" HOME="$HOME" USER="$USER" LANG=en_US.UTF-8 HOST=… PORT=… VIENEU_*=… HF_*=… VIENEU_API_KEY="$KEY" uv run --no-sync python -m apps.openai_speech > >(tee -a "$LOG") 2>&1 &`; `SRV=$!`; `unset KEY`. (`env -i` drops `HF_TOKEN`, proxies, a stray `VIENEU_API_KEY` or `HOST` from the caller; the key reaches only the child env, never argv) | — |
   | h | `trap 'kill -TERM "$SRV" 2>/dev/null; wait "$SRV"; exit 0' INT TERM` | — |
   | i | Readiness: `T0=$SECONDS`; poll `curl -s -o /dev/null -w '%{http_code}' --max-time 2 http://127.0.0.1:8000/health` every 1 s up to `VIENEU_READY_TIMEOUT` (script option `--ready-timeout <s>`, default 120). On `200`: append and print `READY vieneu http://127.0.0.1:8000 after <n>s` (`n = SECONDS - T0`, T4 uses it as cold-start). Server process gone before ready → `log "server exited"`, exit 1. Timeout → `NOT READY after <n>s`, kill `$SRV`, exit 1 | 1 |
   | j | `wait "$SRV"`; server non-zero exit → exit 1 | 1 |

   `--help` prints usage, the env file path, the log dir and the exit codes. Option `--check` runs steps a–e and the key part of f (not `require_port_free`, so it also works while the server runs) and exits 0 without starting anything (used by `smoke-vieneu.sh` as preflight).

   Why `--no-sync`: the venv is built only by `bootstrap.sh vieneu` (`uv sync --frozen`); a start must not resolve/install packages or reach the network, and must not drop an extra installed by the T4 watermark decision ⚠️ confirm `uv run --help | grep -- '--no-sync'` in the installed uv.

3. **Run it** in a dedicated terminal: `worker-node/bin/start-vieneu.sh`. In a second terminal: `curl -s http://127.0.0.1:8000/health` → JSON with `status`, `backend`, `max_streams`, `active`, `waiting`, `sample_rate` (V2). Stop with Ctrl-C.

4. **Runbook entry**: give the plan owner of `worker-node/README.md` (01.1.1-T3) the lines "Start VieNeu: `worker-node/bin/start-vieneu.sh` (foreground, own terminal) · Ready when `READY vieneu … after Ns` · Stop: Ctrl-C". Do not edit README here if 01.1.1-T3 owns it — send via hub.

## Acceptance checks

- [ ] `shellcheck worker-node/bin/start-vieneu.sh` → no findings; `worker-node/bin/start-vieneu.sh --help` → usage, exit 0.
- [ ] `worker-node/bin/start-vieneu.sh --check` → exit 0 on the prepared Mac, with and without the server running.
- [ ] Start → `READY vieneu http://127.0.0.1:8000 after <n>s` with n ≤ 60 (V2 ≈ 19 s + margin); `curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:8000/health` → `200`.
- [ ] `lsof -nP -iTCP:8000 -sTCP:LISTEN` → one line, NAME `127.0.0.1:8000 (LISTEN)`; no `*:8000`.
- [ ] `ps -o command= -p "$(lsof -tiTCP:8000 -sTCP:LISTEN)"` → contains `apps.openai_speech`; does **not** contain the key (`ps -o command= -p <pid> | grep -cFf <(printf '%s\n' "$KEY")` inside a script, pattern from an fd, print count only → `0`, SEC-08).
- [ ] Guard: a second `start-vieneu.sh` while the first runs → exit 2 ("port 8000 busy"), first server unaffected.
- [ ] Guard: edit a scratch copy of the env file (`--env-file <path>` option, test only) with `HOST=0.0.0.0` → exit 2 before starting; same for `VIENEU_PRECISION=int8`.
- [ ] Guard: `HOST=0.0.0.0 worker-node/bin/start-vieneu.sh` (caller env) → still binds `127.0.0.1` (lsof as above).
- [ ] Guard: Keychain item absent (test on a scratch service name via `--key-service <name>`, test only) → exit 2, message names `secrets.sh init-local`, no value printed.
- [ ] Offline: with Wi-Fi off, start → `READY` (weights from cache, `HF_HUB_OFFLINE=1`).
- [ ] Ctrl-C → exit 0; `lsof -nP -iTCP:8000 -sTCP:LISTEN` → empty.
- [ ] Log file exists under `$NTS_HOME/logs/` and holds the server output and the `READY` line.

## Failure handling

| Failure | Action |
|---|---|
| `NOT READY after 120s` | read the log: download attempt → weights incomplete (`fetch-vieneu-weights.sh --verify`); ONNX error → record and stop (T1 install issue); slow load only → rerun with `--ready-timeout 300`, record time, check memory pressure (`memory_pressure`) |
| Offline error "cannot find the requested files in the local cache" | `fetch-vieneu-weights.sh --verify`; if OK, `refs/main` handling differs (T1 Notes ⚠️) → fix in `fetch-vieneu-weights.sh`, not by removing `HF_HUB_OFFLINE` |
| Startup fails because `VIENEU_WATERMARK=1` and the `[watermark]` extra is missing | do not set `0` here; T4 owns the watermark decision (F10); record the log line in T4 |
| `uv run --no-sync` unsupported by installed uv | use `uv run --frozen` ⚠️ and note that it may sync; record uv version |
| Port busy (exit 2) | `lsof -nP -iTCP:8000 -sTCP:LISTEN` to find the owner; never kill an unknown PID |
| Rollback | delete the two new files; nothing outside the repo besides logs is changed |
