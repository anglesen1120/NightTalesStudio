# 01.2.1-T3 — `smoke-vieneu.sh`: health, auth, format, voice, 48 kHz, voice snapshot, loopback bind

| Story | Size | Area | Depends on | Blocks | Gate |
|---|---|---|---|---|---|
| 01.2.1 | S (0.5 d) | Worker | 01.2.1-T2 | 01.2.1-T4, 04.1.2, 04.1.3, 04.2.1 (snapshot), 01.2.2-T6, 04.1.5-T1 (04 CR-16) | 01-ready (`smoke.sh` green) |

## Goal

`worker-node/bin/smoke-vieneu.sh` proves, against the running server, every story-level check of 01.2.1: health without auth, 401 without/with a wrong key, mp3 → 400, unknown voice → 400, wav → 200 at 48 kHz, voice list saved and counted, and the server reachable only on loopback (F09, F19). It is called by `worker-node/bin/smoke.sh` and re-run before each trial run.

## Inputs

- ✅ V2: routes, auth rules (`/health` never needs auth; Bearer required on speech; 401 body `{"error":{"message":"invalid api key",…,"code":401}}`), 400 for format ∉ {pcm, wav} and unknown voice, default `wav` 48 kHz, `POST /v1/voices` = voice-clone upload (multipart: name, file, denoise, description; ≤ 20 MB).
- ✅ V5: 25 voices in SDK 3.8.3 (default "Hải Đăng"), 23 on the HF card. ✅ V1: `VIENEU_QUEUE_TIMEOUT` 10 s → 429.
- ✅ 04 F3: WAV header length `0xFFFFFFFF` → never trust header duration; decode to count samples.
- F09 (clone endpoint), F19 (LAN check from the Mac itself), CR-2 (proxy never forwards `POST /v1/voices`), D3 key `nts.vieneu.api_key`, D4 binds, D9 conventions.
- T2: running server, `start-vieneu.sh --check`, current log path (`$NTS_HOME/logs/vieneu-*.log`, newest).
- Tools: `curl`, `lsof`, `ipconfig`, `ffprobe`/`ffmpeg` 9.0.2 (E2), stdlib Python via `uv run --no-project --python 3.12` (D9) for JSON.

## Steps

1. **Write `worker-node/bin/smoke-vieneu.sh`** (Bash, D9; sources `lib.sh`; never `set -x`). Output contract (shared with `smoke.sh`, see Notes): one line per check `PASS <id>` · `FAIL <id>: <detail>` · `WARN <id>: <detail>` · `INFO <id>: <value>`; exit `0` all PASS (WARN/INFO allowed) · `1` any FAIL · `2` environment error (server not running, tool missing, key missing). Options: `--help`, `--update-snapshot` (writes the snapshot instead of diffing). Base URL is fixed to `http://127.0.0.1:8000` (no option). Env `NTS_VOICES_SNAPSHOT` overrides the snapshot path (default `worker-node/vieneu/voices.snapshot.json`; used only by the drift self-test).

   Preflight (exit 2 on failure): `command -v curl lsof ffprobe ffmpeg`; `worker-node/bin/start-vieneu.sh --check`; `lsof -nP -iTCP:8000 -sTCP:LISTEN` non-empty (else `log "start-vieneu.sh first"`). Key: `KEY="$(secret nts.vieneu.api_key)"`; all authenticated curls use `-H @<(printf 'Authorization: Bearer %s\n' "$KEY")` so the key never appears in argv; wrong-key curls use `-H @<(printf 'Authorization: Bearer %s\n' "wrong-$(openssl rand -hex 16)")`. `TMP="$(mktemp -d)"`, `trap 'rm -rf "$TMP"' EXIT`. Every curl: `--max-time 60` (speech) / `5` (others), `-s -o <file> -w '%{http_code}'`.

   Request bodies are built by the stdlib Python helper (`json.dumps({"model":"vieneu-v3-turbo","input":…,"voice":…,"response_format":…}, ensure_ascii=False)`, so Vietnamese diacritics and quotes are escaped correctly) and piped with `-H 'Content-Type: application/json' --data-binary @-`. Test texts (short, fixed): vi `Xin chào, đây là bài kiểm tra.`, en `This is a short test.`. `VOICE` = `Hải Đăng` if it is an id in the `voices-list` result, else its first id.

2. **Checks (in this order)**

   | id | Request | Expected | Source |
   |---|---|---|---|
   | `health-noauth` | `curl http://127.0.0.1:8000/health` (no header) | `200`; body JSON has keys `status`, `backend`, `max_streams`, `active`, `waiting`, `sample_rate`; `max_streams == 1`; `sample_rate == 48000` ⚠️ field type; `INFO health: <body>` | V2, D11 |
   | `speech-noauth` | `POST /v1/audio/speech` wav body, no `Authorization` | `401`; body contains `invalid api key` | V2 |
   | `speech-wrongkey` | same with wrong Bearer | `401` | V2 |
   | `models` | `GET /v1/models` with key | `200`; `INFO models: <ids>` (expect `vieneu-v3-turbo` ⚠️) | V2, V5 |
   | `voices-list` | `GET /v1/voices` with key | `200`; JSON `{"object":"list","data":[…]}` (04 F2); `INFO voices_count: <n>`; `n == 25` → PASS, `n == 23` or other → `WARN voices-count: <n> (expected 25 for SDK 3.8.3)` | V2, V5 |
   | `voices-noauth` | `GET /v1/voices` without header | status recorded: `INFO voices_noauth_status: <code>` (⚠️ Q3; either answer is acceptable on loopback) | V2 |
   | `voices-snapshot` | normalise `voices-list` body with the Python helper (`json.dumps(obj, ensure_ascii=False, indent=2, sort_keys=True)` + `\n`) → compare with `worker-node/vieneu/voices.snapshot.json`; `--update-snapshot` writes it | equal → PASS; differ → `FAIL voices-snapshot: drift (run with --update-snapshot after review)`; file missing → FAIL unless `--update-snapshot` | 04 §8 "voice list changes" |
   | `speech-mp3` | wav body with `response_format:"mp3"`, with key | `400` | V2, 04 F1 |
   | `speech-unknown-voice` | `voice:"nts-no-such-voice"`, wav, with key | `400` | V2 |
   | `speech-wav-vi` | vi text, `VOICE`, wav, with key → `$TMP/vi.wav` | `200`; first 4 bytes `RIFF`, bytes 8–11 `WAVE` (`head -c 12 \| od -c`); `ffprobe -v error -select_streams a:0 -show_entries stream=sample_rate,channels,codec_name -of csv=p=0` → `pcm_s16le,48000,1` ⚠️ codec/channels; decoded duration `ffmpeg -v error -i vi.wav -f null - -stats` exit 0 and samples/48000 > 0.5 s; `INFO riff_size: <hex of bytes 4–7>` (04 F3 expects `ffffffff`) | V2, 04 F3 |
   | `speech-wav-en` | same with en text | same | V2 |
   | `voices-post-auth-probe` (SEC-03) | Generate a 0.5 s silent WAV in `$TMP` (`ffmpeg -v error -f lavfi -i anullsrc=r=48000:cl=mono -t 0.5 -c:a pcm_s16le "$TMP/probe.wav"`). Send a **complete** multipart `POST /v1/voices` (`-F name=nts-smoke-probe -F file=@"$TMP/probe.wav"`) twice: once with no header, once with a wrong Bearer | both `401` → PASS. `422`/`400` → `FAIL voices-post: not decisive (validation ran before auth)`. Any `2xx` → `FAIL voices-post: clone endpoint open`: then delete the probe voice (⚠️ delete route at the pin; otherwise remove it from the voice store per upstream docs), stop the server, and do not continue | F09, CR-2, SEC-03 |
   | `bind-loopback` | `lsof -nP -iTCP:8000 -sTCP:LISTEN` | every NAME is `127.0.0.1:8000` (or `[::1]:8000`); anything else → FAIL | D4, F09 |
   | `lan-refused` | `IP="$(ipconfig getifaddr en0 \|\| ipconfig getifaddr en1)"`; `curl -s --max-time 3 -o /dev/null "http://$IP:8000/health"`; capture curl exit code | curl exit `7` (connection refused) → PASS; exit `0` → FAIL; no IP on en0/en1 → `WARN lan-refused: no LAN address` (not a FAIL; `bind-loopback` still decides) | F19 |
   | `lan6-refused` (SEC-05) | `IP6="$(ifconfig en0 \| awk '/inet6 / && $2 !~ /^fe80/ {print $2; exit}')"`; `curl -g -s --max-time 3 -o /dev/null "http://[$IP6]:8000/health"` | curl exit `7` → PASS; exit `0` → FAIL; no global IPv6 address → `INFO lan6-refused: no IPv6` | SEC-05 |
   | `log-no-key` (SEC-08) | newest `$NTS_HOME/logs/vieneu-*.log`: `grep -cFf <(printf '%s\n' "$KEY") "$LOG"` (the pattern comes from a file descriptor, so the key is never in `grep`'s argv) | `0` → PASS (print only the count); also `INFO log_has_input_text: <yes/no>` = `grep -cF 'đây là bài kiểm tra'` > 0 (Q8) | D3, SEC-08 |
   | `binds-all` | `worker-node/bin/check-binds.sh` (written in step 2a) | exit 0 → PASS; script absent → **FAIL** (SEC-05) | D4 |

   2a. **Write `worker-node/bin/check-binds.sh`** (owned by this task, README D1 script list; SEC-05). It is an **allowlist**, not a denylist:
   - For each D4 port (8000, 8001, 8002, 8080): every LISTEN row from `lsof -nP -iTCP:<port> -sTCP:LISTEN` must be exactly `127.0.0.1:<port>` or `[::1]:<port>`. A port with no listener → `INFO <port>: not running`.
   - Every LISTEN socket owned by the service processes must be loopback too: collect the pids of the D4 listeners plus their descendants (`pgrep -P` recursively), then `lsof -a -nP -p <pids,…> -iTCP -sTCP:LISTEN` → any non-loopback NAME → FAIL. Scoping by process tree avoids false failures from macOS daemons on other ports.
   - Output uses the same `PASS`/`FAIL`/`INFO` contract; exit `0` / `1` / `2` (D9).
   - Nothing may listen on 8501–8599 (MPT WebUI range, M2; the WebUI is not used in M0, D14) → FAIL if anything does.

   The script uploads only the generated 0.5 s silent probe WAV, and only without a valid key (so a correctly protected server stores nothing). It sends at most two short speech requests (≈ 2–5 s of CPU each).

3. **First run and snapshot.** Start the server (`worker-node/bin/start-vieneu.sh`), then `worker-node/bin/smoke-vieneu.sh --update-snapshot`. Review `worker-node/vieneu/voices.snapshot.json` (count, default voice, fields per object — resolves 04 §10 "voice object shape"). Commit it. Then `worker-node/bin/smoke-vieneu.sh` → all PASS.

4. **Wire into `smoke.sh`.** `worker-node/bin/smoke.sh` is shared with 01.2.2 (MPT smoke): it runs each present `worker-node/bin/smoke-*.sh` in fixed order (`smoke-vieneu.sh`, then MPT's, then others), then `check-binds.sh`, then its own row `git.hooks`: `git -C "$REPO" config --get core.hooksPath` = `.githooks` → PASS, else FAIL (SEC-12, 01.1.2-T4); exit = 2 if any child exited 2, else 1 if any exited 1, else 0. Whichever of 01.2.1-T3 / 01.2.2-T5 lands first creates it; the other only adds its script (coordinated via hub with the 01.2.2 plan owner).

5. **Record** in the T4 baseline (`server.health`) and in plan.md §2: `/health` body, voices count, `voices-noauth` and `voices-post-unauth` statuses, `riff_size`, ffprobe codec/channels, log-contains-input yes/no.

## Acceptance checks

- [ ] `shellcheck worker-node/bin/smoke-vieneu.sh` → clean; `--help` → exit 0.
- [ ] Server running: `worker-node/bin/smoke-vieneu.sh; echo $?` → every line `PASS`/`INFO` (WARN only for `voices-count` or missing LAN IP), exit `0`.
- [ ] Server stopped: `worker-node/bin/smoke-vieneu.sh; echo $?` → exit `2` with message `start-vieneu.sh first`.
- [ ] `grep -n 'Bearer' worker-node/bin/smoke-vieneu.sh` → every hit is inside `-H @<(printf 'Authorization: Bearer %s\n' …)` (key never in argv, D3).
- [ ] Snapshot drift: change one character in a scratch copy of `voices.snapshot.json`; `NTS_VOICES_SNAPSHOT=<scratch> worker-node/bin/smoke-vieneu.sh` → `FAIL voices-snapshot`, exit 1.
- [ ] `uv run --no-project --python 3.12 python -c 'import json;print(len(json.load(open("worker-node/vieneu/voices.snapshot.json"))["data"]))'` → recorded count (expect `25`).
- [ ] `worker-node/bin/smoke.sh; echo $?` → runs `smoke-vieneu.sh`, exit 0.
- [ ] `lan-refused` printed `PASS` (curl exit 7) on this Mac with Wi-Fi/Ethernet up.
- [ ] SEC-03: `voices-post-auth-probe` → `PASS` (two `401`s). If the pinned handler has no auth, this row FAILs and gate 01-ready is blocked until VieNeu runs behind a local filter that rejects `POST /v1/voices` (decision recorded in plan.md §2).
- [ ] SEC-05: `worker-node/bin/check-binds.sh; echo $?` → `0` with VieNeu running; with a scratch listener `python3 -m http.server 8001 --bind 0.0.0.0 &` → exit `1` naming port 8001, then `kill %1`. Renaming `check-binds.sh` away makes `smoke-vieneu.sh` FAIL on `binds-all`.
- [ ] SEC-05: `lan6-refused` → `PASS` or `INFO no IPv6`, never `FAIL`.
- [ ] SEC-08 lint: `grep -nE 'grep -c?F -- "\$' worker-node/bin/*.sh trial/tools/*.sh` → no hits (no key value in any `grep` argv).

## Failure handling

| Failure | Action |
|---|---|
| `speech-noauth` returns 200 | key not reaching the server → stop the server; check T2 step g; never run the server without a key |
| `bind-loopback` FAIL | stop the server immediately; T2 guard is broken → fix before anything else (F09) |
| `lan-refused` returns 200 | same as above; also run `worker-node/bin/check-binds.sh` |
| `voices-post-auth-probe` FAIL | stop; record the statuses; the clone endpoint is open or not decisively protected → escalate to TL. Plan 04 CR-2 blocks it at the proxy, but loopback + key must hold at VieNeu too; if the upstream handler has no auth, add a local filter in front of :8000 before 01-ready |
| `speech-wav-*` 429 | another request is running (1 stream, V1); re-run when `/health` shows `active: 0` |
| `speech-wav-*` ffprobe fails on the unknown-length header | record the exact error; this is the 04.1.1 question — mark `WARN` for header parse, keep FAIL only if `ffmpeg -f null` decode fails; hand the sample to 04.1.1 |
| `voices-count` 23 | WARN; confirm SDK version at the pin (`uv run python -c 'import vieneu; print(vieneu.__version__)'` ⚠️ attribute); update DECISIONS via CR-8 note |
| `log-no-key` count > 0 | stop; rotate `nts.vieneu.api_key` (`secrets.sh` rotate ⚠️ per 01.1.2-T2), delete the log, report upstream behaviour |
| Rollback | delete the new files; no state outside the repo |
