## Goal
`$NTS_HOME/src/mpt` is a detached checkout of `MPT_COMMIT` with a venv built by `uv sync --frozen` on Python 3.11. MPT uses Homebrew's ffmpeg. The pinned `config.example.toml` is copied into the repo with its sha256, as the baseline for the 05.1.1 upgrade diff (CR-7).

## Inputs
- ✅ M7: Python `>=3.11`, `.python-version` 3.11; install `uv python install 3.11 && uv sync --frozen`; ffmpeg lookup `IMAGEIO_FFMPEG_EXE` → PATH → imageio-ffmpeg; pins `faster-whisper==1.1.0`, `moviepy==2.2.1`, `streamlit==1.59.1`, `openai==2.24.0`.
- ✅ M1: `config.example.toml`, key placement (T2 reads it). ✅ M10: MIT licence. ✅ E2: Homebrew ffmpeg 9.0.2 with `libmp3lame` and `aac`.
- D2 `worker-node/pins.env`: `MPT_REPO`, `MPT_COMMIT` (full 40-char SHA; candidate `3d5f4e42…`, full SHA from the MptFacts check `3d5f4e421927d61f3eac729cf4b711ac0b69d688` ⚠️ confirm at install), `MPT_PYTHON=3.11`.
- `worker-node/bin/bootstrap.sh mpt` (01.1.2-T3): clones into `$NTS_HOME/src/mpt`, runs `git checkout --detach $MPT_COMMIT`, verifies HEAD, runs `uv python install $MPT_PYTHON` and `uv sync --frozen`, calls `strip-bundled-music.sh` (T3; skipped with a warning while it is absent). No secrets in this task.

## Steps
1. Preconditions: `command -v uv git` succeed; `test -x /opt/homebrew/bin/ffmpeg`; `grep -E '^MPT_COMMIT=[0-9a-f]{40}$' worker-node/pins.env` matches one line.
2. Run `worker-node/bin/bootstrap.sh mpt`. Do not clone or sync by hand; a problem in clone or sync is fixed in `bootstrap.sh` (01.1.2-T3).
3. Verify the pin and the lock:
   ```bash
   source worker-node/bin/lib.sh; load_pins; H="$(nts_home)"
   git -C "$H/src/mpt" rev-parse HEAD                        # == $MPT_COMMIT
   git -C "$H/src/mpt" status --porcelain --untracked-files=no  # empty (tracked files unmodified, except T3's deletions)
   cat "$H/src/mpt/.python-version"                           # 3.11
   (cd "$H/src/mpt" && uv run python -c 'import sys; print(sys.version.split()[0])')  # 3.11.x
   (cd "$H/src/mpt" && uv sync --frozen)                      # second run: no packages installed/removed
   ```
   Note: after T3, `git status` lists the removed `resource/songs/*` files as deleted. That is expected; filter them with `git status --porcelain --untracked-files=no -- . ':!resource/songs'`.
4. Record the key package versions (these must equal the M7 pins):
   ```bash
   (cd "$H/src/mpt" && uv pip list --format=freeze) | grep -Ei '^(faster-whisper|moviepy|streamlit|openai|fastapi|uvicorn)=='
   ```
5. Bind ffmpeg to Homebrew (M7 lookup order: the env var wins over PATH and the bundled imageio-ffmpeg). `IMAGEIO_FFMPEG_EXE=/opt/homebrew/bin/ffmpeg` is exported by the start scripts (T4), not by the shell profile. Leave the config key `ffmpeg_path` unset (commented out in the example ✅ M1; setting it would also set the env var ⚠️). Check:
   ```bash
   (cd "$H/src/mpt" && IMAGEIO_FFMPEG_EXE=/opt/homebrew/bin/ffmpeg uv run python -c \
     'import imageio_ffmpeg; print(imageio_ffmpeg.get_ffmpeg_exe())')   # /opt/homebrew/bin/ffmpeg
   /opt/homebrew/bin/ffmpeg -hide_banner -version | head -1                # ffmpeg version 9.0.2 … (E2)
   /opt/homebrew/bin/ffmpeg -hide_banner -encoders | grep -E ' (libmp3lame|aac) '
   ```
   Where the version goes: `env-versions.sh` (01.1.1-T1) reports `ffmpeg` in `run.json.env`. No extra file.
6. Snapshot the pinned example config (the baseline for the 05.1.1 upgrade diff, CR-7):
   ```bash
   cp "$H/src/mpt/config.example.toml" worker-node/mpt/config.example.pinned.toml
   { printf '# MPT_COMMIT=%s\n' "$MPT_COMMIT"
     (cd worker-node/mpt && shasum -a 256 config.example.pinned.toml); } > worker-node/mpt/config.example.pinned.toml.sha256
   diff -q "$H/src/mpt/config.example.toml" worker-node/mpt/config.example.pinned.toml   # no output
   ```
   Check that the example contains no secrets (it ships empty keys ✅ M1): `grep -nE '(_key|_keys|token|secret)\s*=\s*"[^"]+' worker-node/mpt/config.example.pinned.toml` must print nothing, or only placeholders that the gitleaks hook (01.1.2-T4) accepts.
7. Licence and scope notes: confirm `head -1 "$H/src/mpt/LICENSE"` → `MIT License` (M10). Write in `worker-node/README.md` (runbook, 01.1.1-T3 owner; send the lines as a request): "MPT MIT @ `<MPT_COMMIT>`; `app/services/upload_post.py` is never enabled or called (T2 guard)".
8. Confirm the M1 line anchors still hold at the pin (T2 needs them):
   ```bash
   grep -nE '^(log_level|listen_host|listen_port)\s*=|^\[(app|whisper|kokoro)\]' worker-node/mpt/config.example.pinned.toml
   ```
   Expected at `3d5f4e42`: L15, L17, L18, `[app]` L20, `[whisper]` L506, `[kokoro]` L582. If they differ, T2 follows the file, not these numbers.

## Failure handling
- HEAD ≠ pin, or `uv sync --frozen` fails because the lock is out of date → stop; fix in `bootstrap.sh` or `pins.env` (01.1.2-T3 / 01.1.1-T2). Never run `uv lock` or plain `uv sync` (that would change the lock).
- Python 3.11 download fails → retry `uv python install 3.11`; no system Python fallback (F18).
- `get_ffmpeg_exe()` does not print the Homebrew path → `imageio_ffmpeg` may resolve differently at the pin ⚠️; check `app/utils/utils.py` `get_ffmpeg_binary` and use the config key `ffmpeg_path` only if the env var is ignored (record as a deviation).
- Example contains a non-empty secret-like value → do not commit; report upstream and redact only in the copy, noting the difference in the `.sha256` comment.
- Rollback: `rm -rf "$NTS_HOME/src/mpt"`; `git rm worker-node/mpt/config.example.pinned.toml*`.
