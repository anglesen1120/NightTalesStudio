## Goal
`worker-node/mpt/config.template.toml` (secret-free, key placement copied from the pinned example) plus `worker-node/bin/render-mpt-config.py` produce `$NTS_HOME/src/mpt/config.toml`. The file is written atomically with mode 0600 and only after every guard passes. Every render reports a secret-free diff whenever the file changed since the previous render (config drift; the WebUI is not used in M0, D14).

- ✅ M1 key placement and defaults (line numbers at `3d5f4e42`; T1 step 8 re-checks them at the pin). ✅ M4 (empty image base URL or model → `ValueError`), ✅ M5 (empty model → `gpt-5.5`), ✅ M8 (missing file → copy of the example; WebUI rewrites via `os.replace`), ✅ M9 (log levels), ✅ M11 (empty `api_key` → auth off).
- D4 ports, D5 placeholders and guards, D6 tap URL, D11 `max_concurrent_tasks = 1`; 04 §5.2 `[kokoro]` values; 01 FR-01-2 / 01.2.4 story model names.

## Steps
1. Write `worker-node/mpt/config.template.toml` with exactly the text below. `string.Template` syntax: `${NAME}` is substituted, and a literal `$` would need `$$` (the text has none). Every key is ⚠️ until T1 step 8 and a key-by-key grep against `config.example.pinned.toml` confirm its name and section at the pin. Keys that are not listed fall back to MPT's code defaults (⚠️ assumed equal to the example defaults).

# to $NTS_HOME/src/mpt/config.toml (0600). Placement copied from worker-node/mpt/config.example.pinned.toml
# (MPT 3d5f4e42). Every key: ⚠️ re-check name + section at the pinned commit. Never edit the rendered file;

2. Write `worker-node/bin/render-mpt-config.py` with this behaviour: stdlib only (`argparse`, `os`, `re`, `string`, `tomllib`, `tempfile`, `difflib`, `json`, `stat`, `sys`, `secrets` for the self-test); run with `uv run --no-project --python 3.12` (D9).
   - **CLI:** `render-mpt-config.py [--template PATH] [--out PATH] [--state PATH] [--check] [--self-test] [--help]`. Defaults: template = `<repo>/worker-node/mpt/config.template.toml` (repo = the script's `../..`); out = `$NTS_HOME/src/mpt/config.toml`; state = `$NTS_HOME/mpt-config.last.redacted.toml`. `NTS_HOME` defaults to `~/.nts` (D1).
   - **Environment checks (exit 2):** the out dir does not exist or has no `main.py`; `realpath(out)` starts with `/Volumes/` (E1: an unencrypted volume with ownership disabled); out exists and is a symlink or a directory (M8 would delete a directory; a symlink would be replaced).
   - **Substitution (exit 1):** `tpl = string.Template(text)`. `set(tpl.get_identifiers())` must equal exactly `{NTS_MPT_API_KEY, NTS_OPENAI_STORY_KEY, NTS_OPENAI_IMAGE_KEY, NTS_PROXY_API_KEY}` (extra or missing placeholder → exit 1). Build the mapping from `os.environ` for these 4 names only. A missing name → `FAIL missing variable NTS_…` and exit 1. Each value must match `^[A-Za-z0-9._-]{16,512}$` (blocks TOML injection through `"`, `\` or newlines, and blocks empty values) → else `FAIL invalid value for NTS_…` (name only) and exit 1. Then `tpl.substitute(mapping)`, which raises on anything left over.
   - **Parse + guards before writing (exit 1):** `cfg = tomllib.loads(rendered)`. Run all guards and print one line per guard (`PASS <name>` / `FAIL <name>: expected <x>`; secret keys print only `set`/`empty`). The guard list, where `app = cfg["app"]`:

     | Guard | Condition | Source |
     |---|---|---|
     | `listen_host` | `cfg["listen_host"] == "127.0.0.1"` | D5, M1 |
     | `listen_port` | `cfg["listen_port"] == 8080` | D4 |
     | `no_host_in_app` | `"listen_host" not in app` (misplaced key would be ignored) | F06 |
     | `log_level` | `cfg["log_level"] == "INFO"` (DEBUG may log prompts; WARNING would hide the M9 markers the collector needs) | §8 plan |
     | `api_key` | `isinstance(app["api_key"], str)` and `len >= 32` | D5, M11 |
     | `video_source` | `== "openai_image"` | D5 |
     | `pexels_api_keys` / `pixabay_api_keys` | `== []` | D5 |
     | `llm_provider` | `== "openai"` | FR-01-2 |
     | `openai_api_key` | non-empty str | M5 |
     | `openai_model_name` / `openai_image_model` | non-empty str | D5, M4, M5 |
     | `openai_base_url` / `openai_image_base_url` | `== "http://127.0.0.1:8002/v1"` | D6 |
     | `openai_image_api_keys` | list of exactly 1 non-empty str | M4 |
     | `subtitle_provider` | `== "whisper"` | D5 |
     | `whisper.model_size` | `== "large-v3-turbo"` | D5 |
     | `enable_redis` | `is False` | D11 |
     | `max_concurrent_tasks` | `== 1` | D5, D11 |
     | `upload_post_enabled` / `upload_post_auto_upload` | `is False` | D5 |
     | `upload_post_api_key` | `== ""` | §8 plan |
     | `kokoro.base_url` | `== "http://127.0.0.1:8001/v1"` | 04 §5.2 |
     | `kokoro.api_key` | non-empty str | 04 §5.2 |
     | `kokoro.voices` | `== []` | 04 F2 |

   - **Config-drift diff (report only, never blocks):** canonicalise a config as sorted lines `<section>.<key> = <json value>`. Redact every key matching `(^|_)(api_key|api_keys|key|keys|token|secret|password)$` to `"<set>"` / `"<empty>"` (lists: `"<set x N>"`). If `out` exists: canonicalise it (parse error → `WARN existing config.toml unparseable`). If a state file exists and differs → `WARN config.toml changed since last render (config drift)` + `difflib.unified_diff` of the redacted lines on stderr. Also print the diff of the previous state against the new render (`INFO template change`) when they differ.
   - **Value-based redaction (SEC-09).** Redaction by key name alone misses a key that lands under an unexpected name (e.g. a key copied into another provider section). Before diffing, also redact **any value** that equals one of the 4 mapping values, or that starts with `sk-`, whatever the key name. Values of existing `config.toml` lines are compared to the mapping in-process; nothing is printed.
   - **Atomic write:** `os.umask(0o077)`; `fd, tmp = tempfile.mkstemp(dir=outdir, prefix=".config.toml.")`; `os.fchmod(fd, 0o600)`; write; `os.fsync(fd)`; `os.replace(tmp, out)`; `fsync` the dir fd; on any exception remove `tmp`. Then write the redacted canonical text to the state file the same way (0600).
   - **`--check`:** no write. Out must be a regular file with `stat.S_IMODE == 0o600` and pass every guard (placeholders not required) → exit 0/1. Used by `start-mpt-api.sh` and `smoke-mpt.sh`.
   - **`--self-test`:** in a `tempfile.TemporaryDirectory` with a fake MPT root (`main.py` touched) and dummy values from `secrets.token_hex(32)` (never Keychain values). Cases and expected exits: (a) valid → 0, file mode 600; (b) `NTS_PROXY_API_KEY` unset → 1; (c) `NTS_MPT_API_KEY=""` → 1; (d) template copy with `listen_host = "0.0.0.0"` → 1; (e) value containing `"` → 1; (f) `guards()` called directly with `api_key = ""` → FAIL `api_key`; (g) `--out` under `/Volumes/…` → 2. For (b)–(e) the sha256 of the out file from (a) must stay unchanged. Prints `PASS selftest:<case>` lines; exit 0 only if all cases pass.
   - **Never:** print a value from the mapping; log the rendered text; accept `--set key=value` overrides.
   - **Exit codes:** 0 ok · 1 guard, substitution or value check failed (nothing written) · 2 usage/environment error (D9). `--help` via argparse. Idempotent: a re-render with the same inputs gives a byte-identical file and no diff output.
3. Wire it up (T4 does the actual calling). Invocation pattern, so that values live only in the child's environment:
   ```bash
   NTS_MPT_API_KEY="$(secret nts.mpt.api_key)" \
   NTS_OPENAI_STORY_KEY="$(secret nts.openai.story)" \
   NTS_OPENAI_IMAGE_KEY="$(secret nts.openai.image)" \
   NTS_PROXY_API_KEY="$(secret nts.proxy.api_key)" \
     uv run --no-project --python 3.12 "$REPO/worker-node/bin/render-mpt-config.py"
   ```
4. Placement cross-check against the pin (manual, once per pin): for every key in the template,
   ```bash
   for k in log_level listen_host listen_port api_key video_source pexels_api_keys pixabay_api_keys \
            openai_image_base_url openai_image_api_keys openai_image_model openai_image_size \
            openai_image_prompt_template llm_provider openai_api_key openai_base_url openai_model_name \
            subtitle_provider enable_redis max_concurrent_tasks upload_post_enabled upload_post_api_key \
            upload_post_auto_upload model_size device compute_type base_url model_id voices; do
     printf '%-30s ' "$k"; grep -nE "^[# ]*$k\s*=" worker-node/mpt/config.example.pinned.toml | head -3 | tr '\n' ' '; echo
   done
   ```
   Then check each line number against the section headers from T1 step 8 (top level < 20 < `[app]` keys < 506 < `[whisper]` keys < … < 582 < `[kokoro]` keys). `base_url`/`api_key` appear in several sections; match the one after `[kokoro]`. Mismatch → fix the template and record it in the PR.

## Failure handling
- A key is missing from the pinned example (renamed upstream) → do not guess: record ⚠️ in plan §2, raise to 05.1.1 (upgrade-diff owner), keep the guard failing until resolved.
- `tomllib` parse error after substitution → template bug (quoting); the value regex prevents key-caused breaks.
- MPT ignores `log_level` or logs prompts at INFO ⚠️ → keep INFO, add a note to the privacy row in plan §8; never DEBUG during measured runs.
- Config-drift diff seen during a measured run → mark the run `issues` "config drift" and re-run.
- Rollback: `rm -f "$NTS_HOME/src/mpt/config.toml" "$NTS_HOME/mpt-config.last.redacted.toml"`; do not start MPT without a rendered config (F07).
