# 01.2.2-T3 — Strip bundled music, record and install a CC0 placeholder

| Story | Size | Area | Depends on | Blocks | Gate |
|---|---|---|---|---|---|
| 01.2.2 | XS (0.25 d) | Worker | 01.2.2-T1 (checkout), 01.1.2-T1 (`worker-node/music/`, `.gitignore` audio rules F16) | 01.2.2-T4 (strip `--check`), T6, 05.3.1-T1 (CR-7), 05.3.2-T1 (05 CR-13), 01.3.3-T1 | 01-ready |

## Goal
MPT's bundled songs (unlicensed YouTube audio, DECISIONS §5.5, 05 F4) are gone from `resource/songs`, and `storage/bgm` is empty. The only background music MPT can pick at random is one CC0 placeholder track that has a licence record and a sha256. The strip runs again after every checkout.

## Inputs
- ✅ M6: songs dir `resource/songs`, uploads `storage/bgm`; random pick by extension `.mp3 .m4a .aac .wav .flac .ogg .opus .wma`; empty list → `no background music files found`, no music; defaults `bgm_type="random"`, `bgm_volume=0.2`. ⚠️ M6: the contents of `resource/songs` were not enumerated.
- DECISIONS §5.5 (delete all default music); F15 / CR-7 (05.3.1-T1 reuses this script as the build check); 05 FR-05-2 (licence fields).
- `bootstrap.sh mpt` (01.1.2-T3) calls `strip-bundled-music.sh` and expects exit 0 ok / 1 audio remains / 2 env error.
- Track choice: **BA pick ⚠️** (CC0 only, instrumental, ≥ 60 s, calm/ambient mood). This file names no track.

## Steps
1. **`worker-node/music/LICENSES.csv`** (tracked; RFC 4180, UTF-8, header exactly):
   ```
   file,title,artist,source_url,license,license_url,attribution,mood_tags,sha256,duration_s,loudness_lufs,added_at
   ```
   - `file`: basename used in `$NTS_HOME/music/` and `resource/songs/` (`[a-z0-9._-]+`, audio extension from M6).
   - Required columns (from the brief): `title, artist, source_url, license, license_url, sha256, duration_s, added_at`. Added to match 05 FR-05-2: `attribution` (may be `n/a:cc0`), `mood_tags` (`;`-separated), `loudness_lufs` (from step 4, or `n/a:<reason>`). 05.3.2 extends the file without renaming columns (05.3.2-T1 appends `track_id,platform_scope,evidence_url,retrieved_at`; every CSV row, active or not, is installed by `install-music.sh`, 05 T4) (05 CR-5).
   - `license`: `CC0-1.0` only for the placeholder. `sha256`: lowercase hex of the audio file. `duration_s`: 1 decimal. `added_at`: ISO-8601 UTC.
   - The BA saves the licence page or proof (URL + retrieval date) in the PR description.
2. **Audio stays out of git.** The source file goes to `$NTS_HOME/music/<file>`, outside the repo. The repo `.gitignore` (01.1.2-T1, F16) must ignore `*.mp3 *.m4a *.aac *.wav *.flac *.ogg *.opus *.wma` everywhere; check with `git check-ignore -q worker-node/music/x.mp3` → exit 0. If a rule is missing → request to 01.1.2-T1 (do not edit `.gitignore` here).
3. **`worker-node/bin/strip-bundled-music.sh`** (D9: `set -euo pipefail`, `--help`, idempotent, shellcheck clean; sources `lib.sh`):
   - Usage: `strip-bundled-music.sh [--check] [--mpt-root DIR]`. Default root `$(nts_home)/src/mpt`.
   - Env checks → exit 2: the root has no `main.py`, or no `resource/` dir.
   - Allowed set = the `sha256` column of `worker-node/music/LICENSES.csv` (parsed with `uv run --no-project --python 3.12 python -c` + `csv`, so quoted commas are handled; with no CSV the allowed set is empty).
   - Scan `resource/songs` and `storage/bgm` (`find … -type f` plus `-type l`), case-insensitive, for the M6 extensions and also `*.mp4 *.webm *.aiff *.aif` (defensive [DECISION]). A symlink is always removed. A regular file is kept only if its `shasum -a 256` is in the allowed set **and** it lives in `resource/songs`. `storage/bgm` must end up empty of audio.
   - Default mode deletes (`rm -f --`) and logs `removed <relpath>` per file and a final `strip: removed N, kept M (licensed)`. `--check` deletes nothing, lists offenders and exits 1 if any.
   - Exit 0 when no unlicensed audio remains after the run. `mkdir -p storage/bgm` so the dir exists (empty).
   - Never touch `models/`, `storage/tasks/` or `config.toml`: deletion is scoped to `resource/songs` and `storage/bgm` by the extension list only. Never run `git clean` (least of all `-fdX`) (01.2.3 plan §7). After a strip run, `fetch-whisper-model.sh --verify` (01.2.3-T1) must still exit 0.
   - Git noise: the deleted tracked files make `git status` in `$NTS_HOME/src/mpt` show `D resource/songs/…`. That is expected and not a pin violation (T1 filter).
4. **Placeholder QA (BA/dev, once):**
   ```bash
   f="$NTS_HOME/music/<file>"
   shasum -a 256 "$f"
   ffprobe -v error -show_entries format=duration:stream=codec_name,sample_rate,channels -of json "$f"
   ffmpeg -hide_banner -nostats -i "$f" -af loudnorm=print_format=summary -f null - 2>&1 | grep 'Input Integrated'
   ```
   Write sha256, duration and loudness into the CSV row.
5. **`worker-node/bin/install-music.sh`** (D9):
   - Usage: `install-music.sh [--mpt-root DIR] [--source DIR]`. Default source `$(nts_home)/music`.
   - For each CSV row: the source file must exist (else exit 1 `missing <file>`) and its sha256 must equal the row (else exit 1 `hash mismatch <file>`). Copy with `install -m 0644 "$src" "$root/resource/songs/<file>"`. Skip if the target already exists with the same hash (idempotent).
   - Then run `strip-bundled-music.sh --check --mpt-root "$root"` → propagate its exit code.
   - Exit 2 on a missing CSV header or a missing root.
6. **Order after every checkout, bootstrap or upgrade:** `bootstrap.sh mpt` (calls strip) → `install-music.sh` → `strip-bundled-music.sh --check`. The API start script (T4) runs `strip-bundled-music.sh --check` before starting and refuses on exit 1 (request recorded in T4).

## Outputs
- Tracked: `worker-node/music/LICENSES.csv` (header + 1 placeholder row), `worker-node/bin/strip-bundled-music.sh`, `worker-node/bin/install-music.sh`.
- `$NTS_HOME/music/<file>` (untracked source); `$NTS_HOME/src/mpt/resource/songs/<file>` (the only song); `$NTS_HOME/src/mpt/storage/bgm/` (empty).

## Failure handling
- No suitable CC0 track yet (BA pick pending) → the CSV holds the header only; the wiring render (T6) runs with `bgm_type=""` ⚠️ (or random over an empty list → no music, M6) and records the issue via `finish_run.py … --issue bgm-placeholder-missing` (01.3.1-T3). Not a blocker for T4/T5.
- MPT at the pin reads music from another dir or extension list ⚠️ → update the scan list here and in 05.3.1 (CR-7) together.
- Anything that lands in `storage/bgm` (no WebUI in M0, D14) → strip removes it at the next start (by design).
- Rollback: `bootstrap.sh mpt` recreates the checkout (songs return with a fresh checkout, then strip removes them again). The CSV row can be removed with a normal commit.
