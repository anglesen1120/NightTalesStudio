# 01.2.2-T6 — Wiring render (cheapest end-to-end, calibration run)

| Story | Size | Area | Depends on | Blocks | Gate |
|---|---|---|---|---|---|

## Goal
One short English landscape video goes through the whole chain: MPT API → tap → OpenAI terms + images → proxy → VieNeu → whisper → MoviePy. It runs inside a measurement run with `run_status=calibration`. The result is a playable MP4 with video and audio, tap usage lines for chat and images, a subtitle file, no silently skipped images, and one sheet row from `finish_run.py`.

## Inputs

- 05 §5.2 (`VideoParams` field names ✅ `schema.py:106-160`) and 05 §5.3 (`POST /api/v1/videos` route ✅, body ✅, prefix ⚠️; task query ⚠️ → not used).
- D3 `nts.mpt.api_key`, `nts.proxy.api_key`; D4 ports 8000/8001/8002/8080; D6 `trial/runs/<run_id>/openai_usage.jsonl`; D8 sheet; D10 run id; D11 idle machine.

## Steps
1. **Fixture** `trial/fixtures/wiring-en.txt` (tracked): a neutral English text of about 80–110 words (≈ 30–45 s of speech), plain prose, no names of real people, no brand names, 4–6 sentences, each with a concrete visual noun (for the terms LLM). Topic: a quiet night walk through an old town. Record `wc -w`.
2. **Pre-flight** (all must pass; each is exit 0 or a listener):
   ```bash
   for p in 8000 8001 8002 8080; do lsof -nP -iTCP:$p -sTCP:LISTEN | grep -q "127.0.0.1:$p" || echo "MISSING $p"; done
   worker-node/bin/smoke.sh                        # VieNeu + MPT smoke + binds → exit 0
   test -f "$NTS_HOME/src/mpt/models/whisper-large-v3-turbo/model.bin"   # 01.2.3-T1
   ls "$NTS_HOME"/src/mpt/resource/songs/ | wc -l  # 1 (placeholder) or 0 (see failure handling)
   ```
   Close heavy apps (D11). Start order, one terminal each: VieNeu (01.2.1-T2 script) → proxy (04.1.2) → tap (01.3.1-T2) → `worker-node/bin/start-mpt-api.sh`.
3. **Pick the voice** from `seed/voices.v1.json` (04 D9; the MPT API never reads the voice list, 04 M6) (04 CR-6):
   ```bash
   uv run --no-project --python 3.12 python -c 'import json; d=json.load(open("seed/voices.v1.json", encoding="utf-8")); print("\n".join(v["id"] for v in d["voices"] if v["language"] == "en" and v["active"]))'
   ```
   Choose one listed `en` id (revision 0: `Ngọc Huyền`, 04 D9; all presets are Vietnamese regional speakers, English quality ⚠️ 04 O2) (04 CR-6). `VOICE="kokoro:<id>"`. The id must not end in `-Female`/`-Male` (04 F5).
4. **Start the run:**
   ```bash
   RUN_ID="$(trial/tools/start_run.sh en landscape "wiring render: night walk" 1 --status calibration --voice "$VOICE" --story-source plan02)"   # script supplied, not MPT-written
   cat "$NTS_HOME/current_run"          # == $RUN_ID (D10 form YYYYMMDD-HHMM-en-landscape-NN)
   ```
5. **Submit** (body fields from 05 §5.2; `video_terms` is **omitted** so MPT generates terms with the LLM, which gives at least one chat call through the tap for 01.3.1-T4 story token calibration; the script is given, so the script LLM is skipped ⚠️ confirm at the pin):
   ```bash
   BODY="$(uv run --no-project --python 3.12 python - "$VOICE" <<'PY'
   import json, sys, pathlib
   print(json.dumps({
     "video_subject": "A quiet night walk through an old town",
     "video_script": pathlib.Path("trial/fixtures/wiring-en.txt").read_text().strip(),
     "video_aspect": "16:9",          # ⚠️ VideoAspect enum value for landscape (05 §5.2)
     "video_source": "openai_image",
     "video_count": 1,
     "video_language": "en",          # ⚠️ accepted format at the pin
     "voice_name": sys.argv[1],
     "bgm_type": "random",            # placeholder track (T3) or none
     "subtitle_enabled": True
   }))
   PY
   )"
   MK="$(security find-generic-password -a "$USER" -s nts.mpt.api_key -w)"
   curl -sS -X POST http://127.0.0.1:8080/api/v1/videos \
     -H @<(printf 'x-api-key: %s\n' "$MK") -H 'Content-Type: application/json' \
     --data-binary "$BODY" | tee "$NTS_HOME/runs/$RUN_ID/submit-response.json"
   unset MK
   TASK_ID="$(uv run --no-project --python 3.12 python -c 'import json,sys;d=json.load(open(sys.argv[1]));print(d.get("data",d)["task_id"])' "$NTS_HOME/runs/$RUN_ID/submit-response.json")"   # ⚠️ field name (05.4)
   ```
   `mkdir -p "$NTS_HOME/runs/$RUN_ID"` first if `start_run.sh` did not create it.
6. **Wait for completion from the log** (the task-query route is ⚠️ 05.4). Poll up to 30 min:
   ```bash
   LOG="$(ls -t "$NTS_HOME"/logs/mpt-api-*.log | head -1)"
   timeout 1800 bash -c "until grep -qE 'task $TASK_ID finished|task failed, task_id: $TASK_ID' '$LOG'; do sleep 5; done"
   grep -E "task $TASK_ID finished|task failed, task_id: $TASK_ID" "$LOG"
   ```
   (`timeout` is GNU coreutils ⚠️; if absent, use a bounded `for i in $(seq 360)` loop.)
7. **Finish the run** (the collector parses the log and the tap JSONL, stops the sampler, appends the row):
   ```bash
   uv run --no-project --python 3.12 trial/tools/finish_run.py "$RUN_ID" --task-id "$TASK_ID" \
     --mpt-log "$LOG" --script trial/fixtures/wiring-en.txt
   ```
8. **Checks** (record every result in `trial/runs/$RUN_ID/notes.md`):
   ```bash
   OUT="$(grep -oE "## generating video: [0-9]+ => .*\.mp4" "$LOG" | tail -1 | sed 's/.*=> //')"    # M9; else:
   [ -n "$OUT" ] || OUT="$(ls -t "$NTS_HOME/src/mpt/storage/tasks/$TASK_ID"/*.mp4 | head -1)"          # ⚠️ file name
   ffprobe -v error -show_entries stream=codec_type,codec_name,width,height:format=duration -of json "$OUT"
   ffmpeg -v error -i "$OUT" -f null - ; echo "decode exit $?"                  # full decode = "plays"
   U="trial/runs/$RUN_ID/openai_usage.jsonl"
   grep -c '"endpoint": *"[^"]*chat/completions' "$U"; grep -c '"endpoint": *"[^"]*images/generations' "$U"
   grep -c '"usage": *null' "$U"                                                   # usage missing (O6 "may be absent")
   grep -c 'openai image generation failed' "$LOG"                                 # skipped keywords (M4)
   grep -E 'subtitle file created: ' "$LOG" | tail -1                              # M9
   grep -E "detected language: '" "$LOG" | tail -1                                 # M3
   grep -E 'loading model: .*whisper-large-v3-turbo' "$LOG" | tail -1              # 01.2.3 offline path
   grep -c 'no background music files found' "$LOG"                                # 0 if placeholder installed
   ```
   `open "$OUT"` → watch once: images change, speech is audible and English, subtitles are visible, music is quiet under the voice.
9. **Cost ceiling and actual** (O8 prices; quality `auto` → the per-image token count is unknown, F03):
   - Chat (luna): `in_tokens × 0.10/1e6 + out_tokens × 0.50/1e6` from the tap lines. Expected < $0.001 [INFERENCE].
   - Images (flare): per line `text_in × 5/1e6 + image_in × 8/1e6 + out × 30/1e6`.
   - **Pre-run ceiling [INFERENCE]:** images ≤ 15 (≈ 45 s / ~3 s per clip; ✅ MPT's per-job default `video_clip_duration` is 5 s → ≈ 9 images, so 15 stays a safe ceiling; 03 CR-8) × 10,000 output tokens (pessimistic placeholder, not a measured value) × $30/1M = **$4.50**. This is below the project hard limit of $25 (D7). Abort the run (Ctrl-C the API) if the tap shows more than 20 image calls.
   - Record the actual totals and the `response.quality` echoed per image (D6) → input to CR-3.

## Failure handling

| Symptom | Likely cause | Action |
|---|---|---|
| `POST` → 401 | wrong key read | re-run `smoke-mpt.sh` |
| `POST` → 400 `field required` (MPT answers every validation error with 400 and this fixed message, never 422; unknown fields are ignored silently — 05 README C5) (05 CR-5) | field name or enum differs at the pin (e.g. `video_aspect`) ⚠️ | read `/openapi.json` `VideoParams`, fix the body, note it for 05.4 |
| `task failed … stage: terms`/script | tap down, key or allow-list (O3/O4), `project_spend_limit_exceeded` (O1) | check the tap JSONL `error_code`; fix in 01.2.4 / 01.3.1 |
| `openai image generation failed` > 0 | 429 Tier 1 (5/min, O8), org verification (O5), allow-list | the run is **invalid**; note the count; wait for verification, or re-run after 1 min; if 429s repeat, raise to 03 (rate pacing) |
| Audio stage fails / 120 s timeout | VieNeu RTF (F01), proxy error | check the proxy log (04, CR-1); the fixture is short, so a timeout here means 01.2.1-T4 gate failure |
| No subtitle file / `loading model` shows a download | model missing, offline mode | 01.2.3-T1 `--verify` |
| `detected language` ≠ `en` | misdetection (M3) | record it; CR-5 input |
| No `task … finished` after 30 min | hang | Ctrl-C the API, keep the log, `finish_run.py` with the failed status per 01.3.1 ⚠️ |
| No `en` id in `seed/voices.v1.json` / `voice_name` rejected (proxy 400) | catalog entry missing or not in the proxy allow-list (04 D9) | fix the catalog file (04.1.2-T1 / 04.2.2-T1); do not list voices by hand in the template (CR-8) (04 CR-6) |
| Placeholder missing (T3 pending) | BA pick not done | run with the empty songs dir (no music, M6); pass `finish_run.py … --issue bgm-placeholder-missing` (col 31 `issues` is never `n/a`, 01.3.1-T1) |

Rollback: nothing to undo in config. Delete `$NTS_HOME/src/mpt/storage/tasks/<task_id>` after the media are copied to `$NTS_HOME/runs/<run_id>/`. A failed calibration row stays in the sheet (marked by `finish_run.py`, D8); re-run with a new `run_id`.
