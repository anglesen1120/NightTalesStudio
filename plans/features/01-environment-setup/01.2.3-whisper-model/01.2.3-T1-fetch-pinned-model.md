# 01.2.3-T1 — Fetch pinned whisper model into MPT lookup dir + offline proof

| Story | Size | Area | Depends on | Blocks | Gate |
|---|---|---|---|---|---|
| 01.2.3 | XS | Worker | 01.1.1-T2, 01.1.2-T3, 01.2.2-T1, 01.2.2-T4 | 01.2.2-T6, 01.2.3-T2, 01.3.3-T1, 05.4.1-T1 (05 CR-13) | 01-ready |

## Goal
`large-v3-turbo` at a pinned revision sits in `$NTS_HOME/src/mpt/models/whisper-large-v3-turbo/` with recorded sha256s, and MPT loads it with `HF_HUB_OFFLINE=1` (no hub call).

## Inputs
- ✅ M3 lookup path `<mpt_root>/models/whisper-<model_size>/model.bin`; log `loading model: …`. ✅ M1 / D5 guard `whisper.model_size == "large-v3-turbo"`. ✅ M7 `faster-whisper==1.1.0`. ✅ W1 repo `mobiuslabsgmbh/faster-whisper-large-v3-turbo`.
- `worker-node/pins.env`: `WHISPER_MODEL_REPO`, `WHISPER_MODEL_REVISION` (D2), `MPT_COMMIT`.
- MPT clone + venv at `$NTS_HOME/src/mpt` (01.2.2-T1); `lib.sh` (01.1.2-T2). No secrets.

## Steps
1. Verify the pin (01.1.1-T2 fills `WHISPER_MODEL_REVISION` with the real 40-hex SHA; `load_pins` rejects anything else, so no placeholder case exists). Cross-check that the revision exists upstream:
   `uv run --project "$NTS_HOME/src/mpt" python -c 'import os; from huggingface_hub import HfApi; print(HfApi().model_info(os.environ["WHISPER_MODEL_REPO"], revision=os.environ["WHISPER_MODEL_REVISION"]).sha)'` (run with pins exported) → prints the same SHA; 404 → see Failure handling. Read the model card licence at that revision ⚠️; record it.
2. Check upstream ignore: `git -C "$NTS_HOME/src/mpt" check-ignore -v models/whisper-large-v3-turbo/model.bin` → expected a match ⚠️; if no match, add `models/` to `$NTS_HOME/src/mpt/.git/info/exclude` (local only, no fork) so `git status` stays clean.
3. Specify `worker-node/bin/fetch-whisper-model.sh` (D9: `set -euo pipefail`, `--help`, `--verify`, exit 0/1/2, sources `lib.sh`, `load_pins`):
   - `DEST="$(nts_home)/src/mpt/models/whisper-large-v3-turbo"`; `SUMS="$REPO_ROOT/worker-node/mpt/whisper-large-v3-turbo.sha256"`.
   - If `$SUMS` exists and `(cd "$DEST" && shasum -a 256 -c "$SUMS")` passes → log "ok, verified", exit 0 (idempotent, no network).
   - `--verify` → only the check above; missing file/mismatch → exit 1.
   - Else download to `"$DEST.tmp"`:
     `uv run --project "$(nts_home)/src/mpt" hf download "$WHISPER_MODEL_REPO" --revision "$WHISPER_MODEL_REVISION" --local-dir "$DEST.tmp"`
     fallback if `hf` missing ⚠️: `uv run --project … huggingface-cli download "$WHISPER_MODEL_REPO" --revision "$WHISPER_MODEL_REVISION" --local-dir "$DEST.tmp"`.
     (If neither entry point exists in MPT's venv, `uv run --no-project --with huggingface_hub hf download …`.)
   - Remove `"$DEST.tmp/.cache"` (hub metadata), require `model.bin`, then: if `$SUMS` exists verify against it (mismatch → exit 1, keep `.tmp` for inspection); else write it: `(cd "$DEST.tmp" && find . -type f ! -path './.cache/*' | sed 's|^\./||' | LC_ALL=C sort | xargs shasum -a 256) > "$SUMS"`.
   - `mv "$DEST.tmp" "$DEST"` (after `rm -rf "$DEST"` only when the old dir failed verification).
   - Never set `HF_TOKEN`; public repo.
4. Run it: `worker-node/bin/fetch-whisper-model.sh`; commit `worker-node/mpt/whisper-large-v3-turbo.sha256`.
5. Survive strip/bootstrap: bootstrap does not download weights (01.1 contract: `bootstrap.sh [mpt|vieneu|all]` = clone, `git checkout --detach $PIN`, `uv sync --frozen`, then `strip-bundled-music.sh`). Run `worker-node/bin/bootstrap.sh mpt` again (which also runs `strip-bundled-music.sh`), then `fetch-whisper-model.sh --verify` → exit 0 (untracked `models/` must survive the detach checkout and the strip). Runbook order (request to 01.1 owner for `worker-node/README.md`): `bootstrap.sh mpt` → `fetch-whisper-model.sh`.
6. Offline proof: start MPT API with `HF_HUB_OFFLINE=1` exported (01.2.2-T4 start script; fallback `cd "$NTS_HOME/src/mpt" && HF_HUB_OFFLINE=1 uv run python main.py`). Submit a subtitle-producing job on a short sample (e.g. the cheapest wiring request of 01.2.2-T5/T6, or a direct call of MPT's subtitle service on a 01.2.1-T4 WAV ⚠️ exact entry point at pin). Then:
   `grep -n 'loading model' "$NTS_HOME"/logs/mpt-api-*.log | tail -1`
   `grep -c -E 'huggingface.co|Downloading|Fetching' "$NTS_HOME"/logs/mpt-api-*.log`
7. Write revision, licence, file list with sizes and sha256 into the carry-over notes (source for 01.3.3-T1).

## Outputs
- `$NTS_HOME/src/mpt/models/whisper-large-v3-turbo/` (untracked).
- Tracked: `worker-node/bin/fetch-whisper-model.sh`, `worker-node/mpt/whisper-large-v3-turbo.sha256`. `WHISPER_MODEL_REVISION` in `pins.env` is written by 01.1.1-T2 and only verified here.
- Recorded: licence, size, log excerpt of the offline load (in `worker-node/README.md` runbook section, via 01.1 owner).

- [ ] `git -C "$NTS_HOME/src/mpt" status --porcelain models/` → empty.
- [ ] Offline log: last `loading model:` line contains `models/whisper-large-v3-turbo`; hub-pattern count = 0; job finishes with `task <id> finished` (M9).
- [ ] `shellcheck worker-node/bin/fetch-whisper-model.sh` → clean; `--help` exit 0.

## Failure handling
- `hf` not found → `huggingface-cli`; both absent → `--with huggingface_hub`.
- Revision 404 → repo re-published; re-run the 01.1.1-T2 pin procedure (no hand edit of `pins.env`), delete `$SUMS`, re-fetch, note the change for CARRY-OVER.
- Checksum mismatch on re-download → stop; do not overwrite `$SUMS`; investigate (revision drift or corrupt transfer).
- MPT logs model name instead of path / tries download offline → lookup path differs at pin ⚠️; read `app/services/subtitle.py` at `MPT_COMMIT`, adjust `DEST`, never patch MPT.
- Disk < 5 GB free → stop.
- Rollback: `rm -rf "$DEST"` and re-run.
