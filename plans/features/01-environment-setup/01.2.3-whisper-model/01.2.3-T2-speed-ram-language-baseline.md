## Goal
`trial/baselines/whisper-mac-<YYYYMMDD>.json` holds wall time, RTF, peak RSS and detected language + probability for vi and en samples, using exactly MPT's parameters.

## Inputs
- ✅ M3 params: `beam_size=5`, `word_timestamps=True`, `vad_filter=True`, `vad_parameters={"min_silence_duration_ms":500}`, no `language`. ✅ M1 `device="cpu"`, `compute_type="int8"`. ✅ W1 no Metal.
- Model dir from T1; MPT venv (`faster-whisper==1.1.0`, M7).
- Samples from 01.2.1-T4 (`$NTS_HOME/runs/samples/vieneu-<lang>-<fixture>.wav`): `vieneu-vi-1000.wav`, `vieneu-en-1000.wav` (~60 s each [INFERENCE]) and `vieneu-vi-5min.wav`, `vieneu-en-5min.wav` if produced. Exact names as recorded in the 01.2.1 baseline `samples[].path`.

## Steps
1. Write throwaway `$NTS_HOME/runs/whisper-baseline/bench.py` (not committed):
   ```python
   import sys, time, json, faster_whisper, ctranslate2
   from faster_whisper import WhisperModel
   t0=time.time(); m=WhisperModel(sys.argv[1], device="cpu", compute_type="int8"); load=time.time()-t0
   t1=time.time()
   segs, info = m.transcribe(sys.argv[2], beam_size=5, word_timestamps=True,
                             vad_filter=True, vad_parameters=dict(min_silence_duration_ms=500))
   segs=list(segs); tr=time.time()-t1
   print(json.dumps({"file":sys.argv[2],"audio_s":info.duration,"load_s":load,"transcribe_s":tr,
     "rtf":tr/info.duration,"lang_detected":info.language,"lang_prob":info.language_probability,
     "segments":len(segs),"faster_whisper":faster_whisper.__version__,"ctranslate2":ctranslate2.__version__}))
   ```
   (Generator must be consumed — transcription is lazy.)
2. Per sample, idle machine (D11), one process:
   `HF_HUB_OFFLINE=1 /usr/bin/time -l uv run --project "$NTS_HOME/src/mpt" python bench.py "$NTS_HOME/src/mpt/models/whisper-large-v3-turbo" <wav> 2> time-<name>.txt > out-<name>.json`
   Peak RSS = `maximum resident set size` in `time-*.txt` (bytes on macOS) ÷ 1048576; wall = `real`. Note: includes the `uv` wrapper; acceptable here (single process).
3. Optional: repeat `vieneu-vi-1000.wav` with `OMP_NUM_THREADS=4` and `=10`; record in `notes`.
4. Merge into `trial/baselines/whisper-mac-<YYYYMMDD>.json` (shape in plan.md §3) with `model_revision` from `pins.env`.
5. Language: if vi sample ≠ `vi` or prob < 0.8 → flag in `notes` and in the CR-5 handoff to 05; note `[whisper] initial_prompt` ⚠️ (existence at `MPT_COMMIT` unconfirmed) as the candidate mitigation. Do not change MPT config here.
6. Compare RAM with 16 GB budget (R1): record whether whisper peak + VieNeu idle RSS (01.2.1-T4) fits alongside the render.

## Outputs
- Tracked: `trial/baselines/whisper-mac-<YYYYMMDD>.json`.
- Untracked: `$NTS_HOME/runs/whisper-baseline/` (script, raw outputs).

## Acceptance checks
- [ ] `python3 -m json.tool trial/baselines/whisper-mac-*.json` → exit 0.
- [ ] ≥ 1 vi and ≥ 1 en sample, each with `wall_s`, `rtf`, `peak_rss_mb`, `lang_detected`, `lang_prob` non-null.
- [ ] `params` equals M3 values; `language` null; `model_revision` equals `WHISPER_MODEL_REVISION`.
- [ ] Run was offline (`HF_HUB_OFFLINE=1`) and succeeded.
- [ ] Misdetection (if any) written in `notes` and sent as CR-5 input.

## Failure handling
- OOM / swap heavy (Activity Monitor memory pressure red) → record, stop; raise R1 to 01.3.2.
- Import error → run inside MPT project only (`uv run --project`); never `pip install` elsewhere.
- 5-min sample missing → record `n/a:not-produced-in-01.2.1-T4`.
- RTF > 1 → record; it is a Mac baseline (R4), not a blocker.
