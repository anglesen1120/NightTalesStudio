## Goal
One command starts a measured run (run id, manifest, sampler) and one command turns the finished MPT task into exactly one complete, validated row in `trial/measurements.csv` plus per-run evidence files in `trial/runs/<run_id>/` (F02, F04, F20, F22, D8).

- ✅ M9 log format and markers; ✅ M3 whisper lines; ✅ M4 `openai image generation failed`; ✅ M5 chat retries; ✅ O6 usage fields; ✅ O8 prices via `trial/prices.json`.

- 01.1.1-T1: `worker-node/bin/env-versions.sh` → one JSON object on stdout (BaseToolingPlan contract, plan.md §2).

## Steps

### A. `trial/tools/start_run.sh`
`trial/tools/start_run.sh <lang> <aspect> "<topic>" <target_minutes> [--status calibration|trial] [--voice <name>] [--story-source mpt|plan02] [--no-tap]` (args agreed with MptPlan for 01.2.2-T6).

1. Validate: `lang ∈ {vi,en}`, `aspect ∈ {landscape,portrait}`, `target_minutes` decimal 0.5–30, topic 1–200 chars without newline, `--status` default `trial`, `--story-source` default `mpt`. Bad → exit 2.
2. Refuse if `$NTS_HOME/current_run` exists → exit 2 `run <id> active; finish or --abort it` (I3).
3. Services up (D4): `lsof -nP -t -iTCP:<port> -sTCP:LISTEN` for 8000, 8001, 8080 must return a pid; 8002 too unless `--no-tap` → else exit 2 naming the port. 8501 optional. For 8002 specifically (NTS01-SEC-04): also read `$NTS_HOME/tap.json` and assert its `pid` equals the pid `lsof` returned for 8002; mismatch → exit 2 "port 8002 is not the usage tap" (some other process is squatting on the tap's port).
4. Pins: `load_pins` (lib.sh); `git -C "$NTS_HOME/src/mpt" rev-parse HEAD` = `MPT_COMMIT`, `git -C "$NTS_HOME/src/vieneu" rev-parse HEAD` = `VIENEU_COMMIT` → else exit 1.
5. Config points at the tap: `run_manifest.py --check-tap` reads `$NTS_HOME/src/mpt/config.toml` with `tomllib` and asserts `app.openai_base_url` and `app.openai_image_base_url` = `http://127.0.0.1:8002/v1` (skipped with `--no-tap`, which instead asserts they are not the tap) → exit 1.
6. Run id (D10): `base="$(date +%Y%m%d-%H%M)-$lang-$aspect"`; `nn` = 01 + count of existing `trial/runs/$base-*` dirs (2 digits). Local time in the id [DECISION: matches the owner's clock; `started_at` in UTC is authoritative].
7. `mkdir trial/runs/$id "$NTS_HOME/runs/$id"` (fail if exists).
8. `uv run --no-project --python 3.12 trial/tools/run_manifest.py start --run-id "$id" --lang … --aspect … --topic … --target-minutes … --status … --voice … --story-source … [--no-tap]` → writes `trial/runs/$id/run.json` (plan.md §3 shape).
9. `printf '%s\n' "$id" > "$NTS_HOME/current_run.tmp" && mv "$NTS_HOME/current_run.tmp" "$NTS_HOME/current_run"` (atomic; the tap reads it per request).
10. Start sampler: `nohup trial/tools/rss_sampler.sh "$id" >"$NTS_HOME/runs/$id/rss_sampler.log" 2>&1 &`; wait ≤ 3 s for `$NTS_HOME/runs/$id/rss_sampler.pid` → else roll back (remove `current_run`, exit 1).
11. Print only `$id` on stdout (callers do `RUN_ID="$(trial/tools/start_run.sh …)"`); human messages go to stderr via `log`.
12. `shellcheck` clean, `--help`, no `set -x`.

### B. `trial/tools/run_manifest.py` (stdlib)
- `start`: builds `run.json`:
  - `pins` from `worker-node/pins.env` (parsed line by line, D2 keys only); `heads` from `git rev-parse`.
  - `env` = `json.loads` of `worker-node/bin/env-versions.sh` stdout (exit ≠ 0 → exit 1 with its stderr).
  - `config`: read the rendered `config.toml` bytes; build a redacted copy by replacing the value of every key whose name matches `(^|_)(api_key|api_keys|key|secret|token|password)$` (TOML line regex `^\s*([A-Za-z0-9_]+)\s*=\s*(.+)$` inside the current `[table]`) with `"<redacted>"`; `sha256_redacted` = sha256 of the redacted text; `redacted_keys` = dotted names; `template_sha256` = sha256 of `worker-node/mpt/config.template.toml`; `settings` = allow-listed non-secret keys (plan.md §3). The redacted text is **not** written anywhere.
  - `tap` = `$NTS_HOME/tap.json` content (or `{"disabled": true}` with `--no-tap`); `vieneu` = `VIENEU_PRECISION`, `VIENEU_MAX_STREAMS` parsed line by line from `worker-node/vieneu/env.example` (the file `start-vieneu.sh` reads, 01.2.1-T2; values only, not secret); `sampler` roots.
  - Paths stored with literal `$NTS_HOME` prefix.
- `--check-tap`: step A5.
- Write `run.json` atomically (tmp + `os.replace`), `indent=2`, `sort_keys=False`.

### C. `trial/tools/finish_run.py` (stdlib, Python 3.12)
CLI:
```
finish_run.py <run_id> --task-id <mpt task id> [--mpt-log P] [--proxy-log P] [--script P] [--output P]
              [--terms-count N] [--issue TEXT]... [--status failed] [--dry-run]
finish_run.py <run_id> --abort
finish_run.py <run_id> --dashboard-cost <usd> --dashboard-day <YYYY-MM-DD>
```
Defaults: `--mpt-log` = newest `$NTS_HOME/logs/mpt-api-*.log` whose mtime ≥ `run.json.started_at`; `--proxy-log` = newest `$NTS_HOME/logs/proxy-*.log` (Q8); `--output` = `$NTS_HOME/src/mpt/storage/tasks/<task_id>/final-1.mp4` (✅ Q2, CR-17); `--script` = `script` key of `…/tasks/<task_id>/script.json` (✅ Q2).

Processing order (each step writes nothing tracked until step 12):
1. Load `run.json`; assert `run_id` matches D10 and equals `$NTS_HOME/current_run` (else exit 2; `--dashboard-cost` exempt); assert `run_id` not yet in `measurements.csv` (I2) → exit 1.
2. Stop the sampler: `kill -TERM $(cat $NTS_HOME/runs/<id>/rss_sampler.pid)`; wait ≤ 5 s for exit (it writes the `all` row of `rss.csv` on TERM).
3. **MPT log parser** (`parse_mpt_log(path, task_id, started_at) -> Stages`):
   - Strip ANSI (`\x1b\[[0-9;]*m`).
   - Header regex (M9): `^(?P<ts>\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}) \| (?P<level>[A-Z]+)\s*\| "(?P<src>[^"]+)": (?P<func>\S+) - (?P<msg>.*)$` ⚠️ confirm padding of `LEVEL` and the separator against the real log in T4.
   - 01 CR-17: split records at **every** header match (records can be glued mid-line in the tee'd log); also accept loguru's default form `YYYY-MM-DD HH:MM:SS.mmm | LEVEL    | module:func:line - msg` (early startup lines).
   - Lines not matching the header are continuation lines → appended to the previous record's `msg` with `\n` (markers are logged as `"\n\n## …"`, M9).
   - Local time → UTC with the machine TZ (`datetime.astimezone()`); record `tz_offset` in `stages.json`.
   - Task scoping: take records with `ts ≥ started_at − 5 s`; the task's first record is the first marker after that; end = `task <task_id> finished` or `task failed` containing `task_id: <task_id>` (M9); records after end ignored. No end record → exit 1 unless `--status failed`.
   - Markers (constant `MARKERS`, versioned `MARKER_SET = 1`):

     | Key | Regex on `msg` |
     |---|---|
     | `script` | `^\s*## generating video script` |
     | `terms` | `^\s*## generating video terms` |
     | `audio` | `^\s*## generating audio` |
     | `audio_end` | `AUDIO_END_RE` ⚠️ Q1 — `None` until T4 sets it |
     | `subtitle` | `^\s*## generating subtitle` (first) |
     | `materials` | `^\s*## downloading videos from (?P<source>\S+)` |
     | `combine` | `^\s*## combining video: \d+ =>` (01 CR-17; `task.py:920`) |
     | `final` | `^\s*## generating video: \d+ =>` (01 CR-17; `task.py:999`) |
     | `finished` | `task (?P<id>\S+) finished` |
     | `failed` | `task failed, task_id: (?P<id>[^,\s]+), stage: (?P<stage>[^,\s]+)` (✅ `task.py:267`, CR-17) |
   - Windows: each present stage runs from its marker to the next present marker (`audio` ends at `audio_end` if set); `total` = first marker → end. Stages absent → `n/a:marker-missing` except `script` with `story_source = plan02` (Q9) → `n/a:story-source-plan02`.
   - Counts in the window: `image_failed` = `openai image generation failed` (M4); `image_rendered` = `image material rendered:` ⚠️; whisper `detected language: '(?P<l>\w+)', probability: (?P<p>[\d.]+)` and `complete, elapsed: (?P<s>[\d.]+) s` (M3); terms list = first continuation after `terms` marker matching `completed:` → `ast.literal_eval` of the `[...]` part → `terms_count`.
   - Output `stages.json`: `{"marker_set":1,"tz_offset":"+07:00","task_id":…,"windows":{"script":{"start":…,"end":…,"seconds":…},…},"total_seconds":…,"counts":{…},"whisper":{"language":…,"probability":…,"elapsed_s":…},"coverage":{"first_marker":…,"end":…,"gaps_seconds":0}}` — `gaps_seconds` = total − Σ windows (must be 0 by construction; T4 checks).
4. **Tap JSONL** (`trial/runs/<id>/openai_usage.jsonl`): aggregate per dictionary cols 8–18, 39–48 (chat = `/chat/completions`, image = `/images/generations`). Model price lookup: exact key or key + `-YYYY-MM-DD` suffix; else `n/a:no-price`. `--no-tap` → all tap columns `n/a:no-tap`. Image lines with `via = "responses"` → `image_cost_usd = n/a:no-price` (01 DEC-11, CR-17); tokens still summed. NTS01-SEC-10: while scanning, any line with `http_status = 401` or `model = null` on a `/chat/completions`/`/images/generations` endpoint adds issue `tap-foreign-call` (MPT always sends a valid key and a `model`; such a line is excluded from the cost/token sums so a foreign caller cannot inflate them) and any line with `error_code = "tap_busy"` adds issue `tap-busy`.
5. **Proxy log** (CR-1): lines with `ts` in the `audio` window and `status = 200` → `tts_seconds_audio`, `tts_wall_seconds`, `tts_chars`; `sources.tts = "proxy-log"`. Missing/unparseable → `ffprobe -v error -show_entries format=duration -of json` of `tasks/<task_id>/audio.mp3` ⚠️ Q2 → `sources.tts = "mpt-audio-ffprobe"`, wall from window; neither → `n/a:no-proxy-log`.
6. **Sampler**: read `$NTS_HOME/runs/<id>/rss_raw.csv`; per window max of the relevant root (dictionary cols 24–26, 52–54); window boundaries `[start, end)`; append per-stage rows to `trial/runs/<id>/rss.csv` (`scope=stage:<key>`).
7. **ffprobe**: `ffprobe -v error -print_format json -show_format -show_streams <output>` → `trial/runs/<id>/ffprobe.json` with `format.filename` replaced by its basename; cols 27–28.
8. **Script**: read text (UTF-8), NFC, word-count rule of T1 → cols 29–30; copy text to `$NTS_HOME/runs/<id>/script.txt` (0600) and the video to `$NTS_HOME/runs/<id>/final-1.mp4` (`cp -c` clone on APFS [INFERENCE]; plain copy fallback). Script text is never written under `trial/`.
9. **Derived**: cols 45, 46, 55, 56 per T1; `machine` from `run.json.env` (col 34).
10. **Issues** (col 31): collector codes from the closed vocabulary in `trial/schema.md` (01.3.1-T1; `story-cost-terms-only` is added whenever `story_source = plan02`, independent of the chat-line count) + `--issue` texts as `note:<text>` (`;` replaced by `,`, newlines → space), sorted, `;`-joined; `none` if empty. `validate_row` rejects a code outside the vocabulary.
11. **Validate** (`validate_row`): exactly `len(COLUMNS)` cells; header of `measurements.csv` == `COLUMNS` (I1); every cell non-empty; every `n/a` matches `^n/a:[a-z0-9-]+$` (I5); numbers parse and are ≥ 0; `run_status` enum; `dashboard_cost_usd_check` = `n/a:pending-dashboard`. Failure → exit 1, list of offending columns on stderr, **nothing written**.
12. **Write** (skipped with `--dry-run`, which prints the row as `name=value` lines): `stages.json`, `ffprobe.json`, `rss.csv` stage rows, `run.json` (`finished_at`, `mpt_task_id`, `run_status`, `sources`) via tmp + `os.replace`; append the row to `measurements.csv` with `csv.writer(lineterminator="\r\n")` under `fcntl.flock`; then `os.remove($NTS_HOME/current_run)`.
13. Print a 10-line summary (run id, status, total s, image count/cost, story cost, USD/min, peaks, issues).

`--abort`: stop sampler, set `run.json.run_status = "failed"` + `finished_at`, append `aborted <UTC ts>` to `trial/runs/<id>/notes.md`, remove `current_run`; no CSV row.

`--dashboard-cost`: locate the row by `run_id`; refuse unless the cell is `n/a:pending-dashboard` (exit 1); tap-day total = Σ of computed costs over **all** JSONL lines (every `trial/runs/*/openai_usage.jsonl` incl. `no-run`) whose `ts` falls in `--dashboard-day` (UTC, Q10); write the value (6 decimals) by rewriting the CSV to a temp file and `os.replace`; print `tap=<x> dashboard=<y> delta=<z>%`; delta > 5 % → append issue `dashboard-delta-<z>pct` to that row's `issues` too and exit 1 (value still written).

Constants in one place at the top of `finish_run.py`: `COLUMNS` (58 names, T1 order), `MARKERS`, `AUDIO_END_RE`, `NA_RE`, `HOP_TOLERANCE_S = 5`.

## Failure handling
- Marker regex misses in the real log → `--dry-run` shows `n/a:marker-missing`; fix regex in `MARKERS` + fixture, rerun (T4 owns this).
- `current_run` left behind after a crash → `finish_run.py <id> --abort`; the tap meanwhile logged into that run's JSONL (acceptable; noted).
- MPT task failed → `finish_run.py … --status failed` writes a row with `run_status = failed` and later stages `n/a:run-failed-at-<stage>` (the failure is data).
- Output/script path differs (Q2) → pass `--output`/`--script`; update defaults after T4.
- Validation fails → fix the input or code, rerun; never hand-edit `measurements.csv` (D8).
- Clock/TZ change during a run → windows wrong; abort and re-run.
