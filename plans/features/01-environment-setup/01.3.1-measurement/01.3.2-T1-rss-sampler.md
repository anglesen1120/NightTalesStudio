# 01.3.2-T1 — Process-tree RAM sampler (`rss_sampler.sh`)

| Story | Size | Area | Depends on | Blocks | Gate |
|---|---|---|---|---|---|
| 01.3.2 | XS | Worker | 01.1.2-T2 (`lib.sh`) | 01.3.1-T3, 01.3.1-T4 | 01-ready |

## Goal
A 1 s background sampler records the RSS of each service's whole process tree (VieNeu, proxy, MPT API incl. ffmpeg children; the `webui_*` columns stay in the schema and read 0 because the WebUI is not used in M0, D14), swap use and memory pressure for one run, so the collector can attribute peaks to MPT stage windows (F04).

## Inputs
- ✅ D4 ports: VieNeu 8000 · proxy 8001 · MPT API 8080 · MPT WebUI 8501 (tap 8002 not sampled — negligible [INFERENCE]).
- ✅ M3: whisper runs inside the MPT process → whisper vs render split only by stage window. MoviePy spawns ffmpeg children (F04) → tree sum needed.
- ✅ D1 (`$NTS_HOME/runs/<id>/` for raw data), D9 (bash conventions, no `sudo`), D10 run id, D11.
- `lib.sh`: `nts_home`, `log`, `die`.

## Steps
1. **Probe (once, record in `worker-node/README.md` sampler section):**
   - `ps -axo pid=,ppid=,rss=,comm= | head -3` — confirm RSS column is KiB (⚠️ Q7: compare one pid with Activity Monitor "Real Memory"/`top -l 1 -pid <pid> -stats pid,mem`).
   - `sysctl -n vm.swapusage` → e.g. `total = 2048.00M  used = 512.25M  free = 1535.75M  (encrypted)` (format ⚠️; parse `used = ([\d.]+)([MG])`).
   - `sysctl -n kern.memorystatus_vm_pressure_level` → `1` normal · `2` warn · `4` critical ⚠️ Q6; `memory_pressure | tail -1` → `System-wide memory free percentage: NN%` ⚠️ Q6. Both without `sudo`; if either is missing → that column `NA`.
2. **`trial/tools/rss_sampler.sh`** (bash, D9: `set -euo pipefail`, `shellcheck` clean, `--help`, no `sudo`, no `set -x`):
   ```
   rss_sampler.sh <run_id> [--interval 1] [--duration <s>]
   rss_sampler.sh --selftest <seconds>
   ```
   - Validate `run_id` (D10 regex); `OUT="$NTS_HOME/runs/$run_id"` must exist (created by `start_run.sh`); write `$OUT/rss_sampler.pid` (`$$`), remove it on exit (`trap … EXIT`).
   - Roots every 10 s (and at start): `pid_for_port() { lsof -nP -t -iTCP:"$1" -sTCP:LISTEN 2>/dev/null | head -1 || true; }` for 8000/8001/8080/8501 (`|| true` is required: under `set -euo pipefail` lsof exits 1 when nothing listens and would kill the loop). uv/uvicorn wrappers: if the listening pid's parent is a `uv` process, the root stays the listening pid (the tree sum below covers children; the wrapper parent is ≤ tens of MB and excluded [INFERENCE]).
   - Loop every `--interval` s (target, not drift-corrected; timestamp each sample):
     - `snap="$(ps -axo pid=,ppid=,rss=,comm=)"` once per tick; one `awk` pass builds children lists and sums RSS for each root's tree (root + all descendants, recursive), output per root: `rss_kb`, `nproc`.
     - `swap_used_mb` from `vm.swapusage` every tick.
     - Optional probes never abort the loop: `lvl="$(sysctl -n kern.memorystatus_vm_pressure_level 2>/dev/null || true)"`, `free="$(memory_pressure 2>/dev/null | awk -F': ' '/free percentage/{gsub("%","",$2);print $2}' || true)"`, `swap="$(sysctl -n vm.swapusage 2>/dev/null || true)"`; empty result → `NA` in the CSV.
     - `pressure_level` and `free_pct` every 5 s (repeat last value between).
     - Append a CSV line to `$OUT/rss_raw.csv`.
   - Stop when: SIGTERM/SIGINT, `--duration` elapsed, or `$NTS_HOME/current_run` no longer equals `run_id` (checked every tick).
   - On stop: write the `all` summary row to `trial/runs/<run_id>/rss.csv` (header if new), then exit 0.
3. **`rss_raw.csv`** (untracked, `$NTS_HOME/runs/<id>/`; header once):
   ```
   ts_utc,vieneu_pid,vieneu_rss_kb,vieneu_nproc,proxy_pid,proxy_rss_kb,proxy_nproc,mpt_pid,mpt_rss_kb,mpt_nproc,webui_pid,webui_rss_kb,webui_nproc,swap_used_mb,pressure_level,free_pct,sample_ms
   2026-09-25T03:31:02Z,4121,2893412,1,4188,61220,1,4302,1893004,3,4410,210332,1,512.3,1,41,38
   ```
   Service not listening → `pid` empty, `rss_kb` 0, `nproc` 0. `sample_ms` = time the tick's work took (overhead evidence).
4. **`trial/runs/<id>/rss.csv`** (tracked summary; numbers only):
   ```
   scope,start_utc,end_utc,samples,vieneu_peak_mb,proxy_peak_mb,mpt_peak_mb,webui_peak_mb,total_peak_mb,swap_start_mb,swap_peak_mb,pressure_max,free_pct_min,mpt_nproc_max,sample_ms_p95
   all,2026-09-25T03:30:15Z,2026-09-25T03:52:40Z,1345,2825.6,59.8,2951.3,205.4,5870.2,512.3,640.0,warn,18,4,41
   ```
   Rows `stage:<key>` are appended by `finish_run.py` (01.3.1-T3) using the same columns and `[start, end)` windows. `pressure_max` ∈ `normal|warn|critical|NA`. MB = KiB / 1024, 1 decimal.
5. **Self-test** `rss_sampler.sh --selftest 60` (no run needed): creates `$NTS_HOME/runs/sampler-selftest-<YYYYmmdd-HHMMSS>/`, starts a throwaway tree listening on port 18099 (`uv run --no-project --python 3.12 python -c` HTTP server that spawns one `sleep 600` child holding ~50 MB via a `python -c "b=bytearray(50*2**20); import time; time.sleep(600)"` child ⚠️ implementation detail) and samples it as `mpt` for 60 s; prints tree RSS, `nproc` (expect 2+), mean/p95 `sample_ms`, and its own CPU from `ps -o %cpu= -p $$` (plus children via `/usr/bin/time -l` on the self-test run); kills the tree.
6. Runbook section "RAM sampler" in `worker-node/README.md` (D9): started by `start_run.sh`, stop semantics, file locations, limits below.

**Measurement limits (write into `worker-node/README.md` and `trial/schema.md` notes):**
- RSS counts shared pages (shared libraries, mmap'd model files) in every process that maps them → tree sums and `total_peak_mb` overstate private use; they are upper bounds [INFERENCE].
- whisper and render run in the same MPT process (M3) → attribution only by stage window from the MPT log; model load time falls into the subtitle window.
- 1 s sampling misses sub-second spikes (ffmpeg bursts) → peaks are lower bounds of the true max for short spikes.
- Alternative for private memory: `footprint <pid>` / `vmmap --summary` ⚠️ (availability without sudo on macOS 27 unconfirmed) — optional one-off comparison in T4, not in the loop.
- Sampler overhead negligible [INFERENCE] — **measured** in the self-test (`sample_ms` p95, CPU %).

## Outputs
- Tracked: `trial/tools/rss_sampler.sh`, runbook section; per run `trial/runs/<id>/rss.csv` (`all` row).
- `$NTS_HOME/runs/<id>/rss_raw.csv`, `rss_sampler.pid` (during run), `rss_sampler.log`; self-test dir.

## Acceptance checks
- [ ] `shellcheck trial/tools/rss_sampler.sh` → no output; `--help` → exit 0; bad run id → exit 2.
- [ ] `--selftest 60`: ≥ 57 rows; `mpt_nproc` ≥ 2; `mpt_rss_kb` ≥ 51200 (child's 50 MiB counted → tree sum works); `swap_used_mb` numeric; `pressure_level` ∈ {1,2,4} or `NA` with Q6 noted.
- [ ] Overhead: self-test `sample_ms` p95 < 100 ms and sampler CPU < 2 % of one core (printed); else raise interval for roots/pressure, not for RSS.
- [ ] RSS unit check: one pid's `rss_kb / 1024` within ± 10 % of `top -l 1 -pid <pid> -stats mem` (Q7), result noted.
- [ ] Stop semantics: `kill -TERM <pid>` → exits 0 within 2 s, `rss.csv` has an `all` row, pid file removed; removing `$NTS_HOME/current_run` stops it within 2 s.
- [ ] With VieNeu stopped: `vieneu_pid` empty, `vieneu_rss_kb` 0, loop continues.
- [ ] `grep -c "$HOME" trial/runs/*/rss.csv` → 0 (numbers only).

## Failure handling
- `lsof` slow (> 500 ms) → roots already refreshed only every 10 s; if still slow, cache roots for the whole run and refresh on missing pid.
- Pid reuse after a service restart → root refresh picks the new listener; the restart is visible as a pid change in raw data; note in `notes.md`.
- `memory_pressure` / sysctl missing (Q6) → `NA`; collector writes `memory_pressure_max = n/a:pressure-unavailable`.
- Sampler dies mid-run → `finish_run.py` sees missing samples → stage peaks `n/a:no-samples-in-window`; re-run if a gate row.
- Swap grows > 1 GiB or pressure critical during a run → record (R1 input for 11/01.3.3); stop VieNeu before render next time (01 §8 risk row).

## Notes
- ⚠️ Q6 `kern.memorystatus_vm_pressure_level` values and `memory_pressure` output format on macOS 27; ⚠️ Q7 `ps` RSS unit; ⚠️ `footprint` availability.
- `/usr/bin/time -l` (01 §4 story 01.3.2 text) gives a single max RSS per command, not per stage and not for already-running services → replaced by this sampler [DECISION, README F04].
