## Failure handling
- sha256/size missing from an upstream task → compute now from `$NTS_HOME` files; if the file is absent, re-fetch at the pinned revision (01.2.1-T1 / 01.2.3-T1 procedure), never an unpinned one.
- Lock differs from pinned commit (`git -C … status --porcelain uv.lock` non-empty) → stop; restore with `git checkout -- uv.lock`, re-run `uv sync --frozen`, re-measure if the trial used the modified lock and note it in §12.
- 05.5.2 not done → write §1–10, leave §11 as `⚠️ 05.5.2`; T1 is not done until §11 is filled.
