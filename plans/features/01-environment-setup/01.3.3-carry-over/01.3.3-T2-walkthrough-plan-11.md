1. Send the document ≥ 1 day before; owner reads it cold.
2. Session (≤ 60 min), agenda:

   2. (20 min) Owner drafts 11.3.1 checklist live from §1–8: driver/CUDA, packages, Python + locks, weights with sha256 verify, config render, env/secrets, binds, systemd units, voices/music.

5. Commit `worker-node/CARRY-OVER.md`; tick gate 01-closed item "`CARRY-OVER.md` reviewed".
