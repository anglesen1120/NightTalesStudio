## Goal

Two presets — `prompts/story/true_crime.vi.v1.md` and `prompts/story/true_crime.en.v1.md` — that write a schema-valid `story.v1` narration **strictly from an approved fact sheet**, with fact rules that make `fact_refs` meaningful and make invention detectable: every claim traces to a fact id, the model never sees or emits a URL or a source id, and no living private person is named.

## Design

### Front-matter and sections

Front-matter `id: true_crime.vi|en`, `topic: true_crime`, `language: vi|en`, `version: v1`, `role: preset`, `target_tier: all`. Sections: persona · beat map · hook rules · **fact rules** (this task's core) · tone and legal rules · twist rules · ending + CTA · keywords · structure tags · length · output.

### Fact rules (verbatim in both files; the contract the writer must obey)

1. **Input.** The data object carries `facts: [{ "id": "f1", "statement": "…", "sources": ["s1"] }]`. Ids are stable and never reused (F12). The model never sees a URL, a domain or a `story_sources.id`.
2. **Every factual claim is tagged.** Any sentence that states a fact about the case (who, when, where, how, what was found, what a named official said) must appear in the `fact_refs` array of its segment. `fact_refs` = `[]` for purely atmospheric or connective sentences.
3. **No invention.** Never add a fact, name, date, number, quote or motive that is not in `facts`. If the story needs a detail that is not there, describe the scene without it (weather, room, distance) — never guess.
4. **No inference presented as fact.** Interpretations ("có lẽ", "có thể", "perhaps") must be marked as such in the narration and must not be tagged as `fact_refs`.
5. **Attribution style.** Facts are narrated with a source-shape phrase ("theo hồ sơ", "theo lời khai", "cảnh sát cho biết" / "according to the file", "in the statement", "police said"), not asserted by the narrator as personal knowledge.
6. **No URLs, no source ids, no alias strings in the text.** Aliases exist only to link facts to their sources; they are backend bookkeeping.
7. **No living private individual is named.** Public figures in an official capacity only if the fact sheet names them and the fact is about their official role. Victims/minors are described without identifying detail.
8. **Similarity.** The narration must be **written from the facts, in our own words**; do not paraphrase a source sentence. Word overlap with any source text blocks approval (FR-02-10, 02.5.6); the preset states that copying a source sentence is a hard failure even when it is accurate.
9. **Uncertainty is preserved.** If the fact sheet marks something as unconfirmed, the narration says so; an unsolved case stays unsolved.
10. **Missing sheet.** No story is written without an approved fact sheet. If `facts` is absent or empty the run is blocked upstream by `fact_sheet_required` (D8); the preset never invents a case and never narrates the absence of one.

### Legal / tone rules

- Neutral, non-accusatory: "the court convicted", "the file names a suspect" — never "the killer" applied to a living person the sheet does not convict.
- **No gore**, no crime-scene detail beyond what a fact states, **no sexual content**, **no detail of minors in danger**; the victim's dignity rule: describe circumstances, not bodies.
- No "true story" framing language that implies a re-enactment of a real person's voice (F31: framing lexicon feeds the real-world detector, 02.8.2-T2).
- `content_warnings` always include `crime` (**T35**); `death`, `violence`, `disturbing` are added as applicable to what the facts state.

### Beat map for this topic

hook (the case's single unanswered detail, ≤ 20 s) → setup (what is documented) → build_up (the investigation as recorded) → clue (a documented detail that matters later) → twist (what the file actually shows, e.g. a wrong early assumption) → reveal (what remains unknown) → aftermath (who is still waiting) → ending + CTA (a question about the case, never a call to judge).

### Hook examples

| | vi | en |
|---|---|---|
| good | "Hồ sơ được mở lại sau mười chín năm, và trang đầu tiên vẫn thiếu một cái tên." | "The file was reopened after nineteen years, and the first page still has no name on it." |
| good | "Cuộc gọi báo án kéo dài bốn mươi giây, và không ai trong bốn mươi giây đó nói tên đường." | "The call lasted forty seconds, and in those forty seconds nobody said the name of the street." |
| bad | "Hôm nay tôi kể cho bạn nghe về kẻ giết người máu lạnh nhất Việt Nam." | "Today I'll tell you about the most cold-blooded killer in the country." |
| bad | "Theo nguồn tin riêng, hung thủ chính là người hàng xóm." | "According to a private source, the killer is the neighbour." |

- Bad rows fail for: sensationalism + naming a living person as guilty, and for an unattributed claim outside the sheet (rules 3/5/6/7).

### Keyword rules for this topic

1–2 English visual keywords per segment, describing **scenes and objects**, never a person's likeness; a keyword must not encode an identification ("man in his forties" is allowed only as an anonymous description; no "Nguyen Van A"). Real place names are allowed only if the fact sheet names the place and the keyword is generic ("rural road", "courthouse steps").

## Failure handling and edge cases

| Case | Behaviour |
|---|---|
| Output invents a name or date | blocking objective issue in review (02.6.1) and a validator fact-ref check; the preset's rule 3 is the authoring fix — never relax the check |
| Output tags an interpretation as `fact_refs` | rule 4 violation; the review prompt cites the same rule text |
| Output copies a source sentence | rule 8; blocked at approval by similarity (FR-02-10) — the preset must show a "facts, in our own words" example pair |
| Brief has no approved sheet | upstream block `fact_sheet_required` (D8); the preset states it and the harness fixture always provides one |
| Fact sheet re-approved after the story was written | `story_fact_sheet_outdated` (D8) at approve; `fact_refs` stay valid because ids are stable (F12) — the preset's ids are opaque tokens and must be copied exactly, never renumbered |
| Model emits alias strings in `text` | validator flags URLs/ids in `text` (D3 rule set); rule 6 is the authoring fix |
| Rollback | revert the two files + the fixture + manifest entries |
