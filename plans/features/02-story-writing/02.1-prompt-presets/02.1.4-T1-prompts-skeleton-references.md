### `manifest.json` (placeholder now, filled as files land)

```json
{
  "release": "2026.10.1",
  "files": {}
}
```

- `release` is the human release tag used in the composite `prompt_version` (`rel=2026.10.1;…`, D5). It is **not** a date.
- `files` maps every prompt file's path **relative to `prompts/`** (forward slashes, e.g. `system/writer.v1.md`) to `{ "version": "v1", "sha256": "<64 lowercase hex>" }` — **T27**: relative keys match the embedded `LinkBase="Prompts"`.
- **T27 exclusions:** `manifest.json` itself, `REFERENCES.md`, `fixtures/**` and `tools/**` are **never** listed (they are not loadable prompts and do not ship in the release manifest); neither are `**/.gitkeep` or dotfiles (02 T75). Fixture ownership: `fixtures/briefs.*` + the true-crime fixture fact sheet → **02.1.3-T0** (T34), `fixtures/rubric.md` → 02.1.3-T1, `fixtures/injection/*` → 02.2.3-T2, `fixtures/seeded-defects/*` → 02.6.1-T2.
- The sha256 is over the file bytes as committed (LF line endings; no BOM). Regenerate with `sha256sum` in the same PR that edits the file.

### `REFERENCES.md` (exact skeleton)

```markdown
# Prompt references — ideas only, no copied text

Rule (FR-02-11): every prompt in this folder is original work written in our own words.
No sentence is copied or translated from another project. Where an *idea* comes from
elsewhere, it is recorded below as one line: the principle, then its source.

| Principle (ours, restated) | Source | Licence of the source | What we took | What we did NOT take |
|---|---|---|---|---|
| Self-review, then at most one revision, then a human decides | InkOS README | AGPL-3.0 | the loop shape | no text, no prompt wording, no code, no translation |
| Short spoken sentences, numbers written as spoken | (own editorial rule) | — | — | — |
```

- The InkOS row is mandatory (I1/F19): the "self-review → one revision → human" shape is the one idea this plan family borrows, and 02.6.1/02.6.2 implement it independently.
- Every later prompt task adds a row only if it actually borrowed an idea; otherwise it adds nothing.

### PR template checkbox

Append to `.github/pull_request_template.md` (create it if absent, with only this section):

```markdown
## Prompt provenance (required when this PR touches `prompts/`)

- [ ] No prompt text was copied or translated from InkOS (AGPL-3.0) or any other project.
- [ ] Any idea taken from elsewhere is recorded as one line in `prompts/REFERENCES.md`.
- [ ] `prompts/manifest.json` sha256 entries match the files changed in this PR.
```

- The checkbox is the human gate; there is no automated licence scanner (out of scope).

## Failure handling and edge cases

| Case | Behaviour |
|---|---|
| A directory's first file lands in a later feature and someone deletes the `.gitkeep` early | the directory disappears from git and the later PR fails to add a file there — the PR that lands the first real file deletes its `.gitkeep` in the same commit |
| `manifest.json` edited by hand with a wrong sha256 | 02.2.3-T1 fails startup (D5); the fix is `sha256sum` + a new PR, never a runtime override |
| `release` changed without changing prompt files | allowed but pointless: it invalidates `prompt_version` comparability (NFR-02-2); change it only when prompts actually change |
| Someone adds a prompt file without a manifest entry | startup failure in 02.2.3-T1 (by design, D5) |
| Rollback | revert the commit; the tree is inert until 02.2.3-T1 loads it |
