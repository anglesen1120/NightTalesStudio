# 02.1.5-T1 — Written-for-the-ear rules + overused-phrase lists (vi, en)

|---|---|---|---|---|---|

## Goal

`prompts/shared/ear-rules.{vi|en}.v1.md` make the narration sound spoken rather than written (short sentences, numbers and dates as they are read aloud, one idea per sentence in tense moments), `prompts/shared/overused.{vi|en}.v1.txt` give ~30 starter phrases per language to use sparingly — a **prompt input, never a ban** — and the **functional naturalness questions** are handed to 02.6.1 as text so the review asks about function (fear, clue, choice, consequence) instead of deleting flagged words.

## Inputs

- README: **D5** (`shared/ear-rules.{vi|en}.v1.md`, `shared/overused.{vi|en}.v1.txt`, placeholders `{{ear_rules}}` / `{{overused_phrases}}`), **D16** (`natural_language` rubric dimension), **V1** (vi token = syllable; diacritics matter), **O9** (these files are part of the static prefix), story 02.1.5 acceptance (both bullets), story 02.1.1 acceptance 2 (vi must read as natural spoken Vietnamese, not translated English).
- `../../../02-story-writing.md` 02.1.5 (the two acceptance bullets, quoted below) and 02.6.1 (review prompt returns `issues[]` with `kind: objective|taste`).
- 02.1.1-T0's spec (these files are injected by `{{ear_rules}}` / `{{overused_phrases}}`).

**Story 02.1.5 acceptance, verbatim:** *"Given each preset, Then it contains our own per-language rules: short spoken sentences, no brackets/lists/footnotes, numbers and dates written the way they are read aloud, one idea per sentence in tense moments, and a per-language list of overused phrases to avoid."* / *"Given the naturalness check, Then it asks functional questions (does this sentence move fear, clue, choice or consequence; is an emotion explained that the scene already shows) rather than deleting flagged words mechanically."*

## Design

### 1. `ear-rules.vi.v1.md` / `ear-rules.en.v1.md` (front-matter `role: shared`, `id: ear-rules.vi|en`, `version: v1`)

Numbered rules, identical numbering in both languages so the review prompt can cite `E<n>` regardless of language:

| # | Rule | vi detail | en detail |
|---|---|---|---|
| E1 | **Short spoken sentences.** Target 8–14 syllables (vi) / 6–12 words (en); split any sentence with two clauses joined by a comma when the second clause changes the scene | "Tôi mở cửa. Không có ai." not "Tôi mở cửa và nhận ra rằng không có ai ở đó cả." | "I opened the door. Nobody." not "I opened the door and came to the realization that nobody was there at all." |
| E2 | **No brackets, lists, footnotes, dashes-as-asides, parentheses, no markdown and no emoji.** A narration has no punctuation the ear cannot hear | drop `(…)`, `[…]`, bullet lists, `—` asides, `**bold**`, `#` headings, emoji | same (**02 T89**) |
| E3 | **Numbers as spoken.** Small counts in words; dates in the spoken form; no digits for years unless the fact sheet's year is read that way; units expanded | "ba giờ sáng" · "mùng một" · "năm 1998" → "năm một chín chín tám" when the register is spoken | "three in the morning" · "nineteen ninety-eight" · "half a mile" not "0.5 mi" |
| E4 | **Dates and times as an anchor, not a stamp.** Prefer "đêm đó", "that night" over a full timestamp; when a real date is a fact, keep it but say it the way a person says it | | |
| E5 | **One idea per sentence in tense moments.** Build-up and twist paragraphs get the shortest sentences in the story | | |
| E6 | **No reported-speech scaffolding.** No "he said that", "she thought about how" chains; put the words or the action directly | | |
| E7 | **Show, do not name, the emotion.** If the scene already shows fear, do not add "tôi rất sợ" | the review question Q3 (below) tests this | |
| E8 | **Read-aloud test.** Every paragraph must survive being read aloud at narration pace without a re-read; a listener cannot go back | | |
| E9 | **Diacritics and register (vi only).** Correct diacritics; spoken register (không dùng từ ngữ văn viết); no translationese constructions; **one consistent narration mode per story** — first person ("tôi" or "chúng tôi") or `third_person` — never mixed | en: contractions allowed; no literary inversion; the same mode rule applies | (**02 T89**) |
| E10 | **Avoid the overused list.** `overused.{lang}.v1.txt` is substituted at the `overused_phrases` placeholder and is a **prompt input and a review input, not a ban**: a phrase may appear once, deliberately; mechanical repetition is the failure | (**02 T89**) | |

- **The anti-mechanical rule (E10 + Q-set):** the overused list never triggers a delete-word rule. It is supplied to the review model, which uses the functional questions to decide whether a sentence earns its place. This is the story's second acceptance bullet.

### 4. Functional naturalness questions — handed to 02.6.1

```text
NATURALNESS QUESTIONS (answer per flagged or suspect sentence; do not delete words mechanically)
Q1 Function: does this sentence move one of — fear, clue, choice, consequence? If none, say which one it should move and how.
Q2 Redundancy: does the scene already show this (an emotion named that the action already carries, a reaction the image already gives)? If yes, the sentence is the problem, not the word.
Q3 Explanation: is the sentence explaining what the reader/listener can already infer? (tension, motive, atmosphere) — prefer the shorter version that trusts the listener.
Q4 Overused phrase: if a phrase from overused.{lang}.v1.txt appears, does it do work here (once, deliberately) or is it filler? One deliberate use is allowed.
Q5 Read-aloud: read the paragraph at narration pace. Where do you stumble or want to go back? Quote the exact clause.
Q6 Register (vi): is this written Vietnamese rather than spoken? Name the written construction and give the spoken alternative.
```

- These six questions are **02.6.1-T1's prompt text input**. **They live in this task file (§4) as the source of truth and in the PR body — not in `ear-rules.{vi|en}.v1.md`**, which carry only model-facing rule text (**02 T88**). Their `kind` mapping: Q1/Q3/Q5 → `taste`; Q6 → `taste`; Q4 → `taste`; Q2 → `taste`. None is `objective` — naturalness never blocks approval mechanically (02.6.1's rule set decides severity).
- The rubric dimension these feed is D16's `natural_language` (1–5), which the review prompt scores with the same anchors.

## Failure handling and edge cases

| Case | Behaviour |
|---|---|
| The model over-uses a listed phrase once per story | allowed by E10; the review asks Q4 and only flags mechanical repetition |
| A phrase in the list is actually required by a fact (true crime date) | E3 wins over E10: a fact's date is said aloud, not avoided |
| vi output shows translationese | Q6 is the mechanism: the review names the written construction and gives the spoken alternative; a systematic failure is a preset/prompt fix (02.1.3-T2), not a word ban |
| The list is too short to matter after 20 stories | append (append-only) and bump the file `version`; `prompt_version` then shows which stories used which list |
| A rater wants to score `natural_language` without the questions | the questions are the raters' checklist (D16 anchors live in 02.1.3-T1's `rubric.md`) |
| Rollback | revert the four files + manifest entries |

## Notes

- [DECISION] The overused list is **never** a mechanical filter. Enforcing it as a word ban would satisfy the letter of 02.1.5 and break its second acceptance bullet; the six questions are the enforcement, and 02.6.1 owns the severity.
- [DECISION] **T83 (moved here from the ear-rule files):** the **substitution contract** — each ear-rule file is injected unchanged at the `ear_rules` placeholder in D5's order, and the narration is **heard, not read**: a listener cannot go back, cannot see punctuation and cannot re-read a clause. The sibling-file pointer (`ear-rules.vi.v1.md` ↔ `ear-rules.en.v1.md`), the "same numbering in both languages" note and the link line also live here, so the injected files carry only model-facing rule text (**02 T83**).
- [DECISION] Rule numbering is shared across languages (`E<n>`, `Q<n>`) so the review prompt, the raters and the presets can cite one id regardless of language.
