## Design

### 1. `trial/tools/freeze_manifest.py` (stdlib, `uv run --no-project --python 3.12`)

```
freeze_manifest.py [--prompts-dir prompts] [--release 2026.10.1] [--exclude fixtures] [--check]
```
- Default mode **writes** `prompts/manifest.json`; `--check` recomputes and compares without writing.
- Exit `0` ok · `1` a check failed (mismatch/missing/added file) · `2` usage or environment error (01 D9).
- `sha256` is computed over the raw bytes (no line-ending normalisation — the catalog hashes the embedded resource).
- `--check` fails on **three** conditions: a listed file's hash differs, a listed file is missing, or a `prompts/**` file that is not excluded is absent from the manifest. The third catches "a preset was added and never released", which is the realistic drift.

```json
{
  "release": "2026.10.1",
  "files": {
    "system/writer.v1.md": { "version": "v1", "sha256": "<64 hex>" },
    "story/ghost.vi.v1.md": { "version": "v1", "sha256": "<64 hex>" }
  }
}
```

- **Keys are relative to `prompts/`** (T27) — e.g. `system/writer.v1.md` — matching the embedded `LinkBase="Prompts"`. This is the TL ruling; do not introduce a repo-relative variant.
- **`fixtures/**`, `tools/**`, `manifest.json`, `REFERENCES.md`, `**/.gitkeep` and dotfiles are excluded** (T27, 02 T75): briefs, rubrics, injection and seeded-defect fixtures, the provenance note and the manifest itself do not change model output, so editing one must not invalidate a release or trip start-up validation. `schemas/*.json`, `system/`, `story/`, `shared/`, `review/`, `revise/`, `facts/`, `bible/`, `ideas/`, `finder/` are all included.
- Fixture ownership (T27 as amended by T34), so no two tasks write the same file: `fixtures/briefs.*` + the true-crime fixture fact sheet → **02.1.3-T0**; `fixtures/rubric.md` → 02.1.3-T1; `fixtures/injection/*` → 02.2.3-T2; `fixtures/seeded-defects/*` → 02.6.1-T2.
- `version` is the file's own suffix (`*.v1.md` → `v1`); a file without a version marker → exit 2, so an unversioned prompt cannot enter a release.

### 3. `trial/ab/handoff.json` — the numbers

```json
  "d15": { "luna_mean_vi": 3.62, "sol_mean_vi": 3.71, "sol_mean_x0_9_vi": 3.339,
           "luna_natural_language_vi": 3.83, "luna_mean_en": 3.55, "sol_mean_en": 3.70,
           "wi": 2, "verdict_ready": true },
  "d4_calibration": { "words_per_minute_measured": null, "source": "01.3.1-T4 not landed (T26: accepted, D4 rates stay the defaults)",
                      "tiers": { "short":    { "tokens": { "vi": 141,   "en": 128   }, "writer_max_output_headroom": { "vi": 0.41, "en": 0.37 } },

  "price_bounds_12_1_1": { "cost_per_story_usd": { "short":    { "gpt-6-luna": 0.00091, "gpt-6-sol": 0.0183 },
                                                   "standard": { "gpt-6-luna": 0.00135, "gpt-6-sol": 0.0281 },
                                                   "long":     { "gpt-6-luna": 0.00192, "gpt-6-sol": 0.0500 } },

                                                         "gpt-6-sol":  { "p50": 26400, "p95": 41200 } },

```

- `d4_calibration.tiers.<tier>.writer_max_output_headroom` = `max(output_tokens observed) / writer_max_output` per tier × language — the input for whether the D4 cap is generous enough. A headroom > 0.95 means the cap is too tight (cap cut risk, O4). The rated matrix fills `standard`; the 12-cell sweep (T1 §1b) fills `short` and `long`.
- `words_per_minute_measured` is `null` with its `source` while 01.3.1-T4 has not landed — accepted by T26; the key is always present so the consumer never has to guess, and D4's rates stay the defaults until it lands.
- `handoff.json` is the machine-readable twin of `REPORT.md`; both are written by `aggregate_scores.py --handoff` (T1's script, extended here) so the numbers cannot diverge between files.

## Tests

- `freeze_manifest.py --check` on a scratch copy of `prompts/`: unchanged → 0; one byte added to a `.md` → 1; one file deleted → 1; a new unlisted `prompts/story/x.vi.v1.md` → 1; a new `prompts/fixtures/new.json` → 0 and a new `prompts/.gitkeep` → 0 (the exclusions are the tests that matter; 02 T75).
- `freeze_manifest.py` on a file named without a version marker (`prompts/system/writer.md`) → exit 2.
- `aggregate_scores.py --handoff --selftest` over the T1 3-story fixture → asserts all six top-level keys, the `null`-with-`source` rule, and that `cost_per_story_usd` matches hand arithmetic from `metrics.json` × O3 rates.
- `d15_verdict_selftest`: four synthetic aggregates — (a) luna 4 % below sol → luna kept; (b) luna 11 % below sol → sol; (c) vi natural language 3.4 with sol higher → sol for vi only; (d) a `†`/`n=1` mean deciding → `verdict_ready = false`.
- Manual: the TL reads `REPORT.md`'s decision section against `DECISIONS.md` §3 and the story's M0 gate (§7) — the numbers must be the same in all three places.

## Failure handling and edge cases

| Case | Behaviour |
|---|---|
| Verdict "presets need work" (both models weak, or sol wins by a wide margin) | **no freeze**: record the verdict + evidence in `DECISIONS.md` §3, hand the `REPORT.md` back to 02.1.1/02.1.2, and T1 reruns as `r2`; `release` stays unfrozen |
| `n=1` on a decisive cell | `verdict_ready = false`; `DECISIONS.md` gets "pending rater completion", not a model choice; never freeze an unresolved decision |
| A preset changes after the freeze | `--check` fails; re-freeze with a **new** release (`2026.10.2`), rerun the affected matrix cells (`--only-missing -r2`) and re-apply D15 — a silent re-hash of `2026.10.1` would make 02.2.3-T1's startup validation meaningless |
| `words_per_minute_measured` absent | `null` + `source` note — T26 accepts it; D4 rates stay the defaults until 01.3.1-T4 lands |
| The per-tier sweep is incomplete (a tier row missing) | `d4_calibration.tiers` carries only the tiers measured, and `REPORT.md` says which tier was not measured; never interpolate a tier from another one |
| `DECISIONS.md` already changed the row (someone else edited it) | re-read before editing; if the row is gone, do not re-add a whole table — report the conflict and put the numbers only in `handoff.json` + `REPORT.md` |
| Both models refused/moderated across a preset | the validity rate, not the rubric, decides; record `presets need work` |
| Rollback | revert the one `DECISIONS.md` row and delete `prompts/manifest.json`; T1/T0 artifacts are untouched |
