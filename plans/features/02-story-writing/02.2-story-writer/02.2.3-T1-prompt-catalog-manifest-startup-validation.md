# 02.2.3-T1 — Prompt catalog + manifest + startup validation

| Story | Size | Area | Depends on | Blocks | Phase / flag |
|---|---|---|---|---|---|

## Goal

`PromptCatalog` loads `prompts/manifest.json` at Worker/Api start-up and **fails start-up**, listing *every* violation (not the first), when a `topic × language` preset is missing, a sha256 differs, a runtime file is absent from the manifest (or listed but absent), or a template uses a placeholder outside the closed list. A composite `prompt_version` identifies exactly which prompt set produced a draft.

## Inputs

- README **D5** (catalog layout, manifest, closed placeholder list, `prompt_version` shape, `EmbeddedResource` snippet), D6 (untrusted data is never substituted into a template), F22 (per-node drift).
- **TL ruling #4 (README §10 T23–T27):** manifest keys are **relative to `prompts/`** matching `LinkBase="Prompts"`; `fixtures/**`, `tools/**` and `REFERENCES.md` are **excluded from the release manifest**.
- 02.1.4-T1 (`prompts/` skeleton + `REFERENCES.md`), 02.1.1-T0 (`schemas/story.v1.json`, `shared/structure-vocab.v1.json`, preset bodies), 02.1.5-T1 (`shared/ear-rules.*`, `shared/overused.*`), 02.1.2-T1 (`shared/keyword-rules.v1.md`).

## Design

**Manifest** — `{ "release": "2026.10.1", "files": { "<key>": { "version": "v1", "sha256": "<hex>" } } }`, keys **relative to `prompts/`** with `/` on every OS; key set = the D5 tree (6 story presets, `system/writer.v1.md`, the `shared/*` set, the 7 step prompts, the 7 `schemas/*.v1.json`). The loader normalises `\`→`/` and **rejects** an absolute key, one containing `..`, one under `fixtures/`/`tools/`, or `REFERENCES.md` (ruling #4). sha256 is over **raw bytes**, so `.gitattributes` pins `prompts/** text eol=lf` — a CRLF checkout would otherwise break every hash. Fixtures still ship embedded (the D5 glob embeds all of `prompts/**`) so tests read them identically; only *integrity tracking* excludes them.

**Embedding** — `<EmbeddedResource Include="../../prompts/**" LinkBase="Prompts" />` in `src/NightTales.Infrastructure/NightTales.Infrastructure.csproj`; logical names become `NightTales.Infrastructure.Prompts.<path with '/' → '.'>`. The loader resolves by **suffix** match against the manifest key, so a prefix change is a one-line fix, not a re-hash ⚠️ confirm on the first build.

**Types** — `IPromptCatalog` (Application `Abstractions/Prompts/`) exposes `Release`, `GetSystemPrompt()`, `GetPreset(Topic, Language)`, `GetShared(PromptFile, Language)`, `GetStepPrompt(PromptStep)`, `GetSchema(string) → BinaryData`, `BuildPromptVersion(PromptVersionParts)`, `Files` (`key → { version, sha256 }`). `PromptCatalog` (Infrastructure `Prompts/`) is a **singleton** that loads and validates in the constructor and keeps texts + schemas in memory (no file system, no per-request I/O — F22). Supporting: `PromptManifest`/`PromptFileInfo`/`PromptManifestLoader`, `PromptTemplate` (placeholder scan + substitution; unknown placeholder → violation, D6), `PromptCatalogException` (`IReadOnlyList<string> Violations`), `PromptCatalogStartupValidator : IHostedService`. `PromptPlaceholders.All` is the closed D5 set: `language_name`, `tier_minutes`, `token_range`, `segment_range`, `keyword_rules`, `ear_rules`, `overused_phrases`, `structure_vocab`.

**Startup validation rules** (all evaluated, all reported; each violation names the file and the expectation):

| # | Rule |
|---|---|
| 1 | manifest parses; `release` matches `^\d{4}\.\d{1,2}\.\d{1,2}$` |
| 2 | all 6 `story/{topic}.{lang}.v1.md` present (3 topics × 2 languages, no gaps) |
| 3 | `system/writer.v1.md`, every `shared/*` used by a preset, `schemas/story.v1.json` and `shared/structure-vocab.v1.json` present |
| 4 | every manifest key exists as an embedded resource, and every embedded **runtime** file (non-`fixtures/`, non-`tools/`) is tracked |
| 5 | sha256(embedded bytes) == manifest `sha256` |
| 6 | every `{{name}}` ∈ `PromptPlaceholders.All`; `schemas/*.json` + `structure-vocab.v1.json` parse as JSON |

**Composite `prompt_version`** — `rel=2026.10.1;sys=writer.v1;preset=ghost.vi.v1;review=v1;revise=v1;schema=story.v1`, from `release` + the `version` of each file the run used (no review step → `review` omitted). Stored on `story_versions`, `fact_sheets`, `generation_runs` (D5).

## Failure handling and edge cases

| Case | Behaviour |
|---|---|
| Prompt bodies not authored yet | Start-up fails by design. This task ships a manifest for the **placeholder** set; the preset tasks replace bodies and re-hash (the `tools/` helper from 02.1.4-T1 regenerates `manifest.json`). ⚠️ The M0→M1 gate must re-hash after every preset edit. |
| Preset edited without re-hashing | Start-up fails with the mismatch (intended). |
| Windows CRLF checkout | `.gitattributes` pins `prompts/**` to LF; without it every hash breaks. |
| Duplicate key after `/`→`\` normalisation | Rejected (case-sensitive `Ordinal`). |
| Rollback | Revert `prompts/manifest.json` + the prompt files together; no migration. |

## Notes
