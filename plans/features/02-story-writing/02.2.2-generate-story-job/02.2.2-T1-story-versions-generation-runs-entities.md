## Goal

The persistence and the domain state machine for a paid generation exist: the `generation_runs` table with D2's two partial unique indexes, the CR-4 `story_versions` provenance columns, the append-only `StoryVersion` aggregate, the `GenerationRun` state holder and the `Episode` story partial with its four domain events — all in one expand-only migration, proven by unit tests for every transition row.

## Design

### `generation_runs` (new; D2, CR-4)

Columns exactly as plan §3.1. Types: `id uuid PK (UUIDv7)`, `user_id uuid NOT NULL FK users`, `series_id uuid NOT NULL FK series`, `episode_id uuid NULL FK episodes ON DELETE CASCADE` (NULL only for `ideas`/`bible_proposal`; NOT NULL for `story`/`fact_sheet`/`find_sources`, T17), `pause_reason text NULL` (T19), `kind text`, `trigger text`, `idempotency_key text NULL`, `status text`, `stage text`, `previous_episode_status text NULL`, `input_fact_sheet_id uuid NULL FK fact_sheets ON DELETE SET NULL`, `reservation_id uuid NULL`, `counts_toward_limit bool NOT NULL DEFAULT true`, `worst_case_usd numeric(12,6) NOT NULL`, `cost_usd numeric(12,6) NULL`, `error_code text NULL`, `error_detail text NULL`, `result_story_version_id uuid NULL`, `result_fact_sheet_id uuid NULL`, `prompt_version text NULL`, `models jsonb NULL`, `attempt int NOT NULL DEFAULT 0`, `queued_at timestamptz NOT NULL`, `started_at timestamptz NULL`, `finished_at timestamptz NULL`, `created_at timestamptz NOT NULL`, `updated_at timestamptz NULL`.

```sql
-- check constraints (plan §3.1): kind, trigger, status, stage, previous_episode_status,
-- scope (T17): (episode_id IS NULL) = (kind IN ('ideas','bible_proposal'))
-- pause (T19): pause_reason IS NULL OR pause_reason IN ('spend_cap_reached','provider_funds_exhausted')
-- money, times, failed=>error_code
CREATE UNIQUE INDEX ux_generation_runs_active_episode
  ON generation_runs (episode_id, kind) WHERE episode_id IS NOT NULL AND status IN ('queued','running');
CREATE UNIQUE INDEX ux_generation_runs_active_series
  ON generation_runs (series_id, kind) WHERE episode_id IS NULL AND status IN ('queued','running');
CREATE INDEX ix_generation_runs_episode_kind_queued ON generation_runs (episode_id, kind, queued_at DESC);
CREATE INDEX ix_generation_runs_open ON generation_runs (status) INCLUDE (worst_case_usd) WHERE status IN ('queued','running');
CREATE INDEX ix_generation_runs_sweep ON generation_runs (status, COALESCE(started_at, queued_at));
CREATE INDEX ix_generation_runs_user_id ON generation_runs (user_id);
```

`IUserOwned` on `user_id` (EF global filter, 09.2.3). `series_id` is **NOT NULL on every row** — no `Guid.Empty` sentinel (D2 L136). `find_sources` is **episode-scoped** (TL T17): `episode_id` is NOT NULL for `story`/`fact_sheet`/`find_sources`, NULL only for `ideas`/`bible_proposal`; `ck_generation_runs_scope` encodes this.

### `story_versions` CR-4 columns (append-only)

```sql
ALTER TABLE story_versions
  ADD COLUMN parent_version_id uuid NULL REFERENCES story_versions(id) ON DELETE SET NULL,
  ADD COLUMN generation_run_id uuid NULL REFERENCES generation_runs(id) ON DELETE SET NULL,
  ADD COLUMN fact_sheet_id     uuid NULL REFERENCES fact_sheets(id)     ON DELETE SET NULL,
  ADD COLUMN schema_version    text NOT NULL DEFAULT 'story.v1';
CREATE UNIQUE INDEX ux_story_versions_episode_version ON story_versions (episode_id, version);
CREATE INDEX ix_story_versions_generation_run_id ON story_versions (generation_run_id);
```

`version = max(version)+1` per episode, computed inside the insert transaction under the episode row lock (§4 U6). Immutability: every property mapped `ValueGeneratedNever()`, `AfterSaveBehavior = Throw`; `IAppDbContext` exposes no `Update`/`Remove` for `StoryVersion`; an architecture test asserts only `Features/Admin` (09.9.1) may set `State` other than `Added`. `generation_run_id` NULL for `source = edited` (02.3.1).

### Domain types

```csharp
// src/NightTales.Domain/Stories/Generation/GenerationRun.cs  (state only, raises NO events)
public sealed class GenerationRun : Entity, IUserOwned, IAuditable
{
    public GenerationRunStatus Status { get; private set; }
    public GenerationStage Stage { get; private set; }
    public int Attempt { get; private set; }
    public void Start(DateTimeOffset now);
    public ErrorOr<Success> AdvanceStage(GenerationStage next, DateTimeOffset now); // forward-only; allows checking -> reviewing after revising
    public void MarkPaused(GenerationPauseReason reason, DateTimeOffset now);
    public void Succeed(decimal costUsd, DateTimeOffset now);
    public void Fail(string errorCode, string? detail, bool countsTowardLimit, DateTimeOffset now);
    public void Cancel(DateTimeOffset now);
}
public enum GenerationRunStatus { Queued, Running, Succeeded, Failed, Cancelled }
public enum GenerationStage { Queued, Writing, Checking, Reviewing, Revising, Scoring, Saving, Done }
public enum GenerationTrigger { User, Autopilot, System }
public enum GenerationPauseReason { SpendCapReached, ProviderFundsExhausted }

// src/NightTales.Domain/Stories/Generation/Events/  (payloads are the contract, D21)
StoryGenerationRequested    { EpisodeId, SeriesId, UserId, GenerationRunId, Trigger }
StoryGenerationStageChanged { EpisodeId, SeriesId, UserId, GenerationRunId, Stage, Trigger }
StoryGenerated              { EpisodeId, SeriesId, UserId, GenerationRunId, StoryVersionId, Revised, Trigger }
StoryGenerationFailed       { EpisodeId, UserId, GenerationRunId, ErrorCode, Trigger }
```

`GenerationErrorCode` is a value object over the D8 job codes + platform pause reasons.

```csharp
// src/NightTales.Domain/Episodes/Episode.Story.cs  (partial of 09.5.1's aggregate)
public ErrorOr<Success> RequestStoryGeneration(Guid generationRunId, GenerationTrigger trigger, DateTimeOffset now);
public ErrorOr<Success> MarkGenerationStage(Guid generationRunId, GenerationStage stage, DateTimeOffset now);
public ErrorOr<Success> CompleteStoryGeneration(IReadOnlyList<Guid> versionIds, Guid currentStoryVersionId, DateTimeOffset now);
public ErrorOr<Success> FailStoryGeneration(Guid generationRunId, EpisodeStatus previousStatus, GenerationErrorCode code, bool countsTowardLimit, DateTimeOffset now);
public ErrorOr<Success> CancelStoryGeneration(Guid generationRunId, EpisodeStatus previousStatus, DateTimeOffset now);
```

Transition authority (unit tests mirror this table 1:1; plan §3.3):

| # | From | Method | Next | Guard | Raises |
|---|---|---|---|---|---|
| T1 | `draft` | `RequestStoryGeneration` | `story_generating` | true-crime sheet check is the **handler's** (`IFactSheetGuard`, T2) | `StoryGenerationRequested` |
| T2 | `story_review` | `RequestStoryGeneration` | `story_generating` | old version stays current until the new one saves | `StoryGenerationRequested` |
| T3 | `story_generating` | `RequestStoryGeneration` | — | 409 `episode_invalid_state` | — |
| T4 | any other status | `RequestStoryGeneration` | — | 409 `episode_invalid_state` | — |
| T5 | `story_generating` | `MarkGenerationStage` | `story_generating` | run stage order via `AdvanceStage` | `StoryGenerationStageChanged` |
| T6 | `story_generating` | `CompleteStoryGeneration` | `story_review` | `versionIds` non-empty **and** contains `currentStoryVersionId` | `StoryGenerated` (`Revised = versionIds.Count > 1`) |
| T7 | `story_generating` | `FailStoryGeneration` | `previousStatus` ∈ {`draft`,`story_review`} | matches the run's stored `previous_episode_status` | `StoryGenerationFailed` |
| T8 | `story_generating` | `CancelStoryGeneration` | `previousStatus` | as T7 | `StoryGenerationFailed` (`ErrorCode = story_generation_cancelled`, D8) |
| T9 | not `story_generating` | `MarkGenerationStage` / `Complete…` / `Fail…` / `Cancel…` | — | `DomainError.Episode.NotGenerating`; the caller logs and returns without touching the episode | — |

Every method is idempotent for a repeat with the same `generationRunId` **and** the same target status (second call returns `Success`, no second event) — this is what makes the at-least-once outbox safe (09.2.4).

### Migration

```
20260924xxxxxx_AddGenerationRunsAndStoryVersionProvenance
  Up:   CREATE TABLE generation_runs + indexes + check constraints
        ALTER TABLE story_versions ADD the four CR-4 columns
        CREATE UNIQUE INDEX ux_story_versions_episode_version
  Down: drop the four columns, drop the table
```

Order: `generation_runs` **before** the `story_versions.generation_run_id` FK. Expand only: no `DROP`, no type narrowing, no backfill (`generation_run_id` NULL for existing rows, `schema_version` defaults `story.v1`).

## Failure handling and edge cases

| Case | Behaviour |
|---|---|
| Lost race on `version = max+1` | the unique index raises → handler maps to 500/409, never a silent duplicate version |
| A `GenerationRun` row with `kind = ideas` or `bible_proposal` and a non-null `episode_id` | `ck_generation_runs_scope` rejects the insert (T17); `story`, `fact_sheet` and `find_sources` **must** carry an `episode_id` |
| `status = failed` without `error_code` | `ck_generation_runs_failed` rejects |
| A sweeper/admin already moved the episode off `story_generating` | T9 returns `NotGenerating`; the caller logs and returns, no double event |
| Migration run twice | expand-only and idempotent-safe under the 09.2.2-T2 harness; no `DROP` |
| Rollback | `Down` drops the table and the four columns — safe while nothing else writes them |

## Notes

- ✅ **`IAuditable` is 09.2.2-T1's (09 W3 CR-38).** `GenerationRun : Entity, IUserOwned, IAuditable` (Design) now compiles against `Domain/Common/IAuditable : ICreatedAt { DateTimeOffset UpdatedAt }`; one EF convention maps `created_at`/`updated_at` to `timestamptz NOT NULL` and `AuditableSaveChangesInterceptor` (Infrastructure, registered on `AppDbContext` before `OutboxSaveChangesInterceptor`) stamps them from `IClock` — `Added` → `CreatedAt` only while still `default`, plus `UpdatedAt`; `Modified` → `UpdatedAt`. A factory that already receives `now` may keep setting `CreatedAt`/`UpdatedAt` explicitly (the interceptor never overwrites a non-default `CreatedAt`), and any set-based `ExecuteUpdateAsync` on this table must add `SetProperty(g => g.UpdatedAt, now)`.
- ✅ `find_sources` is episode-scoped (TL T17); `ck_generation_runs_scope` enforces it.
- ✅ `generation_runs.pause_reason` + `ck_generation_runs_pause` exist (TL T19); `error_detail` no longer carries the pause reason.
- ✅ `story_generation_cancelled` is in D8 (TL T20).
