# 02.3.1-T1 — Edit command with ETag/If-Match

## Goal

`PUT /api/v1/episodes/{id}/story` writes the full edited `story.v1` as a new `story_versions` row (`source = edited`) under an `If-Match` story ETag, recomputes every derived and local field, marks the model review `stale` without any paid call, and refuses an unchanged save so the history stays honest.

## Inputs

- README: **D3** (content shape, derived `body`/`keywords`/`word_count`, validator rules), **D8** (`story_invalid_content` 400, `episode_invalid_state` 409, `story_version_conflict` 412, `if_match_required` 428), **D9** (ETag `"sv-<current_story_version_id>"`), **D12** (`IContentModerator`, `draft` stage), **D13** (`episode.story_version_saved`), **D21** (`StoryDraftValidator`, `StoryQualityChecker`, `SimilarityScorer`, `RunContext`), **D22** (`audit.v1`, segment addressing), **F25** (full content, recompute, `stale`, no paid call), **CR-4** (`parent_version_id`), **CR-7** (`EpisodeUpdated`).
- 02.2.2-T1: `story_versions` entity, `Episode.CompleteStoryGeneration` conventions, `EpisodeUpdated` outbox helper.
- 02.2.1-T1: `StoryDraftValidator`, `StoryContentV1`, derived-field computation (reused, not re-implemented).
- 02.2.3-T1: `PromptCatalog` (only to read `story.v1` schema name for `schema_version`).

## Design

### Command and handler

`src/NightTales.Application/Features/Stories/Commands/EditStory/`

```csharp
public sealed record EditStoryCommand(Guid EpisodeId, StoryContentV1 Content, string IfMatch)
    : IRequest<ErrorOr<StoryVersionDto>>;

public sealed class EditStoryCommandValidator : AbstractValidator<EditStoryCommand>; // EpisodeId != empty, IfMatch non-empty, Content not null

public sealed class EditStoryCommandHandler(
    IEpisodeRepository episodes, IStoryVersionRepository versions, IUnitOfWork uow,
    StoryDraftValidator validator, StoryQualityChecker checker, SimilarityScorer scorer,
    ISimilarityCorpusProvider corpus, IContentModerator moderator, IAuditLogger audit, IOutbox outbox)
    : IRequestHandler<EditStoryCommand, ErrorOr<StoryVersionDto>>;
```

Flow (order matters; every early exit writes nothing):

1. `episodes.GetForEditAsync(id, ct)` — tracked aggregate incl. `current_story_version_id`; not found → `Error.NotFound`.
2. **State**: `episode.Status is EpisodeStatus.Draft or StoryReview` → continue; `StoryApproved` → `Error.Conflict("episode_invalid_state")` (the UI offers reopen); anything else (`StoryGenerating`, `Rendering`, …) → same code. Never `story_not_in_review` (F29/CR-8).
3. **If-Match** (`StoryEtag.TryParse`): missing/blank → `Error.PreconditionRequired("if_match_required")`; parsed id ≠ `episode.CurrentStoryVersionId` → `Error.PreconditionFailed("story_version_conflict")`.
4. **Validate**: `validator.Validate(command.Content, StoryRules.For(episode, series))`. Invalid → `Error.Validation("story_invalid_content", …)` carrying `errors[]` of `{ field, rule, message }`.
5. **No-op rule** (`StoryContentComparer.CanonicalEquals`): canonicalise with `TextNormalizer` (NFC, trim, collapse `\r\n`→`\n`), then compare `body`, the ordered `keywords` list, every segment's `fact_refs` and the metadata block (`title`, `description`, `tags`, `content_warnings`, `structure`). Equal → return the current version projected to `StoryVersionDto`; **no row, no audit, no outbox, unchanged ETag**.
6. **Recompute** on the tracked copy: derived `body`/`keywords`/`word_count` (D3/D4); `audit_report.local` = `checker.Check(content, ctx)` (02.3.4-T1); `audit_report.similarity` = `SimilarityScorer.IsScorable(story, corpus, opt)` first — false → `score = null`, true → `scorer.Score(...).Score` — over `corpus.LoadAsync(episodeId, lang, ct)` (**the sources corpus only**, matching D21 stage 6 and the 02.5.6-T2 calibration of `Similarity:WarnAbove`/`BlockAbove`; the past-episode corpus is the autopilot gate's concern, not this score — adding it here would move the score off the calibrated threshold); `audit_report.moderation` = `moderator.CheckAsync([narration, title, description, tags], ModerationStage.Draft, ct)` — free (O7), so F25's "no paid call on edit" holds; if that call fails, **keep the previous version's `moderation` verdict** (`flagged`/`categories` copied verbatim, never overwritten with an error) and set `moderation.stale = true` — a boolean inside the existing `audit_report.moderation` block (mirroring `model_review.stale`), so D22's layout is extended by one property and **no column/migration** is added; the approve gate re-checks and clears it; `audit_report.model_review` keeps its scores/`prompt_version`/`model` and sets `stale = true`; `audit_report.revision` is carried over unchanged.
7. **Write**: new `StoryVersion { Source = StoryVersionSource.Edited, ParentVersionId = previousCurrentId, Version = maxVersion + 1, FactSheetId = previous.FactSheetId, SchemaVersion = "story.v1", Content = content + backend `fact_sources` (D3) }`; `episode.SetCurrentStoryVersion(newVersion)`; `audit.LogAsync("episode.story_version_saved", Category.Episodes, Visibility.User, data: new { episode_id, version_id, version })`; `outbox.Add(new EpisodeUpdated(episodeId))`; one `SaveChangesAsync`.

No domain event: D21 lists only `StoryApproved`/`StoryReopened` for 02.3 — an edit is an `EpisodeUpdated` [DECISION].

### ETag helper (shared with 02.3.2-T1)

`src/NightTales.Application/Features/Stories/StoryEtag.cs`

```csharp
public static class StoryEtag
{
    public static string For(Guid storyVersionId) => $"\"sv-{storyVersionId}\"";
    public static bool TryParse(string? header, out Guid storyVersionId);   // strips quotes, requires "sv-" + Guid
    public static ErrorOr<Guid> RequireAndMatch(string? ifMatch, Guid currentStoryVersionId);
}
```

`RequireAndMatch` returns `if_match_required` (428) or `story_version_conflict` (412) and is the single place both commands check the header. The route sets the response `ETag` from `StoryEtag.For(dto.VersionId)`.

### Route

`src/NightTales.Api/Endpoints/StoryEndpoints.cs` — `MapPut("/api/v1/episodes/{id:guid}/story", …)`, owner authorization, `[Audited]`-free (the handler audits explicitly because it needs the version id in `data`), `.Produces<StoryVersionDto>(200)`, `.ProducesProblem(400/409/412/428)`, reads `Request.Headers.IfMatch`.

## Failure handling and edge cases

| Case | Behaviour |
|---|---|
| Two tabs, both with the old ETag | the first wins, the second gets 412 and nothing is overwritten (F11) |
| Edit while a `GenerateStoryJob` is running | 409 `episode_invalid_state` — `story_generating` is not editable; the job owns the aggregate |
| Edit while `rendering` | 409 — the render must not change under the renderer |
| `audit_report` missing on the current version (older row) | build a fresh `audit.v1` from the local checks; `model_review` = `{ stale: true, scores: null }`; log a warning |
| The episode has no fetched url sources (or the draft is under `Similarity:MinTokens`) | `IsScorable` is false → `similarity = { score: null, n: 0 }` and `Classify` returns `Pass`; the edit is never failed for a missing corpus |
| Moderation call fails (provider error) | the edit still succeeds, but the previous version's `moderation` verdict is **kept** (never overwritten with null/error) with `moderation.stale = true`; `ApproveStoryCommand` re-runs the free check once, writes the fresh verdict back and clears `stale`, while still applying the kept verdict's blocking categories in the meantime — so an outage can neither silently approve unmoderated text nor deadlock the episode |
| Content exceeds the D3 limits by a hair | `StoryDraftValidator` owns the decision (D3); this handler never re-checks lengths |
| Client sends `fact_sources` | ignored — the backend rebuilds them from `fact_refs` (D3) |
| Rollback | the command is additive; reverting the deploy leaves `edited` rows readable by the job's own read path |
