## Goal

A persisted, versioned `fact_sheets` draft row built by a Hangfire job from one paid extraction call, where every stored fact is deterministically sourced (valid aliases only), deduplicated, and proven not to be a verbatim copy of its sources.

## Inputs

Decisions D1, D2, D5, D7, D8, D9, D13, D14, D21; findings F12, F13, F18, F29; 02 §4 02.5.3. Outputs of 02.5.3-T1 (`IFactExtractor`, `FactsV1`, `FactInputBudget`), 02.2.2-T3 (`generation_runs`, `StaleGenerationSweeperJob`, job wiring), 02.5.2 (`story_sources`), 02.5.6 (`SimilarityScorer.ScoreFact`).

## Design

**Domain** — `src/NightTales.Domain/Research/{FactSheet.cs,FactItem.cs,FactSheetStatus.cs}` exactly as plan.md §3 (`Id`, `EpisodeId`, `Version`, `Status` = `Draft|Approved|Superseded`, `Facts`, `SourceAliases`, `InputTruncated`, `MaxFactId`, `ContentSha256`, `GenerationRunId`, `PromptVersion`, `CreatedBy/At`, `ApprovedBy/At`). `FactSheet.CreateDraft(...)` enforces the invariants (plan.md §3), including the same-transaction demotion of the previous `Approved` row to `Superseded` (T54).

**EF** — `src/NightTales.Infrastructure/Persistence/Configurations/FactSheetConfiguration.cs`, table `fact_sheets`; columns/indexes per plan.md §3, notably `facts jsonb`, `source_aliases jsonb` (alias → `story_sources.id`, CR-4), `input_truncated bool` (CR-4), unique `(episode_id, version)`, partial unique `(episode_id) WHERE status = 1`. Migration `2026xxxx_AddFactSheets` (expand only; no backfill) — **this task owns the migration**, so `Superseded` ships in the initial enum/constraint rather than as a later alter.

```csharp
public sealed record FactSheetValidationContext(
    IReadOnlyDictionary<string, Guid> AliasToSourceId, int MaxFactId, decimal OverlapBlockThreshold, int MaxFacts,
    IReadOnlyDictionary<Guid, SourceText> SourceTexts);
public sealed record FactSheetValidationResult(IReadOnlyList<FactItem> Facts, int NewMaxFactId, IReadOnlyList<FactDrop> Drops);

public static FactSheetValidationResult Validate(FactsV1 output, FactSheetValidationContext ctx, Func<ScoreFactRequest, decimal> scoreFact);
```

Ordered rules (each drop is counted in `Drops`, never thrown): (1) **unknown/empty aliases** → drop `unknown_alias` (F12); partially unknown → keep the known aliases only. (2) **statement shape** — NFC + whitespace collapse; empty or > 600 chars → drop `statement_invalid`. (3) **dedupe** — key = normalized statement + sorted resolved `sourceIds`; first wins → `duplicate`. (4) **verbatim copy** — `scoreFact(statement, citedSourceTexts)` > `OverlapBlockThreshold` → `verbatim_copy` (F18; 02.5.6 owns the scorer, threshold `Similarity:FactOverlapBlock`). (5) **cap** — first `MaxFacts` (40) survivors → `over_cap`. (6) **ids** — `f{++MaxFactId}` in output order, never reused across versions (F12). (7) **hash** — `ContentSha256` = SHA-256 over the canonical JSON of `Facts`. `confidence` is copied through unchanged (`low` is kept and only flagged in the UI — never dropped, T53); the job sets `InputTruncated` from `FactInputBudget` (CR-4) and persists the alias→id map into `source_aliases` (CR-4/D21).

**Command** — `src/NightTales.Application/Features/Research/GenerateFactSheet/{GenerateFactSheetCommand.cs,GenerateFactSheetCommandHandler.cs}`: `GenerateFactSheetCommand(Guid EpisodeId, string IdempotencyKey) → ErrorOr<FactSheetRunDto>` (202). Handler checks series ownership; `episode.Topic == true_crime`; status ∈ {`draft`,`story_review`} else 409 `episode_invalid_state`; ≥ 1 `fetch_status = fetched` source else 409 `fact_sheet_sources_insufficient`; no active `fact_sheet` run for the episode else 409 `fact_sheet_generation_in_progress` (D2 partial unique; catch `23505`); reused idempotency key → the existing run's result. Then `IBudgetGuard.CheckAsync(worstCaseUsd)` → 429 `spend_cap_reached`; `ICreditLedger.ReserveAsync(userId, CreditOperation.FactSheet, episodeId, bound)`; insert `generation_runs` (`kind = fact_sheet`, `trigger = user`, `counts_toward_limit = false`, `worst_case_usd`, `reservation_id`); `[Audited("episode.fact_sheet_generation_requested", Category.Episodes, Visibility.User)]`; enqueue `GenerateFactSheetJob(runId)` (ids-only, D2); outbox `EpisodeUpdated{change="factSheet", status="generating"}`.

**Job** — `src/NightTales.Infrastructure/Jobs/GenerateFactSheetJob.cs`, `[Queue("default")]`, `[AutomaticRetry(Attempts = 0)]` (D7/F23). Stages on `generation_runs.stage`: `queued → running` (reload episode + fetched sources, re-check state else fail `fact_sheet_generation_failed` detail `sources_changed`); `writing` (`IFactExtractor.ExtractAsync` with `FactInputBudget`); `checking` (moderation pre-check per source chunk, D12 free, then `FactSheetValidator.Validate` with `ScoreFact` from 02.5.6); `saving` (insert `fact_sheets` `status = draft`, `version = max+1`, `max_fact_id`, `generation_run_id`, `prompt_version`, `content_sha256`; set `generation_runs.result_fact_sheet_id`; `IUsageMeter.RecordAsync`; `ICreditLedger.SettleAsync`; outbox `EpisodeUpdated{change="factSheet", status="draft", version}`); `done` (`succeeded`, `finished_at`, `cost_usd`).

Failure mapping (D7/D8): `InvalidOutput` → one in-job retry (`attempt = 2`), then `fact_sheet_invalid_output`; `Moderated` → `fact_sheet_moderated` + `moderation_events{stage = fact_sheet}`; `ProviderFundsExhausted` → `provider_funds_exhausted`; `ProviderError`/`ProviderUnavailable` → `fact_sheet_generation_failed`. All failures: `RefundAsync` (D1), usage recorded when present, `EpisodeUpdated{status="failed", errorCode}`, outbox `FactSheetGenerated` only on success.

## Tests

- Validator: alias drops, partial-alias keep, statement shape, dedupe first-wins, verbatim-copy drop, ids from `MaxFactId+1`, ids never reused, cap at `MaxFacts`, stable `content_sha256`, `confidence` copied through including `low` (`FactSheetValidator_KeepsLowConfidenceFact`).
- Persistence: `FactSheetJob_PersistsSourceAliasMap_AndInputTruncatedFlag`; `FactSheetValidator_AssignsIds_ForFactsWithoutConfidence_DroppingTheFact` is **not** expected — a missing `confidence` is a schema failure upstream (T1), not a drop.
- Command: the 409/429 gates above, reservation + enqueue with `runId` only (D2), `23505` → 409 not 500.
- Job: success writes draft v1 and settles; `InvalidOutput` after retry → `fact_sheet_invalid_output` + refund; `Moderated` → `moderation_events{stage = fact_sheet}`; sources removed mid-run → `sources_changed`.
- Integration (`PostgresFixture`): `PostFactSheetGenerate_Returns202`; `GenerateFactSheetJob_ZeroFactsSurvive_SavesEmptyDraft`.

## Failure handling and edge cases

- Zero facts survive the validator → still save a draft with `facts = []`; approve later fails `fact_sheet_sources_insufficient` (F13). One cited source only → draft valid, approve blocked (F13).
- Concurrent generate → `23505` mapped to 409, not 500. Episode deleted mid-run → job no-ops (FK cascade), run failed, no orphan sheet.
- Job crash → no Hangfire retry; `StaleGenerationSweeperJob` (02.2.2-T3) marks the run failed and refunds (D2).
- Reused idempotency key with a different episode → 409 `episode_invalid_state` ⚠️ (confirm the 09 idempotency convention).
