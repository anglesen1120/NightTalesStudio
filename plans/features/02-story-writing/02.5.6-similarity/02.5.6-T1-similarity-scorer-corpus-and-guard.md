## Goal

A pure, deterministic, in-process lexical similarity check: `SimilarityScorer` turns a `story.v1` draft + a corpus into `SimilarityResult` (`score`, `n`, `corpus`, per-segment shares) and the `audit.v1.similarity` projection; `ISimilarityCorpusProvider` supplies the sources and past-episode corpora; `SimilarityApprovalGuard` classifies a stored score as pass/warn/block so 02.3.2-T1 can return 409 `story_too_similar_to_source`.

## Design

### Domain — `src/NightTales.Domain/Stories/Similarity/` (pure, static, no I/O)

```csharp
static string TextNormalizer.Normalize(string text, Language lang);   // NFC → lower → strip punct → keep diacritics → collapse ws
static ulong[] Shingler.Hash(string normalized, int n);               // [] when tokens < n; '\u001f'-joined window → XxHash64
static IReadOnlySet<ulong> Shingler.Shingles(ReadOnlySpan<string> tokens, int n);
static IReadOnlySet<ulong> ShingleSet.From(ulong[] hashes);

record SimilarityOptions(Language Language, int N, double WarnAbove, double BlockAbove, int MinTokens) {
    static SimilarityOptions For(Language lang, SimilaritySettings settings);
    static int NFor(Language lang); }                                  // config Similarity:N:<lang>
record StorySegment(string Address, string Text);                     // title | hook | p:<i> | ending
record StoryText(IReadOnlyList<StorySegment> Segments) { static StoryText From(StoryContentV1 c); }
record CorpusText(Guid SourceId, string Text);                        // never logged (D19)
record SegmentOverlap(string Segment, double Share);
record SimilarityResult(double Score, int N, string Corpus, IReadOnlyList<SegmentOverlap> Segments) {
    object ToAuditSection(); }                                        // D22 { score, n, corpus, segments[{segment,share}] }

static SimilarityResult SimilarityScorer.Score(StoryText, IReadOnlyList<CorpusText>, SimilarityOptions);  // D21 verbatim, non-nullable
static bool SimilarityScorer.IsScorable(StoryText, IReadOnlyList<CorpusText>, SimilarityOptions);
static double SimilarityScorer.ScoreFact(string statement, IReadOnlyList<CorpusText> sources, SimilarityOptions);

enum SimilarityVerdict { Pass, Warn, Block }
static SimilarityVerdict SimilarityApprovalGuard.Classify(double? similarityScore, SimilarityOptions opt);
```

**Semantics (frozen — `plan.md` §3.2).** Story shingles = **union** over segments, corpus shingles = union over texts, `Score = |story ∩ corpus| / |story|`; per-segment share = the same restricted to one segment, emitted only when `> 0`, desc, top 10. `Score` stays non-nullable (D21): `IsScorable` is false when the story has `< MinTokens` (50) tokens or the corpus is empty, and the caller then writes `similarity_score = null` — never a zero result. `ScoreFact` = share of the statement's shingles in its cited sources; statement `< n` tokens → `0`. `Classify`: `null → Pass`, `> BlockAbove → Block`, `> WarnAbove → Warn`, else `Pass` (strict `>`). Seeded `XxHash64` → deterministic; no DI, no provider call, no metering.

## Failure handling and edge cases

| Case | Behaviour |
|---|---|
| Corpus empty (no sources, or none `fetched`) | `IsScorable` false; caller writes `similarity_score = null`, no audit section; approve passes (S8) |
| Story `< MinTokens` (50) | `IsScorable` false → caller writes `null`; the UI shows `story.similarity.unavailable` only when sources exist |
| Storage read fails / times out | the exception reaches the caller, which catches it → `null` + `similarity_unavailable` advisory (S8); the scorer never swallows errors |
| Source text empty after extraction / longer than the cap | empty → skipped; long → truncated before normalisation |
| Segment with `< n` tokens (e.g. a 3-syllable hook) | contributes no shingles; cannot produce a share |
| `ScoreFact` statement `< n` tokens | `0` |
| `XxHash64` collision | can only raise a score (§8); the fix would be `HashToUInt128`, not a threshold change |
| `language` missing from `Similarity:N` | fall back to `en` + warning log; never skip the check |
| Rollback | `Similarity:BlockAbove = 1.0` (warn-only) via config; no deploy, no migration |
