## Design

### Fixture `prompts/fixtures/similarity/sample-set.v1.json` (committed, ≥ 60 samples, ≥ 3 per class per language)

```jsonc
{ "schema": "similarity-samples.v1",
  "samples": [ { "id": "vi-verbatim-paragraph-01", "language": "vi", "class": "verbatim_paragraph",
    "source": { "id": "s1", "text": "…source text…" },
    "story": { "title": "…", "hook": "…", "paragraphs": ["…","…"], "ending": "…" } } ] }
```

`story` → `StoryText.From(StoryContentV1)`; `source` → `CorpusText(s1, text)`.

| Class | Construction | Expected band |
|---|---|---|
| `original` | an M1 sample story vs an unrelated source | ≤ `WarnAbove` |
| `shared_collocation` | an original story sharing only names, places, dates and 2–4-word collocations with the source — the **F18 inflation class** | ≤ `WarnAbove` |
| `light_paraphrase` | the source's sentences reworded (synonym + clause reorder), same facts | ≤ `WarnAbove` |
| `heavy_paraphrase` | source structure kept, wording substantially rewritten | may land in the warn band |
| `quoted_passage` | an original story containing **one** quoted source sentence | ≤ `WarnAbove` |
| `verbatim_paragraph` | one source paragraph inserted verbatim into an otherwise original story | diagnostic only — the paragraph is diluted by the rest of the story |
| `verbatim_full` | the whole source rewritten as the story, paragraph by paragraph | ≥ 0.9 |
| `translated_copy` | the **en** source translated to a **vi** story (and vice versa) | ≈ 0 — documents the residual |
| `fact_copied` / `fact_paraphrased` | a fact statement copied / reworded from its cited source | `ScoreFact` above / below the threshold |

### Harness (offline, deterministic, free — no OpenAI, no network)

`tests/NightTales.Domain.UnitTests/Stories/Similarity/Calibration/{SimilarityCalibrationTests,SimilarityCalibrationReport}.cs`, run as `dotnet test --filter Category=Calibration`. It sweeps the grid and writes a committed `similarity-calibration-report.json` plus a printed decision table.

```csharp
record CalibrationCell(string Class, string Language, int N, double Mean, double P50, double Min, double Max);
record CalibrationChoice(int NVi, int NEn, double WarnAbove, double BlockAbove, double CopiedFactThreshold, int PerfBudgetMs);
record CalibrationReport(string GeneratedAt, IReadOnlyList<CalibrationCell> Cells,
    CalibrationChoice Chosen, CalibrationChoice? Previous, IReadOnlyList<string> Warnings);
```

Grid: `n ∈ {6, 8, 10, 12, 14}` per language, taken from `SimilarityOptions.For` so the harness measures exactly what production runs.

### Decision rule (deterministic — no run-time judgement)

1. **`n`**: among the candidates where `max(score)` over `{original, shared_collocation, light_paraphrase, quoted_passage}` is minimal and `min(score)` over `{verbatim_full} ≥ 0.9`, pick the **largest** `n` (longer n-grams are more specific → fewer false positives). If none qualifies, keep the defaults (vi 10 / en 8) + a warning.
2. **`WarnAbove`** = `max` over the same four non-copy classes, rounded **up** to the next 0.01, floored at `0.02`.
3. **`BlockAbove`** = `min` over `{verbatim_full}` only, rounded **down** to the next 0.01; must be `≥ WarnAbove + 0.05`, else keep 0.15 and warn. `verbatim_paragraph` is deliberately **not** in this set: it is one copied paragraph inside an otherwise original story, so it scores low by construction and would drag the block down to the warn level. It is reported as a dilution/recall diagnostic only.
4. **`CopiedFactThreshold`** = midpoint of `max(fact_paraphrased)` and `min(fact_copied)`, rounded to the next 0.05.
5. **`PerfBudgetMs`** = `ceil(2 × measured p95)` from T1's perf test on the CI machine.
6. **Report the residual**: `translated_copy`'s mean per direction, with "cross-language translation copying is not detected (F18); mitigated by facts-only writer input (02.5.5)". No threshold may be chosen to chase this class.

## Steps

1. Author the fixture (≥ 60 samples) — `original`/`shared_collocation` from the 02.1.3-T1 sample stories, the rest hand-built from **public-domain or synthetic** source text (no copyrighted article text is committed ⚠️ confirm with the TL).
2. Add `SimilarityCalibrationTests` + the report writer; assert the fixture loads and every class has ≥ 3 samples per language.
3. Implement the sweep and the decision rule exactly as above; write the JSON report.
4. Run it; update `appsettings.json` (`Similarity:WarnAbove/BlockAbove/N:vi/N:en/Perf:BudgetMs`, `Research:FactSheet:CopiedFactThreshold`).
5. Add `Calibration_ConfigMatchesReport` so a later config edit without a re-run fails the build.
6. Add the `DECISIONS.md` §3 entry (CR-10) when any value differs from the §5.9 defaults (0.05 / 0.15 / 8) — numbers, sample-set size, residual statement.
7. Record the re-run triggers in the report: any change to `TextNormalizer`/`Shingler`, the D4 token rule, `Similarity:MinTokens`, or a new language.
8. Hand the chosen `BlockAbove` to 02.8.2-T3 (its validator compares against it).

## Failure handling and edge cases

| Case | Behaviour |
|---|---|
| No candidate `n` separates the classes | keep the defaults (vi 10 / en 8, 0.05 / 0.15), record a `warning`, escalate to the TL — never lower `BlockAbove` to make the numbers look good |
| `BlockAbove` would fall below `WarnAbove + 0.05` | keep 0.15 and warn; the sample set is too small |
| `verbatim_paragraph` diluted below `BlockAbove` | expected: the score is a share of the **whole** story; the report warns and the D22 per-segment shares still flag the segment in the UI (block rule stays overall-score-based — see Notes) |
| `translated_copy` ≈ 0 | expected residual (F18); documented, not "fixed" by a threshold |
| Fixture would need copyrighted source text | use public-domain or synthetic sources only ⚠️ confirm with the TL before committing |
| A later `TextNormalizer`/`Shingler`/D4 change | re-run is mandatory (step 7); `Calibration_ConfigMatchesReport` + the report's `previous` block make drift visible |
| Rollback | thresholds live in config; restore the previous values and re-run the harness |

## Notes

- [DECISION] The decision rule is deterministic and the report is committed, so "why 0.15?" is answerable from the repo — §5.9's "⚠️ calibrate" is thereby discharged or explicitly deferred.
- [OPEN] **Dilution.** The score is a share of the whole story (F18/§5.9), so one copied paragraph inside a long story can fall under `BlockAbove`. This is why `BlockAbove` is calibrated on `verbatim_full` only and `verbatim_paragraph` is a diagnostic. This task reports the dilution but adds no per-segment block rule — that would extend the frozen `SimilarityOptions`/`SimilarityApprovalGuard` contract (S10) and is a TL decision; the per-segment shares are already stored (D22) for the warn hint.
- [OPEN] `Similarity:Perf:BudgetMs = 500` (plan §3.3) is a placeholder; step 5 replaces it with `2 ×` the measured p95.
- ⚠️ `n ∈ {6, 8, 10, 12, 14}` and the ≥ 3-samples-per-class floor are proposals; widening them costs only offline harness time.
