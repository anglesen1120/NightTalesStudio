## Goal

F17's missing quality check: a frozen set of ≥ 20 seeded-defect drafts proves the review prompt detects objective defects (recall ≥ 80 %) without blocking clean drafts (false-blocking ≤ 10 %), and the **cheapest** model that passes (luna vs sol) is pinned as `OpenAi:Models:Review` with the numbers in `DECISIONS.md` §3 (D15).

## Design

**Fixture `prompts/fixtures/seeded-defects/<id>.json`** (one draft per file, no manifest entry — T27):

```json
{ "id": "vi-ghost-01", "language": "vi", "topic": "ghost", "tier": "standard", "clean": false,
  "brief": "…", "draft": { "title": "…", "hook": {…}, "paragraphs": [ … ], "ending": {…}, "structure": {…} },
  "defects": [ { "type": "missing_setup_before_twist", "segment": "p:7", "note": "the twist has no earlier clue" },
               { "type": "ear_rule_violation", "segment": "p:3", "note": "10-syllable clause with two subclauses" } ] }
```

`defects` is `[]` when `clean: true`. Seeded defects are **objective types only** (taste is not a defect) and never include `revision_drift` (platform-emitted).

**Set composition (22 drafts).**

| Language | ghost | spiritual | true_crime | clean |
|---|---|---|---|---|
| vi | 6 | 3 | 3 | 2 |
| en | 4 | 2 | 2 | 2 |

Rules: every objective type in the T1 enum appears in ≥ 1 seeded defect; each draft has 1–3 defects; `true_crime` drafts carry `fact_ref_invalid`/`fact_not_in_sheet` cases and one `clean` true-crime draft (to prove `factual_care` does not over-block); 5 clean drafts total (vi 2, en 2, true-crime 1). Drafts are hand-written (or writer-generated then hand-edited) and frozen — a change requires re-running the set.

**Scorer** `tests/NightTales.TestKit/Review/SeededDefectScorer.cs` (pure, unit-testable without the API):

```csharp
public sealed record SeededDefectReport(int Drafts, int CleanDrafts, int SeededDefects, int DetectedDefects,
    double Recall, int CleanDraftsWithBlocking, double FalseBlockRate,
    IReadOnlyDictionary<string, double> RecallByType, IReadOnlyList<string> UnseededBlockingTypes, decimal CostUsd);
public static SeededDefectReport Score(IReadOnlyList<SeededDraft> drafts, IReadOnlyList<StoryReviewV1> reviews, decimal costUsd);
```

- **Detection rule**: a seeded defect counts as detected when the review has an issue whose `type` equals the seeded `type` **and** whose `segment` equals the seeded `segment` (severity `blocking` or `advisory` both count — recall measures detection).
- `recall = DetectedDefects / SeededDefects` (target ≥ 0.80).
- `falseBlockRate = CleanDraftsWithBlocking / CleanDrafts` (target ≤ 0.10), where "with blocking" = ≥ 1 issue with `severity = blocking`.
- `RecallByType` exposes a type the prompt systematically misses; `UnseededBlockingTypes` lists blocking types the model invents on clean drafts (precision signal for the TL).

**Harness** `tests/NightTales.AcceptanceTests/Review/SeededDefectAcceptanceTests.cs`:

- `[Trait("Category","Acceptance")]`; skipped unless `OPENAI_LIVE_TESTS=1` (D20). Uses the real `PromptCatalog` + `OpenAiTextClient` (no `FakeTextClient`), `Story:Review` settings as shipped, and an **override** of `OpenAi:Models:Review` per pass (`gpt-6-luna`, then `gpt-6-sol`).
- Writes `trial/review/acceptance-<model>-<yyyyMMdd-HHmm>.json` (untracked, T25) with per-draft `{ id, seeded[], detected[], blockingOnClean[] }` plus the `SeededDefectReport`, and prints a model-comparison markdown table (recall, false-block, per-type recall, cost) to the console.
- `--max-usd 5` hard stop reusing the M0 harness switch (T25); the run aborts before the second model if the first already exceeds the cap.
- Asserts `Recall >= 0.80` and `FalseBlockRate <= 0.10` for the model being pinned, so the run fails loudly instead of silently producing a report nobody reads.

**Decision (D15).** Pick `gpt-6-luna` if it passes both thresholds; else `gpt-6-sol` if it passes and luna does not; else neither passes → the prompt is amended (T1) and the set re-run, thresholds unchanged. Write to `DECISIONS.md` §3: model, `recall`, `false_block_rate`, per-type gaps, cost per review, and the date. Then set `OpenAi:Models:Review` and note the per-call bound change for 12.1.1 (sol is ~20× the review cost, ⚠️ plan §11.2).

## Steps

1. Author the 22 fixture files; add a fixture-schema unit test (every file parses, `defects[].type` ∈ the objective enum, ≥ 1 fixture per objective type, 5 clean drafts).
2. Add `SeededDefectScorer` + its unit tests (no API).
3. Add the acceptance harness with the per-model override, the report writer and the threshold asserts.
4. Run the set on `gpt-6-luna`; if a type is systematically missed, amend `prompts/review/v1.md` (T1) and re-run before comparing models.
5. Run the set on `gpt-6-sol`; produce the comparison table.
6. Record the decision in `DECISIONS.md` §3, set `OpenAi:Models:Review`, and hand the cost number to 12.1.1/`price_versions`.

## Failure handling and edge cases

| Case | Behaviour |
|---|---|
| Provider down / key missing | Harness aborts before writing a report; no decision recorded, no config change |
| A type is never detected by any model | Reported as a prompt gap → amend `prompts/review/v1.md` and re-run; **never** lower the threshold |
| Clean drafts flagged blocking (false-block > 10 %) | Tighten the prompt's `blocking` criteria (T1) and re-run; do not delete the clean drafts |
| A model passes recall but not false-blocking | Not eligible (D15 requires both) |
| Cost cap reached mid-run | Run stops, report marked `partial: true`, no decision recorded |
| Fixture drift (a draft edited later) | Set is frozen; any edit invalidates the report and requires a re-run |
| Model alias unavailable | Harness fails with the model name in the message; try the documented alias before changing the decision |

## Notes

- [DECISION] Recall counts `advisory` detections; false-blocking counts only `blocking` issues on clean drafts. This separates "did it see the defect" from "did it over-block", which is exactly what the gate threshold (02.8.2-T3) consumes.
- [DECISION] The set is frozen and lives in `prompts/fixtures/`, **not** in the release manifest (T27); it is a test asset, never shipped to the model.
- ⚠️ 22 drafts × 2 models at `standard` tier ≈ $0.6–$3 depending on the model (O3) — the `--max-usd 5` cap covers both passes.
