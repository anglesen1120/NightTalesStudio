## Goal

Seven reviewed style templates that follow one slot order (so scenes of one series describe medium, palette, light and people the same way, G5), with vi/en labels and hints, in the tracked file `seed/style-templates.v1.json` that the seeder (CR-1) and the M0 tools read.

## Inputs

- README **D1** (template contract: one `{term}`, 60–600 chars, no line break, no `"`, **no** negative clause), **D2** (7 names, topic hints, topic rule, labels as i18n keys, preview key), **D13** (M0 uses the template as MPT's global template).
- 03 high-level G4 (true crime: illustration/silhouette/scenery only), G5 (describe place/time/light the same way), 03.1.1 acceptance (≥ 6 templates, `{term}`).
- 02.1.2-T1 keyword rules: keywords are English scene phrases of 3–12 words ("subject + place + light/time"), so the template must not repeat light/time words that fight the keyword.
- I3: MPT replaces `{term}` literally; I11: commas are safe only because `video_terms` is sent as an array (D4).

## Design

### Slot order (every template)

`<medium> of {term}[, framing]. <palette>, <texture>, <light>, <composition>, <people rule>, <mood>.`

- **medium** first (what kind of picture) — keeps the look stable across keywords.
- **people rule** always present: silhouettes / blurred / no faces. For `true_crime`: "no faces, no identifiable people".
- No negative safety words ("no gore", "no text", …): the builder appends `NegativeClause.V1` (D1).
- No colour or light word that contradicts a typical keyword ("at dawn" in a keyword + "moonlight" in the template is acceptable; the keyword wins in practice ⚠️ checked on the contact sheet).

## Steps

2. Write the 7 rows into `seed/style-templates.v1.json` exactly as in the table.

Produce the M0 global-template strings for the 05.5.2 runs (D13): `dark-folklore-ink` for the vi ghost run and `foggy-cinematic` for the en ghost run, each = template + `" "` + `NegativeClause.V1`. Hand them to 01.2.2-T2 / 05.5.2 as the value of `openai_image_prompt_template` for those runs (they replace the temporary neutral template).
6. Owner review of the texts (15 min) before 03.3.2-T1 spends money on them.

## Failure handling and edge cases

| Case | Behaviour |
|---|---|
| A template reads badly with a real keyword ("… of rural road at night … pale moonlight") | fix the template, not the keyword rules; re-run the contact sheet cells for that template only |
| The owner wants a 6-template catalogue (O5) | set `case-file-illustration` `active = false`; true crime then has one style |
| A label is too long for the picker card | the hint may wrap; the label must be ≤ 32 chars (all are) |
| Rollback | revert the files; the M0 runs fall back to the 01 temporary neutral template |
