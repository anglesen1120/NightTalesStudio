## Design

```csharp
namespace NightTales.Domain.Catalog;

public static class NegativeClause
{
    public const string Version = "v1";
    public const string V1 = "No gore, no blood, no text, no letters, no logos, no watermark, no real person likeness.";
    public static string Current => V1;
}

public sealed record ScenePrompt(string Text, string ModerationText, string Sha256);

public static class ScenePromptBuilder
{
    public const string Placeholder = "{term}";

    public static ScenePrompt Build(StyleTemplate style, string keyword)
    {
        var term = keyword.Trim();
        var styled = style.Template.Replace(Placeholder, term, StringComparison.Ordinal);
        var text = styled + " " + NegativeClause.Current;
        return new ScenePrompt(text, styled, Sha256Hex(text));
    }

    public static string Sha256Hex(string text) =>
        Convert.ToHexStringLower(SHA256.HashData(Encoding.UTF8.GetBytes(text)));
}

public static class StylePromptVersion
{
    public static string For(StyleTemplate style) =>
        $"style={style.Name}@{ScenePromptBuilder.Sha256Hex(style.Template)[..8]};neg={NegativeClause.Version}";
}

public static class StyleTopicPolicy
{
    public static bool IsAllowed(Topic topic, string? topicHint) => topic == Topic.TrueCrime
        ? topicHint == "true_crime"
        : topicHint != "true_crime";
}
```

`StyleTemplateRules.Validate(string name, string template) → ErrorOr<Success>` returns `Error.Validation` with codes (field errors for the seed report):

| Code | Rule |
|---|---|
| `style_name_invalid` | not `^[a-z0-9]+(-[a-z0-9]+)*$` or length ∉ 3..40 |
| `style_term_count` | `{term}` occurs ≠ 1 time |
| `style_length` | trimmed length ∉ 60..600 |
| `style_line_break` | contains `\r` or `\n` |
| `style_quote` | contains `"` |
| `style_has_negative_clause` | contains `NegativeClause.Current`, or (case-insensitive) `no gore`, `no text`, `watermark` |

- `StyleTemplate.Create(name, template, topicHint, previewStorageKey, active)` calls the rules (09.2.2-T1 keeps its signature; this task adds the call).
- Seed hook (CR-1): `StyleTemplateSeeder` loads `seed/style-templates.v1.json` (copied to output as content, `seed/**` → `Seed/`), checks `negativeClauseVersion == NegativeClause.Version`, validates each row, and aborts the whole seed with `seed_style_template_invalid:<name>:<code>` on the first failure. Upsert semantics stay those of 09.2.5-T1.
- `Convert.ToHexStringLower` exists from .NET 9 ⚠️ [INFERENCE: BCL, confirm on net10.0 at implementation; fallback `Convert.ToHexString(...).ToLowerInvariant()`] (DoR DR-4).
- Keyword content is **not** validated here (that is `KeywordRules` / 03.2.2); the builder only trims.

## Failure handling and edge cases

| Case | Behaviour |
|---|---|
| Keyword contains `{term}` | replaced text keeps the literal `{term}` from the keyword (single `Replace` pass) — harmless; `KeywordRules` rejects braces anyway (charset) |
| Seed file clause version ≠ Domain version | seed aborts (`seed_negative_clause_mismatch`) — the file and code must ship together |
| Template text changed in a later seed | new `StylePromptVersion`; existing series pick it up on the next render (F16, documented in `seed/style-templates.md`) |
| A series points at a template that later fails the rules | cannot happen through the seeder (it aborts); a hand-edited DB row still renders, and `StyleTemplate.Create` is not called on load |
| Rollback | revert the Domain files and the seeder change; the table and data stay |
