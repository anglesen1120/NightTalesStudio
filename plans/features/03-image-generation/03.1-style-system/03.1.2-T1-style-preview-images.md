# 03.1.2-T1 — Preview images: generate, convert, upload, seed keys

| Story | Size | Area | Depends on | Blocks | Phase / flag |
|---|---|---|---|---|---|
| 03.1.2 | XS (0.25) | Worker + Ops | 03.1.1-T1 (templates), 03.3.2-T1 (tool with `--mode previews`), 11.4.1-T1 (`nt-public-<env>` bucket; CLI in `worker-node/storage/README.md`, 11 CR-13) | 10.4.2-T1 (picker grid) | P · M0 (generate) → M1 (upload) · none |

## Goal

Each of the 7 templates has one static preview image, made once by the operator from a fixed neutral keyword, stored in the public bucket, and referenced by `preview_storage_key` in the seed file — never generated per user.

## Inputs

- README **D2** (landscape, WebP, ≤ 150 KB, 768 px wide, key `style-previews/<name>.v1.webp`, bucket `nt-public-<env>`), **F12**.
- 03.3.2-T1 tool `trial/tools/image_contact_sheet.py` (calls through the usage tap with the `nts.openai.image` key, 01 D3/D6/D7).
- `ffmpeg` with WebP support ⚠️ (01 E2 lists ffmpeg 9.0.2; `libwebp` encoder not checked — step 1).

## Design

- Preview keyword per topic hint (from 02.1.2-T1 "good" examples, so previews match what real keywords look like):
  - `ghost`: `old wooden door with a brass handle, night`
  - `spiritual`: `small roadside shrine with incense smoke at dawn`
  - `true_crime`: `rural road at night, single streetlight, wet asphalt`
- Prompt = `ScenePromptBuilder` equivalent (template with `{term}` replaced + `" "` + `NegativeClause.V1`), size `1536x1024`, quality = the 03.3.2 winner (or `medium` if 03.3.2 is not decided yet).
- Output PNG → `ffmpeg -i in.png -vf scale=768:-2 -c:v libwebp -quality 80 out.webp`; if > 150 KB lower `-quality` in steps of 10 down to 50.
- Upload: the storage CLI recorded by 11.4.1-T1 in `worker-node/storage/README.md` (provider from 11.2.1-T1; operator key `NTS_PREVIEW_WRITE_KEY`/`_SECRET`, Keychain `nts.preview.write`, put on `style-previews/` only; credentials never in argv; 11 D20 H9; 11 CR-13), object key `style-previews/<name>.v1.webp`, `Content-Type: image/webp`, `Cache-Control: public, max-age=31536000, immutable` (the `.v1` in the key makes it immutable).
- Seed file: set `previewStorageKey` for all 7 rows.

## Steps

1. Check `ffmpeg -hide_banner -encoders | grep -i webp`; if missing, use `cwebp` from Homebrew (`libwebp`, BSD-3 ⚠️ licence check) instead.
2. Run `trial/tools/image_contact_sheet.py --mode previews --templates seed/style-templates.v1.json --out "$NTS_HOME/runs/style-previews-<YYYYmmdd>"` (7 calls; `--max-usd 2`).
3. Owner picks each preview (re-roll a template at most twice; each re-roll is one more call).
4. Convert to WebP as above; check size ≤ 150 KB and width 768.
5. Upload to `nt-public-<env>` for each environment that exists (dev storage emulator, staging, prod).
6. Set `previewStorageKey` in `seed/style-templates.v1.json`; commit; re-seed.
7. Add a "Style previews" section to `worker-node/README.md`: how to regenerate one preview (new key `.v2`, never overwrite `.v1`).

## Outputs

- Storage objects `style-previews/<name>.v1.webp` × 7 (per environment); local originals under `$NTS_HOME/runs/style-previews-*/` (untracked).
- Changed (tracked): `seed/style-templates.v1.json` (`previewStorageKey`), `worker-node/README.md` (section).
- Cost line appended to `trial/images/REPORT.md` (03.3.1-T1 owns the file).

## Failure handling and edge cases

| Case | Behaviour |
|---|---|
| A preview is `moderation_blocked` | pick the next "good" keyword of the same topic from 02.1.2-T1; record the block in `REPORT.md` (it is evidence for 03.4 block rates) |
| Image shows text/letters despite the clause | re-roll once; if it repeats, raise to 03.1.1 (the clause may need V2, plan §10) |
| Storage provider not chosen yet (11.2.1 open) | keep the WebP files in `$NTS_HOME` and leave keys null; the picker shows the label only (10.4.2 empty state) |
| Rollback | set the keys back to null; objects can stay (public, generic) |
