## Goal

The owner rates 80 images (10 keywords × `low|medium|high|auto` × landscape/portrait) without knowing which quality made which image, and every call's echoed quality and token usage is recorded — the evidence for the CR-3 quality decision and for the first `tokens_per_image` numbers.

### Tool `trial/tools/image_contact_sheet.py` (stdlib only)

```text
usage: image_contact_sheet.py --mode sheet|previews --matrix FILE --templates FILE --out DIR
                              [--aspects landscape,portrait] [--qualities low,medium,high,auto]
                              [--base-url http://127.0.0.1:8002/v1] [--max-usd 8] [--self-test]
```

- Key from env `OPENAI_API_KEY` only (set by the wrapper); refuses to start if it is empty; never echoes it.
- One request per cell: `POST {base}/responses` (01 DEC-11/03 CR-15: `OPENAI_IMAGE_API=responses`) JSON `{"model": <OPENAI_IMAGE_HOST_MODEL>, "input": prompt, "reasoning": {"effort": <OPENAI_EFFORT_IMAGE_HOST>}, "tools": [{"type":"image_generation","model":"gpt-image-2","size":size,"quality":quality}], "tool_choice": {"type":"image_generation"}}` (`quality` omitted for the `auto` cell, like MPT, I1). Timeout 300 s. No retries (a failed cell is recorded and left empty). ⚠️ On today's relay size/quality/model are advisory — the echo is always `gpt-image-2-codex`/`auto` (codex#28723); record the echo + actual image size, not the request, per cell.
- Response: decode `b64_json` or download `url` (1 attempt); save `img/<keyword_id>-<aspect>-<quality>.png`; append a row to `contact-sheet-results.csv` (plan §3) with `usage` numbers and the echoed `quality`/`size`.
- Cost per call = `text_tokens × 5 + image_tokens × 8 + output_tokens × 30` / 1e6; running total > `--max-usd` → stop before the next call, exit 3.
- Blind page: for each keyword × aspect the 4 images get letters A–D from a seeded shuffle (`random.Random(sha256(keyword_id+aspect))`); `index.html` shows letters only; the mapping goes to `contact-sheet-key.json`.
- `--mode previews`: one landscape image per template with its topic's preview keyword (03.1.2-T1), quality from `--qualities` (single value), files `previews/<name>.png`.
- Run ids for the tap: the wrapper writes `$NTS_HOME/current_run` = `<YYYYMMDD-HHMM>-en-landscape-90` before the landscape batch and `…-en-portrait-91` before the portrait batch (numbers 90+ mark non-video runs; `finish_run.py` is **not** called for them).

### Wrapper `trial/tools/run-contact-sheet.sh`

```bash
#!/usr/bin/env bash
set -euo pipefail
HERE="$(cd "$(dirname "$0")" && pwd)"; REPO="$(cd "$HERE/../.." && pwd)"
. "$REPO/worker-node/bin/lib.sh"
NTS_HOME="$(nts_home)"
OPENAI_API_KEY="$(secret nts.openai.image)" \
  uv run --no-project --python 3.12 "$HERE/image_contact_sheet.py" "$@"
```

(`secret` from 01 `lib.sh`; the key lives only in the child's environment.)

### Decision rule (applied by 03.3.1-T2, fixed here)

Per aspect: `mean(q)` = mean owner rating of quality `q` over the 10 keywords; `flagRate(q)` = share of cells with `text_visible` or `face_realistic` or `gore`. Choose the **cheapest** `q ∈ {low, medium, high}` with `mean(q) ≥ 4.0`, `mean(q) ≥ max_q mean − 0.5` and `flagRate(q) ≤ 0.1`. If none qualifies → `high` and a note. `auto` is reported (its echoed quality and tokens) but is not a candidate, because it is not predictable (D9).

## Steps

1. Write `trial/images/contact-sheet-matrix.json` from the table above.
2. Write the tool and the wrapper; `shellcheck` the wrapper; run `--self-test` against a local stub (no key, no spend).
3. Start the tap (01.3.1-T2). Run the landscape batch, then the portrait batch (`--max-usd 8` total across both; the second call gets the remaining budget).
4. Owner rates in `index.html` → `contact-sheet-ratings.csv` (≈ 30 min), then opens `contact-sheet-key.json`.
5. Summarise in `trial/images/REPORT.md` §Contact sheet: per aspect × quality mean rating, flag rate, mean/max output tokens, cost per image; the echoed quality of the `auto` cells; any `moderation_blocked` cells; whether the negative clause held (text/face flags).
6. Keep the run folders in `$NTS_HOME/runs/contact-sheet-<YYYYmmdd>/`.

## Failure handling and edge cases

| Case | Behaviour |
|---|---|
| `moderation_blocked` on a cell | record it, leave the cell empty, continue; report per template (evidence for 03.4 block rates) |
| 429 at Tier 1 (5/min) | the tool sleeps 13 s between calls by default (`--pace-seconds 13`) so it never exceeds 5/min; a 429 anyway → record and continue |
| `quality` rejected for flare (400) | record the error; the cell is empty; the decision rule works on the remaining qualities |
| Budget reached mid-batch | exit 3; the owner decides to raise `--max-usd` (within the project limit) or rate the partial sheet |
| Rollback | nothing to roll back; delete the run folder to free disk |
