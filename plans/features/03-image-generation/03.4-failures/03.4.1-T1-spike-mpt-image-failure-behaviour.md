## Goal

Every README `I` fact that plan 03 builds on is confirmed (or corrected) at the **pinned** MPT commit by running MPT against a scripted fake Images API, and the result — task states, error text, log lines, order, clip length, which terms were called — is written to `worker-node/contract/images.md` with saved samples. No real prompt is ever sent to OpenAI to provoke a block (D14).

## Design

### Image stub `trial/tools/image_stub.py` (stdlib)

- `ThreadingHTTPServer` on `127.0.0.1:18003`, route `POST /v1/images/generations`; anything else → 404.
- Returns a valid 1536×1024 or 1024×1536 PNG (generated once in memory: solid colour + the slot number drawn as blocks, no font needed) as `b64_json`, with `usage {input_tokens: 90, input_tokens_details {text_tokens: 90, image_tokens: 0}, output_tokens: 1000, total_tokens: 1090}` and `quality: "medium"`.
- Behaviour is scripted by a JSON file `--script FILE`: `{ "default": "ok", "by_call": { "3": "moderated" }, "by_prompt_contains": { "__BLOCK__": "moderated" } }`. Outcomes:
  - `ok` · `moderated` → 400 `{"error":{"code":"moderation_blocked","message":"Your request was rejected by the safety system.","type":"image_generation_user_error"}}`
  - `rate` → 429 `{"error":{"code":"rate_limit_exceeded",…}}` · `quota` → 429 `{"error":{"code":"insufficient_quota",…}}`
  - `e500` → 500 · `slow` → sleeps 320 s (beyond MPT's 300 s read timeout) · `garbage` → 200 with a non-image body · `url` → 200 with `data[0].url` pointing at the stub's `/img/<n>.png`
- Writes `stub-calls.jsonl`: `{ n, ts, prompt_sha256, prompt_len, size, has_auth_header, outcome }` — the prompt **hash and length**, never the text in the committed samples (the text is our own fixture, but the rule stays the same as production, D12).

### Spike MPT profile

- A second rendered config `$NTS_HOME/src/mpt/config.spike.toml`, produced by `render-mpt-config.py --profile spike` (small flag added to the 01 renderer; in this profile the guards accept `openai_image_base_url = "http://127.0.0.1:18003/v1"` with `openai_image_api_keys = []`, and they expect `openai_base_url` on the same stub URL and `listen_port = 18080` — five rewritten lines in total, see the renderer docstring). The API is started with that file copied into place by `start-mpt-api.sh --profile spike`, and the normal config is restored on stop ⚠️ (MPT reads `config.toml` from its root, 01 M8 — confirm the swap approach with the 01.2.2 owner; alternative: a second MPT worktree `$NTS_HOME/src/mpt-spike`).
- Voice: a real short TTS track (≈ 40 s English text) through the proxy, or any MPT voice that works offline; the story is fixed in `trial/fixtures/spike-images-en.txt`.
- Submit body: D4 fields unless a case says otherwise; `video_terms` = a JSON list of 8 fixture terms `t01 … t08` (styled with a fixed template + clause so length ≈ 330 chars, like production); 40 s audio / 10 s clips → 4 images needed.

### Output `worker-node/contract/images.md`

Sections: pin + date; fact table I1–I17 with the P0 result; one subsection per case (what was sent, stub calls, task API sample path, log excerpt with prompts replaced by `<prompt sha256=…>`); conclusions for the relay (D5), report (D6) and classifier (D7); open points for 05.4.1. ## Steps

1. P0: confirm the pin and re-read the four MPT files; update README §1 `I` rows if a line or behaviour differs (then re-check F01–F04).
2. Write `image_stub.py` (+ `--self-test`: each outcome returns the right status/body; PNG decodes with the stdlib `zlib` check) and `redact_prompts.py`.
3. Add `--profile spike` to the renderer and start script (or the second worktree), agreed with the 01.2.2 owner.
4. Write the fixture story and the 8 styled terms.
5. Run P1–P11 (≈ 10 min each; P8 ≈ 6 min longer). Save samples after each case.
6. Write `images.md`; hand the image section to 05.4.1 and the shapes to 11.1.2-T1 (mock) and 03.4.3-T1 (relay).
7. Stop the spike profile; `smoke.sh` green again on the normal profile (proves the swap was undone).

## Failure handling and edge cases

| Case | Behaviour |
|---|---|
| Pin differs from the snapshot in image code | record the diff in `images.md`, fix README §1, re-validate D4–D7 before 03.4.3-T1 |
| Config swap leaves the spike config in place | `start-mpt-api.sh` refuses to start the normal profile when `openai_image_base_url` points at 18003 (guard); restore by re-rendering |
| TTS unavailable (04 not ready) | use MPT's `edge`/offline voice only for the spike ⚠️ (network call to Microsoft; acceptable for a spike text, not for trial runs) or wait for 04.1.2 |
| MPT behaves non-deterministically across runs | repeat P2 three times; record all |
| Rollback | stop the stub, re-render the normal config |
