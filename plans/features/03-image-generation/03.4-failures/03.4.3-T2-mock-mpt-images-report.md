## Goal

Local development and CI can reproduce every image outcome of D7 without a GPU node or OpenAI: mock-mpt returns the same `images.v1` block as the real adapter, chosen by an environment variable or a trigger keyword.

## Inputs

- README **D6** (shape), **D7** (outcome rows to cover), **D14** (`MOCK_IMAGE_REPORT` values), **CR-5** (11.1.2 gets the variable).
- 11 §5.3: mock-mpt config `MOCK_FAIL_MODE` (`tts_failed`/`image_moderated`/`timeout`/`lost_task`) and trigger keyword `__fail_image__`.
- 03.4.3-T1 samples `worker-node/contract/samples/images/relay-status-*.json`.

## Design

- `MOCK_IMAGE_REPORT` (default `ok`), parsed once at start; invalid → mock fails to start.

| Value | Terminal state | `images` block |
|---|---|---|
| `ok` | complete | `called = succeeded = needed_guess`, `failed = []`, one `usage` entry per success (1,000 output tokens, `estimated = false`) |
| `moderated:<slots>` e.g. `moderated:3,7` | complete | those slots in `failed` with `moderation_blocked`, `called = planned_needed + n`, spares consumed |
| `skipped:<share>` e.g. `skipped:0.15` | complete | `round(share × needed)` slots failed with `http_status 500` / `upstream_error` |
| `moderated_all` | failed (`materials`) | every slot `moderation_blocked`, `succeeded = 0` |
| `funds` | failed (`materials`) | first slot `429 insufficient_quota`, rest unattempted |
| `none` | complete | `images` omitted (tests the missing-report path, D7 row 8 / estimates) |

- `needed_guess` = `min(planned, ceil(canned_video_seconds ÷ video_clip_duration))`; the canned MP4 is 10 s (11.1.2), so tests that need more images set `MOCK_VIDEO_SECONDS` (default 10) — the mock only uses it for the report, not the file.
- Per-request override: a `video_terms` entry containing `__block_image__` marks that slot moderated (works alongside the existing `__fail_image__` = `moderated_all`). This lets one test run cover several rows without restarting the mock.
- The mock validates the submit fields of D4 and returns 400 `adapter_contract_violation` (the `render-node.v1` code, 05 CR-4) if `video_terms` is a string, `video_concat_mode ≠ sequential`, `video_clip_duration` missing, or `image_plan.prompt_sha256` length ≠ `video_terms` length. This makes the backend's D4 mapping testable in CI.
- The emitted block is validated against `images.v1.schema.json` in the mock's own tests.

## Failure handling and edge cases

| Case | Behaviour |
|---|---|
| The real adapter shape changes | `images.v1.schema.json` changes first (03.4.3-T1); the mock's schema test fails until updated |
| `MOCK_FAIL_MODE=image_moderated` (older 11.1.2 setting) | kept as an alias of `MOCK_IMAGE_REPORT=moderated_all` |
| Rollback | revert the mock change; backend tests using the report then fail loudly (intended) |
