# 04.1.1-T1 — Spike: PCM/WAV decode, streaming transcode, abort and disconnect behaviour at the pin

| Story | Size | Area | Depends on | Blocks | Phase / flag |
|---|---|---|---|---|---|
| 04.1.1 | S (0.5) | Worker | 01.2.1-T4 (samples, RTF), 01.2.1-T2 (VieNeu running on `127.0.0.1:8000`), 01.2.2-T1 (MPT venv: `requests 2.33.1`, `moviepy 2.2.1`) | 04.1.2-T1, 04.3.1-T1 | P · M0 |

## Goal

Prove on the implementation machine, at the pinned VieNeu and MPT commits, the four facts D4 rests on: (1) the exact D4 ffmpeg command turns VieNeu PCM (and WAV) into a correct MP3; (2) MP3 bytes flow while VieNeu is still synthesising; (3) a post-commit abort surfaces in MPT's own `requests` as `ChunkedEncodingError`; (4) how quickly VieNeu frees its stream slot after the client disconnects (F17). Output: `worker-node/proxy/SPIKE.md` with a results table and a go/no-go for D4.

## Inputs

- README **D3** (upstream body), **D4** (ffmpeg command, commit rule), **D5** (60 s admission budget), **X1**, **X2**, **F12**, **F17**, **V1–V11**, **M1–M9**, **R1**.
- `worker-node/pins.env` via `load_pins` (`VIENEU_COMMIT`, MPT pin; 01 D2).
- Keychain `nts.vieneu.api_key` via `secret nts.vieneu.api_key` (`worker-node/bin/lib.sh`).
- 01.2.1-T4 samples in `$NTS_HOME/runs/samples/` and its RTF table; fixture texts `trial/fixtures/tts-vi-1000.txt`, `tts-en-1000.txt`, `tts-vi-5min.txt`.
- MPT venv `$NTS_HOME/src/mpt/.venv/bin/python` (01.2.2-T1).

## Design

Throwaway scripts under `$NTS_HOME/runs/spike-04/` (not tracked): `spike_pipe.py` (httpx stream → ffmpeg, timestamps), `abort_server.py` (minimal uvicorn + starlette app), `mpt_client.py` (run in MPT's venv). Scratch venv `$NTS_HOME/runs/spike-04/.venv` (Python 3.12, `uv pip install httpx uvicorn starlette`). Only `SPIKE.md` is tracked. Keys go to curl via `-H @<(printf 'Authorization: Bearer %s\n' "$KEY")`, never argv; no `set -x`.

D4 command under test (exactly):
`ffmpeg -hide_banner -loglevel error -f s16le -ar 48000 -ac 1 -i pipe:0 -vn -c:a libmp3lame -b:a 192k -write_xing 0 -id3v2_version 0 -flush_packets 1 -f mp3 pipe:1`

## Steps

0. **Re-check facts at the pin.** `load_pins`; confirm `git -C "$NTS_HOME/src/vieneu" rev-parse HEAD` = `VIENEU_COMMIT`. If ≠ `c1390abb…`, diff `apps/openai_speech.py` against `/private/tmp/vieneu_speech_truth.py` and re-read the cited lines of V1–V7, V9 (`src/vieneu/v3turbo.py`), V8 (`voices_v3_turbo.json`: count, default, gender set, aliases). Re-check M1–M9 at the MPT pin (`app/services/voice.py` L2144–2228, L371, L692; `task.py` L537; `uv.lock` versions). Record each id as `same` / `changed: <what>` in SPIKE.md table S0. A changed fact that D3–D7 depends on → no-go, escalate.
1. **(a) PCM vs WAV decode.** For `tts-vi-1000.txt`: request PCM (D3 body) and WAV (`response_format: "wav"`), save raw bytes; pipe each through the D4 command (WAV variant: `-f wav -i pipe:0`). Record exit code, stderr lines, `ffprobe -show_entries format=duration` of the MP3, and expected = `pcm_bytes / 2 / 48000`. Also: header-only / empty input → exit code and output size (X1 44-byte case), first two MP3 bytes (`ff fb`/`ff f3` sync). Confirm `X-Sample-Rate: 48000`, `Content-Type` prefix `audio/pcm`, `X-Request-Id: spk-…` (V4).
2. **(b) Streaming.** `spike_pipe.py` streams VieNeu PCM for `tts-vi-5min.txt` into ffmpeg stdin as chunks arrive and reads stdout in 16 KiB reads. Log monotonic timestamps: POST sent, first PCM byte, first MP3 byte, every MP3 write, last byte, ffmpeg exit. Report `first_mp3_ms`, `max_gap_ms` between MP3 writes, total wall, RTF. Go criterion: `first_mp3_ms` < 30,000 and `max_gap_ms` < 60,000.
3. **(c) Abort seen by MPT's `requests`.** `abort_server.py` on `127.0.0.1:<ephemeral>` (scratch venv) serves a `StreamingResponse` that yields 64 KiB of real MP3 from (a), then raises. `mpt_client.py`, run with `$NTS_HOME/src/mpt/.venv/bin/python`, does `requests.post(url, json={...}, timeout=120)` exactly like M3 and prints the exception class. Also a trickle variant (1 KB/s for 5 s, `timeout=2`) → expect 200 complete (X2). Record `requests.__version__` (expect 2.33.1, M9).
4. **(d) Disconnect → slot release.** With VieNeu idle, poll `GET /health` every 250 ms in the background, recording `active`/`waiting`. Start a streamed 5-min PCM request with httpx, close it after 5 s of audio. Record `t_close → active == 0` delay. Repeat 3×. Also: immediately after close, send a new request and record whether it gets 429 (V3) and after how long it is admitted.
5. **(e) MoviePy decode of a streamed MP3.** Save the full MP3 from (b) and run `$NTS_HOME/src/mpt/.venv/bin/python -c 'from moviepy import AudioFileClip; ...'` (the same logic `tools/mpt_decode_check.py` will use, D14): duration finite, > 0, and |MoviePy − pcm duration| ≤ 0.1 s.
6. **(f) Sampling defaults.** From the pinned `openai_speech.py` record `temperature`, `top_k`, `top_p`, `repetition_penalty`, `max_chars`, `sample_rate` defaults (V1) and `VIENEU_QUEUE_TIMEOUT`/`max_streams` (V3) as the effective values the proxy inherits (D3 sends none).
7. Write `worker-node/proxy/SPIKE.md` (tables S0, A–F, then **Go/No-go for D4** with one line per criterion). Machine facts: `sw_vers`, `ffmpeg -version | head -1`, CPU, RAM.

## Tests

Spike, no permanent tests. The recorded experiments are the evidence; permanent regression coverage of the same behaviours is `test_wire_abort_after_commit_raises_chunked_encoding_error` and `test_wire_slow_trickle_under_short_timeout_succeeds` (04.1.2-T2) and the MPT-side runs of 04.1.2-T3.

## Failure handling and edge cases

- VieNeu pin differs and a V fact changed → record, mark NO-GO if D3/D4/D6 depend on it, message the TL; do not patch the contract here.
- (b) fails the go criterion (no MP3 before 30 s, or gap ≥ 60 s) → `D4: NO-GO`, [OPEN] escalate to the TL. Do **not** design chunking or buffering in this task (chunking was withdrawn by F01/CR-2).
- (c) shows a clean end instead of `ChunkedEncodingError` → NO-GO for the F02 abort rule; record uvicorn/starlette versions.
- (d) release delay > 30 s → GO for D4 but flag for the TL: D5's 60 s budget minus the delay leaves < 30 s for a retry (README plan §10 open item).
- WAV warnings (`Ignoring maximum wav data size`) are expected (F12), not a failure.
- VieNeu not running → `die 2` with a hint to 01.2.1-T2; do not start it from this task.
