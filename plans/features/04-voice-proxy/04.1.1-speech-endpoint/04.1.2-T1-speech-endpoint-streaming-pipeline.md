## Goal

A working `POST /v1/audio/speech` in package `nts_vieneu_proxy` that authenticates MPT, validates the body (D3 steps 2–6), streams VieNeu PCM through ffmpeg to MPT as MP3 (D4), never sends a 200 for empty audio, aborts the connection on any post-commit failure, and writes one D7 log line per request. Plus the project skeleton and `seed/voices.v1.json` revision 0.

## Design

**Skeleton.** `worker-node/proxy/pyproject.toml` (name `nts-vieneu-proxy`, `requires-python = ">=3.12,<3.13"`, deps `fastapi`, `uvicorn`, `httpx`; dev group `pytest`, `pytest-asyncio`, `requests`; `[tool.pytest.ini_options] asyncio_mode = "auto"`), `.python-version` = `3.12`, `uv.lock` (licence check is 04.1.5-T1), `src/nts_vieneu_proxy/{__init__,__main__,app,config,catalog,upstream,transcode,errors,reqlog}.py`. `voice_cache.py`/`health.py` are added by 04.1.3-T1/04.1.4-T1. All `uv` commands run with `UV_PROJECT_ENVIRONMENT="$NTS_HOME/src/proxy-venv"` (README D14), never a repo-local `.venv`.

**config.py.** `Settings.from_env(environ)` applies the D13 table exactly: host = `127.0.0.1`; `VIENEU_BASE_URL` matches `^http://127\.0\.0\.1:\d{1,5}$`; keys ≥ 32 chars; bitrate ∈ {128k,160k,192k}; integer ranges; `first_audio_deadline_s > admission_wait_s`. Any failure → `ConfigError(var_name)`, `str(err)` = `invalid config: <VAR>`. `ffmpeg_path` is resolved with `shutil.which`; **not found is not a ConfigError** (README D8/D13): the resolved path is `None`, health reports `ffmpeg_missing` (04.1.4-T1) and speech answers 500 `transcode_failed`.

**catalog.py.** `load_catalog(path)` parses JSON, checks D9 file and entry rules **in the D9 check order** (parse → file keys/types → per entry in file order: keys/types → id → slug → other fields → duplicates → active per language; first failure wins, README T14), returns `Catalog`. Unknown or wrongly typed properties are rejected (entry-level ones carry the entry's id). Codes: `voice_id_invalid`, `voice_slug_mismatch`, anything else → `catalog_invalid` (with `voice_id` when entry-level). `validate_voice_id` implements: NFC-equal, `== strip()`, `re.fullmatch(r"[^\W_][\w .\-]{0,63}", id)` (Python `str` semantics are the D9 standard), no `-Female`/`-Male`/`:`, not `endswith("-V2")`. `slugify` implements the D9 algorithm (`Hải Đăng` → `hai-dang`, `Ngọc Huyền` → `ngoc-huyen`).

**seed/voices.v1.json revision 0** (D9): `schema voices.v1`, `revision 0`, `vieneuCommit` = `VIENEU_COMMIT` from `worker-node/pins.env`; entries `Hải Đăng` (vi, male) and `Ngọc Huyền` (en, female) per V8, `tags []`, `active true`, `previewStorageKey null`. NFC bytes; loaded by `load_catalog` in a test.

**errors.py.** `ProxyError(code, http_status, message, retry_after=None)`; `error_body(code, message)` → `{"error": {"message": message[:200], "type": "proxy_error", "code": code}}`. This task defines the codes it raises; 04.1.2-T2 completes the D6 table.

**upstream.py.** `VieneuClient(settings, transport=None)` wraps one `httpx.AsyncClient(base_url=vieneu_base_url, timeout=httpx.Timeout(connect=upstream_connect_timeout_s, read=upstream_read_gap_s, write=10, pool=upstream_connect_timeout_s), transport=transport)`, header `Authorization: Bearer <vieneu_api_key>`. `speech_stream(body)` is an `asynccontextmanager` doing `client.stream("POST", "/v1/audio/speech", json=body)` and yielding `UpstreamSpeech(status, headers, request_id=headers.get("x-request-id"), aiter_pcm(), error_message())` — `error_message()` reads ≤ 4 KiB of a non-200 body and returns `error.message` or `None`. No other path string exists in the module except those of `voices`/`health` (04.1.3-T1, 04.1.4-T1).

**transcode.py.** `ffmpeg_args(ffmpeg_path, bitrate)` returns exactly the D4 argv. `Mp3Encoder`: `start()` (`create_subprocess_exec`, PIPE ×3, starts a stderr task keeping the last 8 KiB), `feed(b)` (write + `drain`), `close()` (close stdin), `read(n=16384)` (`b""` on EOF), `wait()`, `kill()` (idempotent; kill + wait, never leaves a zombie), property `stderr_tail`.

**reqlog.py.** `RequestLog` dataclass with the D7 fields (`ts, rid, route, method, voice, chars, audio_seconds, vieneu_ms, ffmpeg_ms, ttfb_ms, max_gap_ms, admission_wait_ms, bytes_out, status, http_status, error_code, upstream_rid, ignored_fields, wall_ms`); `emit(entry)` = `sys.stdout.write(json.dumps(asdict(entry), ensure_ascii=False, separators=(",", ":")) + "\n"); flush`. On failure only, D4's `ffmpeg_stderr_tail` and the `pcm_odd_tail` warning are appended as extra keys (see Notes).

**app.py.** `create_app(settings, catalog, *, vieneu_transport=None)` → `FastAPI(docs_url=None, redoc_url=None, openapi_url=None)`; state per pinned interface; `asyncio.Semaphore(proxy_max_concurrent)` as `app.state.speech_slots` (D5 budget logic is 04.1.2-T2). Route `POST /v1/audio/speech` takes `request: Request` (no pydantic model, so auth runs before the body is read).

Pipeline pseudo-code (one `SpeechPipeline` per request, all resources owned by an `AsyncExitStack`):

```python
async def speech(request):
    log = RequestLog(ts=utc_ms(), rid=f"px-{secrets.token_hex(4)}", route="/v1/audio/speech", method="POST", ...)
    t0 = loop.time(); p = None
    try:
        check_auth(request)                        # 401 proxy_unauthorized, before body
        req = parse_and_check(await read_body(request), catalog)   # D3 2-6; T2 adds step 1 limit + 413
        log.voice, log.chars, log.ignored_fields = req.voice, len(req.input), req.ignored
        p = SpeechPipeline(app.state, req, log, deadline=t0 + first_audio_deadline_s)
        first = await p.open_until_first_mp3()     # admit → upstream_open → first_audio; raises ProxyError
    except ProxyError as e:
        log.status = log.http_status = e.http_status; log.error_code = e.code
        if p: await p.close()                      # close() emits the log line (exactly once)
        else: emit(log)                            # auth/parse errors: no pipeline, emit here
        return JSONResponse(error_body(e.code, e.message), e.http_status, headers=retry_after(e))
    except BaseException:                          # bug or cancellation before commit: never leak slot/ffmpeg/log
        log.status = 500; log.error_code = log.error_code or "internal_error"
        if p: await p.close()
        else: emit(log)
        raise
    log.http_status = 200                          # COMMIT
    return StreamingResponse(p.body(first), media_type="audio/mpeg",
        headers={"Cache-Control": "no-store", "X-Request-Id": log.rid}, background=BackgroundTask(p.close))

async def open_until_first_mp3(self):
    await self.admit()                             # semaphore (T2: budget + 429 retry); sets self.slot_held = True only after acquire succeeds
    try:
        async with asyncio.timeout_at(self.deadline):   # D4: the 90 s commit deadline also bounds waiting for VieNeu's headers (every T2 retry POST included)
            self.up = await self.stack.enter_async_context(vieneu.speech_stream(UPSTREAM_BODY(req)))
    except TimeoutError: raise ProxyError("upstream_first_audio_timeout", 504, ...)
    if up.status != 200: raise map_upstream_status(up)       # 400/401/429/5xx → D6
    if not ctype(up).startswith("audio/pcm") or up.headers.get("x-sample-rate") != "48000":
        raise ProxyError("upstream_bad_format", 502, ...)
    self.enc = Mp3Encoder(ffmpeg_path, mp3_bitrate); await enc.start()   # PermissionError/OSError → transcode_failed 500
    self.pump = create_task(self.pump_in())        # upstream → enc.feed, counts pcm_bytes, then enc.close()
    try:
        chunk = await wait_for(enc.read(), timeout=self.deadline - loop.time())
    except TimeoutError: raise ProxyError("upstream_first_audio_timeout", 504, ...)
    if chunk == b"":                               # ffmpeg ended before any MP3
        await self.pump                            # re-raises upstream errors → upstream_unavailable
        if self.pcm_bytes == 0: raise ProxyError("upstream_empty_audio", 502, ...)
        raise ProxyError("transcode_failed", 500, ...)
    return chunk

async def body(self, first):
    self.outcome = None
    try:
        yield self.write(first)                    # sets ttfb_ms, bytes_out, gap tracking
        while True:
            if loop.time() > t0 + request_max_s: self.fail("request_max_exceeded")
            chunk = await self.read_or_fail()      # races enc.read() with self.pump; pump error → upstream_stream_broken
            if chunk == b"": break
            yield self.write(chunk)
        rc = await enc.wait(); self.ffmpeg_ms = ...
        if rc != 0: self.fail("transcode_failed")
        await self.pump                            # must have finished cleanly
        self.outcome = 200
    except AbortStream as e:
        self.outcome = (502, e.code); raise        # raising inside the iterator: uvicorn drops the socket, no final chunk (X2)
    except (asyncio.CancelledError, GeneratorExit, OSError):
        self.outcome = self.outcome or (499, "client_disconnected"); raise
    finally:
        await self.close()                         # idempotent

async def close(self):
    if self.closed: return
    self.closed = True
    for t in (self.pump,): t and t.cancel()
    if self.enc: await self.enc.kill()             # reaps ffmpeg even if cancelled (shielded)
    await self.stack.aclose()                      # closes upstream response → VieNeu sees disconnect
    if self.slot_held: self.release_slot(); self.slot_held = False   # never release a slot that proxy_busy never acquired
    fill log timings; audio_seconds = round(pcm_bytes / 2 / 48000, 3)
    if self.committed: log.status = 200 if outcome == 200 else outcome[0]; log.error_code = ...
    emit(log)                                      # exactly once per request
```

Cancellation safety: `close()` runs under `asyncio.shield` for the `kill()`/`aclose()` part; `pump_in` catches `CancelledError`, closes ffmpeg stdin and re-raises; `Mp3Encoder.kill()` swallows `ProcessLookupError`. `log` is emitted once (`self.closed` guard); `BackgroundTask` covers a response that was never iterated.

## Failure handling and edge cases

- ffmpeg missing at request time (deleted after startup) → `transcode_failed` 500 before commit.
- Upstream sends headers then stalls → `upstream_first_audio_timeout` 504 (deadline counts from arrival, D4).
- PCM arrives but ffmpeg writes nothing before stdin close → `transcode_failed` 500 (not a 200).
- Odd `pcm_bytes` → accepted, warning logged.
- Non-`ProxyError` exceptions before commit: `httpx.TransportError` → 502 `upstream_unavailable`; `OSError` from ffmpeg → 500 `transcode_failed`; anything else is a bug: `close()` still runs (slot released, ffmpeg reaped, one log line with `status: 500`, `error_code: internal_error`), then the exception propagates and uvicorn logs it to stderr. `internal_error` is the log-only D6 row for this case.
