# 04.1.2-T3 — MPT-side acceptance and performance baseline

| Story | Size | Area | Depends on | Blocks | Phase / flag |
|---|---|---|---|---|---|

## Goal

Prove with MPT's own code path (`app.services.voice.tts()` → `kokoro_tts` → `_openai_compatible_tts`, MPT's pinned `requests` and `moviepy`, M1–M3, M9) that the running proxy delivers complete, decodable MP3 for short and 5-minute vi/en texts, measure it against the direct-VieNeu baseline, and publish the CR-2 pass/fail numbers (`ttfb_ms` < 30,000, `max_gap_ms` < 60,000) in `trial/baselines/proxy-mac-<YYYYMMDD>.json`. Also prove the failure path: VieNeu dies mid-request → 3 MPT attempts → task fails at `audio` (M2, M8).

## Design

**Files (tracked).**
- `trial/tools/bench-proxy.sh` — Bash, `set -euo pipefail`, shellcheck clean, `--help`, exit 0 pass / 1 fail / 2 usage-or-env; sources `worker-node/bin/lib.sh` (`nts_home`, `load_pins`, `log`, `die`). Options: `--repeats N` (default 2), `--fixtures vi-1000,en-1000,vi-5min,en-5min`, `--inject-failure`, `--out FILE` (baseline path; default `trial/baselines/proxy-mac-<YYYYMMDD>.json` from the **local** run start date — the same local day as the file's `date` field, while `started_at_utc` stays UTC ISO-8601), `--force` (overwrite the target in place). Existing file: the **default** name keeps its `-2`, `-3`, … sibling fallback and logs the path it used, unless `--force` overwrites the default; an explicit `--out FILE` that exists without `--force` is a usage error, exit 2 (no sibling fallback).
- `trial/tools/bench_proxy_mpt.py` — stdlib only; run as `cd "$NTS_HOME/src/mpt" && .venv/bin/python "$REPO/trial/tools/bench_proxy_mpt.py" <fixture> <voice> <out.mp3>`; imports `app.services.voice`, calls `tts(text=<file text>, voice_name=f"kokoro:{voice}", voice_rate=1.0, voice_file=<out.mp3>)`, prints one JSON line `{fixture, voice, ok, client_wall_ms, out_bytes}` (`ok` = returned value is not `None` and file exists). Never prints the text.
- `worker-node/proxy/tools/mpt_decode_check.py` — D14; `<mp3>` → prints `{"path":…, "duration_s": …}` from `moviepy.AudioFileClip`; exit 1 if duration not finite or ≤ 0.

**Correlation.** The proxy log (`$NTS_HOME/logs/proxy-*.log`, newest file, D7) is read after each call; the run takes the single new `route = "/v1/audio/speech"` line (the bench runs calls sequentially, so exactly one new line per call; more → exit 1).

**Baseline schema `proxy-baseline.v1`.**

```json
{ "schema": "proxy-baseline.v1", "date": "2026-10-01", "machine": { "model": "…", "cpu": "…", "ram_gb": 32, "os": "…" },
  "pins": { "vieneu_commit": "<40 hex>", "mpt_version": "1.3.7", "requests": "2.33.1", "moviepy": "2.2.1", "ffmpeg": "…" },
  "proxy": { "mp3_bitrate": "192k", "proxy_max_concurrent": 2, "catalog_revision": 0 },
  "runs": [ { "fixture": "vi-5min", "voice": "Hải Đăng", "repeat": 1, "ok": true, "status": 200,
      "chars": 4210, "audio_seconds": 301.337, "moviepy_duration_s": 301.37, "ttfb_ms": 1290, "max_gap_ms": 2210,
      "vieneu_ms": 175210, "ffmpeg_ms": 84, "wall_ms": 175420, "client_wall_ms": 175980,
      "direct_vieneu_wall_ms": 172900, "overhead_pct": 1.8 } ],
  "checks": { "ttfb_lt_30s": true, "max_gap_lt_60s": true, "overhead_le_5pct": true, "duration_within_0_1s": true },
  "failure_injection": { "mpt_attempts": 3, "proxy_statuses": [502, 502, 502], "task_failed_stage": "audio", "ok": true },
  "result": "pass" }
```

`overhead_pct = (median(wall_ms) − direct_vieneu_wall_ms) / direct_vieneu_wall_ms × 100` per fixture, direct wall from 01.2.1-T4 (same machine). Informational since 04 CR-17/T20 (2026-09-28) — `overhead_le_5pct` gates on `in_request_overhead_pct` instead. No input text, no keys.

**Additive fields (2026-09-26, `04 CR-17`; QA-PR7-1/3).** These keys are **additions**: nothing above is renamed, removed or re-purposed. CR-17 was accepted 2026-09-28 (option 2, T20): `in_request_overhead_pct` is the NFR-04-3 gate metric; `overhead_pct` and `rtf_normalised_overhead_pct` stay informational.

```json
{ "…": "…",
  "finished_at_utc": "2026-10-01T01:14:07Z", "direct_baseline_voice": "Hải Đăng",
  "paths_relative_to": "$NTS_HOME", "skipped_checks": [],
  "test_ids": { "mpt_tts_5min_vi_under_idle_timeout": "vi-5min", "…": "…" },
  "summary": { "vi-5min": { "proxy_rtf": 0.18231, "direct_rtf": 0.18561,
      "rtf_normalised_overhead_pct": -1.78, "in_request_overhead_pct": 0.0086 } } }
```

- `summary.<fx>.proxy_rtf` = median over the fixture's runs of `wall_ms / (audio_seconds × 1000)`; `summary.<fx>.direct_rtf` = `direct_vieneu_wall_ms / (direct_vieneu_audio_s × 1000)` taken from the direct baseline (null when that baseline has no audio for the fixture).
- `summary.<fx>.rtf_normalised_overhead_pct` = `(proxy_rtf − direct_rtf) / direct_rtf × 100`, rounded to 2 decimals (null if either RTF is null). Informational only since 04 CR-17/T20 (the NFR-04-3 gate is `in_request_overhead_pct`, next bullet).
- `summary.<fx>.in_request_overhead_pct` = median over the fixture's runs of `(wall_ms − vieneu_ms) / vieneu_ms × 100`, rounded to 4 decimals, computed from the same D7 log lines the bench already reads (runs with a null `wall_ms` or `vieneu_ms` are skipped; `null` when no run qualifies, never a substituted value). It needs no second run, so it is drift-free.
- `direct_baseline_voice` = the voice the direct-VieNeu baseline was recorded with (its `runs[].voice`, else a top-level `voice`), `"unknown"` when the file records none. For `trial/baselines/vieneu-mac-20260925.json` this is `Hải Đăng`, i.e. **the en fixtures' denominator is a vi-voice run** (CR-17).
- `paths_relative_to: "$NTS_HOME"` = every local path in the file (`runs[].mp3_path`) is written **relative to `$NTS_HOME`**, never absolute (SEC-PR7-3).
- `test_ids` = map from this task's Tests ids to the fixture/check name recorded in this file: `mpt_tts_short_vi_200_decodes` → `vi-1000`, `mpt_tts_short_en_200_decodes` → `en-1000`, `mpt_tts_5min_vi_under_idle_timeout` → `vi-5min`, `mpt_tts_5min_en_under_idle_timeout` → `en-5min`, `mpt_tts_vieneu_killed_three_attempts_task_fails_audio` → `failure_injection`.
- `finished_at_utc` = assembly time (ISO-8601 UTC, `Z`); `started_at_utc` is the **run's** start and is stamped when the run begins, not at assembly (QA-PR7-3).
- `skipped_checks` = the checks that could not be evaluated (today only `overhead_le_5pct`); `[]` otherwise.

**Pass rule (CR-2, gate 04-M0).** For every run: `status = 200`, `ok`, `ttfb_ms < 30000`, `max_gap_ms < 60000`, `|moviepy_duration_s − audio_seconds| ≤ 0.1`; per 5-min fixture `summary.<fx>.in_request_overhead_pct ≤ 5` (NFR-04-3; metric per 04 CR-17/T20 — `overhead_pct` and `rtf_normalised_overhead_pct` are informational, never gating); failure injection `ok`. Any miss → `result: "fail"`, exit 1. **No `-5min` fixture in `--fixtures`, or a `-5min` fixture whose `in_request_overhead_pct` is null** (no run carried a usable D7 `wall_ms`+`vieneu_ms` pair): NFR-04-3 is not evidenced, so `checks.overhead_le_5pct = null` (never the vacuous `all([]) = true`), `skipped_checks: ["overhead_le_5pct"]`, `result: "incomplete"` and exit 1 — an un-evidenced NFR is not a pass (QA-PR7-1). The `≤ 5 %` threshold itself is unchanged; `result` has three values: `pass`, `fail`, `incomplete`, and the verdict line prints `INCOMPLETE 04.1.2-T3`.

## Steps

1. Preconditions: VieNeu up (`curl -fsS http://127.0.0.1:8000/health`), proxy started by `start-proxy.sh` (04.1.5-T1), `smoke-proxy.sh` PASS, MPT `config.toml` `[kokoro] base_url = "http://127.0.0.1:8001/v1"`. Else exit 2.
2. For each fixture × repeat (sequential): run the helper in MPT's venv; read the new proxy log line; run `mpt_decode_check.py` with MPT's interpreter; print `INFO bench.<fixture>.<n>: ttfb_ms=… max_gap_ms=…`.
3. Compute overheads from the 01.2.1-T4 baseline; write `trial/baselines/proxy-mac-<YYYYMMDD>.json`.
4. `--inject-failure`: start `vi-5min` through MPT's task path using 01.2.2-T5's submit helper (`voice_name = "kokoro:Hải Đăng"`); when the proxy log shows the request (poll VieNeu `/health` `active = 1`), stop VieNeu (`kill` the PID from 01.2.1-T2's pidfile); wait for the MPT task to reach a terminal state; collect from the MPT log the attempt lines and the task's `failed_stage` and error text; restart VieNeu with its start script and wait for `/health`.
5. Print `PASS 04.1.2-T3` or `FAIL 04.1.2-T3: <check>`; hand the file to the TL for CR-2.

## Acceptance checks

- `trial/tools/bench-proxy.sh --repeats 2 --inject-failure` → exit 0, last line `PASS 04.1.2-T3`.
- `python3 -c 'import json,sys; b=json.load(open(sys.argv[1])); assert b["result"]=="pass" and len(b["runs"])==8'` on the file → exit 0.
- Failure injection: the proxy log shows 3 speech lines for that task, the first `status: 502` `error_code: upstream_stream_broken` (post-commit abort), the next two `status: 502` `upstream_unavailable`; the MPT task shows `failed_stage = "audio"` and error `failed to synthesize audio; verify the selected voice and TTS connectivity` (M8).
- `grep -c 'Authorization\|Bearer' trial/baselines/proxy-mac-*.json` = 0.

## Tests

- No new pytest tests (this task is the acceptance run). `bench-proxy.sh` is checked with `shellcheck trial/tools/bench-proxy.sh` and `bench-proxy.sh --help` (exit 0).
- The run itself exercises, with MPT's pinned client: `mpt_tts_short_vi_200_decodes`, `mpt_tts_short_en_200_decodes`, `mpt_tts_5min_vi_under_idle_timeout`, `mpt_tts_5min_en_under_idle_timeout`, `mpt_tts_vieneu_killed_three_attempts_task_fails_audio` — these ids are the `fixture`/check names recorded in the baseline file, not pytest tests.

## Failure handling and edge cases

- `tts()` returns `None` but the proxy log says 200 → MPT-side decode issue; keep the MP3, run `mpt_decode_check.py`, record, `FAIL`.
- `ttfb_ms` ≥ 30,000 on the 5-min fixture → CR-2 fail; report to TL with `admission_wait_ms` and `vieneu_ms` (capacity problem, not a timeout bug).
- Overhead > 5 % but gaps fine → FAIL of NFR-04-3 only; TL decides (bitrate, `flush_packets` cost).
- Failure injection kills VieNeu before commit → first status is 502 `upstream_unavailable` instead of `upstream_stream_broken`; rerun, waiting for `ttfb_ms` evidence (first proxy write) before the kill.
- 01.2.1-T4 baseline missing for a fixture → exit 2 (cannot compute overhead); do not substitute.
- MPT attempt log wording for exceptions is not quoted in M2 ⚠️ — count attempts from the proxy log (authoritative) and record MPT's lines verbatim.
