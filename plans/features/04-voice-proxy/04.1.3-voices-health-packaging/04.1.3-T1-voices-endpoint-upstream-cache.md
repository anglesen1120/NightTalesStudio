## Goal

`GET /v1/audio/voices` returns the catalog's active voices that also exist upstream, in the shape MPT's (unused) voice-list reader would accept, without ever calling VieNeu on the request path — backed by a small background cache of VieNeu's canonical voice names.

## Design

### `upstream.py` addition

```python
async def voices(self) -> list[dict]:
    """VieNeu GET /v1/voices → the `data` array (V7). Raises ProxyError(upstream_auth_failed) on
    401/403 and ProxyError(upstream_unavailable) on connect/timeout/5xx/other non-200/invalid JSON;
    the caller (voice_cache.py) records the code as a refresh failure, not a request failure."""
```

Uses the same `httpx.AsyncClient` and `VIENEU_API_KEY` bearer as `speech_stream`/`health` (one client instance on `app.state.vieneu`, built from `Settings` in 04.1.2-T1). Connect timeout = `UPSTREAM_CONNECT_TIMEOUT_S`; read timeout fixed at 5 s (voice list is small and this call is never on the hot path).

### `voice_cache.py`

```python
@dataclass
class _CacheState:
    names: frozenset[str]
    last_error: str | None          # D6 code of the LATEST refresh if it failed, else None
    ever_succeeded: bool
    last_refresh_monotonic: float

class UpstreamVoiceCache:
    def __init__(self, client: VieneuClient, interval_s: int): ...
    async def start(self) -> None:      # spawns the background asyncio.Task, does one synchronous
                                         # refresh first so the cache is warm before serving requests
    async def stop(self) -> None:       # cancels the task; called from app lifespan shutdown
    async def names(self) -> frozenset[str]:  # returns the current cached set, never awaits I/O
    @property
    def last_error(self) -> str | None: ...   # "upstream_auth_failed" | "upstream_unavailable" | None
    @property
    def ever_succeeded(self) -> bool: ...
```

- `names()` = the set of `entry["id"]` for every entry in VieNeu's `data` array (the server sets `id` = `name` = the preset key, README D9 / `openai_speech.py` L149) — **canonical names only**; `entry["aliases"]` is read and discarded (F07: an alias must never satisfy `id ∈ UpstreamVoiceCache.names()`).
- Refresh loop: `await asyncio.sleep(interval_s)` then call `client.voices()`. On success, replace `names`, clear `last_error`, set `ever_succeeded = True`. On `ProxyError`, keep the previous `names` and set `last_error = exc.code`; on any other exception, keep `names` and set `last_error = "upstream_unavailable"`; log a warning (structured, code only). The latest refresh result always overwrites `last_error`, so a stale cache never hides a failure (README D8). The loop never raises out of itself (a broad `except Exception` around the refresh body; `asyncio.CancelledError` is re-raised).
- Startup: `start()` performs one refresh **before** returning, so the very first request after boot has real data; if that first refresh fails, `names()` starts as an empty `frozenset`, `ever_succeeded = False` and `last_error` is set. 04.1.4-T1's health then reports `vieneu_auth_failed` or `vieneu_unreachable` (by code), **not** `catalog_voice_missing` (README D8).

### Route

Registered in `app.py` (04.1.2-T1's file; this task adds the handler and the one line that includes it):

```python
@router.get("/v1/audio/voices")
async def list_voices(request: Request) -> JSONResponse:
    require_bearer(request)                                   # D2 auth, same helper as /v1/audio/speech
    upstream_names = await request.app.state.voice_cache.names()
    catalog: Catalog = request.app.state.catalog
    voices = [
        {"id": v.id, "name": v.display_name, "language": v.language, "gender": v.gender}
        for v in catalog.active_voices()
        if v.id in upstream_names
    ]
    return JSONResponse({"voices": voices})
```

No pagination, no filtering query params (not in D9). Order = catalog file order (stable, no sort — avoids a spurious diff-noise requirement).

## Failure handling and edge cases

| Case | Behaviour |
|---|---|
| VieNeu unreachable at every refresh since boot | `names()` stays `frozenset()`; `/v1/audio/voices` returns `{"voices": []}` (200, not an error — the route itself never calls upstream, so it has nothing to fail on); `04.1.4-T1`'s health reports `vieneu_unreachable` (or `vieneu_auth_failed` on 401/403), not `catalog_voice_missing` |
| Catalog has zero active voices for a language (should not happen post-D9 validation, but this route does not re-validate the catalog) | Returns whatever is active; an empty result is valid JSON, not an error |
| VieNeu adds a new voice never in the catalog | Ignored — the route only ever returns catalog ids, never anything upstream-only |
| Background task raises an unexpected (non-`ProxyError`) exception | Caught by the broad `except Exception` in the loop body; logged; loop continues on the next tick; cache never crashes the process |
| `stop()` called mid-refresh at shutdown | `asyncio.CancelledError` propagates through `await asyncio.sleep`/the httpx call; the task exits cleanly, no orphaned socket (httpx client itself is closed by `app.py`'s existing shutdown, owned by 04.1.2-T1) |
| Concurrent requests during a refresh | `names()` reads an immutable `frozenset` reference; no lock needed (the refresh swaps the reference, never mutates in place) |

## Notes

- This task deliberately does **not** add a manual "refresh now" endpoint or query parameter — D9 says "Reload = restart" for the catalog file itself, and the upstream cache has its own fixed interval; adding an on-demand refresh would be undocumented scope.
- `01.2.2-T6`'s dependency on this story is **soft** (CR-6): MPT's API render path never calls this route (M6), so `01.2.2-T6` (wiring render) does not have to wait for this task to complete; it only benefits from it for local verification.
