## Design

### Lock and licences

- `worker-node/proxy/pyproject.toml` pins the D1 dependency set (`fastapi`, `uvicorn` without `[standard]`, `httpx`; test: `pytest`, `pytest-asyncio`, `requests`) and `requires-python = "==3.12.*"`.
- `uv lock --project worker-node/proxy` produces `uv.lock` (committed, with hashes, D1).
- Licence table: `uv export --project worker-node/proxy --format requirements-txt --no-hashes | ...` piped through `pip-licenses`-equivalent, or read directly from `uv.lock`'s package metadata (⚠️ exact tool [INFERENCE] — resolved when the lock is actually run; the acceptance check below is the hard requirement, not the tool). Output: `worker-node/proxy/LICENSES.md`, one row per resolved package (name, version, licence). Any row with an AGPL family or a non-commercial licence fails this task (reject the dependency, do not vendor around it, find an alternative).

### `worker-node/bin/start-proxy.sh`

```bash
#!/usr/bin/env bash
set -euo pipefail
source "$(dirname "${BASH_SOURCE[0]}")/lib.sh"

usage() { echo "Usage: start-proxy.sh [--check]"; }
CHECK_ONLY=0
[[ "${1:-}" == "--help" ]] && { usage; exit 0; }
[[ "${1:-}" == "--check" ]] && CHECK_ONLY=1

[[ "$CHECK_ONLY" == "1" ]] || require_port_free 8001   # exits 2 when the port is already listening (01 D4); --check works while the proxy runs

PROXY_API_KEY="$(secret nts.proxy.api_key)"
VIENEU_API_KEY="$(secret nts.vieneu.api_key)"
REPO_ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/../.." && pwd)"
VOICE_CATALOG_FILE="$REPO_ROOT/seed/voices.v1.json"

if ! curl -fsS -o /dev/null "http://127.0.0.1:8000/health"; then
  die 2 "VieNeu is not listening on 127.0.0.1:8000; start it first (01.2.1-T2 start-vieneu.sh)"
fi

export PROXY_HOST=127.0.0.1 PROXY_PORT=8001 PROXY_API_KEY VIENEU_API_KEY \
  VIENEU_BASE_URL=http://127.0.0.1:8000 VOICE_CATALOG_FILE PROXY_MAX_CONCURRENT=2

PY="$(nts_home)/src/proxy-venv/bin/python"
[[ -x "$PY" ]] || die 2 "proxy venv missing; run worker-node/bin/bootstrap.sh proxy"

if [[ "$CHECK_ONLY" == "1" ]]; then
  "$PY" -c \
    "import os, sys
from nts_vieneu_proxy.config import Settings, ConfigError
from nts_vieneu_proxy.catalog import load_catalog, CatalogError
try:
    s = Settings.from_env(os.environ); load_catalog(s.voice_catalog_file)
except (ConfigError, CatalogError) as e:
    print(f'invalid: {e}', file=sys.stderr); sys.exit(2)
print('config OK')" || exit 2
  exit 0
fi

LOG="$(nts_home)/logs/proxy-$(date +%Y%m%d-%H%M%S).log"
log "starting proxy, log: $LOG"
# No exec: the proxy runs in the foreground as a child of this script, its output tee'd to the log (01 D9).
"$PY" -m nts_vieneu_proxy 2>&1 | tee "$LOG"
exit "${PIPESTATUS[0]}"
```

- `require_port_free`, `secret`, `nts_home`, `log`, `die` are existing `lib.sh` helpers (01 conventions) — reused, not redefined.
- Keys never touch `argv` or a log line: `secret` returns them on stdout into a shell variable, which is only ever placed into the **environment** of the proxy child process.
- `--check` mode runs `Settings.from_env` + `load_catalog` in-process (catches config/catalog errors, D1/D9/`ConfigError`/`CatalogError`) without binding the port — usable pre-flight.
- Refuses to start if VieNeu's own `/health` is not answering on 8000 (fast, clear failure instead of a slow first-request timeout).
- Foreground, not `exec`'d (an `exec` inside a pipeline does not replace the script); the exit code is the proxy's (`PIPESTATUS[0]`). The listener's command line is `…/proxy-venv/bin/python -m nts_vieneu_proxy`, which the 01.2.2-T4 check matches.

### `worker-node/bin/smoke-proxy.sh`

```bash
#!/usr/bin/env bash
set -euo pipefail
source "$(dirname "${BASH_SOURCE[0]}")/lib.sh"

BASE="http://127.0.0.1:8001"
PROXY_API_KEY="$(secret nts.proxy.api_key)" || die 2 "nts.proxy.api_key missing"
[[ ${#PROXY_API_KEY} -ge 32 ]] || die 2 "nts.proxy.api_key too short"
command -v curl >/dev/null && command -v ffprobe >/dev/null && command -v lsof >/dev/null || die 2 "curl/ffprobe/lsof missing"
TMP="$(mktemp -d)"; trap 'rm -rf "$TMP"' EXIT
RC=0
pass() { echo "PASS $1"; }
fail() { echo "FAIL $1: $2"; RC=1; }
# Fresh process substitution per call: a <(…) fd can be read only once, and the key never enters argv (01 D3).
acurl() { curl -sS -H @<(printf 'Authorization: Bearer %s\n' "$PROXY_API_KEY") "$@"; }
# JSON checks without jq (01 D9: jq is not assumed): stdlib Python, the expression gets the parsed object as `d`.
pyjson() { uv run --no-project --python 3.12 python -c "import json,sys; d=json.load(sys.stdin); sys.exit(0 if ($1) else 1)"; }
pyget()  { uv run --no-project --python 3.12 python -c "import json,sys; d=json.load(sys.stdin); print($1)"; }

check_health() {
  local code; code="$(curl -sS -o "$TMP/health.json" -w '%{http_code}' "$BASE/health")"
  [[ "$code" == "200" ]] && pyjson 'd["schema"]=="proxy-health.v1" and d["reasons"]==[]' <"$TMP/health.json" \
    && pass health_200_schema || fail health_200_schema "code=$code"
}
check_auth_required() {
  local code; code="$(curl -sS -o /dev/null -w '%{http_code}' -H 'Content-Type: application/json' -d '{}' "$BASE/v1/audio/speech")"
  [[ "$code" == "401" ]] && pass speech_no_key_401 || fail speech_no_key_401 "code=$code"
  code="$(curl -sS -o /dev/null -w '%{http_code}' -H @<(printf 'Authorization: Bearer wrong-%s\n' "$(openssl rand -hex 16)") \
    -H 'Content-Type: application/json' -d '{}' "$BASE/v1/audio/speech")"
  [[ "$code" == "401" ]] && pass speech_wrong_key_401 || fail speech_wrong_key_401 "code=$code"
}
check_no_docs() {
  local p code
  for p in /docs /redoc /openapi.json; do
    code="$(curl -sS -o /dev/null -w '%{http_code}' "$BASE$p")"
    [[ "$code" == "404" ]] && pass "no_route_${p#/}" || fail "no_route_${p#/}" "code=$code"
  done
}
check_method_not_allowed() {
  local code; code="$(acurl -o /dev/null -w '%{http_code}' -X POST "$BASE/v1/audio/voices")"
  [[ "$code" == "405" ]] && pass voices_post_405 || fail voices_post_405 "code=$code"
}
check_clone_route_404() {   # VieNeu's clone upload route is never proxied (01 CR-2, D2)
  local code; code="$(acurl -o /dev/null -w '%{http_code}' -X POST "$BASE/v1/voices")"
  [[ "$code" == "404" ]] && pass clone_route_404 || fail clone_route_404 "code=$code"
}
check_voices_nonempty() {
  acurl "$BASE/v1/audio/voices" -o "$TMP/voices.json"
  pyjson 'len(d["voices"])>0' <"$TMP/voices.json" && pass voices_nonempty || fail voices_nonempty "empty list"
}
check_unknown_voice_400() {
  local code; code="$(acurl -o "$TMP/unknown.json" -w '%{http_code}' -H 'Content-Type: application/json' \
    -d '{"input":"xin chào","voice":"__no_such_voice__"}' "$BASE/v1/audio/speech")"
  [[ "$code" == "400" ]] && pyjson 'd["error"]["code"]=="voice_not_in_catalog"' <"$TMP/unknown.json" \
    && pass unknown_voice_400_code || fail unknown_voice_400_code "code=$code"
}
check_mp3_and_log() {
  local marker="smokemarker$(openssl rand -hex 4)" voice body head dur logf last
  voice="$(pyget 'd["voices"][0]["id"]' <"$TMP/voices.json")"
  body="$(VOICE="$voice" MARKER="$marker" uv run --no-project --python 3.12 python -c \
    'import json,os; print(json.dumps({"input": "Đêm nay trời trong, gió nhẹ. " + os.environ["MARKER"], "voice": os.environ["VOICE"]}, ensure_ascii=False))')"
  acurl --max-time 120 -H 'Content-Type: application/json' --data-binary "$body" "$BASE/v1/audio/speech" -o "$TMP/smoke.mp3"
  head="$(xxd -p -l2 "$TMP/smoke.mp3")"
  [[ "$head" == "fffb" ]] && pass mp3_frame_sync || fail mp3_frame_sync "head=$head"
  dur="$(ffprobe -v error -show_entries format=duration -of csv=p=0 "$TMP/smoke.mp3")"
  awk -v d="$dur" 'BEGIN{exit !(d>0.5)}' && pass mp3_duration || fail mp3_duration "dur=$dur"
  sleep 1   # the D7 line is written after the response ends
  logf="$(ls -t "$(nts_home)"/logs/proxy-*.log | head -1)"
  last="$(grep -F '"route":"/v1/audio/speech"' "$logf" | tail -1)"
  printf '%s' "$last" | pyjson 'all(k in d for k in ("ts","rid","route","voice","chars","audio_seconds","vieneu_ms","ffmpeg_ms","ttfb_ms","max_gap_ms","status","http_status")) and d["status"]==200' \
    && pass log_line_has_d7_fields || fail log_line_has_d7_fields "fields/status"
  grep -qF "$marker" "$logf" && fail log_line_no_input_text "marker found in log" || pass log_line_no_input_text
  local hits; hits="$(grep -cFf <(printf '%s\n' "$PROXY_API_KEY") "$logf" || true)"   # pattern from an fd, never argv (01 SEC-08)
  [[ "$hits" == "0" ]] && pass log_no_key_leak || fail log_no_key_leak "hits=$hits"
}
check_listener() {
  local rows pid cmd
  rows="$(lsof -a -nP -iTCP:8001 -sTCP:LISTEN -Fpn 2>/dev/null)"
  pid="$(printf '%s\n' "$rows" | sed -n 's/^p//p' | head -1)"
  cmd="$(ps -o command= -p "$pid" 2>/dev/null || true)"
  [[ "$cmd" == *"-m nts_vieneu_proxy"* ]] && pass listener_entry_point || fail listener_entry_point "cmd=${cmd:0:80}"
  printf '%s\n' "$rows" | sed -n 's/^n//p' | grep -qvE '^(127\.0\.0\.1|\[::1\]):8001$' \
    && fail listener_loopback_only "non-loopback listener" || pass listener_loopback_only
}

check_health; check_auth_required; check_no_docs; check_method_not_allowed; check_clone_route_404
check_voices_nonempty; check_unknown_voice_400; check_mp3_and_log; check_listener
exit "$RC"
```

(Sketch — exact function bodies are implemented against the real running proxy in this task; the row list above is the acceptance contract, not just an example.) Joins `smoke.sh` (01.2.1-T3 aggregator) as one more sourced script; `check-binds.sh` (01.2.1-T3, existing helper) is reused for the listener-command and bind-address checks (CR-6: command must contain `nts_vieneu_proxy`; bind must be `127.0.0.1:8001` only, no `0.0.0.0`).

## Failure handling and edge cases

| Case | Behaviour |
|---|---|
| Port 8001 already bound | `start-proxy.sh` → `require_port_free 8001` exits 2 (01 D4) before touching Keychain |
| VieNeu not listening on 8000 | `start-proxy.sh` → `die 2` with a clear message, no proxy process started |
| Keychain item missing | `secret nts.proxy.api_key` fails (existing `lib.sh` behaviour) → script exits before any network call |
| `uv lock` resolves a package with an unacceptable licence | Task is not done; swap the dependency (e.g. an alternative ASGI/HTTP library) — never vendor around a rejected licence |
| `smoke-proxy.sh` run against a proxy with only revision-0 catalog (development) | `voices_nonempty` still passes (2 entries, D9); `unknown_voice_400_code` still passes (any id not `Hải Đăng`/`Ngọc Huyền` is unknown) |
| Systemd unit's paths differ from the node layout | Paths are fixed by 11 D8 (11 CR-6); 11.3.1-T2 checks the unit with `systemd-analyze verify` before activation |
| `smoke.sh` aggregator run without a proxy running | The proxy section reports `FAIL` rows (connection refused), not a crash of the whole aggregator — matches the 01.2.1-T3 aggregator's existing per-section isolation |

## Notes

- The `--check` mode intentionally reuses the pinned `Settings.from_env`/`load_catalog` functions directly (no HTTP), so a config typo is caught in under a second instead of via a failed `curl`.
- `smoke-proxy.sh`'s `mp3_frame_sync` check accepts `fffb` (MPEG-1 Layer III) or `fff3` (MPEG-2) sync words — ffmpeg's exact frame-sync byte depends on the sample rate/layer chosen; the D4 command fixes `-ar 48000`, which is MPEG-1, so `fffb` is the expected value in practice, `fff3` accepted defensively.
