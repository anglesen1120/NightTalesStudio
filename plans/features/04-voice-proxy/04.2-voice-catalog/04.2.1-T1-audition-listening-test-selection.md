## Goal

Every VieNeu preset (except `Adam bựa`, O4) is heard in a ghost-story register in Vietnamese and in English by blind raters, and 3–4 voices per language are selected against the D11 thresholds — with the scores, tags and selection recorded as tracked evidence, so that 04.2.2-T1 can write catalog revision 1 without further judgement calls.

- V8 ✅ (25 presets, NFC, `gender`, `description` = `Nam/Nữ · Bắc/Trung/Nam · <style>`, aliases), V11 ✅ (upstream RTF 0.58 fp32 one stream).

## Design

### Audition texts

| File | Target | Content rule |
|---|---|---|
| `trial/fixtures/voice-audition.vi.txt` | ≈ 85 syllables (≈ 30 s at ≈ 170 syllables/min [INFERENCE]; replace with the 01.2.1-T4 measured rate) | ghost-story register; includes dialogue, a question, a whisper-like line, numbers, one loanword; all six tones; no real names |
| `trial/fixtures/voice-audition.en.txt` | ≈ 75 words (≈ 30 s at ≈ 150 wpm [INFERENCE]; replace with 01.2.1-T4) | same register; includes `th`, `r/l`, final consonant clusters, one question, one quoted line; no real names |

Both files UTF-8, NFC (checked: `python3 -c 'import sys,unicodedata as u;t=open(sys.argv[1],encoding="utf-8").read();sys.exit(t!=u.normalize("NFC",t))' <file>`), single paragraph, no pause tags.

### Tool `worker-node/proxy/tools/audition.py`

Stdlib only (`urllib.request`, `json`, `subprocess`, `secrets`, `random`, `csv`, `unicodedata`, `argparse`). Run as `uv run --no-project --python 3.12 worker-node/proxy/tools/audition.py <cmd> …` — no proxy venv needed. Exit 0 ok · 1 runtime failure · 2 usage/config.

| Subcommand | Does |
|---|---|
| `candidates --snapshot <f>` | prints the candidate list: `data[].id` minus `Adam bựa`; aliases never listed (V8); each id NFC-checked; exit 2 if the snapshot is unreadable or has 0 candidates |
| `generate --snapshot <f> --lang vi\|en\|both --out <dir>` | for each candidate × language: POST `http://127.0.0.1:8000/v1/audio/speech` with `{ "model": "vieneu-v3-turbo", "input": <text>, "voice": <id>, "response_format": "pcm", "stream_format": "audio", "sample_rate": 48000 }` (same upstream body as D3); checks status 200 and `X-Sample-Rate: 48000`; streams the body into the D4 command `ffmpeg -hide_banner -loglevel error -f s16le -ar 48000 -ac 1 -i pipe:0 -vn -c:a libmp3lame -b:a 192k -write_xing 0 -id3v2_version 0 -flush_packets 1 -f mp3 <dir>/<sample_id>.mp3`; records `pcm_bytes`, `audio_seconds`, `wall_ms` |
| `sheet --out <dir>` | writes blank rater sheets `<dir>/sheet.<lang>.csv` in a fresh random order per language, plus `playlist.<lang>.m3u` in the same order |
| `unblind --key <dir>/key.json --sheets <sheet…> --out trial/voice-audition/results.csv` | joins filled sheets with the key, adds voice metadata, validates scores 1–5 |
| `summarize --results trial/voice-audition/results.csv` | per language × voice: means, pass/fail against thresholds, ranking with tie-breaks, suggested tags; prints a Markdown table for the README |

- Key: `VIENEU_API_KEY` from the environment only (`Authorization: Bearer …` header built in-process); missing → exit 2 `VIENEU_API_KEY not set`; never printed or logged.
- Blind ids: `sample_id = "s-" + secrets.token_hex(3)` per candidate × language, unique (regenerated on collision), carrying no voice information. Mapping `{ sample_id: { voice_id, language } }` written only to `$NTS_HOME/runs/voice-audition/key.json` (facilitator only; not tracked, not shown to raters).
- `FFMPEG_PATH` honoured (default `ffmpeg`), exec without shell.
- `generate` is resumable: an existing `<sample_id>.mp3` of the same voice × language (per `key.json`) is skipped; `--force` regenerates.

### Rater sheet and `results.csv`

Rater sheet `sheet.<lang>.csv` (given to raters): `sample_id, rater, naturalness, intelligibility, night_fit, mispronunciations, rater_tags, notes`.

`trial/voice-audition/results.csv` (tracked, one row per rater × sample, after unblinding):

```
language,sample_id,voice_id,gender,region,style,rater,naturalness,intelligibility,night_fit,mispronunciations,rater_tags,notes
vi,s-3fa9c1,Thiện Minh,male,Bắc,kể chuyện,OW,4,5,5,"",deep;calm,""
```

- `rater` = initials only (§8 of plan.md). Scores are integers 1–5. `mispronunciations` = free text of mispronounced words (never the whole text). `rater_tags` ⊆ {`deep`, `warm`, `calm`, `bright`, `whisper`}, `;`-separated.

### Selection rules

1. Per language, mean over raters: naturalness ≥ **3.5** and intelligibility ≥ **4.0** → passes.
2. Rank passing voices by mean `night_fit`, then naturalness, then intelligibility.
3. Tie-breaks in order: fewer distinct mispronunciations → keeps gender balance → (vi) adds a region not yet selected → VieNeu `featured = true` → lexical order of `id`.
4. Take 3–4. Gender balance goal: ≥ 1 female and ≥ 1 male per language when a passing voice of each gender exists; otherwise record "gender balance not possible" in the README.
5. One language per voice (F08): a voice passing in both languages goes to **en** if en has < 3 passing voices, otherwise to the language where it ranks higher [DECISION: en is the scarce language, F04], unless that leaves vi with < 3.

### Tags

- From the VieNeu `description` (split on `·`, trim; positions: gender · region · style): region `Bắc → northern`, `Trung → central`, `Nam → southern` (the **second** field; the first field `Nam` means male); style `kể chuyện`/`đọc truyện → storyteller`, `tự nhiên`/`giọng đọc tự nhiên → natural`, `tin tức → news`.
- Rater tags: a tag from {`deep`, `warm`, `calm`, `bright`, `whisper`} is kept when ≥ half the raters of that language chose it.
- Max 4 tags (D9): style + region + at most 2 rater tags (most votes first). en entries carry no region tag [DECISION: the region describes a Vietnamese accent, meaningless to en users].

### Time estimate

24 candidates (25 presets − `Adam bựa`, V8; re-count at the pin) × 2 languages = 48 samples × 30 s = 24 min of audio. At RTF 0.58 (V11, upstream) ≈ 14 min generation on CPU plus ≈ 1 s/request overhead → ≈ 15 min; replace with `48 × 30 s × rtf_measured` from 01.2.1-T4. Rater time: 24 × 30 s listening ≈ 12 min per language, ≈ 30–40 min with scoring. Developer effort (tool, texts, facilitation, summary) fits S (0.5).

## Steps

1. Write the two audition texts; check NFC and the size targets (count syllables = whitespace tokens for vi; words for en).
2. Implement `audition.py` (subcommands above) and its tests.
3. `audition.py candidates --snapshot worker-node/vieneu/voices.snapshot.json` → confirm the count (24 expected at c1390abb ⚠️ re-check at the pin).
4. Generate: `source worker-node/bin/lib.sh && VIENEU_API_KEY="$(secret nts.vieneu.api_key)" uv run --no-project --python 3.12 worker-node/proxy/tools/audition.py generate --snapshot worker-node/vieneu/voices.snapshot.json --lang both --out "$(nts_home)/runs/voice-audition"`.
5. `audition.py sheet --out "$(nts_home)/runs/voice-audition"`; hand each rater the playlist + sheet of their language (vi: owner + one native; en: ≥ 1 fluent English listener).
6. Collect sheets; `audition.py unblind …` → `trial/voice-audition/results.csv`.
7. `audition.py summarize …` → paste the table into `trial/voice-audition/README.md`; apply selection and tag rules; write the selected set (id, language, gender, tags, means).
8. If no en candidate passes: write section "O2 escalation" in the README (top 3 en voices with means), send to the owner, record the answer and date. TL recommendation: (a) launch with the best-rated voice if its mean naturalness ≥ 3.0, otherwise (b).
9. Hand the selected set to 04.2.2-T1.

## Failure handling and edge cases

| Case | Behaviour |
|---|---|
| VieNeu 429 (busy, V3) | sleep `Retry-After` (≤ 5 s) and retry, max 5; then record the sample as failed and continue |
| VieNeu 400 unknown voice (snapshot ≠ running pin) | exit 1 after the run with the list; re-take the snapshot (01.2.1-T3) — never edit ids by hand |
| `X-Sample-Rate` ≠ 48000 or 0 PCM bytes | sample marked failed; exit 1 at the end |
| Rater cannot finish | a language needs ≥ 2 vi raters and ≥ 1 en rater; below that, selection is not written |
| Snapshot count ≠ 25 at the pin | use the snapshot (D11 says "all presets of the pinned snapshot"); note the count in the README |
| Fewer than 3 passing vi voices | select the passing ones (≥ 1) and record it; < 1 → owner decision, same path as O2 |
