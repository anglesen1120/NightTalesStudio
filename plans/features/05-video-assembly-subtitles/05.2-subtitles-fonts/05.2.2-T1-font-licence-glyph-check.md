## Goal

Register the two Vietnamese-capable fonts MPT already bundles (`BeVietnamPro-Bold.ttf`, `BeVietnamPro-Medium.ttf`), keep their licence text, prove the bundled copy matches an upstream artefact, and give provisioning and adapter health a fail-closed check that runs MPT's **own** glyph function (D7 ✅). The default `STHeitiMedium.ttc` misses 92 of the 178 Vietnamese letters (X1 ✅, F04 ✅), so a job without `font_name` renders broken vi subtitles.

## Inputs

- Contract `../README.md`: D7, D9 of 01, X1, L1, F04, C16, D14.
- `$MPT_ROOT` (default `$NTS_HOME/src/mpt`) with `resource/fonts/BeVietnamPro-Bold.ttf`, `BeVietnamPro-Medium.ttf`, `STHeitiMedium.ttc` and the venv `$MPT_ROOT/.venv/bin/python` (01.2.2-T1).
- Upstream artefact: the OFL text at the L1 URL `https://raw.githubusercontent.com/bettergui/BeVietnamPro/main/OFL.txt` (✅) plus a release TTF for the binary comparison ⚠️ (URL recorded in `FONTS.csv.source_url`).
- MPT's glyph function `app.services.video.subtitle_font_supports_text` (C16 ✅ — the only caller today is `webui/Main.py` L7774 ⚠️).
- Tools: `uv run --no-project --python 3.12` for stdlib helpers (D14 ✅); Pillow comes with MPT's venv via moviepy ⚠️.

## Design

- **`worker-node/fonts/FONTS.csv`** — header exactly `file,family,style,license,license_url,source_url,sha256,checked_at` (D7 ✅), two rows:
  `BeVietnamPro-Bold.ttf,Be Vietnam Pro,Bold,OFL-1.1,<L1 URL>,<upstream artefact URL>,<measured sha256>,<ISO date>`
  `BeVietnamPro-Medium.ttf,Be Vietnam Pro,Medium,OFL-1.1,<L1 URL>,<upstream artefact URL>,<measured sha256>,<ISO date>`
  The snapshot hash `2fe6c3f9…30bfe` is X1 evidence only: the register records the value measured on the implementation machine at `MPT_COMMIT`.
- **`worker-node/fonts/OFL-BeVietnamPro.txt`** — byte-identical copy of the L1 text; the retrieval date lives in `FONTS.csv.checked_at`.
- **Upstream comparison.** Download the upstream TTF to `$NTS_HOME/runs/font-proof/upstream/` and compare `shasum -a 256`: equal → the bundled copy is the upstream artefact; different → compare the name table with `PIL.ImageFont.truetype(path).getname()` (must report family `Be Vietnam Pro`), record ⚠️ in the task Notes, and keep the MPT copy only if the name table is Be Vietnam Pro **and** the OFL text is present. Never replace the MPT file or add a second font copy to the repo (D7 ✅).
- **`trial/fixtures/vi-glyphs.txt`** — 178 Vietnamese letters (NFC, both cases, all tone combinations) + ASCII letters/digits + the FR sentence `Người đàn bà áo trắng đứng dưới gốc đa`, generated by one documented command that asserts 178.
- **`worker-node/mpt/tools/font_glyph_check.py`** — run with `$MPT_ROOT/.venv/bin/python`; reads the call shape from `webui/Main.py` L7774 at `MPT_COMMIT` and calls `subtitle_font_supports_text(font_path, ch)` **once per distinct letter/digit** of the fixture, because the function returns only a bool and truncates its sample to the first 64 distinct L/N characters (`video.py` L1197–1203; T7). Exit 0 = all characters supported; exit 1 = missing glyphs (prints the distinct letters and the count) **or** a sha256 mismatch against `FONTS.csv`; exit 2 = usage, missing venv/module, or an uncallable signature (prints what it observed — never guesses). `--proof-out FILE` renders the FR sentence at size 84 with PIL.
- **`worker-node/bin/check-fonts.sh [--mpt-root DIR]`** — 01 D9 conventions (exit 0 ok / 1 failed / 2 usage-environment): resolves `$MPT_ROOT` (default `$NTS_HOME/src/mpt`), checks each `FONTS.csv` row (file exists, sha256 matches) and then runs the glyph check with the MPT venv, printing one line per check. Used by 11.3.1-T1 provisioning and by the adapter's cached assets job (`assets.font`, refreshed at start, on change and every 600 s — never per health request, D15 P1).

## Steps

1. `set -euo pipefail`; `export NTS_HOME="${NTS_HOME:-$HOME/.nts}"`; `MPT_ROOT="${MPT_ROOT:-$NTS_HOME/src/mpt}"`; `mkdir -p worker-node/{fonts,bin,mpt/tools} trial/fixtures "$NTS_HOME/runs/font-proof/upstream"`.
2. Measure the hashes and record them in `FONTS.csv`:
   `shasum -a 256 "$MPT_ROOT/resource/fonts/BeVietnamPro-Bold.ttf" "$MPT_ROOT/resource/fonts/BeVietnamPro-Medium.ttf"`
   `$MPT_ROOT/.venv/bin/python -c "from PIL import ImageFont;print(ImageFont.truetype('$MPT_ROOT/resource/fonts/BeVietnamPro-Bold.ttf').getname())"` → expect `('Be Vietnam Pro', 'Bold')`.
3. Fetch the OFL text verbatim into `worker-node/fonts/OFL-BeVietnamPro.txt` and the upstream TTF into the proof dir; compare the sha256 (Design rule) and write the outcome into the task Notes.
4. Generate the fixture with the documented one-liner (asserts 178 unique NFC letters):
   `uv run --no-project --python 3.12 python -c "import unicodedata as u;b='aăâbcdđeêghiklmnoôơpqrstuưvxy';bs=[c for c in b]+[c.upper() for c in b];v='aăâeêioôơuưy';t='\u0300\u0301\u0303\u0309\u0323';L=list(dict.fromkeys(bs+[u.normalize('NFC',c+d) for c in v+v.upper() for d in t]));assert len(L)==178,len(L);x=[chr(c) for c in range(0x30,0x3a)]+[chr(c) for c in range(0x41,0x5b)]+[chr(c) for c in range(0x61,0x7b)];open('trial/fixtures/vi-glyphs.txt','w',encoding='utf-8').write('\n'.join(L+x)+'\nNgười đàn bà áo trắng đứng dưới gốc đa\n')"`
5. Write `font_glyph_check.py` and run it on both registered fonts (expect exit 0) with `--proof-out`.
6. Write `check-fonts.sh`, `chmod +x`, run `bash -n` then `worker-node/bin/check-fonts.sh --mpt-root "$MPT_ROOT"` → exit 0.
7. Look at `$NTS_HOME/runs/font-proof/BeVietnamPro-Bold.png` (size 84, FR sentence): no tofu box, all diacritics legible, correct baseline. Record the observation.
8. Negative tests: `STHeitiMedium.ttc` (X1 expects **92** missing letters) and a corrupted copy of the Bold file (hash mismatch). Record both exit codes and the printed counts.

## Tests

- **Exit-code matrix:** glyph check → 0 on both registered fonts, 1 on `STHeitiMedium.ttc`, 1 on a corrupted copy, 2 with no arguments and 2 when `$MPT_ROOT/.venv/bin/python` is missing.
- **Signature guard:** a venv whose `subtitle_font_supports_text` cannot be called as `(font_path, text)` → exit 2 with the observed signature (no guessing).
- **Hash guard:** a `FONTS.csv` row whose `sha256` differs from the file on disk → exit 1 before the glyph step (fail closed). Wrapper semantics: `check-fonts.sh --mpt-root /nonexistent` → exit 2 with a hint naming 01.2.2-T1; unknown flag → exit 2.

## Failure handling and edge cases

- `$MPT_ROOT/resource/fonts` missing → exit 2 with a hint to 01.2.2-T1; never download a font into the MPT checkout here.
- `subtitle_font_supports_text` import or signature mismatch → exit 2 with the observed signature and escalate to the TL (README open item; C16 cites only `webui/Main.py` L7774 ⚠️). Do not reimplement the glyph test.
- Upstream artefact unreachable or its hash differs → record ⚠️ with the name-table output and keep the MPT copy only if the name table says Be Vietnam Pro and the OFL text is present; never swap the file.
- `STHeitiMedium.ttc` shows a count other than 92 → record the measured count (X1 was measured on the planning Mac with Pillow 11.3.0); the check still exits 1.
- Pillow absent in the MPT venv → skip `--proof-out` (the glyph check must not depend on PIL) and record the proof as not produced.
- No secret is printed and nothing is written outside `$NTS_HOME` and the repo paths above; `check-fonts.sh` needs no key.
