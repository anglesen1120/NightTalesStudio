## Design

### Preset file (D6 verbatim)

`seed/subtitle-presets.v1.json` is written exactly as D6 ✅ — revision 1, `fontName = "BeVietnamPro-Bold.ttf"`:

```json
{ "schema": "subtitle-presets.v1", "revision": 1, "fontName": "BeVietnamPro-Bold.ttf",
  "presets": {
    "landscape": { "fontSize": 84, "strokeWidth": 3.0, "strokeColor": "#000000", "textForeColor": "#FFFFFF",
                   "textBackgroundColor": false, "roundedSubtitleBackground": false,
                   "subtitlePosition": "bottom", "customPosition": 70.0, "maxCharsPerLine": 42, "maxLines": 2 },
    "portrait":  { "fontSize": 64, "strokeWidth": 3.0, "strokeColor": "#000000", "textForeColor": "#FFFFFF",
                   "textBackgroundColor": false, "roundedSubtitleBackground": false,
                   "subtitlePosition": "custom", "customPosition": 62.0, "maxCharsPerLine": 28, "maxLines": 2 } } }
```

`maxCharsPerLine`/`maxLines` are not MPT fields: they drive `subtitle_fit.py` and the advisory `long_cues` count (D6 ✅). The mapper converts the camelCase keys to snake_case; a value change bumps `revision` and `subtitles.preset` becomes `<aspect>@<revision+1>` (D6/D11 ✅).

### Fit tool

`worker-node/mpt/tools/subtitle_fit.py`, run with `$MPT_ROOT/.venv/bin/python`:
`subtitle_fit.py --script FILE --preset landscape|portrait --aspect landscape|portrait [--presets FILE]`

- Splits the script exactly like MPT does: `utils.split_string_by_punctuations(utils.normalize_script_for_subtitle_matching(script))` (C15 ✅) — one cue per chunk.
- Wraps each cue with `app.services.video.wrap_text` at the preset's `fontSize` and 90 % of the frame width (1920 × 0.9 = 1728 px landscape, 1080 × 0.9 = 972 px portrait, C16 ✅).
- Prints per cue `n, chars, lines, longest_line_chars, over_max_lines` (`over_max_lines = lines > maxLines`), then a summary `cues, max_chars_per_line, max_lines_seen, long_cues` (the last = cues with `chars > maxCharsPerLine × maxLines`). Exit 0 always; exit 2 on usage/environment (01 D9).

### Preview renders and frames

- Fixtures `trial/fixtures/subtitle-preview-vi.txt` / `-en.txt`, ≈ 30 s each with clauses of 30–60 chars (vi with diacritics).
- Four renders via `mpt_client.py` with the stubs (vi/en × landscape/portrait), each with `preset = landscape|portrait` and `font_name = "BeVietnamPro-Bold.ttf"`; three frames per render at timestamps inside a cue (checked against `subtitle.srt`): `ffmpeg -ss <t> -frames:v 1 -y "$FRAMES/<id>-t<t>.png"`.
- Portrait frames get the Shorts overlay `trial/fixtures/shorts-overlay-1080x1920.png` composited (BA-drawn from a screenshot of the owner's own Shorts; **never committed if it contains third-party content** ⚠️ — tracked fallback: a rectangle-only mock at the bottom 25 % and the right 15 % [INFERENCE]).
- Owner review (O4 ✅): the frames are the approval surface; without a new decision the tuning range is ± 4 px font size, stroke 2–4 and `customPosition` 55–70 (portrait only — landscape uses `subtitlePosition = "bottom"`, where MPT ignores `customPosition`, C16 ✅).

### Acceptance targets (X2 ✅, D6)

The fit tool must report `max_chars_per_line ≤ 42` chars/line for landscape (size 84) and `≤ 28` for portrait (size 64) on the 30 s fixtures; X2 measured ≤ 41 at size 84, so cues of exactly 42 chars are listed separately for visual review (the cap stays D6's — README open item).

## Steps

1. `set -euo pipefail`; `export NTS_HOME="${NTS_HOME:-$HOME/.nts}"`; `MPT_ROOT="${MPT_ROOT:-$NTS_HOME/src/mpt}"`; `FRAMES="$NTS_HOME/runs/subtitle-preview"`; `mkdir -p seed worker-node/mpt/tools trial/fixtures "$FRAMES"`.
2. Write `seed/subtitle-presets.v1.json` (Design block, verbatim) and validate: JSON parses, `schema`/`revision`/`fontName` present, both presets have exactly the D6 keys.
3. Write the two fixtures (≈ 30 s each; vi with `Đỗ`, `Nguyễn`, `Lý Thường Kiệt`; en with one clause > 84 chars to exercise a 3-line cue).
4. Write `subtitle_fit.py` and run it four times (vi/en × landscape/portrait), e.g. `$MPT_ROOT/.venv/bin/python worker-node/mpt/tools/subtitle_fit.py --script trial/fixtures/subtitle-preview-vi.txt --preset landscape --aspect landscape`; record the summaries in the Notes and check them against the acceptance targets.
5. Render the four previews one at a time (stubs, no spend):
   `uv run --no-project --python 3.12 trial/tools/mpt_client.py run --spec "$FRAMES/<id>.spec.json" --run-dir "$FRAMES/<id>"` — each must end `succeeded` with non-null `output.subtitles` (D4/D9 ✅).
6. Extract the frames (read `subtitle.srt` to pick a timestamp inside a cue) and composite the overlay on the portrait ones (`ffmpeg -i frame.png -i overlay.png -filter_complex overlay -y out.png`), or draw the rectangle mock if the screenshot must not be used.
7. Present the frames to the owner (O4) and record the approval or the requested change: inside the O4 range → adjust and re-render the affected aspect; beyond it → the TL updates D6 first, then `revision` is bumped (D6/D11 ✅).
8. Commit only the preset file, the two fixtures, `subtitle_fit.py` and (conditionally) the overlay mock with its provenance note.

## Tests

- **Fit vs X2:** both fixtures reproduce the X2 ✅ bands at size 84 / 64 within one char, and a deliberate size change (e.g. 70) shows the expected wider band — proves the tool uses the preset size, not a constant.
- **Cue boundary:** a 42-char cue is not `long` (cap = `maxCharsPerLine × maxLines`) and a 3-line cue is `over_max_lines`; both are printed.
- **Determinism and exit codes:** the same script and preset print the same summary twice; 0 for a normal run, 2 for usage/environment, never 1 (the tool reports, it does not judge).

## Failure handling and edge cases

- `wrap_text` or the `utils` helpers cannot be imported → exit 2 naming the missing symbol; never reimplement the wrap or the split (C15/C16 ✅).
- Owner rejects the look inside the O4 range (± 4 px size, stroke 2–4, `customPosition` 55–70) → adjust, re-render, keep `revision = 1` until approved; outside the range → stop, the TL updates D6 first, then the revision becomes `<aspect>@2` (D6/D11 ✅).
- Portrait frames show the Shorts buttons over a cue → record it as the F23 ✅ finding with the frame; the only lever is font size (within O4) or a D6 position change via the TL.
- A render finishes with no subtitles (`output.subtitles` null) → check `render-check.v1.subtitles.present` and the whisper step, then re-render; never hand-draw frames. An overlay screenshot with third-party content is not committed — use the rectangle mock and note the limit.
- Stub port in use (18003/18004) → stop and report; never start a second stub.
