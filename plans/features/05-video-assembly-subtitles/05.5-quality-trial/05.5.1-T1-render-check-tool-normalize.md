# 05.5.1-T1 — `render_check.py`: probe, loudness normalisation and SRT checks

| Story | Size | Area | Depends on | Blocks | Phase / flag |
|---|---|---|---|---|---|
| 05.5.1 | M (1.0) | Worker | 05.4.1-T1 (real task-dir samples, SRT variants S7/S8) | 05.5.2-T1, 05.2.1-T1, 05.5.1-T2, 11.3.5-T3 (the adapter post-processing calls it; 11 CR-4) | P · M0 · none |

## Goal

One stdlib tool that measures a finished MPT task dir and emits `render-check.v1`: the M0 trial is judged on numbers (05.5.2-T1), 05.2.1-T1 calibrates the SRT thresholds, and the node adapter (11.3.5-T1) embeds the same object as `check` in `render-status.v1` (D4) and normalises every render to −15 LUFS (D9, X3, O3a). The tool decides nothing; thresholds are C# (05.5.1-T2, D10).

## Inputs

- README **D9** (CLI, steps 1–7, report keys, exit codes, `--normalize`), **D6** (42/2 landscape, 28/2 portrait), **D13**, **D14**, **C13–C17**, **X3–X5**, **F02**, **F03**, **F05**, **F17**.
- 05.4.1-T1 task dirs kept under `$NTS_HOME/runs/spike-05/` (never committed: media and `script.json` hold content, D14): `final-1.mp4` + `audio.mp3` + `subtitle.srt` + `script.json`, incl. **S7** (all cues `00:00:00,000`) and **S8** (empty/absent SRT). Committed test inputs are lavfi-generated media and text SRT fixtures only (T10).
- MPT checkout at `MPT_COMMIT` (`$MPT_ROOT/.venv/bin/python`); ffmpeg/ffprobe from Homebrew (Mac) and the node image (node); 01 D9 exit codes.

## Design

**Files.** `worker-node/checks/render_check.py`, `worker-node/checks/tools/gen_chunk_fixtures.py`, `worker-node/checks/fixtures/*.srt`, `worker-node/checks/fixtures/chunking/*.json`, `worker-node/checks/README.md`.

```
render_check.py run --task-dir DIR --aspect landscape|portrait --subtitles on|off [--normalize] [--presets FILE] [--out FILE]
render_check.py --self-test [--keep]
```

Exit **0** report written (pass/fail is not decided here) · **1** input unreadable (report still written, `errors` non-empty) · **2** usage/environment (including an unwritable or symlinked `--out`, T75). An unexpected exception → traceback on stderr, a minimal report (every block `null`, `errors: ["internal_error"]`), exit 1 (T75). `--out` defaults to `<dir>/render-check.json`. Every subprocess: `subprocess.run([...], timeout=…)`, list arguments, never a shell.

1. **Container.** `ffprobe -v error -show_format -show_streams -of json <dir>/final-1.mp4` (and again on `final-1.norm.mp4` after step 4 with `--normalize`: the `container`/`video`/`audio`/`faststart` blocks describe the **served** file, `input` keeps only the original's `file`/`bytes`/`sha256`; D15 P2; hashes in 1 MiB chunks, D15 P3), timeout **60 s** → `container.format`, `container.duration_s`, `video {codec, pix_fmt, width, height, fps}`, `audio {codec, sample_rate, channels}`, `input {bytes, sha256}`. Failure → `errors: ["container_invalid"]` (X5), exit 1; missing stream → `no_video_stream` / `no_audio_stream`.
2. **Narration.** `ffprobe -v error -show_entries format=duration -of json <dir>/audio.mp3` (60 s) → `narration.duration_s`; missing → `errors: ["audio_missing"]`, `duration_s = null` (then the policy's `duration` fails, F17).
3. **Loudness pass 1.** `ffmpeg -hide_banner -nostdin -i <dir>/final-1.mp4 -vn -af loudnorm=I=-15:TP=-1.5:LRA=11:print_format=json -f null -`, timeout **`max(120, 2 × duration)` s**, capped by the remaining run budget; a non-finite duration or one over 4 h → `container_invalid` with no ffmpeg step (T77). Parse the last `{…}` block of stderr (`input_i`, `input_tp`, `input_lra`, `input_thresh`, `target_offset`, `normalization_type`) → `loudness.before`. `input_i == "-inf"` → `errors: ["audio_silent"]` + `silence.longest_s = container.duration_s` (X4).
4. **Normalise (only with `--normalize`).** `ffmpeg -hide_banner -nostdin -i <dir>/final-1.mp4 -c:v copy -af loudnorm=I=-15:TP=-1.5:LRA=11:measured_I=<i>:measured_TP=<tp>:measured_LRA=<lra>:measured_thresh=<t>:offset=<o>:linear=true:print_format=json -c:a aac -b:a 192k -ar <input sample rate> -movflags +faststart <dir>/final-1.norm.mp4` (same timeout). Re-measure: `ffmpeg -hide_banner -nostdin -i <dir>/final-1.norm.mp4 -vn -af ebur128=peak=true -f null -` → summary block (`Integrated loudness`, `LRA`, `True peak`) → `loudness.after`. `normalization_type != "linear"` → `warnings: ["loudnorm_dynamic"]`. `output = {file: "final-1.norm.mp4", bytes, sha256, normalized: true}`; without the flag `output = null` and only `before` is filled.
5. **Silence.** `ffmpeg -hide_banner -nostdin -i <served file> -vn -af silencedetect=noise=-50dB:d=2 -f null -` (`final-1.norm.mp4` with `--normalize`, else `final-1.mp4`; D15 P2) → sum of `silence_duration` → `silence.total_s`, max → `silence.longest_s` (0.0 when none).
6. **Subtitles.** `off` → `present = false`, other subtitle fields `0`/`null`, SRT not read. `on` → read `<dir>/subtitle.srt` (UTF-8, BOM and CRLF tolerated): missing → `errors: ["srt_missing"]` + `present = false`; unparsable → `srt_unparsable`. A cue block = optional index line, then `HH:MM:SS,mmm --> HH:MM:SS,mmm`, then text lines. Computed: `cues`, `zero_duration` (end == start), `overlapping`, `non_monotonic`, `out_of_range` (end > duration + 0.5 s), `coverage_share` (union of the positive cue intervals ÷ narration, fallback container; D9 wins, T75), `max_cue_chars`, `long_cues` (text > `maxCharsPerLine × maxLines` of the `--aspect` preset in `--presets`, D6), `cps_p95` (nearest-rank 95th of `chars ÷ max(duration, 0.05)`), `sync_suspect` (`cps` > `MAX_CPS` = 25 **or** cue duration > `MAX_CUE_S` = 12 s; module constants, calibrated by 05.2.1-T1, a change bumps `tool_version`; T3). Time errors are counted per cue (`srt_time_invalid`), not fatal.
7. **Text match, then report.** Read `<dir>/script.json` (C13), chunk the body with the **ported** `normalize_script_for_subtitle_matching` + `split_string_by_punctuations` over `const.PUNCTUATIONS` (C15), compare cue *i* (NFC, whitespace collapsed, trailing punctuation stripped) with chunk *i* (index-aligned as MPT's sentence mode assigns them) → `text_mismatch_cues`, `text_matches_script = (text_mismatch_cues == 0)`. Fill `schema`, `tool_version` `"1.0.0"`, `ffmpeg_version` (first line of `ffmpeg -version`), `input.file`, `warnings`, `errors`; write atomically (`render-check.json.tmp` → `os.replace`).

**Chunking fixtures (drift guard).** `gen_chunk_fixtures.py` runs with MPT's interpreter, imports MPT's own `split_string_by_punctuations`, `normalize_script_for_subtitle_matching` and `const.PUNCTUATIONS` (module paths from 05.4.1-T1 ⚠️) and writes one file per input text: `{"input_sha256", "normalized", "punctuations", "chunks"}`, inputs = the sample scripts (vi, en, S7, S8) plus the `trial/fixtures/` texts. Generated **once**; `--check` re-generates into a temp dir and diffs byte-for-byte → exit 1 on drift (re-run after each MPT upgrade; 05.1.1-T1's diff is the natural home ⚠️, no hard edge).

**Temp files:** the normalised output is written to a fresh unique name in the task dir, then `os.replace`d onto `final-1.norm.mp4`; the pass-1 JSON stays in memory; ffmpeg stderr goes to a private 0700 temp dir. `final-1.mp4` is read-only, opened `O_NOFOLLOW`, hashed through that fd, and at the end its inode, size, mtime and sha256 are re-asserted → `input_changed` (T76).

## Tests

`--self-test` builds media with `ffmpeg -f lavfi` in a temp dir (no binary media in the repo, D14) and asserts named fields:

| Case | Generation / fixture | Assertion |
|---|---|---|
| good landscape | `testsrc2=1920x1080@30` + `sine=440@48000`, `-t 12`, libx264/aac + `good.srt` | `duration_s ≈ 12`, `1920×1080`, `audio.codec == "aac"`, `present`, `zero_duration == 0`, `text_matches_script` |
| portrait | same at `1080x1920` | `1080×1920` |
| silent | video + `anullsrc` | `"audio_silent" in errors`, `silence.longest_s ≈ duration` (X4) |
| wrong resolution | `1280x720` | `width == 1280`, **exit 0** (the policy's `resolution` check, not the tool) |
| truncated | first 400 KB of the good file | exit 1, `errors == ["container_invalid"]` (X5) |
| no audio stream | video only | `"no_audio_stream" in errors`, `narration.duration_s is None` |
| loud | good file at ≈ −8 LUFS | `--normalize`: `before ≈ −8`, `after ∈ [−16, −14]` (X3) |
| SRT variants | `fixtures/*.srt` | `cues`, `zero_duration`, `overlapping`, `out_of_range`; empty → `present == false` + `srt_empty` |

## Failure handling and edge cases

- ffmpeg/ffprobe missing → exit 2, no partial report. Timeout → `probe_timeout` / `ffmpeg_timeout` in `errors`, exit 1, fields measured so far kept (the policy fails `container_valid`).
- One cue `00:00:00,000 --> 00:00:00,000` (F02) → `cues = 1`, `zero_duration = 1`, `coverage_share = 0.0`, exit 0; the policy fails `subtitles_present`.
- `script.json` missing/no script field → `text_matches_script = null`, `warnings: ["script_missing"]` (05.5.1-T2 treats `null` as a failed `subtitle_text` ⚠️ confirm there).
- Chunking drift after an MPT upgrade → `--check` fails; regenerate and re-record 05.4.1-T2's samples — never adapt the port silently.
- `--aspect` disagreeing with the frame size → no tool error; spaces/non-ASCII paths are safe by construction; a 0-byte file → `container_invalid`, exit 1.

## Notes

- **Performance (measured 2026-09-27, T77):** check-only = two audio decodes; `--normalize` = four audio decodes (two on the input, two on the served file) plus one video stream copy, zero video decodes (X3). S3 sample 0.95 s / 1.53 s; 10-minute 1080p synthetic render 7.2–8.3 s / 22.3–23.5 s on Apple M4, i.e. 0.8–2.6 % of the adapter's 900 s check budget (11.3.5-T3). Every ffmpeg step's timeout is capped by the remaining `RUN_BUDGET_S = 840` s.
- `--normalize` is what makes the D10 `loudness` check meaningful (C17, F05); without it the trial only measures.
