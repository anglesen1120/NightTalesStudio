## Steps

1. `dotnet new sln`; create each project with `dotnet new classlib|web|worker|xunit3`, then delete the template sample files.
2. Write `global.json`, `Directory.Build.props`, `Directory.Packages.props` and `.editorconfig` as above.
3. Add the project and package references exactly per the D1 table, with no `Version=` on any `PackageReference`.
4. Add the `ApplicationAssemblyMarker`, the Api `Program.cs` and the Worker `Program.cs`.
5. Create `NightTales.ci.slnf`.
6. `dotnet restore` to generate `packages.lock.json`, then commit the lock files.
7. `.gitignore`: `bin/`, `obj/`, `.env`, `*.user`, `TestResults/`.

## Failure handling and edge cases

| Case | Behaviour |
|---|---|
| SDK 10.0.401 missing on a machine | `global.json` fails fast with the SDK error; install via 01 setup (`dotnet-install`), or roll forward to a newer 10.0.4xx patch |
| A transitive package pulls a vulnerable version | `NuGetAudit` (on by default in .NET 10) reports it as a warning, which fails the build → pin with `CentralPackageTransitivePinningEnabled` |
| The Mediator generator runs in two hosts | intended: Api and Worker each generate their own `Mediator` (D4). Application must not reference the generator |
| Lock file drift on package update | the CI locked restore (09.1.5-T1) fails → run `dotnet restore --force-evaluate` locally and commit |
