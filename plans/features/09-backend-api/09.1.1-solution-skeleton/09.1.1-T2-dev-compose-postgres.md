## Goal

`docker compose up -d postgres` gives every developer the same local PostgreSQL 17, reachable only from localhost. The Api and Worker find it through configuration that is never committed.

## Inputs

- README F10 / CR-6 (this file is PostgreSQL-only; 11.1.1-T1 extends it), D8 (`postgres:17-alpine`), O3.
- 00 §5.1 local dev row.

## Design

`docker-compose.yml` (repo root):

```yaml
name: nighttales
services:
  postgres:
    image: postgres:17-alpine
    environment:
      POSTGRES_DB: ${POSTGRES_DB:-nighttales}
      POSTGRES_USER: ${POSTGRES_USER:-nighttales}
      POSTGRES_PASSWORD: ${POSTGRES_PASSWORD:?set POSTGRES_PASSWORD in .env}
    ports: ["127.0.0.1:5432:5432"]
    volumes: ["pgdata:/var/lib/postgresql/data"]
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U $${POSTGRES_USER} -d $${POSTGRES_DB}"]
      interval: 5s
      timeout: 3s
      retries: 20
volumes:
  pgdata: {}
```

- `.env.example` (committed): `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD=change-me-local`. `.env` is git-ignored (09.1.1-T1).
- Connection string: `ConnectionStrings:Postgres`, set with `dotnet user-secrets set` for Api and Worker, or with the env var `ConnectionStrings__Postgres`. Nothing goes into `appsettings*.json`.
- `docs/dev-setup.md` section "Database": the three commands (copy `.env.example`, `docker compose up -d postgres`, set user-secrets).
- [DECISION] No pgAdmin or other tools in this file. 11.1.1-T1 owns every additional service.

## Steps

## Outputs

## Acceptance checks

- [ ] `docker compose config` → valid. Without `POSTGRES_PASSWORD` it fails with the message "set POSTGRES_PASSWORD in .env".
- [ ] `docker compose up -d postgres && docker compose ps` → `postgres` reports `healthy` within 100 s.
- [ ] `psql "host=127.0.0.1 user=nighttales dbname=nighttales" -c 'select version()'` → PostgreSQL 17.x.
- [ ] From another host on the LAN, port 5432 is not reachable (bound to 127.0.0.1).
- [ ] `git grep -n "POSTGRES_PASSWORD="` → only `.env.example`.

## Failure handling and edge cases

| Case | Behaviour |
|---|---|
| Port 5432 already used by a local PostgreSQL | set `ports: ["127.0.0.1:5433:5432"]` in a `docker-compose.override.yml` (git-ignored) and the matching connection string |
| Volume from an older major | the container refuses to start → `docker compose down -v` (dev data is disposable) |
| Apple Silicon | `postgres:17-alpine` is multi-arch; no platform override needed |
