## Goal

An owner reads the full settings catalog, changes a non-critical value (validated against §5.6's rules), tests an integration with one harmless call, views/rolls back history, and manages worker nodes — all through `OwnerPolicy` + step-up re-auth, with `setting_secret_required` closing the "change the host, keep the old key" attack and `If-Match` closing lost-update races. Critical-integration freezing is **09.10.2-T2**; connect-time egress validation is **09.10.2-T3** (this task calls that factory, does not implement it).

## Design

Implements §C3.1's non-critical/read/test/rollback/node rows and **D6**.

```csharp
public sealed record UpdateSettingsCommand(string Integration,
    IReadOnlyDictionary<string, JsonNode?> Values,
    IReadOnlyDictionary<string, SecretString> Secrets,
    string? Reason, string IfMatch) : ICommand<ErrorOr<SettingIntegrationDto>>;

[Audited("settings.changed", Category.Support, Visibility.Internal)]
public sealed class UpdateSettingsCommandHandler(ISettingsCatalog catalog, ISystemSettingsRepository repo,
    ISettingsEncryptor encryptor, IEnvSettingsLock envLock, TimeProvider clock) : ICommandHandler<UpdateSettingsCommand, ErrorOr<SettingIntegrationDto>>
{
    public async Task<ErrorOr<SettingIntegrationDto>> Handle(UpdateSettingsCommand cmd, CancellationToken ct)
    {
        if (envLock.IsLocked(cmd.Integration)) return Error.Validation("setting_invalid", "reason: env_locked");
        var rule = catalog.RuleFor(cmd.Integration);   // https/allow-list/CIDR/timeout/model rules, §5.6
        var validation = rule.Validate(cmd.Values, cmd.Secrets);
        if (validation.IsError) return Error.Validation("setting_invalid", validation.Detail);
        var current = await repo.LoadAsync(cmd.Integration, ct);
        if (current.ETag != cmd.IfMatch) return Error.Validation("setting_conflict");   // 412, 09 W3 CR-31
        if (rule.ChangesBaseUrl(cmd.Values, current) && !cmd.Secrets.ContainsKey(rule.SecretKeyName))
            return Error.Validation("setting_secret_required");
        if (rule.Critical) return await DelegateToCriticalPath(cmd, ct);   // 09.10.2-T2's command, invoked here as a soft port
        foreach (var (key, value) in cmd.Values) await repo.ApplyValueAsync(cmd.Integration, key, value, ct);
        foreach (var (key, secret) in cmd.Secrets) await repo.ApplySecretAsync(cmd.Integration, key, secret, ct);
        return catalog.Project(cmd.Integration);
    }
}
```

`ISettingsCatalog.RuleFor(integration)` is the one place §5.6's per-integration table lives in code: allow-list host(s), CIDR-only flag (`mpt`), timeout bounds, known-model set (`text_model` against the pinned `gpt-6-luna` family), `disposable_domains` shape (lowercase, IDN-normalized, ≤ 200, no wildcards), `trial.credits` range 0…10000. `POST …/test` reuses the same rule's `TestProbe` delegate (list models / adapter `GET /v1/health` / provider status / SMTP `NOOP` / format check) with a 5 s timeout, `AllowAutoRedirect = false`, and the **09.10.2-T3** `ConnectCallback` factory; a non-2xx or timeout maps to 502 `setting_test_failed` with the HTTP status only, never the response body.

`GET /admin/settings` response uses `SettingsCatalogDto`/`SettingIntegrationDto`/`SettingKeyDto` (plan.md §5); `lockedByEnvironment` comes from `IEnvSettingsLock.IsLocked(integration)` (checks a known env-var name pattern per integration, e.g. `Settings__Openai__ApiKey` present ⇒ locked); the "mpt node image key" row is rendered read-only with `NodeManaged = "node-managed, rotate via runbook"` and no `PUT` accepts it.

**Worker nodes.** `GET/POST /admin/worker-nodes`, `PATCH /admin/worker-nodes/{id}` reuse `WorkerNodeDto`; `POST` creates a `system_settings` row with `WorkerNodeId` set (09.10.1-T2's invariant) for the adapter key; `PATCH` supports `state ∈ {active, draining}` and an optional new key (re-encrypted under that node's purpose).

5. Implement `TestSettingCommandHandler` (`[NotAudited]`, no state change) calling `RuleFor(integration).TestProbe` through the 09.10.2-T3 connect-time-validated `HttpClient`.

## Acceptance checks

1. Given role `admin`, When `GET /admin/settings` or any route of this task is called, Then 404 `not_found` (never 403).
2. Given owner + fresh re-auth, When `PUT /admin/settings/openai` changes `text_model` to an unknown value, Then 400 `setting_invalid` and no row changes.
3. Given `payment.base_url` changes with no `secret_key` in the body, Then 400 `setting_secret_required`.
4. Given `POST /admin/settings/mpt/test` for a node whose adapter is down, Then 502 `setting_test_failed` and the response never contains the adapter's body.
5. Given a stale `If-Match`, Then 412 `setting_conflict` (Part A's ETag convention, 09 W3 CR-31) and no row changes.
6. Given `GET /admin/settings`, Then no response field ever contains a `secret_ciphertext` or a decrypted secret value — only `value` (non-secret) or `secretHint`.
7. Given the `mpt node image key` row, Then it is listed read-only with `nodeManaged` text and rejects any `PUT`.

## Failure handling and edge cases

| Case | Handling |
|---|---|
| `PUT` targets `mpt` node image key row | Rejected before validation — that row has no `integration/key` pair reachable through this endpoint (it is not in `system_settings`) |
| Two owners `PUT` the same integration concurrently | Second writer's `If-Match` is stale → 412 `setting_conflict` (09 W3 CR-31), must re-`GET` and retry |
| `…/test` called with an unsaved `base_url` and no new secret | 400 `setting_secret_required` — the stored secret is never sent to an unvalidated host |
| Env lock appears mid-request (race) | `IEnvSettingsLock.IsLocked` re-checked inside the same handler call, before validation — no window where a locked integration is written |
| Rollback target version has a purged secret | Response lists `secretReentryRequired` keys; the API does not attempt to decrypt a null ciphertext (09.10.1-T2) |
