## Goal

A creator can list the selectable voices and the visual styles the platform offers, so 10.4.x can fill the voice picker and the 10.4.2 style grid: `GET /voices?language=` returns only `active` voices as `{ id, displayName, language, gender, tags, previewUrl }` with a public preview URL, and `GET /style-templates?topic=` returns only templates allowed for that topic (`true_crime` never mixes with fiction — 03 CR-2), both cacheable and cheap.

```csharp
public sealed record ListVoicesQuery(string? Language) : IQuery<ErrorOr<IReadOnlyList<VoiceListItemDto>>>;
public sealed record ListStyleTemplatesQuery(string? Topic) : IQuery<ErrorOr<IReadOnlyList<StyleTemplateListItemDto>>>;

public sealed record VoiceListItemDto(string Id, string DisplayName, string Language, string Gender,
                                      IReadOnlyList<string> Tags, string? PreviewUrl);
public sealed record StyleTemplateListItemDto(string Id, string Name, string? TopicHint, string? PreviewUrl);

public interface IPublicAssetUrl { Uri? Build(string? storageKey); }   // [INFERENCE: name]

internal sealed class ListVoicesHandler(IReadDb db, IPublicAssetUrl urls)
    : IQueryHandler<ListVoicesQuery, ErrorOr<IReadOnlyList<VoiceListItemDto>>>;

internal sealed class ListStyleTemplatesHandler(IReadDb db, IPublicAssetUrl urls)
    : IQueryHandler<ListStyleTemplatesQuery, ErrorOr<IReadOnlyList<StyleTemplateListItemDto>>>;
```

Queries are read-only: they go through the pipeline without `UnitOfWorkBehavior`, idempotency or audit (D4 — steps 4–6 apply to commands only), so no `SaveChanges`, no transaction, no `IUnitOfWork` reference.

Two projections (no `Include`, no N+1; sets are closed and bounded — 04 D9 voices, 03 D2 seven templates):

```csharp
// voices, ordered by id for a stable ETag
db.Query<Voice>()
  .Where(v => v.Active && (q.Language == null || v.Language == q.Language))
  .OrderBy(v => v.Id)
  .Select(v => new { v.Id, v.DisplayName, v.Language, v.Gender, v.Tags, v.PreviewStorageKey });

// style templates; the topic rule is the shared Domain policy (03 CR-2)
db.Query<StyleTemplate>().Where(t => t.Active).OrderBy(t => t.Id)
  .Select(t => new { t.Id, t.Name, t.TopicHint, t.PreviewStorageKey });
```

`StyleTopicPolicy` is applied **after** the row read (`StyleTopicPolicy.IsAllowed(topic, row.TopicHint)`, 03.1 plan L53) because the policy resolves `Topic` × hint in code, not in SQL; the candidate set is ≤ 7 rows, so this is not a table scan (alternative — a `CASE` expression in SQL — is rejected: it would duplicate the policy, forbidden by reuse).

Validation (FluentValidation) runs before the handler (D4 slot 3):

- `Language` optional; when present it must parse to `Language { Vi, En }` → else `Error.Validation(ErrorCodes.ValidationFailed, "…", field: "language")` → **400 `validation_failed`** with `errors.language`.
- `Topic` optional; when present it must parse to `Topic { Ghost, Spiritual, TrueCrime }` → else **400 `validation_failed`** with `errors.topic`. Omitted `topic` = "no topic filter" ⇒ all active templates.
- `Language`/`Topic` are parsed with the same snake_case-insensitive rules D14 uses for enum wire values (`vi`, `en`, `true_crime`, `ghost`, `spiritual`) — the local wire name for a `Topic` member is its snake_case name.

`IPublicAssetUrl` + configuration:

```csharp
public sealed class ConfigurationPublicAssetUrl(IOptions<StorageOptions> options) : IPublicAssetUrl
{
    public Uri? Build(string? storageKey)   // null key | empty base | unsafe key | non-https outside Development → null
}
public sealed class StorageOptions { public string PublicBaseUrl { get; set; } = ""; public bool RequireHttps { get; set; } = true; }
```

| Key | Default | Note |
|---|---|---|
| `Storage:PublicBaseUrl` | `""` | Base URL of `nt-public-<env>` (11 README L253). Empty → `previewUrl: null` everywhere + **one** startup warning. [INFERENCE: key] |
| `Storage:RequireHttps` | `true` | Ignored in Development (local emulator may be `http://localhost:9000`). [INFERENCE] |
| `Catalog:PublicCacheSeconds` | `3600` | `Cache-Control` max-age on both catalog routes. [INFERENCE] |

Key safety: reject absolute keys, a leading `/`, `\`, or any `..` segment → `null` + one warning (never echo the key to the client, never 500).

Endpoint (`src/NightTales.Api/Endpoints/CatalogEndpoints.cs`), both routes require an authenticated bearer token (no `[AllowAnonymousRequest]`):

| Method | Route | Query | Result |
|---|---|---|---|
| GET | `/api/v1/voices` | `language?` | `200 { items: [...] }`, `ETag`, `Cache-Control: public, max-age=<Catalog:PublicCacheSeconds>` |
| GET | `/api/v1/style-templates` | `topic?` | same |

- ETag [INFERENCE]: SHA-256 (first 16 hex) over the serialized `items` array in its deterministic order, exposed as `ETag: "<hex>"`; `If-None-Match` equal (strong compare, D7) → `Results.StatusCode(304)` with the same `ETag` and no body. A catalog update (re-seed) changes it.
- No `cursor`/`limit` (closed sets, plan §5 [DECISION]); no `Vary` needed (the answer is user-independent); no `Cache-Control` on error responses.

## Steps

1. Add `IPublicAssetUrl` (Application) + `ConfigurationPublicAssetUrl` + `StorageOptions` (Infrastructure); register `StorageOptions` with the two keys and log one startup warning when `PublicBaseUrl` is empty. Reject unsafe keys per Design.
2. Add the two DTOs and the two `sealed` handlers under `Features/Catalog/`; validators for `Language`/`Topic` with the snake_case enum parsing.
3. Apply `StyleTopicPolicy.IsAllowed` in the style-template handler (03 CR-2 table: `true_crime` × {`true_crime` ✓, else ✗}; `ghost`/`spiritual` × {`true_crime` ✗, else ✓}; `null` hint allowed for fiction only).
4. Map both routes in `CatalogEndpoints : IEndpointGroup` (discovered at startup, D14) with `.RequireAuthorization()`, the cache header, the computed ETag and the `If-None-Match` → 304 path.
5. Add the integration fixtures: a seeded catalog set (active + inactive voice, `vi`/`en`, one voice without `preview_storage_key`, two `true_crime` + five fiction templates) through 09.2.5-T1's seeders.
6. Register `IPublicAssetUrl` in both composition roots (Api and Worker) so the Worker tests can build URLs identically.

## Acceptance checks

- [ ] `GET /api/v1/voices` returns only `active = true` rows, each with `id`, `displayName`, `language`, `gender`, `tags`, `previewUrl` (camelCase on the wire, D14).
- [ ] `?language=vi` returns only `vi`; `?language=xx` → `400 validation_failed` with `errors.language`; no `language` → both languages.
- [ ] `previewUrl` = `Storage:PublicBaseUrl` + `preview_storage_key` when both are present; `null` when the key is absent, the base URL is empty, or the key is absolute/contains `..`; the response never contains a storage credential.
- [ ] `GET /api/v1/style-templates?topic=true_crime` returns only `topic_hint = 'true_crime'` rows; `topic=ghost` and `topic=spiritual` return no `true_crime` row; omitted `topic` returns all active rows; an unknown topic → `400 validation_failed` with `errors.topic`.
- [ ] `active = false` templates are absent from every answer.
- [ ] Both routes answer `Cache-Control: public, max-age=<Catalog:PublicCacheSeconds>` and an `ETag`; a repeat with `If-None-Match` = that ETag answers `304` with no body and the same `ETag`; a changed catalog (re-seed) changes the ETag and answers `200`.
- [ ] Both routes answer `401` without a bearer token, and no route accepts anonymous access.
- [ ] Each request issues exactly **one** database query (D8 `IReadDb`, no tracking); no `SaveChanges`, no transaction, no `IUnitOfWork` in the handlers.
- [ ] No log line contains the key, the full `previewUrl` or any token; the empty-base-URL warning is logged once at startup, not per request.

## Failure handling and edge cases

| Case | Behaviour |
|---|---|
| `language`/`topic` unparsable (e.g. `Language=`, `topic=TRUE_CRIME` outside the accepted spelling, `topic=news`) | `400 validation_failed`, field named, no query executed |
| `Storage:PublicBaseUrl` empty/unset (dev, misconfigured env) | `previewUrl: null` for every row, one startup warning, `200` unchanged — the picker hides the play control |
| Seed key absolute, with `..`, or with a leading `/` | `previewUrl: null` + one warning; never a redirect, never a 500, never the key echoed |
| Empty catalog (fresh DB before the seeder) | `200 { "items": [] }` — not 404; the UI shows an empty picker |
| Template de-activated while a series uses it | Hidden here (03 README L98), still valid for the existing series (03 D2) |
| Two rows with the same `id` (seed error) | Impossible per seed validation (04 D9 unique ids, 03 `StyleTemplateRules`); the handler does not de-duplicate |
| Client sends `If-None-Match: *` or a malformed value | Ignored for the strong comparison of this route (D7 compares exact strings) → `200` |
| Failure of the underlying query (DB down) | Standard pipeline: `503 service_unavailable` (>500 handling of 09.1.4-T1); the handler caches nothing, so the next request retries |
