## Goal

`GET /api/v1/episodes/{id}` answers the whole episode page in one fast call: status, the next actions the domain allows, the latest render job's `stage`/`percent`, the final video asset metadata and a publications placeholder — with the episode's `"ep-<xmin>"` ETag so the client can revalidate cheaply (304). One projection query plus one render (and optionally asset) query run **sequentially** on the same `DbContext`, no N+1 ([RULED — README §B10 WT46]).

public sealed record EpisodeDetailDto(

Handler (D8/D10/D15 — three reads, two round trips, BD16; **sequential** on the one `DbContext`, [RULED — README §B10 WT46]):

```csharp
internal sealed class GetEpisodeByIdHandler(IReadDb db) : IQueryHandler<GetEpisodeByIdQuery, ErrorOr<EpisodeDetailDto>>
{
    public async ValueTask<ErrorOr<EpisodeDetailDto>> Handle(GetEpisodeByIdQuery q, CancellationToken ct)
    {
        var episode = await db.Query<Episode>().Where(e => e.Id == q.Id)
            .Select(e => new { e.Id, e.SeriesId, e.Title, e.Brief, e.LengthTier, e.Status,
                               e.FinalVideoAssetId,
                               Etag = EF.Property<uint>(e, "xmin") })            // D15 / N8
            .SingleOrDefaultAsync(ct);
        if (episode is null) return Error.NotFound(ErrorCodes.NotFound, "Episode was not found.");
        if (episode.Status == EpisodeStatus.Cancelled) return Error.NotFound(ErrorCodes.NotFound, "Episode was not found.");

        // WT46: sequential awaits on the one DbContext — EF forbids concurrent operations, so no Task.WhenAll
        var render = await db.Query<RenderJob>().Where(j => j.EpisodeId == q.Id)
            .OrderByDescending(j => j.Id)                                   // WT49: no created_at column; id DESC = UUIDv7 order
            .Select(j => new RenderJobSummaryDto(j.Id, j.Status, j.Stage, j.Percent, j.Attempt,
                                                 j.ImagesNeeded, j.SubmittedAt, j.FinishedAt))
            .FirstOrDefaultAsync(ct);
        FinalVideoAssetDto? finalVideo = null;
        if (episode.FinalVideoAssetId is { } assetId)
            finalVideo = await db.Query<Asset>().Where(a => a.Id == assetId)
                .Select(a => new FinalVideoAssetDto(a.Id, a.SizeBytes, a.Sha256, a.ContentType, a.DurationSec, a.RetentionUntil))
                .FirstOrDefaultAsync(ct);

        return new EpisodeDetailDto(episode.Id, episode.SeriesId, episode.Title, episode.Brief,
            episode.LengthTier, episode.Status, EpisodeNextActions.For(episode.Status),
            $"ep-{episode.Etag}", render, finalVideo, Publications: null);
    }
}
```

The tenant filter (D10) hides other users' rows, so "not mine", "unknown" and "cancelled" are one indistinguishable `404 not_found` (D10 ✅).

Endpoint — extend the existing mapping in `EpisodeEndpoints` (no new route, no new endpoint group):

```csharp
group.MapGet("/{id:guid}", async (Guid id, ISender sender, HttpContext http, CancellationToken ct) =>
{
    var result = await sender.Send(new GetEpisodeByIdQuery(id), ct);
    if (result.IsError) return result.ToHttpResult();               // 404 not_found (09.1.4-T1)
    var dto = result.Value;
    http.Response.Headers.ETag = $"\"{dto.Etag}\"";                // D15: header + DTO field
    if (http.Request.Headers.IfNoneMatch == $"\"{dto.Etag}\"")
    {
        http.Response.Headers.CacheControl = "no-cache";           // revalidate every time
        return Results.StatusCode(StatusCodes.Status304NotModified);
    }
    http.Response.Headers.Vary = "Authorization";                  // [INFERENCE]
    return Results.Ok(dto);
}).RequireAuthorization();
```

| Method | Route | Success | Errors |
|---|---|---|---|
| GET | `/api/v1/episodes/{id}` | `200` + `ETag: "ep-<xmin>"` + DTO `etag`; `304` when `If-None-Match` matches (weak comparison is not used — exact string, D7) | `404 not_found` (unknown, other user's, `Cancelled`), `400 validation_failed` (malformed id, route constraint), `401` |

The 304 path returns before the render/asset queries only if the client sends the current ETag — [DECISION] the handler still computes the full DTO first, because `xmin` is only knowable from the same projection; a later optimisation (read `xmin` alone, then the blocks only on a miss) is **not** taken now, to keep one handler and one code path.

`publications`: always `null` in P. When 06 lands it fills the field from query (2)'s batch (or the TL approves a documented third query); this task must not add a third query speculatively (BD16).

## Failure handling and edge cases

| Case | Behaviour |
|---|---|
| Unknown id / other user's episode / `Cancelled` | `404 not_found`, identical body and no field naming the reason (D10) |
| Malformed id (`/episodes/abc`) | `400 validation_failed` from the route constraint, before the handler |
| Episode with no render job yet | `renderJob: null`, `200` — the UI shows "not started" |
| `final_video_asset_id` set but the asset row missing (data drift) | `finalVideo: null`, `200`; log one warning with the episode id (never 500) |
| More than one active render job (should be impossible — BD5's unique partial index `(episode_id)` for active states) | The newest is returned; the projection stays deterministic (`id DESC`, UUIDv7 — WT49) |
| `If-None-Match: W/"ep-5"` (weak) or a multi-value header | Not equal to the strong value → `200` (D7 compares exact strings) |
| Client caches a 304 but the episode changed | The new ETag differs, so the next request is a miss; `Cache-Control: no-cache` forces revalidation |
| DB down | `503 service_unavailable` (09.1.4-T1); nothing cached, nothing partial |
| 02.3.4-T2 or 03.4.2-T1 not yet applied | `currentStory`/`generation`/`renderJob.images` are simply absent; no `null` placeholder member is added early |
