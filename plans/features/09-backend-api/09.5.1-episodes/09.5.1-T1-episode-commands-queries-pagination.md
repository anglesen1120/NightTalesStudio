## Goal

A user can create episodes in their own non-archived series, list them with stable cursor pages, read one, and delete it (cancel). Deletion is refused while generating or rendering, and it schedules the episode's assets for removal.

Handler rules:
- **Create:**
  1. Load the series by id (tenant filter) → missing: 404 `not_found`; archived: 409 `series_archived`.
  2. `Episode.Create(series.UserId, series.Id, title?.Trim(), brief.Trim(), tier, clock.UtcNow)`.
  3. Return the id. The ETag is read after commit by the endpoint (09.4.1-T1 pattern).
- **Validator:**
  - brief 1–1,000 chars after trim; no control characters other than `\n` and `\t`;
  - title ≤ 120 after trim (empty → null);
  - `LengthTier` defined.
- **Delete:**
  1. Load (tenant filter; `Cancelled` counts as not found) → 404.
  2. `IfMatch` present and ≠ `ETags.Episode(e.Version)` → 412 `episode_conflict`.
  3. `e.Cancel(now)` → `episode_invalid_state` from `StoryGenerating`, `Rendering` or `Published`.
- **Mark assets:** `UPDATE assets SET retention_until = LEAST(COALESCE(retention_until, @now), @now) WHERE episode_id = @id AND deleted_at IS NULL`, via `ExecuteUpdateAsync` in the command transaction. Idempotent.
- **List:**
  - `IReadDb.Query<Episode>().Where(status != Cancelled)`, plus the optional `SeriesId` and `Status` filters;
  - keyset on `(CreatedAt, Id)` descending with the shared `Cursor`;
  - `Take(limit + 1)`;
  - project to `EpisodeListItemDto(Id, SeriesId, Title, Status, LengthTier, CreatedAt, UpdatedAt, Etag)`.
- **Get:** projection to `EpisodeDto`; `Cancelled` → 404.

Routes (`EpisodeEndpoints : IEndpointGroup`):

| Method | Route | Result |
|---|---|---|
| POST | `/api/v1/series/{seriesId}/episodes` | 201 + `Location: /api/v1/episodes/{id}` + `ETag` |
| GET | `/api/v1/episodes?seriesId=&status=&cursor=&limit=` | 200 page |
| GET | `/api/v1/episodes/{id}` | 200 + `ETag` |
| DELETE | `/api/v1/episodes/{id}` | 204; `If-Match` optional |

## Failure handling and edge cases

| Case | Behaviour |
|---|---|
| The series is archived between load and save | allowed: the check is at load; archiving never blocks existing episodes (S2 of 09.4.1) |
| Delete races with a generate command | both lock the episode row: 02 uses `LockEpisodeForUpdateAsync`; delete loads through the tracked context and `xmin` catches the race → 409 `concurrency_conflict` on the loser |
| The outbox handler runs twice | idempotent update |
| An episode without assets | the update touches 0 rows; success |
