## Goal

## Design

```csharp
// Application/Abstractions/Storage/IBlobStore.cs          (BD10; ErrorOr wrappers on the untyped members are [INFERENCE])
public sealed record BlobInfo(long Bytes, string Sha256);
public sealed record BlobObject(Stream Content, string ContentType, long? Length);

public interface IBlobStore
{
    Task<ErrorOr<BlobInfo>> PutAsync(string bucket, string key, Stream content, string contentType, CancellationToken ct);
    Task<ErrorOr<BlobObject>> OpenReadAsync(string bucket, string key, CancellationToken ct);
    Task<ErrorOr<Success>> DeleteAsync(string bucket, string key, CancellationToken ct);          // missing key == success
    Task<ErrorOr<bool>> ExistsAsync(string bucket, string key, CancellationToken ct);
    Task<ErrorOr<BlobObject>> OpenReadAsync(string bucket, string key, long fromByte, CancellationToken ct);   // ranged read for upload resume (06.2.3-T2; 06 CR-12)
    IAsyncEnumerable<string> ListKeysAsync(string bucket, string prefix, CancellationToken ct);                // prefix sweeps for the deletion engine (13.3.1-T1; 13 CR-6)
    Uri CreateReadUrl(string bucket, string key, TimeSpan ttl, string? downloadFileName);        // synchronous (BD10)
}

// Application/Abstractions/Storage/StorageSettings.cs      ([INFERENCE] names; secrets never logged)
public sealed class StorageSettings
{
    public required string ServiceUrl { get; init; }         // dev http://storage:8333; staging/prod https://storage-<env>.internal (11 D21, T77) — TLS trust via the internal root CA in the host/container trust store, no pinning (T81)
    public string? PublicServiceUrl { get; init; }           // browser-reachable endpoint used ONLY to presign read URLs (dev http://localhost:8333; staging https://media.staging.<domain>, prod https://media.<domain>, T75/T83); null = ServiceUrl (10 CR-21)
    public string Region { get; init; } = "us-east-1";
    public bool ForcePathStyle { get; init; }                // true in all envs — the gateway has no per-bucket DNS (BD10 amended, 11 CR-15, T75)
    public required string AccessKey { get; init; }          // nts/<env>/STORAGE_ACCESS_KEY
    public required string SecretKey { get; init; }          // nts/<env>/STORAGE_SECRET_KEY
    public StorageBuckets Buckets { get; init; } = new();
    public int PresignTtlMinutes { get; init; } = 15;        // validated 1..15 (WF16)
    public int TikTokPresignTtlMinutes { get; init; } = 120;  // validated 1..120, read only by 07.3.1-T1's `PULL_FROM_URL` presign (never mixed with the general 1..15 ceiling; 07 CR-4)
    public string HealthMarkerKey { get; init; } = "_health/storage-ready.txt";
    public int HealthProbeSeconds { get; init; } = 30;       // prober interval; /health/ready never touches S3
}
public sealed class StorageBuckets { public string Media { get; init; } = "nt-media-dev"; public string Public { get; init; } = "nt-public-dev"; public string Music { get; init; } = "nt-music-dev"; }
public static class BlobLocator { public static string BucketFor(AssetKind kind, StorageSettings s) => s.Buckets.Media; }   // all assets rows live in media

// Infrastructure/Storage/StorageHealth.cs  ([INFERENCE]; same shape as 11's INodeHealthCache)
public sealed record StorageHealth(bool IsHealthy, DateTimeOffset CheckedAt, string? ErrorCode);
public interface IStorageHealthCache { StorageHealth Current { get; } void Set(StorageHealth health); }
```

`S3BlobStore` (Infrastructure/Storage): one `IAmazonS3` built with `new AmazonS3Client(new BasicAWSCredentials(accessKey, secretKey), new AmazonS3Config { ServiceURL = ServiceUrl, ForcePathStyle = ForcePathStyle, RegionEndpoint = RegionEndpoint.GetBySystemName(Region), UseHttp = ServiceUrl.StartsWith("http://") })` [⚠️ W5: the exact property names of `AmazonS3Config` in 4.0.103.4 are unverified — spike in step 1]; the staging/prod `ServiceUrl` is TLS to `https://storage-<env>.internal` (T77) trusted through the internal root CA that 11.4.1-T2 installs in the host and container trust stores — no client-side certificate pinning (T81).

- `PutAsync`: `PutObjectAsync` streaming with an incremental SHA-256 (`IncrementalHash`) while copying to the request stream; returns bytes + hex digest; `DisablePayloadSigning` **not** set unless the spike proves SeaweedFS needs it (⚠️).
- `OpenReadAsync`: `GetObjectAsync` → `BlobObject(response.ResponseStream, response.Headers.ContentType, response.ContentLength)`; the caller owns the stream.
- `ExistsAsync`: `GetObjectMetadataAsync`; `S3Exception` with `StatusCode == NotFound` → `false` (⚠️ `AmazonS3Util.DoesS3BucketExistV2Async` is **not** used — it is a bucket call).
- `DeleteAsync`: `DeleteObjectAsync`; `NoSuchKey`/404 is success (09.7.3-T1 re-runs depend on it).
- `CreateReadUrl`: `new GetPreSignedUrlRequest { BucketName = bucket, Key = key, Verb = HttpVerb.GET, Expires = DateTime.UtcNow.Add(ttl), Protocol = Protocol.HTTPS }` + `ResponseHeaderOverrides = new ResponseHeaderOverrides { ContentDisposition = SafeAttachment(downloadFileName), ContentType = "video/mp4" }` (`ResponseHeaderOverrides.ContentDisposition` ✅ W5), then `GetPreSignedURL` (⚠️ the 4.x async twin `GetPreSignedURLAsync` may exist — use whichever the spike finds, keeping the port synchronous).
- `SafeAttachment(string? fileName)`: `null → null`; else ASCII-fold the input, replace `"`, `\`, `%`, CR, LF, TAB and other controls with `_`, collapse to `[A-Za-z0-9 ._-]`, trim to 80 chars, then `attachment; filename="<ascii>"; filename*=UTF-8''<percent-encoded>` (RFC 6266/5987). A test asserts no CR/LF/quote can reach the header.
- Failure mapping: any `AmazonS3Exception`/`HttpRequestException`/timeout → `Error.Failure(ErrorCodes.ServiceUnavailable)` → 503 `service_unavailable` (D17/D5 precedent); `AccessDenied` additionally increments `blob_store_operations_total{op,outcome="denied"}` and logs bucket + key **prefix only** (never the full key, never credentials).
- Registration: `AddStorage(IConfiguration)` in Infrastructure; registered in Api **and** Worker (the sweep, 09.6.3-T2's ingest and 02's fetcher path need it in the Worker).

Endpoint (`Api/Endpoints/EpisodeVideoEndpoints.cs`):

```csharp
group.MapGet("/episodes/{id:guid}/video-url", async (Guid id, IAppDbContext db, IBlobStore blobs, StorageSettings s,
                                                     IUnitOfWork uow, IAuditWriter audit, ICurrentUser user,
                                                     IClock clock, CancellationToken ct) =>
{
    var episode = await db.Episodes.AsNoTracking().SingleOrDefaultAsync(e => e.Id == id, ct);   // tenant filter (D10)
    if (episode is null) return Results.NotFound();                                            // foreign or unknown → 404
    if (episode.FinalVideoAssetId is not { } assetId) return Results.NotFound();                // nothing to serve yet
    var asset = await db.Assets.AsNoTracking().SingleOrDefaultAsync(a => a.Id == assetId && a.DeletedAt == null, ct);
    if (asset is null) return Results.NotFound();                                              // retention already deleted it

    var ttl = TimeSpan.FromMinutes(s.PresignTtlMinutes);
    var expiresAt = clock.UtcNow.Add(ttl);
    var url = blobs.CreateReadUrl(BlobLocator.BucketFor(asset.Kind, s), asset.StorageKey, ttl, $"{VideoSlug.From(episode.Title)}.mp4");

    await using var tx = await uow.BeginAsync(ct);                                             // a GET has no pipeline (D5)
    await audit.WriteAsync(new AuditEntry(                                                     // joins the ambient transaction
        Action: "episode.video_url_issued", Category: Category.Episodes, Visibility: Visibility.User,
        SubjectUserId: user.Id, ActorUserId: user.Id, EntityType: "episode", EntityId: id,
        Data: new { episodeId = id, assetId, expiresAt }, Ip: null, UserAgent: null), ct);      // never the URL/signature
    var committed = await uow.CommitAsync(ct);
    if (committed.IsError) return committed.Errors.ToProblem();                                 // 503; no URL is handed out unaudited

    return Results.Ok(new VideoUrlDto(url.ToString(), expiresAt));
});
```

`VideoSlug.From(string? title)` (Application/Features/Assets) — public static helper, reused by 13's export: title → ASCII-fold → non-alphanumerics to `-` → lowercase → trim `-` → truncate 80 → `"nighttales"` when empty. No title text, no user id.

Storage health (BD12 + BD16): `StorageHealthProbe` (`BackgroundService`, tick `Storage:HealthProbeSeconds` = 30, 5 s timeout) writes the marker when `ExistsAsync(media, Storage:HealthMarkerKey)` is false (`PutAsync` of a 0-byte `text/plain` body, idempotent) and stores `StorageHealth(IsHealthy, CheckedAt, ErrorCode)` in the singleton `IStorageHealthCache` — the 11 `NodeHealthPoller`/`INodeHealthCache` pattern. `/health/ready` (09.9.3-T1's assembly, BD12) **reads the cache only**, so an LB probe never issues an S3 HEAD (BD16: "health endpoints read caches only"); a stale cache (older than 3 × the interval) or `IsHealthy = false` makes the probe answer **`200` with `status = Degraded` and the `storage` component degraded** — a storage fault never turns readiness into 503 (only a database failure does) [RULED — README §B10 WT38/WT15]. The marker lives in the **media** bucket because the app key cannot write `nt-public-<env>` (11 D20 H9).

## Failure handling and edge cases

- **Storage unreachable / AccessDenied**: `service_unavailable` 503, one metric increment, fixed English description; the exception's `Message` is logged at `Warning` **without** the key and signature (BD16). No retry inside the endpoint (the SDK's own retry policy stays at its default; BD6's custom pipelines are for the render node only).
- **Audit commit fails**: the endpoint returns 503 and hands out no URL — an unaudited presigned URL must not exist. The transaction wraps only the audit insert (no lock is held on the episode read).
- **Health cache stale**: the probe updates it every `Storage:HealthProbeSeconds`; if the probe thread dies, the cache ages out and `/health/ready` answers **`200` + `status = Degraded`** (WT38/WT15) — never 503, and never a per-probe S3 HEAD (BD16).
- **Presign with a 0-length or `null` title**: `VideoSlug` falls back to `nighttales`, so the header is never empty.
- **Clock/expiry**: `expiresAt` is computed from the same `IClock` instant used for the signature; a skew larger than the TTL is impossible inside one request.
- **Object deleted by the sweep but the row still says live**: the endpoint 404s (the asset lookup filters `deleted_at IS NULL`), which is the honest answer.
- **Bucket missing in the environment**: `PutObjectAsync` returns `NoSuchBucket` → 503 with a message pointing at 11.4.1-T1; no auto-create (least privilege, no `CreateBucket` permission).
- **Rollback**: unregister the endpoint group; the port and implementation stay (02 and 09.6.3-T2 depend on them). No data change.
