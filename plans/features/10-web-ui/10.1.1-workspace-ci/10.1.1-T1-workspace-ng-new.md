# 10.1.1-T1 — Workspace: `ng new`, static prerender, aliases, budgets

| Story | Size | Area | Depends on | Blocks | Phase / flag |

## Goal

Create the `web/` workspace every other frontend task builds inside: Angular 22.2.x, standalone only, strict TS + `strictTemplates` + `noUncheckedIndexedAccess`, SCSS, **zoneless**, the `@angular/build:application` builder with `outputMode: 'static'`, the `@core/*` / `@shared/*` / `@features/*` aliases, the raw bundle budgets, a Node **26.10.0** pin (`engines.node ^26.10.0`, 10 CR-43) with a committed `package-lock.json`, a server-routes file that marks every path `RenderMode.Client` (nothing is server-rendered), and the recorded name of the client-fallback file the container must serve. No screen, no legal page and no prerendered route is created here — the four `RenderMode.Prerender` legal routes, `LegalDocumentPage` and `tools/web/legal-to-json.mjs` belong to **10.3.1-T1** (README D12, TL ruling WR1).

## Design

**Convention:** every command in this folder runs with the working directory `web/`; commands shown in `plan.md`/acceptance lines that start with `web/…` run from the repo root.

**Files created**

| File | Content |

| `web/tsconfig.json` | `strict: true`, `strictTemplates: true`, `noUncheckedIndexedAccess: true`, `noImplicitOverride`, `noFallthroughCasesInSwitch`, `paths: { "@core/*": ["src/app/core/*"], "@shared/*": ["src/app/shared/*"], "@features/*": ["src/app/features/*"] }` |

| `web/src/app/core/prefs/preferences.store.ts` (+ `.spec.ts`) | `@Injectable({ providedIn: 'root' })`; signals `uiLanguage: Signal<UiLanguage>` (`'vi' \| 'en'`, default `'vi'`) and `theme: Signal<ThemePreference>` (`'dark' \| 'light'`, default `'dark'`); methods `read()`, `setLanguage(lang)`, `setTheme(t)`; storage key `nts.prefs.v1` storing `{ uiLanguage, theme }`; every access wrapped in `try/catch` and guarded by `typeof localStorage !== 'undefined'`. This is the **only** `localStorage`/`sessionStorage` site in the app (D2/D6) |
| `web/src/styles.scss` | empty baseline (tokens are 10.1.3-T1's); no `@import` of a CDN font |
| `web/src/index.html` | `<html lang="vi">`, `<app-root></app-root>`, `<title>NightTales Studio</title>` (a brand, not a translatable string), no inline script, no third-party request |
| `web/.gitignore` | `.angular/`, `dist/`, `node_modules/` (also covered by the root ignore), later `e2e-results/`, `playwright-report/`, `test-results/` (10.1.5-T1) |

**Store API (used by the shell in 10.2.6-T1 and by the language switch in 10.3.x):** `PreferencesStore` is root-provided with `readonly` signals and two setters; it never touches the network and never stores anything but the language and theme (D6). Hand-written test stub only, no mocking library (D15).

**Copy keys.** None introduced: the workspace renders no user-visible string (the route table is empty, the template is a router outlet, and `index.html` carries only the brand title). The first keys land with `10.2.5-T1` (Transloco scopes) and the first screen with `10.2.6-T1`/`10.3.1-T1`; `plan.md` §6 lists the contract they must satisfy.

**a11y (D16).** Nothing to interact with yet; the workspace only has to make the baseline possible: `<html lang>` present, one `<h1>` rule enforced later by review, no inline styles/scripts that a CSP would have to allow, `styles.scss` free of `:focus { outline: none }`. Component-level a11y starts with 10.1.3-T1's shared components.

**Performance (NFR-10-2).** Raw budgets guard the build here; the 250 kB gzip gate is 10.1.5-T1's `tools/web/check-gzip-budget.mjs` wired into `web.yml`. The empty shell makes no HTTP request, starts no timer and adds no `DestroyRef` need (D17); the static output means the first paint of the fallback HTML does not wait for JS.

**Security.** Nothing persisted except `nts.prefs.v1` (no PII, no token — D6/NFR-10-5); no secret, no third-party font/CDN, no inline executable script in `index.html` (the CSP generator will fail on one, D4); the workspace adds no `bypassSecurityTrust*`/`[innerHTML]` usage for 10.1.2-T1 to catch.

## Steps

1. `npx @angular/cli@22 new web --style=scss --ssr --server-routing` ⚠️ (flag names confirmed for 22.2.x; adjust and record if they differ), `--skip-git`, in the repo root; delete the CLI's default `app.spec.ts` (a tautology test) and its demo template/styles; set `outputMode: "static"` in `angular.json`.
2. `npm install` once to write `web/package-lock.json`, then verify `npm ci` from a clean `node_modules`; pin the `@angular/*` versions exactly; add `engines.node` and `web/.nvmrc`.
3. Apply the `tsconfig.json` flags and the three aliases; set `polyfills: []`; import `PreferencesStore` through `@core/prefs` from `app.config.ts` (or an eager provider) so the alias is proven by the build.
4. Set the `angular.json` budgets exactly as in the table and prove the error budget bites: temporarily set `maximumError: "10kB"`, `npm run build` must exit non-zero, revert.
5. Add `core/prefs/preferences.store.ts` + `preferences.store.spec.ts` (the only storage site) and `src/styles.scss`/`index.html` as tabled.
6. Add `app.routes.server.ts` with the single `**` Client entry (no `Prerender` entry — that is 10.3.1-T1's) and `app.routes.ts` with the empty table; run `npm run build` and confirm the static output is produced **without** any prerendered route directory.
7. Record in the PR body: `ls -R dist/web`, the **client-fallback file name** (expected `index.csr.html` ⚠️ — it becomes the default of `NTS_SPA_FALLBACK` in 10.1.1-T2), the initial-chunk raw sizes, the resolved Node/npm versions, and the effective `ng new` flags.
8. Hand over: 10.1.2-T1 (lint), 10.1.5-T1 (test harness), 10.1.1-T2 (container), 10.3.1-T1 (first routes + prerender entries).

## Failure handling and edge cases

| Case | Behaviour |
|---|---|
| `ng new` flag names differ in CLI 22.2.x | create the workspace with the closest flags and add the missing files by hand; the acceptance checks (zoneless, static, budgets, aliases, empty route table) are the gate, not the flag spellings — record the effective flags |
| The builder rejects an empty `routes` array ⚠️ | keep `app.routes.ts` empty if it builds; if it does not, use the single `{ path: '', pathMatch: 'full', children: [] }` entry — **never** add a placeholder page component (the first real pages are 10.3.1-T1/10.2.6-T1) |
| Static output without prerender emits no HTML file | the fallback file is still produced; if a build-time check is needed, assert `index.csr.html` exists — do **not** add a `Prerender` entry to force one |
| Initial raw bundle is above 700 kB later | the warning prints; if it *errors*, split the offending import instead of raising the budget (D13 is the contract) |
| `@angular/material` gets added here by mistake | it is not needed for T1; 10.1.3-T1 owns it, and adding it now would raise the initial bundle without use |
| Node 26.10.0 in `.nvmrc` is not installable on the machine | use the highest available 26.x patch (≥ 26.10.0), record it, and keep `engines.node` at `^26.10.0` (10 CR-43); if no 26.x build is available, stop and escalate — the pin is the contract (`DECISIONS.md` §10.13) |
| Critical-CSS inlining is turned back on (someone "optimises" the build) | `csp:gen` fails on the injected `onload` handler; keep `optimization.styles.inlineCritical: false` (WR12) and fix the build option instead of adding the handler's hash |
| A route is added here because "the app looks empty" | reject in review: an empty table is the intended state; the shell (10.2.6-T1) and the public pages (10.3.1-T1) own the first routes |
