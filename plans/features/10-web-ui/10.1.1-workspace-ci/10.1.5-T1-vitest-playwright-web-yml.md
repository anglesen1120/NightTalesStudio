## Goal

Make fast, honest tests the default: zoneless Vitest/jsdom for stores/components/tools, a Playwright suite in `web/e2e` (config, axe fixture, owner TOTP auth helper) that runs against `http://localhost:4200`, a gzip-budget script that enforces NFR-10-2, and `.github/workflows/web.yml` with the D15 pipeline — `npm ci`, lint, i18n check, `api:gen` drift, unit, build, gzip budget, CSP generation — **without** compose or e2e, which `11.5.1-T1`'s `e2e.yml` runs through `npm run e2e`.

| `web/e2e/fixtures/axe.ts` | `expectA11yClean(page, { include?, exclude? } = {})` — `new AxeBuilder({ page }).withTags(['wcag2a','wcag2aa','wcag21a','wcag21aa']).analyze()`, asserts `violations` is empty and prints `id/impact/help/nodes` for each; the helper proves itself on a known-bad `setContent('<img src="x">')` page inside the same spec file |
| `web/e2e/fixtures/auth.ts` | `totp(base32Secret, { digits = 6, step = 30, t = Date.now() })` (RFC 6238, HMAC-SHA1, `node:crypto`) and `loginAsOwner(page)` — navbar-free direct navigation to the login route, credentials from `NTS_E2E_OWNER_EMAIL`/`NTS_E2E_OWNER_PASSWORD`; first-run enrolment reads the manual key from the MFA setup page and persists it **only** to the git-ignored `web/e2e/.auth/owner-totp.json` (mode 0600, deleted by the global teardown); the retry condition is the API code **`invalid_mfa_code`** (WR14, not `invalid_totp`), waiting for the next 30 s step (`30_000 - (Date.now() % 30_000) + 1_500` ms) and retrying **once**. `page.route`/`page.clock` only — **no in-app test hooks** (no debug switch, no bypass route, no seeded session in the app). | `web/e2e/global-teardown.ts` | deletes `web/e2e/.auth/` (the enrolled owner secret) at the end of every run, including failures (WR14), and prints nothing about the secret |
| auth specs convention | any spec that authenticates sets `test.use({ trace: 'off', video: 'off' })` (WR14) — Playwright still writes a screenshot on failure only; app timers in specs are advanced with `page.clock` (`install`/`fastForward`), never with `waitForTimeout`, while the TOTP step boundary remains a real wall-clock wait because the server validates the code against its own clock |
| `web/e2e/totp.unit.spec.ts` | the RFC 6238 SHA-1 vectors (secret `12345678901234567890`, `t` = 59 / 1111111109 / 1111111111 / 1234567890 / 20000000000 → `94287082`/`07081804`/`14050471`/`89005924`/`69279037`, truncated to the last 6 digits) — proves the helper before any login spec depends on it; no browser fixture is requested, so no browser launches |
| `web/e2e/smoke.spec.ts` | two targets. **Both**: the app boots at the `baseURL` (today the static fallback document — the route table is empty until 10.2.6-T1/10.3.1-T1), axe clean, `page.on('console')` reports no error, `page.on('requestfailed')` is empty, no document/script/style response ≥ 400. **`NTS_E2E_TARGET=container` only** (the mode `e2e.yml` uses, where nginx serves): the **WR2 header matrix** — the full D4 set (CSP + `referrer-policy` + `x-content-type-options` + `permissions-policy` + `cross-origin-opener-policy`) on `/`, on a deep client route that falls back, and on a prerendered legal route (`/vi/privacy`, `test.skip` with a printed reason until 10.3.1-T1 ships it — never a silent pass), while a hashed asset returns the security headers but **no** `content-security-policy`; `page.request.get('/healthz')` → 200 with `content-type: text/plain` and body `ok`. Those assertions **fail** (never skip) when container mode is requested and a header is missing; the dev server sends no D4 headers and answers `/healthz` with the SPA fallback, so they are not run in dev mode at all. **Always**: the accepted-cookie probe of the ruling |
| `web/tools/web/check-gzip-budget.mjs` | `--dir dist/web/browser --budget 256000`; parses the fallback HTML for initial-chunk references (`<script src>`, `<link rel="modulepreload">`, `<link rel="stylesheet">`), gzips each file (`zlib.gzipSync(buf, { level: 9 })`), prints `file raw gzip` rows plus the total, exit 1 when `total > budget` with the overage printed (NFR-10-2, D13; the constant is named `BUDGET_BYTES = 250 * 1024` with a comment that D13 reads "250 kB") |
| `web/tools/web/check-gzip-budget.test.mjs` | Node `--test`: builds two temp fixtures (under and over budget) and asserts exit code + the reported byte count; also asserts a missing directory fails loudly (never silently passes) |
| `.github/workflows/web.yml` | see below |
| `web/.gitignore` (append) | `e2e-results/`, `playwright-report/`, `test-results/`, **`e2e/.auth/`** (the enrolled TOTP secret must never be committed — WR14) |

**`web.yml` (exact)**

```yaml
name: web
on:
  pull_request:
    paths: ['web/**', '.github/workflows/web.yml']
  workflow_dispatch:
permissions: { contents: read }
concurrency: { group: 'web-${{ github.ref }}', cancel-in-progress: true }
defaults: { run: { working-directory: web } }
jobs:
  build-test:
    runs-on: ubuntu-24.04
    timeout-minutes: 20
    steps:
      - uses: actions/checkout@<sha>
      - uses: actions/setup-node@<sha>
        with: { node-version-file: web/.nvmrc, cache: npm, cache-dependency-path: web/package-lock.json }
      - run: npm ci
      - run: npm run lint              # ng lint + forbidden-pattern scan + fixture matrix (10.1.2-T1)
      - run: npm run i18n:check        # vi/en key parity + usage (10.2.5-T1, D10)
      - run: npm run api:gen:check     # regeneration from the pinned openapi.json produces no diff (10.1.4-T1, D5)
      - run: npm run test:ci
      - run: npm run test:tools
      - run: npm run build
      - run: npm run budget:gzip
      - run: npm run csp:gen           # tools/web/gen-csp.mjs (10.1.6-T1, D4): validation only — fails on inline handlers / javascript: URLs; its output (dist/nginx/csp-headers.conf) is never committed and is consumed by web/Dockerfile
```

**Deliberate absences**: no `docker compose`, no `npm run e2e`, no service container, no artifact upload — e2e (and its trace/video artifacts) belongs to `e2e.yml` (11.5.1-T1:22), and the D15 pipeline is complete without them per the ruling. The Node pin is read from `web/.nvmrc` (`node-version-file` = **26.10.0**, i.e. the contract's *`setup-node` node-version 26*; no duplicated hard-coded `node-version`, one source of truth — 10 CR-43). Every action is pinned by a full SHA (Dependabot `github-actions` group; 11.5.3-T1 reviews), and the `npm` Dependabot entry lives at `web/` with majors excluded (11.5.3-T3:23).

**Script contract** (the whole workspace depends on these names): `start`, `build`, `test` (`ng test`), `test:ci` (`ng test --watch=false`), `test:tools` (`node --test tools/web`), `lint`, `lint:app`, `lint:forbidden`, `lint:fixtures`, `e2e` (`playwright test`), `budget:gzip`, `container:smoke` (10.1.1-T2), plus the three added by other tasks and already referenced by `web.yml`: `i18n:check` (10.2.5-T1), `api:gen`/`api:gen:check`/`api:gen:local` (10.1.4-T1), `csp:gen` (10.1.6-T1). `web.yml` lands with the complete step list; steps whose script is owned by another task turn green in the same wave (CRs in `plan.md` §10).

**Copy keys.** None — no UI in this task. The workspace renders no string yet (empty route table), so locale coverage cannot be asserted here: the `vi`/`en` **key** parity gate is `i18n:check` (10.2.5-T1), invoked (not implemented) by `web.yml`, and the first bilingual screen assertions belong to the specs of 10.3.1-T1/10.4.x/10.5.x. The harness only has to keep both locales reachable (`baseURL` + the `NTS_E2E_*` env vars, no hard-coded locale path).

**a11y (D16).** `expectA11yClean` runs on every page a spec visits (D15) with the WCAG 2.1 AA tag set; the helper carries a self-proving negative case (`<img>` without `alt` must be reported) so a silently broken axe setup fails the run instead of passing everything. Keyboard/focus checks that axe cannot do (focus visible, no keyboard trap except modal dialogs, `aria-live` feedback) are asserted in the screen specs of 10.3.x–10.5.x, not here.

**Performance.** `test:ci` is the PR gate (fast, jsdom, no browser); the Playwright suite is intentionally out of `web.yml` so a PR that touches only styles does not pay for a browser run; `budget:gzip` fails the build on an initial-chunk regression (NFR-10-2) instead of relying on review; the smoke spec asserts **no** extra network request beyond the document and its chunks (guards against accidental polling, D13/D17).

**Security.** No secret in the workflow (the owner credentials exist only as `e2e.yml`/local env values, never here; `permissions: contents: read`); tokens are never written to `storageState` (D15 forbids reuse) and Playwright's traces are failure-only artifacts of a local stack; the gzip script reads build output only; the workflow runs no `pull_request_target` and no third-party action outside the SHA-pinned set.

## Failure handling and edge cases

| Case | Behaviour |
|---|---|
| `@angular/build:unit-test` options differ in 22.2.x | record the effective options in the PR body; if Vitest cannot run through the builder, run it through `ng test` with the closest supported runner and keep the *name* `test:ci` stable (the workflow depends on the script, not the internals) |
| Jest is the CLI default instead of Vitest ⚠️ | the D15 contract is Vitest; if the builder only offers Jest in this version, stop and escalate rather than silently switching the runner |
| axe reports violations on a page this task owns no code for | the failure is real and belongs to that screen's task (10.3.x–10.5.x); `expectA11yClean` supports `exclude` only with an explicit comment naming the owning task and a linked issue — never a blanket disable |
| Compose stack not up (11.1.1-T1 soft) | `webServer` starts `npm start`; the cookie probe skips with a printed reason; everything else runs |
| The dev API is not up | probe skip (above); the smoke spec's other assertions never call the API |
| Flaky TOTP login | the helper waits for the next step and retries once; a second failure is a hard failure (never a longer retry loop) — later specs must not retry globally |
| Trace/video grow the artifact size | the `outputDir` is git-ignored and the artifacts are uploaded only on failure by `e2e.yml`; retention is that workflow's setting |
| `npm ci` cache miss slows the job | `setup-node` caches on `web/package-lock.json`; the job target is < 10 min and is recorded in the PR |
