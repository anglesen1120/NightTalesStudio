## Goal

Define the NightTales look once and give every wave-1 screen the same primitives, so ten screens do not invent ten empty states. One Material M3 theme (dark default, light option) whose tokens live in a single place, self-hosted Be Vietnam Pro with full Vietnamese coverage, and the wave-1 half of the D11 shared UI kit: `PageHeader`, `EmptyState`, `ErrorState`, `LoadingState`, `StatusChip`, `ConfirmDialog` (with the empty-in-P `cost-line` slot), `Stepper`, `CharCounter`, `CopyableCode` and the inline-`<svg>` icon components (**WR4**: these two components and the icons are owned here, not by the feature tasks). Every component is standalone, `OnPush`, inputs/outputs only, keyboard reachable, contrast-checked in both themes, with copy in vi and en from the `core` i18n scope.

## Design

**Theme package — `web/src/app/shared/ui/theme/`**

- `_tokens.scss` — custom properties under `:root, [data-theme='dark']` and `[data-theme='light']`:
  `--nts-color-{bg,surface,surface-variant,on-surface,on-surface-muted,primary,on-primary,outline,error,warn,success,focus}`,
  `--nts-space-{1..8}` (4 px base), `--nts-radius-{sm,md,lg}`, `--nts-elevation-{1,2,3}`,
  `--nts-font-sans` (`'Be Vietnam Pro', system-ui, sans-serif`), `--nts-font-mono`,
  `--nts-type-{display,title,body,label,caption}-{size,line,weight}`.
  Both themes define the **same** key set; a missing key is a test failure.
- `_theme.scss` — builds the Material M3 theme from those values, dark as the default `$type`, light emitted under `[data-theme='light']`; ⚠️ the exact Material 22.2 SCSS entry (`mat.theme(...)` vs the older `define-theme` composition) is confirmed against the installed package and recorded in a comment at the top of the file.
- `_typography.scss` — `@font-face` rules from `@fontsource/be-vietnam-pro` (400/500/600 × latin/latin-ext/vietnamese) with `font-display: swap`; ⚠️ the exact subset file names are confirmed from the installed package (`O-D` in plan §10). Material Symbols and any icon font are **banned**: glyphs are inline `<svg>` inside each component, so no third-party font or CDN request exists and `font-src 'self'` stays true.
- `web/src/styles.scss` — imports `theme/tokens`, `theme/typography`, `theme/theme` in that order, then `@angular/material` prebuilt typography only if the M3 mixin requires it; nothing else.

**Theme state — `web/src/app/core/prefs/theme.store.ts`**

```ts
export type ThemeName = 'dark' | 'light';

@Injectable({ providedIn: 'root' })
export class ThemeStore {
  readonly theme: Signal<ThemeName>;                 // default 'dark' (D11)
  init(): void;                                      // app initializer: read pref, apply dataset.theme
  setTheme(next: ThemeName): void;                   // write pref via core/prefs, apply attribute
}
```

`init()` is registered by 10.1.1-T1's `provideAppInitializer`; persistence goes through the `core/prefs` storage port only (D2 bans `localStorage` outside `core/prefs`), and only the theme name — a closed enum validated on read — is ever stored.

**Components — one folder per component under `web/src/app/shared/ui/<name>/`** (`<name>.ts` + `.html` + `.scss` + `.spec.ts`), all `standalone: true, changeDetection: ChangeDetectionStrategy.OnPush`, exported from `web/src/app/shared/ui/index.ts`:

| Component | Inputs / outputs | Notes |
|---|---|---|
| `PageHeader` | `titleKey: string`, `subtitleKey?: string`, `backHref?: string`; content slot `[actions]` | renders the single `<h1>` of a page; `backHref` renders a link with `core.ui.pageHeader.back` as its accessible name |
| `EmptyState` | `titleKey: string`, `bodyKey?: string`, `actionLabelKey?: string`; `action = output<void>()` | `role="status"`; illustration is `aria-hidden="true"`; action is a real `<button>` |
| `ErrorState` | `bodyKey: string`, `titleKey?`, `traceId?: string`, `retryLabelKey?`; `retry = output<void>()` | `role="alert"`; takes **already-mapped** copy (`errors.<code>` from 10.2.2-T1), never raw `ProblemDetails.detail` (D9); `traceId` shown in `core.ui.errorState.traceId` |
| `LoadingState` | `rows: number` (3–6), `labelKey?: string` | `aria-busy="true"` + polite live label; skeleton shapes `aria-hidden`; CSS shimmer disabled under `prefers-reduced-motion` |
| `StatusChip` | `statusKey: string`, `appearance: 'neutral' \| 'info' \| 'success' \| 'warn' \| 'error'` | closed icon map `STATUS_ICON` (inline SVG); unknown code → `core.ui.statusChip.unknown` + neutral appearance, never a crash; icon **and** text so meaning is not carried by colour (D16) |
| `ConfirmDialog` | `titleKey`, `bodyKey`, `confirmLabelKey`, `destructive?: boolean`, `pending?: boolean`; slot `[cost-line]`; `confirmed = output<void>()`, `cancelled = output<void>()` | wraps `MatDialog` with a closed data contract; CDK focus trap, `Escape` cancels, focus restored to the trigger; `cost-line` stays empty in P (D14) |
| `Stepper` | `steps: readonly { labelKey: string; state: 'done' \| 'current' \| 'todo' }[]`, `orientation: 'horizontal' \| 'vertical'` | `<ol>` semantics, `aria-current="step"`, done steps announce "done"; horizontal collapses to vertical below 360 px |
| `CharCounter` (**WR4**) | `value: number`, `max: number`, `labelKey?: string` | `core.ui.charCounter.label`, `core.ui.charCounter.over` | a plain `<span>` referenced by the field through `aria-describedby` — **never** a live region (announcing every keystroke is hostile to screen readers); over `max` it switches to the error style plus `core.ui.charCounter.over`, and the `CharCounter_signal` is `computed` from the input, not a new signal per key (D18) |
| `CopyableCode` (**WR4**) | `value: string`, `labelKey?: string` | `core.ui.copyableCode.copy`, `core.ui.copyableCode.copied` | the `<code>` is focusable and readable by AT; the copy button has an `aria-label` and its outcome is announced with `aria-live="polite"`; the value is never inside an `aria-hidden` region; the clipboard call is `navigator.clipboard.writeText` with a graceful fallback message when it is unavailable |
| inline icons (**WR12**) | `labelKey?: string` | `core.ui.icons.<name>` (only when `labelKey` is set) | one tiny standalone `OnPush` component per glyph: `icon-check`, `icon-clock`, `icon-alert`, `icon-play`, `icon-pause`, `icon-copy`, `icon-unknown`; inline `<svg>` with `aria-hidden="true"` by default and `role="img"` + `aria-label` when `labelKey` is passed. **No `MatIconRegistry` SVG set and no icon font**: both need `bypassSecurityTrustResourceUrl` and the `angular#components` Trusted Types policy, which WR12/`angular#unsafe-bypass`-style weakening forbids |

**Security surface of the kit.** The kit holds no credential and no content: the only persisted value is the theme name through `core/prefs` (a closed `'dark' | 'light'` enum, never a token, story text or legal text — D2/D6, F25); no component logs, and nothing from an `ErrorState` body is written to storage or printed to the console (only the `traceId` is displayed, D9). No component uses `innerHTML`/DOM string APIs (lint-banned, D2) and none adds a Trusted Types policy — the theme layer produces CSS only. The single navigation surface is `PageHeader.backHref`, bound with `[routerLink]`: it must start with a single `/` (never `//`, a scheme, a backslash or an absolute URL) so a caller cannot turn a header into an open redirect; the component rejects such a value (no navigation) and the spec asserts it.

**Copy keys** created in `web/src/assets/i18n/core/vi.json` and `en.json` (both files, identical key sets): `core.ui.pageHeader.back`, `core.ui.pageHeader.actions`, `core.ui.emptyState.title`, `core.ui.emptyState.body`, `core.ui.errorState.title`, `core.ui.errorState.body`, `core.ui.errorState.retry`, `core.ui.errorState.traceId`, `core.ui.loadingState.label`, `core.ui.confirm.title`, `core.ui.confirm.cancel`, `core.ui.confirm.confirm`, `core.ui.dialog.close`, `core.ui.statusChip.unknown`, `core.ui.stepper.step`, `core.ui.stepper.current`, `core.ui.theme.toggle`, `core.ui.theme.dark`, `core.ui.theme.light`, `core.ui.charCounter.label`, `core.ui.charCounter.over`, `core.ui.copyableCode.copy`, `core.ui.copyableCode.copied`, `core.ui.icons.<name>`.

**Reuse, not duplication (D11/WR4).** Consumers get the kit from `@shared/ui`. This task produces `Stepper` (10.3.3-T1/T3, 10.4.2-T2), `ConfirmDialog` for every destructive action, `CharCounter` (field limits), `CopyableCode` (recovery codes) and the inline-`<svg>` icons that `StatusChip` and later screens consume. Built **later by their owners** and reused from `shared/ui/` (or `core/state`, `shared/util`) once a second feature needs them: `ConflictDialog`, `RetryCountdown`, `bindFieldErrors`, `FormErrorAlert` → 10.2.2-T1; `IdempotencyKeys` → 10.2.3-T1; `core/state/cursor-list`, `shared/util/cursor-page`, `core/state/visible-poll` → 10.2.6-T1; `SegmentChips` → 10.5.3-T1; `AudioPreviewButton` → 10.4.2-T2; `InlineAnnotation` → 10.5.10-T1; `DiffView` → 10.5.4-T1; `ReauthDialog` → 10.3.3-T3. No second copy of a helper may appear in a feature folder (D2/D11).

## Steps

1. Create `shared/ui/theme/_tokens.scss` with the full key set for dark and light; add `_typography.scss` and `_theme.scss`; wire `web/src/styles.scss`.
2. Add the font dependency (`@fontsource/be-vietnam-pro`, exact version, no `^` for Material/CDK per D1) and the three `@font-face` families per weight/subset.
3. Implement `core/prefs/theme.store.ts` + `ThemeName`; apply `document.documentElement.dataset['theme']` on init and on change.
4. Build `LoadingState`, `EmptyState`, `ErrorState` (the three state primitives with their roles and live regions).
5. Build `PageHeader` (single `<h1>`, actions slot) and `Stepper` (list semantics, `aria-current`).
6. Build `StatusChip` with the closed inline-SVG icon map and the unknown-code fallback.
7. Build `ConfirmDialog` over `MatDialog` with the closed data contract, the `[cost-line]` slot (projected, unused in P), pending state and focus restoration.
8. Build the inline-`<svg>` icon components under `shared/ui/icons/` (seven glyphs, `labelKey?` input, no registry, no icon font — WR12); `StatusChip` consumes them by name.
9. Build `CharCounter` (`value`/`max`, `computed` over/under state, `aria-describedby` wiring, no live region) and `CopyableCode` (`value`, copy button with `aria-label` + polite announcement, clipboard fallback).
10. Add `shared/ui/index.ts` barrel; keep every component's style block ≤ 8 kB.
11. Create `web/src/assets/i18n/core/{vi,en}.json` with the key list above (vi first, then the en translations; leaves camelCase, style `core.area.item`).
12. Write the component specs and the token/contrast spec (see Tests); run `npm run lint` and the unit suite in `web/` to confirm the `ui` layer injects nothing but the dialog/stepper primitives.
13. Update `web/README.md` (or the repo dev-setup note if 10.1.1-T1 created it) with one paragraph: where tokens live, how to add a token in both themes, and that an icon font is banned.

## Acceptance checks

- [ ] Dark is the default theme on boot; `ThemeStore.setTheme('light')` switches every token and survives a reload through `core/prefs`; no other storage key is written.
- [ ] Every colour token defined in `[data-theme='light']` also exists in `:root, [data-theme='dark']` (spec fails on a missing key), and the token spec proves contrast ≥ 4.5:1 for body text and ≥ 3:1 for focus rings in both themes.
- [ ] **No network request to any font/icon CDN** occurs on a rendered page (asserted in the spec via a fail-on-request hook and confirmed in the container e2e of 10.1.6-T1); Vietnamese diacritics render from the self-hosted subset.
- [ ] `EmptyState`, `ErrorState`, `LoadingState`, `StatusChip`, `Stepper`, `PageHeader` each render in a host component with `vi` and `en` copy; a missing key fails the spec.
- [ ] `ConfirmDialog` traps focus, cancels on `Escape`, restores focus to the trigger, disables its confirm button while `pending`, and renders the `[cost-line]` slot only when the caller projects content (empty in P).
- [ ] `StatusChip` with an unknown `statusKey` renders `core.ui.statusChip.unknown` with a neutral appearance and an icon — never colour alone, never an exception.
- [ ] `CharCounter` shows `value`/`max` from a `computed` signal, is referenced by its field through `aria-describedby`, is **not** a live region, and past `max` switches to the error style + `core.ui.charCounter.over` in both languages.
- [ ] `CopyableCode` copies through `navigator.clipboard.writeText`, announces the result politely, and shows the fallback copy (no crash, no silent no-op) when the clipboard API is unavailable; the code value is reachable by a screen reader.
- [ ] Every icon is an inline-`<svg>` component: `aria-hidden="true"` without `labelKey`, `role="img"` + accessible name with it; **no `MatIconRegistry` SVG set, no `bypassSecurityTrustResourceUrl`, no icon font or remote glyph request** anywhere in the kit (WR12).
- [ ] `PageHeader` with a hostile `backHref` (`//evil.example`, `https://evil.example`, `\\evil`) performs no navigation and logs nothing; a relative in-app path navigates normally.
- [ ] No component writes to storage, logs page/API content, or creates a Trusted Types policy; the only persisted value is the theme name.
- [ ] Keyboard-only walkthrough of every component: no trap outside the dialog, visible focus everywhere, target size ≥ 24 px, no horizontal scroll at 360 px; axe (WCAG 2.1 AA tags) clean in the e2e pass that visits the first real pages.
- [ ] `prefers-reduced-motion: reduce` disables the skeleton shimmer and any transition.
- [ ] `npm run lint` passes with the `ui` boundary rules active (no store/`HttpClient` injection anywhere in `shared/ui/**`), and every component is `OnPush`.
- [ ] `npm run build` stays inside the `angular.json` raw budgets and any single component style block is ≤ 8 kB.

## Tests

`web/src/app/shared/ui/theme/tokens.spec.ts` (both-theme key parity from the parsed SCSS, contrast ratios from token values), `core/prefs/theme.store.spec.ts` (default, set, persist, reload with a fake `core/prefs` storage), `<component>.spec.ts` for each of the seven (TestBed host, one spec per state, a11y assertions: `role`, `aria-busy`, `aria-current="step"`, focus trap + restore for the dialog, the `aria-label`/text pairing for the chip), `char-counter.spec.ts` (under/at/over `max`, the `aria-describedby` link, no live region asserted on the host), `copyable-code.spec.ts` (success announcement, clipboard-unavailable fallback, accessible name), `icons.spec.ts` (each glyph renders one `<svg>`, `aria-hidden` by default, `role="img"` + label with `labelKey`, and the kit source contains no `MatIconRegistry`/`bypassSecurityTrustResourceUrl` reference — asserted against the runtime API surface, not template text), `web/src/app/shared/ui/i18n-keys.spec.ts` (loads both `core` JSON files through a Transloco test double and asserts every key referenced by the seven components exists in **both** languages and that the two files have identical key sets), `page-header.spec.ts` (relative path navigates; `//host`, `https://…`, `\\host` and a scheme-relative value are rejected and produce no navigation), `no-third-party-assets.spec.ts` (fails if any component template or style references `fonts.googleapis`/`fonts.gstatic`/an `@import url(http…`).

Hand-written fakes only — this task has no HTTP, so no network fake is needed; the a11y contract is asserted directly in the component specs rather than through a library. The e2e/axe half is inherited from 10.1.6-T1's CSP fixture once real pages exist.

## Failure handling and edge cases

| Case | Behaviour |
|---|---|
| A token exists in dark but not light | The spec fails with the key name; ship blocked (never a silent fallback that looks "nearly right" in one theme) |
| Vietnamese glyphs missing from the chosen subset | The typography spec renders a diacritic-heavy sample string and the token test fails if the selected subset omits `vietnamese` |
| Component style block grows past 8 kB | Split the component or move rules into the theme partial; the budget step in `web.yml` is the guard |
| `StatusChip` receives a wire code with no copy key | Falls back to `core.ui.statusChip.unknown`, neutral appearance; the fallback is asserted so a backend enum addition never breaks a screen |
| `ErrorState` is handed a raw `ProblemDetails.detail` | Design rejects it: the component only accepts a copy key + an optional `traceId`; reviewers check inputs, and 10.2.2-T1 owns the mapping |
| S caller projects a `cost-line` template in P | Renders nothing today because P passes none; the slot must exist and be empty so 10.8.x is a one-line change (D14) |
| Material 22.2's theme SCSS entry differs from the documented one (`O-E`) | Recorded in a file comment with the installed version; the token layer is plain CSS custom properties, so a Material API change cannot break feature code |
| Font package fails to install (offline CI) | Build fails loudly at `npm ci`; no runtime fallback to a CDN is ever added (D11) |
