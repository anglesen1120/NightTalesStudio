## Goal

Ship the prerendered public shell: `/<lang>/` landing and `/<lang>/pricing`, the prerendered `/` language redirect, the prerender list, `sitemap.xml` and `robots.txt`, and per-language SEO head (`<title>`, `description`, `canonical`, `hreflang` + `x-default`, `og:`). Pricing tiers come from checked-in content with **no prices of record invented** (ST-1); **no API call runs during prerender** (D12).

## Design

Files under `web/src/app/features/public/` (D2):

- `public.routes.ts` — lazy routes for `/<lang>/` and `/<lang>/pricing`; `app.routes.server.ts` gains the prerender list (`vi`, `en` × `/`, `/pricing`, `/privacy`, `/terms`, `/report`, `/help`) and the `/` redirect entry.
- `domain/public.model.ts` — `UiLang`, `PricingTier`, `PricingContent`, `PublicPageMeta`, `SitemapEntry` (`plan.md` §3.1).
- `data-access/pricing-content.ts` — loads and validates `web/src/content/pricing/<lang>.json` against `PricingContent` at build/test time; no `HttpClient`.
- `ui/landing.page.ts` — OnPush standalone component; hero + CTAs; no store, no fetch.
- `ui/pricing.page.ts` — OnPush; renders `PricingTier[]`; CTA `/register`, or `/billing` when `SessionStore.status === 'authenticated'` (read-only).
- `shared/util/lang-redirect.ts` — resolves the language: stored preference → `Intl`/browser → `vi`; calls `history.replaceState` to `/<lang>/` (no full reload).
- `shared/util/page-meta.ts` — builds `PublicPageMeta` per route/language; applied via Angular `Title`/`Meta` and a `link[rel=canonical]`/`link[rel=alternate]` writer.
- `web/public/sitemap.xml` (static, six paths per language) and `web/public/robots.txt` (`Disallow: /admin`, `/account`, `/billing`, `/cancel-request`).

i18n: scope `public` (exists); marketing copy in `content/<area>/<lang>.json`; error copy in `errors`; every key vi + en (F20).

## Steps

1. Add `public.routes.ts` and register the routes; extend `app.routes.server.ts` with the exact six-path-per-language prerender list and the `/` redirect entry (SD2, ST-10).
2. Implement `lang-redirect.ts` with `Intl` + stored preference + `vi` default and `history.replaceState`.
3. Implement `pricing-content.ts` + `web/src/content/pricing/vi.json` and `en.json` with tier structure and **placeholder** price text only.
4. Build `landing.page.ts` and `pricing.page.ts` from the 10.3.1-T0 design at all three breakpoints, dark/light, vi/en.
5. Implement `page-meta.ts` and wire `<title>`, `description`, `canonical`, `hreflang` (+`x-default`) and `og:` per route/language.
6. Write `sitemap.xml` (six paths × two languages) and `robots.txt` with the disallow list.
7. Verify no `HttpClient`/API call runs during prerender (grep + prerender smoke).
8. Run the axe spec and the budget check; confirm `public` chunks within budget and no admin/billing chunk referenced from the initial bundle.

## Acceptance checks

- **Given** a production build, **When** `/<lang>/` and `/<lang>/pricing` are requested, **Then** the served HTML is prerendered (content present without JS) and contains no API call.
- **Given** `/` is requested, **When** the client runs, **Then** it resolves the language (`vi` default) and `history.replaceState`s to `/<lang>/`.
- **Given** any public page, **When** the head is inspected, **Then** `<title>`, `description`, `canonical`, `hreflang` alternates + `x-default` and `og:` tags are present for that language.
- **Given** `sitemap.xml`, **When** parsed, **Then** it lists all six paths per language; **and** `robots.txt` disallows `/admin`, `/account`, `/billing`, `/cancel-request`.
- **Given** the pricing page, **When** rendered, **Then** tiers come from `content/pricing/<lang>.json`, no price of record is shown (placeholder only), and each tier CTA targets `/register` (or `/billing` when authenticated).
- **Given** a published price (once the owner supplies one), **When** the e2e runs against the compose stack, **Then** that price also exists in `GET /billing/packages` (ST-1).
- **Given** the pages, **When** axe runs with `wcag2a,wcag2aa,wcag21a,wcag21aa,wcag22aa`, **Then** zero violations in vi and en.
- **Given** a JS-disabled client, **When** the landing loads, **Then** CTAs and legal links still work.

## Tests

- Unit (Vitest): `lang-redirect` (preference/browser/default precedence), `page-meta` builder (canonical + `hreflang` + `x-default`), `pricing-content` loader (schema validation, placeholder path).
- Component (Vitest): `landing.page` and `pricing.page` render from content; signed-in CTA variant.
- Prerender smoke: assert prerendered HTML contains the hero/tier text and no `<script>` fetch of the API.
- e2e (Playwright, `e2e.yml` via 11.5.1-T1): `/` redirect; head tags per language; any published price present in `GET /billing/packages`.
- Axe spec with the WCAG 2.2 tag set; budget check via `tools/web/check-gzip-budget.mjs`.

## Failure handling and edge cases

| Case | Handling |
|---|---|
| No stored preference and `Intl` unavailable | Default to `vi`; never throw |
| `content/pricing/<lang>.json` malformed | Build/test fails with a schema error; page never ships a partial tier list |
| Owner supplies figures late | Prices stay placeholders until provided; the e2e price-parity assertion activates once present (ST-1) |
| `/help` or `/report` not yet built | The prerender list includes them; if their owner is late, prerender emits an empty shell — recorded as `[OPEN]`, not patched here |
| A prerender-time API call is introduced | Prerender smoke fails the task; D12 forbids it |
| Budget regression | `check-gzip-budget.mjs` fails; reduce chunk or move heavy code behind lazy routes |
