## Goal

A creator can list, create, edit and archive a series, and picks the visual style from a labelled grid whose copy comes from the seed. The 4-step editor (topic + language → aspect → voice → style) is one form with typed reactive controls, so every episode of the series keeps the same style; the topic cannot be changed while autopilot is on, the language cannot be changed at all, and a true-crime series shows only the two illustration styles plus the responsibility notice (03 CR-7).

**Typed reactive form (step mapping).** `FormGroup` with `title` (`Validators.required`, `maxLength(120)`), `topic`, `language`, `aspect`, `voiceId`, `styleTemplateId`, optional `storyPreset` (rendered as "default" only — the preset picker is not in P [OPEN: no preset catalog UI is specified in the files read; the field is submitted as `null`]). The `Stepper` renders 4 steps: 1 topic+language, 2 aspect, 3 voice (the `VoicePicker` of 10.4.2-T2 bound to `voiceId`), 4 style (`StyleGrid` bound to `styleTemplateId`). Next is disabled while the step's controls are invalid; the component never calls the API — the store does.

**Edit vs create.** `mode: 'edit'` loads `GET /series/{id}`, keeps the returned `etag` as the store's baseline, disables the language control with the hint `series.language.locked` (09.4.1: `language` is immutable) and, when `autopilotEnabled`, disables the topic control with the hint `autopilot.topic_locked` (key from 02.8.3 §6, used verbatim). Save calls `PATCH` with `If-Match`; on 412 the store keeps the entered values, sets `conflict = true` and the page opens `ConflictDialog` (Reload latest / Save mine as new version / Cancel). "Save mine as new version" re-submits against the freshly `GET`-ed ETag.

**Language-change rule (U6).** `setLanguage()` clears `voiceId`, clears the style selection **only if** the new topic makes it incompatible (a `true_crime` template under a fiction topic — the same rule the API enforces, computed with the local `isTopicCompatible()` helper mirroring `StyleTopicPolicy`), and announces `series.voice.clearedByLanguage` / `series.style.clearedByTopic` in an `aria-live` region.

**Archive.** `ConfirmDialog` with the series title; on confirm `DELETE`; the row is removed optimistically and restored on failure with the `series.archive.failed` snackbar (10 s undo is not offered for archive — it is a server-side archive flag, and the row is recoverable with `includeArchived`).

**Copy keys.** Scope `series`: `series.list.title|empty|new|archived|includeArchived`, `series.step.topic|aspect|voice|style`, `series.field.title|topic|language|aspect|voice|style`, `series.topic.ghost|spiritual|trueCrime`, `series.aspect.landscape|portrait`, `series.language.locked`, `series.style.trueCrimeNotice` (verbatim from 03), `series.style.<name>.label|.hint` (verbatim, from the seed), `series.style.clearedByTopic`, `series.voice.clearedByLanguage`, `series.save.saved|conflict`, `series.archive.confirm|failed`, `series.email.label`? — no. Plus `errors.<code>` for `validation_failed`, `voice_language_mismatch`, `series_conflict`, `series_archived`, `series_topic_locked`, `concurrency_conflict`, `network_error`, `rate_limited`, `unknown_error` (D9). Gone/dropped keys: none.

**Performance.** One `GET /series` per page and one per `loadMore`; the editor loads voices only when step 3 is reached (or the language changes) and templates only when step 4 is reached **or** the topic changes — at most one request each per change, with the previous list kept while loading; `track item.id` in every `@for`; style images deferred to the viewport; the gzip budget impact is ~10 kB on the lazy `series` chunk (well inside 250 kB).

**Security.** No token in storage; `PATCH`/`DELETE` always conditional/authorized server-side; the `If-Match` value is only ever the one the server returned (never recomputed client-side); no `[innerHTML]` for hints/labels (interpolation only — the hint texts are translated strings whose only substitution syntax is `{...}` for TranslationParams); titles are escaped by Angular; no series title in `console.*`; `series_topic_locked` (409) is shown with the autopilot hint rather than silently reverting.

**A11y (D16).** `Stepper` marks the current step `aria-current="step"`; each step is a `<fieldset>`+`<legend>`; the aspect choice is a radio group with text labels and a 16:9/9:16 icon; the style grid is a radio group with `alt` = label; error text is linked with `aria-describedby`; focus moves to the first invalid control after a failed step/submit; `CharCounter` announces through `aria-live="polite"`; the conflict dialog traps focus and restores it; all controls ≥ 24 px; 360 px layout stacks cards.

**Approved design handoff (2026-10-02).** Use [`03-dashboard-series.html`](../../../../design/ui/screens/03-dashboard-series.html): list `f-series-loading`, `f-series-list`, `f-series-empty`, `f-series-archived`, `f-series-archive`, `f-series-error`; wizard `f-new-step1`, `f-new-step2`, `f-new-step3`, `f-new-step3-empty`, `f-new-step4`, `f-new-step4-truecrime`, `f-new-errors`; edit `f-edit`, `f-conflict`, `f-unsaved`; overview `f-detail`, `f-detail-archived`, `f-detail-404`. This task owns the overview shell and all three overview states; Autopilot tasks only mount their tab body. Every screen-03 balance is S-only reference and is omitted in P.

`SeriesListPage`, `SeriesEditorPage` and `SeriesDetailPage` are containers over route-scoped stores; `SeriesRow`, `StyleGrid`, `VoicePicker` and step bodies consume readonly view models and emit typed intent unions. Typed-form value/status/server-error changes bridge to a template-read signal and clean up through `DestroyRef`; route-id/session-generation changes invalidate catalog/detail/save results and stop audio. Voice/style catalogs are unpaged `{items}` with ETag/304, never cursor-normalized. `PATCH /series/{id}` returns only `{etag}` plus `ETag`: the adapter returns `{etag}` and never fabricates a full `Series`; the store updates only fields from the submitted patch, and reloads before it needs any other authoritative field. No idempotency key is invented; create/save/archive use one in-flight intent and 412 never auto-retries.

## Failure handling and edge cases

| Case | Handling |
|---|---|
| 412 `series_conflict` | `ConflictDialog`; unsaved input kept in memory until the user chooses (D9). |
| 409 `concurrency_conflict` (race after the check — `09.4.1/plan.md:101`) | Same dialog; copy is the generic conflict message with `traceId` in the details view. |
| 409 `series_topic_locked` | Topic reverted to the stored value, hint `autopilot.topic_locked`, link to the Autopilot tab. |
| 409 `series_archived` | Archived chip + `errors.series_archived`; Save disabled (the series cannot be un-archived in P). |
| 400 `voice_language_mismatch` | Voice field cleared, `aria-live` announcement, focus to the voice step (step 3 is opened automatically). |
| 400 `validation_failed` with `errors.limit` (list) | Generic list error + `RetryCountdown` only for 429; the query drops to the default limit. |
| 428 missing `If-Match` | Treated as a client bug: `console.error` in dev + generic message (D9); never auto-retried. |
| Empty series list | `EmptyState` with the "Create series" action. |
| Style template de-activated while a series uses it | Hidden from the grid (`09.4.2-T1:147`); the edit form keeps the stored id as an extra card flagged `series.style.inactive` [OPEN: the exact fallback shape is not defined upstream; the card renders the stored id + label key if it exists]. |
| Cursor tampered with / garbage | `nextCursor` from the wire is opaque; a 400 drops the cursor and reloads the first page. |
| Topic changed to `true_crime` while a fiction style is selected | The style is cleared immediately with `series.style.clearedByTopic`; the server would refuse anyway (`validation_failed` field `styleTemplateId`). |
| Deep link to a missing/foreign series | 404 → the page shows the not-found state (no retry loop, no id echo). |
| Rollback | Revert the four route entries and the `index.ts` exports; the shell hides the nav item (10.2.6-T1 reads the same flag-free route list). |
