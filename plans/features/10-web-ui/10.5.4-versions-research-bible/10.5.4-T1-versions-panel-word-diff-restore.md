## Goal

On the episode editor route the owner opens a versions side panel, sees every `story_versions` row (version, source, word count, similarity, approved/current badges), selects two versions and reads a **word-level** diff between them, then restores an old version **as a new version** (existing versions are never mutated — 02.2.2-T1:53). Produces the shared `DiffView` component (D11) and `shared/util/text-diff.ts`, both reused by 10.5.7-T1 (bible ops) and 10.5.3-T2 (similarity highlights).

**`text-diff.ts` (pure, no Angular import — D2):**

```ts
export type DiffKind = 'equal' | 'insert' | 'delete';
export interface DiffSegment { kind: DiffKind; text: string; }
export interface WordDiff { segments: DiffSegment[]; added: number; removed: number; truncated: boolean; }
export const MAX_DIFF_TOKENS = 20_000;                    // per side, guards O(n·m) on 60-segment stories (C9)
export function diffWords(left: string, right: string): WordDiff;   // NFC + whitespace collapse, then jsdiff diffWordsWithSpace
```

Counts are token counts of inserted/deleted segments; `truncated = true` when either side exceeds `MAX_DIFF_TOKENS` (compare the tails only, never the whole body).

**`DiffView` API** (inputs/outputs only, `OnPush`, no store — D2):

```ts
readonly left  = input<string | null>(null);
readonly right = input<string | null>(null);
readonly rows  = input<DiffRow[]>([]);              // generic structured diff (WR16/P3); 10.5.7-T1 feeds BibleOp → DiffRow
readonly mode  = input<'word' | 'rows'>('word');    // 'word' = text diff over left/right; 'rows' = the rows input
readonly label = input<string>('');                 // aria label for the region
readonly rendered = output<WordDiff>();             // emitted once per input change (counts for the summary line)
```

Template: `@for (s of diff().segments; track $index)` inside `<div class="diff" [attr.aria-label]="label()" tabindex="0">`; added/removed hunks carry a leading `+`/`−` glyph and `data-kind` for tests. Model size per side ≤ 8 kB is checked by the story budget rule only when the consumer defers (`@defer` keeps it out of the initial chunk); the component itself renders the segment list with `track $index` and **never** recomputes the diff in the template — it is computed once in a `computed()`.

**`VersionsStore`** (provided on the editor route, not root):

```ts
readonly versions = signal<StoryVersionSummary[]>([]);
readonly leftId = signal<string | null>(null);       // defaults to the previous version
readonly rightId = signal<string | null>(null);      // defaults to the current version
readonly left = signal<StoryVersionDetail | null>(null);
readonly right = signal<StoryVersionDetail | null>(null);
readonly diff = computed<WordDiff | null>(() => this.left() && this.right() ? diffWords(this.left()!.body, this.right()!.body) : null);
readonly loading = signal(false); readonly loadingSide = signal<'left' | 'right' | null>(null);
readonly restoring = signal(false); readonly error = signal<AppError | null>(null);
readonly canRestore = computed(() => !!this.left() && this.left()!.versionId !== this.right()?.versionId && !this.left()!.isCurrent);
load(episodeId: string): Promise<void>;
select(versionId: string, side: 'left' | 'right'): Promise<void>;   // fetches only that side, keeps the other
restoreAsNewVersion(episodeId: string): Promise<Result<void>>;
reset(): void;                                                       // SESSION_SCOPED (D6)
```

`restoreAsNewVersion` = confirm dialog → `storyStore.replaceDraft(left().content)` → `storyStore.save(episodeId)` (10.5.3-T1 sends `{ content }` + `If-Match: currentStory.etag`) → on success `load()` again (the new version appears, `isCurrent`) and emit the `episodes.versions.restored` snackbar. No new repository write path is created: reuse the 10.5.3-T1 `StoryRepository.save`.

**Routes / deep link** [DECISION — client routes belong to plan 10]: the panel is a child of the editor route; `?panel=versions&left=<versionId>&right=<versionId>` reopens the same view (shareable, no content in the URL — only ids). That link is the cross-folder target of 10.5.3-T2's "Automatically corrected once" diff link (10.5.1-episodes-editor plan §10 O10): the `revised` version opens on the right with its predecessor on the left (`plan.md` §10 item 6).

## Acceptance checks

- [ ] The panel lists versions in server order (`version DESC`) with version number, `createdAt` (`Intl` for `vi-VN`/`en-US`), word count, similarity, and `current`/`approved` badges; an episode with no versions shows the `episodes.versions.empty` empty state, not an error.
- [ ] Selecting two rows renders a word-level diff with a `+`/`−` glyph per hunk and the `episodes.versions.diff.summary` sentence in a polite live region; adding `<script>alert(1)</script>` to a version's text renders it as visible text.
- [ ] Selecting the same version on both sides disables the diff (`episodes.versions.selectTwo`).
- [ ] `Restore` is disabled for the current version and while `restoring`; the confirm dialog names the source version and says the old version is kept.
- [ ] After a restore the list contains a **new** version whose body equals the restored one, `source = 'edited'`, and the previous rows are unchanged; the editor draft is the restored content.
- [ ] A stale ETag (412) opens `ConflictDialog` with Reload / Save mine as new version / Cancel; the draft is kept in memory until a choice is made.
- [ ] Restoring while the episode is `story_approved` (409 `episode_invalid_state`) shows `episodes.versions.needsReopen` with an action that calls 10.5.6-T1's reopen.
- [ ] No request is made while the panel is closed; opening the panel with both ids in the query makes exactly two `detail` calls.
- [ ] Both languages render (no missing key); axe (WCAG 2.1 AA) reports no new violations on the editor route with the panel open.
- [ ] gzip budget of the episode route stays under the gate threshold with `DiffView` deferred.

## Tests

- **Vitest store** (`versions.store.spec.ts`, fake repository): success/empty/`AppError` (404 → `error`, network → `network_error`); `select` fetches only the changed side (assert call count 1 after the first selection, 2 total); defaults (previous vs current) chosen from the list; `restoreAsNewVersion` sends the old `content` with the **current** `etag`, reloads, clears `dirty`; 412 → `pendingConflict` + draft unchanged; 409 → `needsReopen`; 428 → no user-visible error and a console warning in dev; `reset()` clears all signals.
- **Vitest component**: `DiffView` (counts, glyphs, no markup execution, `ops` mode), `VersionsPanel` (two selections → `rendered` output emitted once; `Restore` disabled states; snackbar text).
- **Pure**: `text-diff.spec.ts` — identical inputs, pure insert/delete, NFC/CRLF, `MAX_DIFF_TOKENS` truncation flag, 60-segment/40k-char pair completes < 250 ms [INFERENCE: measured in the test with a generous bound].
- **Playwright** `web/e2e/episodes-versions.spec.ts`: generate → edit/save → compare v1/v2 → assert the diff summary matches the seeded edit → restore v1 → assert a third version with v1's body and `source=edited`; axe per page visited; runs in the owner project with a per-file UI login (D15/F08).
- No test pins incidental copy or template text; assertions are on behaviour and key presence only.

## Failure handling and edge cases

- **412 `story_version_conflict`** on restore → `ConflictDialog` (D9); never a silent overwrite.
- **409 `episode_invalid_state`** (approved / rendering) → `needsReopen` offer; on 409 the panel refetches the episode detail for `nextActions`.
- **409 other / 400 `story_invalid_content`**: own versions are always valid, so a 400 is logged with the trace id and shown as `unknown_error` [INFERENCE]; no retry loop.
- **404** (episode or version gone) → the row is removed and the list reloaded; a persistent 404 paints `ErrorState` with a retry button.
- **Network failure** between the two `detail` calls → keep the successful side and retry only the failed side; a retry button re-runs one call.
- **Very long stories** (≤ 60 segments, C9): the diff is computed once per pair, capped at `MAX_DIFF_TOKENS` per side; on truncation the panel shows a notice instead of a misleading diff.
- **Both sides identical content in different versions** → `added=0, removed=0` with the "no differences" copy (no empty region).
- **Restore while dirty**: the dirty guard runs first; choosing "cancel" aborts the restore (no PUT).
- **428** is a client bug → console + generic message, never a user-facing "conflict".
- **Rapid selection changes**: in-flight `detail` responses are matched by `versionId` before assignment (last-write-wins per side, no flicker).
- Panel left open on a hub reconnect: `resync` refetches the version list **only** while the panel is open (D8/D17), coalesced within 250 ms.

### Angular implementation amendment (2026-10-02)

- Approved-frame prerequisite is `05-versions-research.html#f-versions-*` through `plan.md` §12; deferred placeholder/loading/error/truncated states follow the locked contract; flag to the owner only if a new visual state is needed (does not reopen the approval or block the task).
