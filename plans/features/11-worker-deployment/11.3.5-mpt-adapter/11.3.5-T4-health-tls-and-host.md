## Goal

Make the adapter a node service: the `INodeHealthSource` over the D7 sources with per-source caches (MPT, proxy, relay, assets, disk, GPU incl. the new `gpu` block, codec), Kestrel HTTPS on `Adapter:Port` 8090 with the node certificate and the private-address guard, the S3 startup key checks, the D6 configuration binding, and the relay host wiring for `03.4.3-T1` (loopback 8091 bound to `IImagePlanSink`). The whisper warm-up is **not** here — `gpu-smoke.sh` owns it (D9/D12); this task only reports `mpt.whisper_device`/`video_codec`/`threads_per_task`.

## Design

### Health sources (D7)

| Source | Probe | Interval | Health fields | Failure reason |
|---|---|---|---|---|
| MPT | `GET /ping` + authenticated `GET /api/v1/tasks?page=1&page_size=1` | 15 s | `ok`, `commit`, `config_profile`, `started_at`, `whisper_device`, `video_codec`, `threads_per_task` | `mpt_unreachable`, `mpt_unauthorized` |
| proxy | `GET Adapter:ProxyHealthUrl` (2 s, body kept verbatim) | 15 s | `tts_proxy` as `JsonElement` (+ `ProxyHealthView.From`) | `tts_proxy_not_ok` |
| relay | in process (`ImagePlanRegistry`, `TokenBucket`) | per request | `ok`, `tokens_available`, `active_plans` | `image_relay_not_ok` |
| assets | `/opt/nts/current/worker-node/bin/check-fonts.sh --mpt-root /opt/nts/current/mpt` and `/opt/nts/current/worker-node/bin/check-music.sh --mpt-root /opt/nts/current/mpt --catalog /opt/nts/current/seed/music-tracks.v1.json --json` (05.2.2-T1, 05.3.1-T1) | 600 s, on change, single-flight | `ok`, `font`, `music_revision`, `music_missing[]`, `checked_at` | `font_missing`, `music_missing` |
| disk | `statvfs` on `/var/lib/nts/mpt/storage` [RULED — README §10 T63] (D20 H16) — the **one** syscall behind every disk figure (`task_dir_free_bytes`, `used_pct`, `disk_low`, and the Worker's `render_node_disk_used_pct`); no second stat, `du` or per-task walk | 15 s | `ok`, `task_dir_free_bytes`, `used_pct` | `disk_low` (≥ 85 %) |
| GPU | `nvidia-smi --query-gpu=utilization.gpu,memory.used,memory.total,temperature.gpu --format=csv,noheader,nounits` | 15 s | `gpu { ok, util_pct, mem_used_mb, mem_total_mb, temp_c, sampled_at }` | `gpu_unavailable` |
| codec | `Adapter:FfmpegPath -hide_banner -encoders` contains `Adapter:VideoCodec` | start | `mpt.video_codec` assertion | `codec_unavailable` |
| config | the rendered `/var/lib/nts/mpt/config.toml` node profile (`[whisper] device = "cuda"`, `compute_type`) | start | `mpt.whisper_device`, `mpt.config_profile` | `config_mismatch` |

`GET /v1/health` reads caches only (Q1); a periodic source older than 3 × its interval counts as failed (start-only sources — codec, config — are judged by their probe result only, T40); `status = ok` iff `reasons = []`, else HTTP 503 (05 D4). `mpt.started_at` comes from T2's `MptProcessStartReader`; `mpt.commit` comes from the bundle `MANIFEST.json` / `worker-node/pins.env` at startup.

### Host

```csharp
// Program.cs of NightTales.MptAdapter
builder.Services.Configure<AdapterOptions>(builder.Configuration.GetSection("Adapter"));
builder.Services.AddOptions<RenderNodeServerOptions>().Bind(builder.Configuration.GetSection("RenderNodeServer")).ValidateOnStart();
builder.Services.AddSingleton<INodeHealthSource, NodeHealthSource>();          // aggregated, cached
builder.Services.AddHostedService<MptTaskPoller>();                            // T2
builder.Services.AddHostedService<PostProcessor>();                            // T3
builder.Services.AddHostedService<HealthSamplerService>();                     // the per-source timers
builder.Services.AddSingleton<IImagePlanSink, ImagePlanSinkAdapter>();         // 03.4.3-T1 seam
builder.WebHost.ConfigureKestrel(k => k.Listen(IPAddress.Parse(options.ListenAddress), options.Port,
    l => l.UseHttps(X509Certificate2.CreateFromPemFile("/etc/nts/tls/adapter.crt", "/etc/nts/tls/adapter.key"))));
app.MapRenderNodeV1();                                                         // T1
```

Private-address guard: reject `0.0.0.0`, `::` and any public address at startup; a loopback address is allowed only when `ASPNETCORE_ENVIRONMENT = Development` (F26) — [RULED — README §10 T44] (D20 H2) staging runs `Staging`, never Development, so a loopback binding is a Development-only convenience; the certificate's SHA-256 fingerprint **and its `NotAfter`** are logged once (`GetCertHashString(SHA256)`, E6) so the operator can pin it in `RenderNodes:Nodes[i]:TlsCertSha256` (D11) and rotate before expiry — [RULED — README §10 T57] (D20 H12) the Worker's pin callback independently re-checks `NotAfter`, `render_node_cert_expiry_days{node}` is owned by 11.3.3-T1, and the alert fires at 30 days (rule in 11.6.2-T1).

Startup checks, fixed messages, exit 2: `RenderNodeServer:ApiKey` missing; `ADAPTER_API_KEY` equal to any of `ADAPTER_API_KEY_NEXT`, `NTS_MPT_API_KEY`, `NTS_PROXY_API_KEY`, `NODE_OPENAI_IMAGE_KEY` (S3); `Adapter:ListenAddress` any/public; certificate or key missing/unparsable; `Adapter:DataDir` not writable. Non-fatal (health reason instead): missing ffmpeg/codec, `nvidia-smi` absent, relay startup failure, `config_mismatch`.

|---|---|---|

Relay wiring: when `ImageRelay:Enabled` (default true) start `ImageRelayHost` on `127.0.0.1:8091` and bind its `ImagePlanRegistry` as the `IImagePlanSink` (`Register` at submit, `Release` at cleanup → deletes the JSONL and the plan file, `BuildReport` for the terminal status); when disabled, bind a no-op sink, omit `images`, and the node config must point MPT at OpenAI (emergency profile, 03.4.3-T1).

## Steps

1. Add `AdapterOptions` + `NodeHealthSource` with one cached holder per source (value + `sampled_at` + interval) and the staleness rule.
2. Implement the MPT, proxy, disk and GPU samplers (list arguments, no shell), the `nvidia-smi` CSV parse and the `gpu_unavailable` path.
3. Implement the assets job (single-flight, 600 s + on change; parse the JSON of `check-music.sh --json`), the codec probe and the `config.toml` node-profile assertion.
4. Implement the relay health block and the `IImagePlanSink` binding to `03.4.3-T1`'s registry; keep `03.4.3-T1` the owner of `relay_*` codes and the JSONL.
5. Configure Kestrel HTTPS on `ListenAddress:8090` with `/etc/nts/tls/adapter.crt|key`, the private-address guard and the fingerprint log line.
6. Implement the startup checks (S3 key equality, cert, data dir) with the fixed exit-2 messages and the non-fatal health reasons.
7. Bind every D6 key, validate on start, and wire the hosted services (`MptTaskPoller`, `PostProcessor`, `HealthSamplerService`).
8. Tests below; then the node gate `11-node` (health 200 with `gpu`/`tts_proxy`/`image_relay`/`assets` ok, port scan, fixture replay).

## Acceptance checks

- [ ] `GET /v1/health` performs zero MPT, proxy, `nvidia-smi` and asset-script calls when the caches are fresh (asserted by request/process counters).
- [ ] With `nvidia-smi` absent or failing, the response still returns the full shape with `gpu.ok = false` and `reasons` containing `gpu_unavailable`, HTTP 503.
- [ ] A health probe from the fixtures (`render-node-health.v1.ok`, `.proxy-down`, `.disk-low`) is reproduced field-for-field, timestamps excepted.
- [ ] A source whose `sampled_at` is older than 3 × its interval counts as failed and appears in `reasons`.
- [ ] The codec probe rejects a fake ffmpeg that does not list `Adapter:VideoCodec` → `codec_unavailable`, no exit; a real `/usr/bin/ffmpeg` with `libx264` → reason absent.
- [ ] `Adapter:ListenAddress = 0.0.0.0` (and a public address) refuse to start with a fixed message; a private address starts and binds 8090 over TLS with the node certificate; the fingerprint of the loaded certificate is logged once in `GetCertHashString(SHA256)` form.
- [ ] `ADAPTER_API_KEY` equal to `NTS_MPT_API_KEY` (or `NTS_PROXY_API_KEY`, `NODE_OPENAI_IMAGE_KEY`, `ADAPTER_API_KEY_NEXT`) exits 2 with the fixed message before any listener opens; a missing `RenderNodeServer__ApiKey` exits 2 too.
- [ ] `Adapter:DataDir` not writable → exit 2; the assets job runs single-flight and only every 600 s (asserted with a fake clock), adding `checked_at` without re-running the scripts per request.
- [ ] With `ImageRelay:Enabled`, the relay listens on `127.0.0.1:8091` and the health `image_relay` block reports `tokens_available`/`active_plans`; `Release` removes the task's JSONL and plan file; with the flag off the sink is a no-op and `images` is omitted.

## Failure handling and edge cases

| Case | Behaviour |
|---|---|
| Relay startup fails (port in use, bad clause hash) | `image_relay.ok = false` → health 503 → no dispatch (03.4.3-T1 owns the checks) |
| Proxy health body not JSON | `tts_proxy_not_ok`; the previous good body is kept only for logging, never returned as ok |
| `systemctl` unavailable (dev container) | `mpt.started_at = null`; the lost rule's restart part is disabled (T2) |
| `nvidia-smi` present but reports an error string | `ok = false`, reason `gpu_unavailable`, values `null` |
| Health source throws | fail closed → 503 with the source's reason (or `config_mismatch` for an unknown source) |
| Key rotation (`ADAPTER_API_KEY_NEXT` set) | both keys accepted, no drain; after the Worker's key changes, NEXT is promoted to current and removed (D11) |
| Cert expired / not yet valid | startup exits 2 (a node certificate is provisioned by `make-adapter-cert.sh` for 397 days, D11); [RULED — README §10 T57] (D20 H12) the Worker side independently rejects a pinned certificate past `NotAfter` and warns from 30 days out |
| Rollback | health sources are additive (05 CR-4); reverting the release restores the previous listener config; the `gpu` block disappears only if `11.3.3`/`11.6.2` would then lose GPU metrics — never expected because the block ships with this task |

- `mpt.commit` has no confirmed live source (MPT `/ping` was not read); it is taken from `MANIFEST.json`/`pins.env` at startup [RULED — README §10 T19].
- Node logs stay on the node (S7, 03 D12); health/status carry ids, hashes, counts and codes only.
