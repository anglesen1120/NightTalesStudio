# web

Angular workspace of the NightTales Web UI (plan 10). This file only documents what a developer must not get wrong; the contract is `plans/features/10-web-ui/README.md`.

## Generated API client (`src/app/shared/api/**`)

The client is generated by `ng-openapi-gen` (pinned in `package.json`) from the vendored backend document `openapi.json`, which is the `openapi` artifact of `backend.yml` (09.1.5-T1). `tools/web/openapi.lock.json` records its source, `info.version`, SHA-256 and `sourceCommit` (the backend commit it was built from); `tools/web/openapi-contract.test.mjs` recomputes the hash.

- **Never edit `src/app/shared/api/**` or `openapi.json` by hand.** Both are generated/vendored, are excluded from lint, and a hand edit fails `npm run api:gen:check` with the file and line.
- `npm run api:gen` regenerates the tree from the committed `openapi.json` (second run: no diff).
- `npm run api:gen:check` (alias `api:check`, run by `web.yml`) regenerates into a temp directory and fails on any drift, on an absolute `http(s)://` literal in generated code (the SPA is same-origin) and when `index.ts` stops exporting `ProblemDetails`. It also rejects an `api-gen.config.json` option the pinned generator does not support.
- **Adopting a new backend document:** produce `src/NightTales.Api/openapi.json` with the backend build (`docs/dev-setup.md`, "build-time OpenAPI generation") or download the `openapi` artifact, then run `npm run api:gen:local -- <path>`. It replaces `openapi.json`, rewrites the lock and regenerates the tree; commit the three together and review the generated diff (`ProblemDetails` and the DTOs the screens map) in the same PR.
- Only `features/*/data-access/**` and `core/**/data-access/**` may import `@shared/api` (spec files excepted); everything else goes through the domain port.
- `excludeTags` in `api-gen.config.json` lists tags the generator cannot import (a dotted tag such as `NightTales.Api`, which ASP.NET gives lambda handlers). Operations under an excluded tag have no generated client; the fix is an explicit `WithTags` on the backend endpoint, after which the entry is removed.
